### Themes

The push to deploy autonomous agents is running well ahead of security and evaluation infrastructure. Real-world platforms are racking up critical vulnerabilities—from LiteLLM auth bypasses in [Top MCP security resources — October 2026](https://adversa.ai/blog/top-mcp-security-resources-october-2026/) to rule file injections detailed in [Package Hallucination Attacks on Coding Agents through Prompt Injection in Rule Files](https://arxiv.org/abs/2610.09264v1). Compounding the issue, the tools used to measure safety are unreliable: [On the Reliability of LLM-Based Vulnerability Patching Benchmarks](https://arxiv.org/abs/2610.10150v1) shows that high benchmark pass rates for automated security patches obscure a systemic failure to align with real developer test suites.

Meanwhile, market hype around smaller, faster models overlooks fundamental training limitations. While vendors ship low-cost models like [Claude Haiku 5.5](https://simonwillison.net/2026/Oct/7/claude-haiku-5-5/), theoretical work in [Gains and Collapse in On-Policy Distillation:A Reinforcement Learning Perspective](https://arxiv.org/abs/2610.03185) offers a reality check: distillation techniques narrow model focus rather than imparting true reasoning upgrades. Optimization work like [DeepSeek-V4.1-Flash on vLLM](https://vllm.ai/blog/2026-10-07-deepseek-v41-flash) delivers impressive inference speedups, but speed should not be confused with enhanced capacity.

### Worth a closer look

- [Inverting Multi-Vector Visual Document Indices](https://arxiv.org/abs/2610.09920) — Demonstrates that storing visual patch embeddings in RAG pipelines provides zero data privacy, as conditional image models can invert the stored vectors back into legible, sensitive document text.
- [Gains and Collapse in On-Policy Distillation:A Reinforcement Learning Perspective](https://arxiv.org/abs/2610.03185) — A necessary read for anyone relying on model compression; it formally frames on-policy distillation through RL to show why smaller models collapse when trying to exceed their base capabilities.
- [On the Reliability of LLM-Based Vulnerability Patching Benchmarks](https://arxiv.org/abs/2610.10150v1) — Reveals severe evaluation distortions in automated vulnerability patching benchmarks, showing how "successful" AI patches frequently fail basic unit tests written by human engineers.

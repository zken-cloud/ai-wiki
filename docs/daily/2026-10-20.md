# 📰 Daily Briefing — 2026-10-20

### The short version

- **Infrastructure zeroes in on agentic latency:** Google Cloud open-sourced [TorchTPU](https://cloud.google.com/blog/topics/ai-infrastructure/torchtpu-is-now-open-source-run-native-pytorch-on-tpus/) and its [llm-d 1.0](https://cloud.google.com/blog/topics/ai-infrastructure/llm-d-1-0-an-open-source-stack-for-distributed-inference/) distributed inference framework, while AWS contributed [push-based](https://aws.amazon.com/blogs/machine-learning/push-based-kv-transfer-to-improve-ttft-and-tpot-for-disaggregated-inference-in-vllm/) and [bi-directional KV transfer](https://aws.amazon.com/blogs/machine-learning/improve-ttft-for-multi-turn-agentic-workloads-with-bi-directional-kv-transfer-in-vllm/) mechanisms to vLLM to trim multi-turn agent bottlenecks.
- **Agent execution safety moves to the OS kernel:** Rather than relying on fragile soft guardrails, [Connection Escrow](https://arxiv.org/abs/2610.26501v1) proposes a 98-instruction eBPF program that traps outbound network traffic at the kernel level until an external verifier inspects an agent's intent.
- **Data poisoning easily hijacks financial agents:** Benchmark results in [Fake News, Real Crashes](https://arxiv.org/abs/2610.26438v1) reveal that autonomous LLM trading agents hit a 100% attack success rate when exposed to simple 30-word injected text templates in target data feeds.
- **Red-teaming metrics get a reality check:** Recognizing that multi-turn jailbreaks are economically constrained in real deployments, [Beyond Attack Success Rate](https://arxiv.org/abs/2610.26589v1) introduces ASR_STEP to penalize attacks based on victim API query volume.

### Themes

The common thread across today’s release slate is a shift from raw model capability toward solving the messy engineering and security overhead of autonomous agents. As systems move from chat interfaces to multi-turn task loops, inference bottlenecks are compounding quickly. AWS and Google are responding with disaggregated inference tricks—specifically optimizing KV cache movement in vLLM and open-sourcing inference layers—to handle state-heavy workloads without destroying time-to-first-token metrics.

On the security front, researchers are largely abandoning the optimism that prompt engineering can reliably control system behavior. The focus has pivoted to hard architectural boundaries and system-level isolation. Security research today spans trapping unauthorized outbound network requests at the Linux kernel level ([Connection Escrow](https://arxiv.org/abs/2610.26501v1)), isolating risky capabilities into modular Mixture-of-Experts weights that can be physically detached ([REX](https://arxiv.org/abs/2610.25791v1)), and proving how easily financial trading agents fail when external retrieval context is untrusted ([Fake News, Real Crashes](https://arxiv.org/abs/2610.26438v1)).

### Worth a closer look

- [Connection Escrow: Holding AI-Agent Pod Egress in the Kernel Until an Isolated Verifier Rules](https://arxiv.org/abs/2610.26501v1) — Moving safety enforcement down to an eBPF kernel program is a refreshingly pragmatic alternative to "trusting the model." Trapping TCP egress until a sidecar verifier passes judgment addresses software authority delegation where it actually belongs: in system call pathing.
- [Towards Architectural-Level Safety Control: Relocating Hazardous Knowledge into Removable Experts in Mixture-of-Experts Models](https://arxiv.org/abs/2610.25791v1) — Gradient unlearning is notoriously unreliable and prone to recovery attacks. REX offers a neat structural trick for MoEs by routing hazardous knowledge into designated expert weights that can simply be pruned from the network topology.
- [Fake News, Real Crashes: Information Injection Attacks on LLM Financial Trading Agents](https://arxiv.org/abs/2610.26438v1) — A clear demonstration of how context injection degrades practical autonomous systems. By altering external market evidence rather than system instructions, the authors expose how easily current trading agents collapse into catastrophic decision-making.

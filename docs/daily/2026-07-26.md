### The short version

- **Overhyped benchmarks hit reality:** [A Frozen 12B Beats Frontier Models on Verified Work: 100% Accuracy, 0 Tokens, Bit-Exact, Forever](https://arxiv.org/abs/2607.23806v1) turns out to be less about model capabilities and more about caching exact-match solutions in deterministic external memory.

### Themes

Today’s papers highlight a widening gap between architectural claims and system realities. Several authors attempt to fix context management and attribution, but expose fundamental flaws in how models handle information. [How Context Attribution Handles What the Model Already Knows](https://arxiv.org/abs/2607.23804v1) reveals that standard attribution methods become unfaithful whenever provided context overlaps with pre-training memory. Rather than addressing model memory head-on, papers like [ACM: Agentic Context Management for Long Horizon Tasks](https://arxiv.org/abs/2607.23809v1) and [A Frozen 12B Beats Frontier Models on Verified Work](https://arxiv.org/abs/2607.23806v1) push task memory into external state management and hard-coded lookup structures.

A parallel theme is the structural fragility of post-training controls. Whether it is position bias exploited to hijack recommenders in [Ranked by Position: Order Sensitivity as an Exploitable Attack Surface in LLM Listwise Recommenders](https://arxiv.org/abs/2607.24869v1), or spectral "intruder dimensions" breaking fine-tuned models in [The Intruder Threshold: A Spectral Law for LoRA Fine-Tuning](https://arxiv.org/abs/2607.23711v1), current alignment and fine-tuning techniques remain leaky abstractions. This fragility extends to operational security, where theoretical safety limits clash with real-world infrastructure problems like key fraud in [An Inside Look at the Relay Market Powering Token Resellers and Fraud](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything).

### Worth a closer look

- [Asymmetric Collapse in Model Merging: When Refusal Overwrites Recognition](https://arxiv.org/abs/2607.27240v1) provides a cautionary result for teams combining fine-tuned weights: merged models often retain safety surface features (refusal) while completely degrading the underlying reasoning required to classify input correctly.
- [The Intruder Threshold: A Spectral Law for LoRA Fine-Tuning](https://arxiv.org/abs/2607.23711v1) introduces a predictive spectral tool to identify when Low-Rank Adaptation will cause catastrophic forgetting, moving LoRA parameter selection closer to a math problem and away from trial-and-error.
- [An Inside Look at the Relay Market Powering Token Resellers and Fraud](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything) gives a practical look into how enterprise API leaks and stolen cloud credits translate into cheap, unmonitored LLM access on secondary markets.

### The short version

- **Defense-in-depth is failing LLMs:** [Layered LLM Defenses as an Ensemble](https://arxiv.org/abs/2608.28327v1) shows that stacking safety guardrails offers a false sense of security, as positive failure correlations between layers cause joint attack success rates to far exceed theoretical predictions.
- **LLMs know they are being hacked and execute anyway:** Researchers in [Recognition Without Enforcement](https://arxiv.org/abs/2608.28502v1) identified a critical structural flaw where models explicitly register unauthorized instructions in their internal activations, yet proceed to execute them regardless.
- **Code generation remains a security liability:** [Compared to What? A Human-Anchored Security Benchmark for LLM-Generated Infrastructure-as-Code](https://arxiv.org/abs/2608.28021v1) demonstrates that frontier LLMs produce Infrastructure-as-Code with 3.2x to 3.8x the vulnerability density of human engineers.
- **Prompt injection enters courtrooms:** A practical attempt to weaponize indirect prompt injection was discovered [hidden directly inside an official legal filing](https://www.schneier.com/blog/archives/2026/08/hiding-prompt-injection-in-legal-filing.html), targeting automated legal summarization tools.

### Themes

Today’s releases showcase a stark divide between vendor narratives around autonomous agents and the operational realities of securing them. A heavy cluster of security papers highlights structural failures in LLM governance. Trajectory-scoped safety monitors fail over long loops ([Safety Does Not Compose: Non-Decaying Loop State for Autonomous LLM Agents](https://arxiv.org/abs/2608.27141v2)), models leak sensitive runtime contexts through simple tool descriptions ([ContextLeak](https://arxiv.org/abs/2608.27800v1)), and multi-layered defense stacks prove expensive and ineffective due to correlated failure modes ([Layered LLM Defenses as an Ensemble](https://arxiv.org/abs/2608.28327v1)). The consensus is tightening: self-policing models do not work, and external deterministic control is non-negotiable.

Concurrently, researchers are pushing past naive context-window scaling toward active runtime management. Frameworks like [ContextPilot](https://arxiv.org/abs/2608.28476) and [LoopArena](https://arxiv.org/abs/2608.28281) focus on pruning context and separating controller logic from worker execution. This reflects practical infrastructure pivots seen in enterprise deployments, such as OpenAI's sandboxed desktop execution in [Understanding ChatGPT Work](https://simonwillison.net/2026/Aug/30/understanding-chatgpt-work/) and AWS integrating agentic tools directly into developer telemetry via [Agentic observability with Amazon OpenSearch Service MCP Apps](https://aws.amazon.com/blogs/machine-learning/agentic-observability-with-amazon-opensearch-service-mcp-apps/).

### Worth a closer look

- [Recognition Without Enforcement: Configuration-Dependent Failures in LLM Agent Instruction Arbitration and External Control](https://arxiv.org/abs/2608.28502v1) — Demolishes the assumption that models can self-arbitrate malicious intent. Proving that an LLM can explicitly acknowledge an attack in text while executing it anyway is a strong argument for mandatory deterministic reference monitors.
- [Layered LLM Defenses as an Ensemble: Access Tiers, Inference Cost, and the Measured Failure Correlation Between Defense Layers](https://arxiv.org/abs/2608.28327v1) — Essential reading for AI platform architects. It provides concrete empirical data showing why layering guardrail models inflates inference budgets without delivering multiplicative security gains.
- [Hiding Prompt Injection in Legal Filing](https://www.schneier.com/blog/archives/2026/08/hiding-prompt-injection-in-legal-filing.html) — A brief but notable datapoint confirming that indirect prompt injection has moved out of academic synthetic benchmarks into wild, real-world legal document workflows.

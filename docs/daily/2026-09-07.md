### The short version

* **OpenAI promotes internal self-improvement loops:** In a pair of self-congratulatory posts, OpenAI claims coding agents and recursive self-improvement are drastically accelerating its internal research velocity, alongside philosophical musings on aligning an ["alien mind"](https://openai.com/index/an-alien-mind).
* **Decompilers produce silent behavioral drifts:** Research in [When LLM Decompilers Recompile More and Preserve Less](https://arxiv.org/abs/2609.05370v1) shows LLM decompilers frequently emit code that compiles cleanly and passes basic tests while silently stripping security fixes or diverging from original binary behavior.
* **Prompt injection moves to automated optimization:** Adversaries are formalizing prompt injection as a systematic test-time search problem ([Rethinking Indirect Prompt Injection as a Test-Time Search Problem](https://arxiv.org/abs/2609.04495v1)) and scaling adaptive visual attacks ([Repeat-After-Me](https://arxiv.org/abs/2609.04533v1)) against frontier multimodal models.
* **Stateful agents introduce persistent state leakage:** Beyond basic context wiping, long-running LLM agents accumulate unsafe residual state across KV caches, tool plans, and compressed memory, necessitating dedicated state-unlearning frameworks ([Forgetting Without Restarting](https://arxiv.org/abs/2609.04875v1)).

### Themes

**The growing gap between agent capability claims and system-level correctness.** While lab PR emphasizes autonomous coding agents accelerating R&D ([Research acceleration: The view inside OpenAI](https://openai.com/index/research-acceleration-view-inside-openai)), technical papers paint a messier picture of agent execution. Models systematically over-edit existing codebases ([When Models Edit Too Much](https://arxiv.org/abs/2609.04061)), create subtle semantic divergence in binary decompilation ([When LLM Decompilers Recompile More and Preserve Less](https://arxiv.org/abs/2609.05370v1)), and fail to maintain instruction-to-effect security boundaries without explicit assume-guarantee contracts ([CONTINUITY](https://arxiv.org/abs/2609.05269v1)). The industry continues pushing autonomous execution into production faster than it can guarantee state hygiene or functional fidelity.

**Adversarial AI turns into a compute-bound search problem.** Attacks on LLMs are shifting from heuristic prompt crafting to automated optimization. Security research today demonstrates that indirect injections can be formulated as automated test-time searches ([Rethinking Indirect Prompt Injection as a Test-Time Search Problem](https://arxiv.org/abs/2609.04495v1)), while visual prompt injections rely on black-box adaptive loops ([Repeat-After-Me](https://arxiv.org/abs/2609.04533v1)). Meanwhile, human targets face hyper-personalized spear-phishing where contextual detail systematically increases victim click rates ([Engineered Persuasion](https://arxiv.org/abs/2609.04410v1)). 

### Worth a closer look

* [When LLM Decompilers Recompile More and Preserve Less](https://arxiv.org/abs/2609.05370v1) — Exposes a critical flaw in code evaluation: LLM-decompiled code often re-compiles fine and passes basic test suites, but the underlying binary semantics diverge or quietly drop security patches.
* [Forgetting Without Restarting: Execution-State Unlearning for Stateful LLM Agents](https://arxiv.org/abs/2609.04875v1) — Correctly identifies that standard model "unlearning" fails long-running agents because sensitive information remains trapped in KV caches, working memory, and pending tool plans.
* [Beneath the Surface of Chains-of-Thought: A Mechanistic Interpretation of Reasoning Operations in LLMs](https://arxiv.org/abs/2609.04753) — Offers a rare mechanistic look inside the hidden layers of LLMs, demonstrating that Chain-of-Thought step types form distinct, separable geometric structures rather than just textual fluff.

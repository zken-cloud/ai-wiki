### Themes

**Agentic ambitions outpace security fundamentals.** While labs publish theoretical frameworks for LLMs that evolve their own code and execution environments ([HarnessDev](https://arxiv.org/abs/2609.01437), [Aspire](https://arxiv.org/abs/2608.31111)), applied security researchers are having a field day exposing how easily these systems break. Attacks targeting Retrieval-Augmented Generation ([CodePoisonRAG](https://arxiv.org/abs/2609.02774v1)), remote tool access ([ACLE-MCP](https://arxiv.org/abs/2609.02690v1)), and semantic skill selection ([Implicit Manipulation for Skill Selection](https://arxiv.org/abs/2609.02035v1)) demonstrate that giving models persistent memory and external execution capabilities multiplies attack vectors faster than vendors can secure them.

**The theoretical limits of natural language safety.** A foundational tension is emerging between how AI safety is implemented and how models actually compute. [The Implications of Linguistic Illegibility for LLM Security](https://arxiv.org/abs/2609.02852v1) argues that evaluating safety by probing text output is inherently flawed because continuous activation spaces do not map cleanly to natural language. Empirical papers back this up: standard alignment guardrails consistently fail when bad actors manipulate higher-level semantic structures or router mechanisms ([Counter-GEO-Bench](https://arxiv.org/abs/2609.02316v1), [SEAL](https://arxiv.org/abs/2609.02293v1)), showing that surface-level text filters are little more than security theater.

### Worth a closer look

- [The Implications of Linguistic Illegibility for LLM Security](https://arxiv.org/abs/2609.02852v1): A critical theoretical paper that challenges the industry's reliance on text-based safety evaluation, arguing that internal model activations cannot be reliably audited through natural language.
- [EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction](https://arxiv.org/abs/2609.02783): Evaluates LLM agents efficiently by using a lightweight decision tree to predict trajectory failure early and terminate doomed runs before wasting tokens.
- [Language Models Can Control Their Own Attention](https://arxiv.org/abs/2609.02737): Details "Declarative Attention," a mechanism allowing models to explicitly flag unnecessary context regions during reasoning, enabling inference engines to skip reading parts of the KV cache without extra scoring modules.
- [Cliff: Learning Process Rewards from the First Mistake](https://arxiv.org/abs/2609.02817): A focused approach to process reward models in reinforcement learning that pinpoints the exact token where a model's reasoning diverges, offering a cleaner signal for step-level credit assignment.

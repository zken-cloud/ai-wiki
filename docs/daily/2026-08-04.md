### Themes

As autonomous agents move deeper into production environments, their underlying security debt is becoming undeniable. The threat model has expanded beyond simple single-turn prompt injections into complex vector attacks on agent state and infrastructure. Research like [Benign Alone, Harmful Together](https://arxiv.org/abs/2608.01759v1) demonstrates how self-evolving agents can be trick-fed benign experiences that combine dangerously later on, while [LLM Heist](https://embracethered.com/blog/posts/2026/hijacking-litellm-for-fun-and-profit/) illustrates how the actual middleware routing these models (such as LiteLLM) is routinely vulnerable to key theft and tool-call injection.

At the same time, the reality of agent reliability continues to lag far behind vendor hype. Benchmarking efforts are shifting toward real-world dynamic environments, revealing harsh failure modes: [SWE-Touch](https://arxiv.org/abs/2608.02499) shows that coding agents struggle when human users introduce concurrent edits, and formal verification frameworks struggle to handle high-entropy attack vectors ([Why Formal Monitors Fail](https://arxiv.org/abs/2608.01388v1)). When custom orchestration setups break entirely after routine downstream model updates ([Quoting Steve Yegge](https://simonwillison.net/2026/Aug/4/steve-yegge/#atom-everything)), it is clear that building brittle prompt-and-state wrappers around black-box API endpoints remains an inherently unstable architecture.

# 📰 Daily Briefing — 2026-09-20

### The short version

- **Alignment midtraining fails under pressure:** A scale-up empirical study in [Stress-testing Alignment Midtraining](https://arxiv.org/abs/2609.20412v1) shows that midtraining alignment techniques collapse when tested against unmonitored rules or out-of-distribution scenarios on models up to 110B parameters.
- **Harnesses beat raw model scaling for agent reliability:** Research in [How Do Agent Harnesses Create Value? Planning Information and Release Control in Stateful LLM Agents](https://arxiv.org/abs/2609.20474v1) highlights that cheap, external read-only verifiers (costing under $0.01) block 61% of invalid actions, proving system architecture matters more than raw model intelligence for agent safety.
- **Vector embeddings don't understand physics:** [Embedding Models Measure in Peculiar Ways](https://arxiv.org/abs/2609.20821v1) reveals that text embedding spaces fail to accurately model basic physical quantities like mass, distance, and volume, relying instead on superficial string matching.
- **Model confidence remains fragile:** [An Analysis of Training-Free Self-Reported Confidence in Language Models](https://arxiv.org/abs/2609.20541v1) finds that while verbalized self-confidence outperforms consensus sampling, it remains uncomfortably sensitive to prompt phrasing and systemic model blind spots.

### Themes

**The shift from model weights to agent infrastructure.** Today’s papers point toward a growing realization that reliable AI systems rely less on coaxing emergent behavior out of weights and more on traditional software engineering around the model. Research like [Chronicle: Cut-Point Replay for Regression Testing of LLM Agents](https://arxiv.org/abs/2609.20625v1), [SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness](https://arxiv.org/abs/2609.20519v1), and [How Do Agent Harnesses Create Value?](https://arxiv.org/abs/2609.20474v1) focus on state control, deterministic replay, and low-cost verification gates to enforce reliability in non-deterministic environments.

**Exposing representational shortcuts.** A parallel cluster of papers takes a sober look at what models actually represent internally. [Embedding Models Measure in Peculiar Ways](https://arxiv.org/abs/2609.20821v1) demonstrates that spatial and physical grounding in embeddings is largely an illusion of text similarity. Meanwhile, work on [Xeno-Interpretability: Investigating the Alien Minds of LLMs](https://arxiv.org/abs/2609.20408v1) attempts to formalize internal representations that have no human concept equivalent, emphasizing that internal model representations rarely match human intuition.

### Worth a closer look

Planning Information and Release Control in Stateful LLM Agents](https://arxiv.org/abs/2609.20474v1): Offers hard ROI metrics on agent design, demonstrating that simple external guardrails and structured planning yield immediate reliability gains for negligible cost.
- [Embedding Models Measure in Peculiar Ways](https://arxiv.org/abs/2609.20821v1): Essential reading for teams relying on vector search for quantitative, scientific, or physical RAG workflows, clearly defining where standard embeddings break down.

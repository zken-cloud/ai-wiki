# 📰 Daily Briefing — 2026-10-18

### The short version

* [Retrieved but Not Read](https://arxiv.org/abs/2610.21731v1) highlights a persistent RAG failure mode: search-augmented models frequently ignore up-to-date retrieved context in favor of stale parametric memory.
* Infra bottlenecks remain severe, but [When the KV Cache Is Slower Than the GPU](https://arxiv.org/abs/2610.21500) shows dramatic engineering gains, cutting long-context p99 prefill latency from 83.32s down to 0.67s.
* Interpretability tools have a measurement problem: [Diminishing Returns of Data in Sparse Autoencoders](https://arxiv.org/abs/2610.20680) proves that SAE functional metrics converge far earlier than actual feature reproducibility, masking unstable underlying representations.
* Physical security on the edge remains brittle: [When Rotation Bounds Nothing](https://arxiv.org/abs/2610.21276v1) demonstrates that streaming model weights into volatile memory fails to prevent model theft under cold-boot attacks.

### Themes

**The context illusion.** Industry marketing remains obsessed with scaling token windows, but today's papers highlight the gap between carrying context and utilizing it. [Beyond Context Length](https://arxiv.org/abs/2610.22067v1) pushes back on context size as a proxy for capability, showing that evidence dispersion and reasoning depth are what actually break models. Meanwhile, [Retrieved but Not Read](https://arxiv.org/abs/2610.21731v1) demonstrates that even when relevant information is fed directly into the prompt via search, models routinely default to their pretraining weights. System-level patches like [When the KV Cache Is Slower Than the GPU](https://arxiv.org/abs/2610.21500) and midtraining recipes like [Priming Base Models for Agentic Post-Training](https://arxiv.org/abs/2610.22019v1) fix the latency and data pipeline plumbing for long context, but the underlying reasoning failures remain unsolved.

**Flawed measurement tools.** A recurring motif today is the unreliability of standard AI evaluation metrics. [Diminishing Returns of Data in Sparse Autoencoders](https://arxiv.org/abs/2610.20680) warns that standard functional metrics for SAEs give a false sense of convergence while true feature extraction remains unstable. [One Bias Score, Two Factors](https://arxiv.org/abs/2610.20993) shows that multiple-choice option bias scores conflate two distinct failure modes, rendering single-number benchmarks misleading. Finally, [Equal CER, Unequal Damage](https://arxiv.org/abs/2610.20461) correctly notes that standard character error rates fail to capture semantic damage in OCR, though swapping simple edit distances for an uncalibrated LLM judge introduces its own set of evaluation traps.

### Worth a closer look

* [Retrieved but Not Read: Understanding Why Search-Augmented LLMs Fail to Use Available Evidence](https://arxiv.org/abs/2610.21731v1) — Essential reading for teams deploying RAG in production, detailing precisely when and why models stubbornly ignore retrieved facts in favor of outdated parametric memory.
* [Diminishing Returns of Data in Sparse Autoencoders: Functional Behavior does not Guarantee Feature Reproducibility](https://arxiv.org/abs/2610.20680) — A vital sanity check for safety teams using SAEs for mechanistic interpretability, showing that headline performance numbers mask severe feature instability unless token budgets are massively increased.
* [When Rotation Bounds Nothing: Streaming Image Classifiers to Field Nodes Under Physical Capture](https://arxiv.org/abs/2610.21276v1) — A clear-eyed security paper exposing how easily edge-deployed multi-exit models can be reverse-engineered via physical memory dumps, puncturing common assumptions about streaming weight security.

### The short version

* **Agent security is pivoting from probabilistic guardrails to deterministic static gates.** Frustrated by non-deterministic failures and persistent prompt injections, research like [NOMOS](https://arxiv.org/abs/2610.11030v1) focuses on statically compiling safety policies into runtime gates that bypass LLM evaluators entirely.
* **Anthropic deepens its public-sector and defense commitments.** Anthropic announced a $150 million commitment to the US government's [Genesis Mission](https://www.anthropic.com/news/genesis-mission-commitment) alongside a dedicated [Cyber Mission](https://www.anthropic.com/news/anthropic-cyber-mission), solidifying its alignment with federal defense infrastructure ahead of an updated [Usage Policy](https://www.anthropic.com/news/2026-usage-policy-update).
* **Serving infrastructure is retooling for multi-turn sessions over single prompts.** Releases like [NVIDIA Dynamo](https://pytorch.org/blog/session-aware-agentic-inference-with-nvidia-dynamo/) and routing architectures like [TokenRouter](https://arxiv.org/abs/2610.12242) reflect an industry shift toward managing stateful, long-running agent interactions rather than isolated query-response loops.
* **Evaluation benchmarks continue to overestimate agent capabilities.** Findings from [Learn2Play Bench](https://arxiv.org/abs/2610.08215) and [TestPrism](https://arxiv.org/abs/2610.12289) show that LLM performance degrades sharply when pretraining data memorization is neutralized or when evaluations extend beyond a single reference solution.

### Themes

The operational reality of AI agents is forcing a shift away from reliance on model self-governance. Empirical audits like [Skill Constellations](https://arxiv.org/abs/2610.11169v1) reveal a chaotic ecosystem built on unversioned, copy-pasted dependencies across more than two million GitHub agent skills. In response, security research is moving away from the assumption that models can self-police at runtime. Approaches such as [NOMOS](https://arxiv.org/abs/2610.11030v1) and [LTBD](https://arxiv.org/abs/2610.11634v1) strip runtime decision-making from the LLM, enforcing static schema verification and explicit boundary delimiters to control tool execution.

At the same time, computing infrastructure is adjusting to the cost and latency profiles of agentic workloads. Systems can no longer afford to treat inputs as stateless, independent API calls. Infrastructure initiatives like [NVIDIA Dynamo](https://pytorch.org/blog/session-aware-agentic-inference-with-nvidia-dynamo/) focus on session-level tracking to optimize KV caches and compute allocation across agent trajectories. Meanwhile, commercial positioning is solidifying around sovereign and defense contracts, with frontier labs trading generic enterprise promises for state-level integration.

### Worth a closer look

* [Skill Constellations: Tracing the Supply Chain of Agent Skills on GitHub](https://arxiv.org/abs/2610.11169v1) maps over two million agent skill adoptions, exposing critical supply-chain vulnerabilities where unversioned code copying leaves agent ecosystems exposed to silent, unpatchable exploits.
* [NOMOS: Compiling Written Policies into Statically Verified Tool-Call Gates for LLM Agents](https://arxiv.org/abs/2610.11030v1) offers a practical blueprint for compiling natural-language enterprise policies into deterministic, static schema checks, bypassing runtime LLM inference for safety enforcement.
* [Learn2Play Bench: How Well Do LLM Agents Learn from Experience in Unfamiliar Environments?](https://arxiv.org/abs/2610.08215) tests LLM agents in text environments featuring counterintuitive mechanics, effectively stripping away memorized internet priors to measure genuine in-context adaptation.

### Themes

Today’s research highlights a clear transition from prompt-level security to agent-level vulnerabilities. As developers encourage agents to dynamically acquire, write, and store reusable skills, they open new attack surfaces. [SkillJack: Persistent Skill Backdoors in Self-Evolving Agents](https://arxiv.org/abs/2608.03509v1) shows that an agent's experience-to-skill pipeline can be subverted into saving malicious routines into its persistent memory. Defense research is attempting to react in tandem, with benchmarks like [When Agents Learn to Be You: Benchmarking Privacy Leakage, Impersonation Risk, and Defenses in Persona Skills](https://arxiv.org/abs/2608.03700v1) and testing suites like [SkillSentry: Adaptive Honey Worlds for Dynamic Safety Testing of Agent Skills](https://arxiv.org/abs/2608.03485v1) trying to catch conditional malware inside dynamic agent toolsets.

Simultaneously, empirical research is calling out basic architectural blind spots in code and reasoning models. Despite claims of autonomous problem solving, [To Add Is Machine, To Delete Is Human: Measuring and Mitigating Deletion Avoidance in LLM Code Editing](https://arxiv.org/abs/2607.28887) documents a strong additive bias in coding models—a refusal to purge redundant code that quickly turns codebases into unmaintainable messes. When combined with long-horizon stress tests like [MerchantBench: Benchmarking LLM Agents for Long-Term Coherence in E-Commerce Operations](https://arxiv.org/abs/2607.28956), it becomes evident that current models struggle significantly once forced out of short-context, single-turn evaluation loops.

### Worth a closer look

- [SkillJack: Persistent Skill Backdoors in Self-Evolving Agents](https://arxiv.org/abs/2608.03509v1): A troubling look at how agents designed to learn from experience can be tricked into writing, caching, and repeatedly executing backdoored skills without explicit human intervention.
- [To Add Is Machine, To Delete Is Human: Measuring and Mitigating Deletion Avoidance in LLM Code Editing](https://arxiv.org/abs/2607.28887): Quantifies a frustratingly common real-world problem—LLM coders adding endless wrappers rather than removing dead code—and provides a practical targeted post-training fix.
- [The Frontier AI Vulnerability Burst: Industrializing Autonomous Zero-Day Discovery in Open-Source Software](https://unit42.paloaltonetworks.com/frontier-ai-vulnerability-burst/): An alarming demonstration of scale in automated offensive security, raising serious questions about how open-source maintainers will handle a flood of thousands of AI-discovered zero-day reports.

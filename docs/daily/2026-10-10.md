### The short version

- Context-level enforcement helps code safety: [Applying Security by Design at the Point of Execution](https://arxiv.org/abs/2610.10659v1) shows that serving security requirements to models via Model Context Protocol (MCP) servers at runtime reduces vulnerabilities in AI-generated backend code.

### Themes

Agentic capabilities continue to move faster than their safeguards. While academic benchmarks attempt to evaluate abstract qualities like self-awareness under knowledge conflict ([Accurate but Not Humble](https://arxiv.org/abs/2610.12360)) or synthetic scientific discovery ([Can AI Agents Make Open-Ended Scientific Discovery?](https://arxiv.org/abs/2610.08927)), real-world deployments show basic operational failures. The news that Anthropic agents autonomously submitted incomplete visa applications ([Quoting The New York Times](https://simonwillison.net/2026/Oct/10/the-new-york-times/)) highlights how easily long-horizon tools breach boundaries when left unmonitored. 

Simultaneously, systemic fragility plagues user-facing AI pipelines. AI search infrastructure remains easy to compromise with cheap SEO-style tactics ([From Public Posts to AI-Search Citations](https://arxiv.org/abs/2610.11932v1)), and visual models still routinely generate convincing evidence for false claims ([False Claims, Credible Images](https://arxiv.org/abs/2610.11112v1)). Research is leaning toward post-hoc inference interventions—such as activation steering for unlearning ([Nullify](https://arxiv.org/abs/2610.10655v1)) and dynamic diffusion filtering for audio deepfakes ([Detection-Guided Adaptive Purification](https://arxiv.org/abs/2610.10752v1))—to patch foundational vulnerabilities without complete retraining.

### Worth a closer look

- [From Public Posts to AI-Search Citations: Measuring the Fragility of AI Search](https://arxiv.org/abs/2610.11932v1) provides an empirical teardown of 10 commercial AI search products, demonstrating how easily cheap Generative Engine Optimization (GEO) manipulates modern retrieval-augmented generation pipelines.
- [Applying Security by Design at the Point of Execution: How Governed Security Requirements Affect the Security of AI-Generated Code](https://arxiv.org/abs/2610.10659v1) outlines a practical architectural pattern for locking down LLM coders by piping real-time governance rules into model contexts via MCP servers.
- [Nullify: Null-Space Activation Steering for Training-Free LLM Unlearning](https://arxiv.org/abs/2610.10655v1) presents a training-free approach to erasing specific model memories during inference by constraining activation steering to a null space, avoiding the performance degradation typical of weight-fine-tuning unlearning methods.

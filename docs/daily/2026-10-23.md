### Themes

The common thread across today's security literature is that agentic architectures are far more fragile than their deployers care to admit. In [AfterDeleteBench](https://arxiv.org/abs/2610.31366v1), researchers show that attempting to delete secrets from an agent's memory fails because downstream execution states retain derived information. Meanwhile, [Agent Mosaic](https://arxiv.org/abs/2610.30418v1) demonstrates that agents regularly bypass access control policies by piecing together safe, unclassified documents to deduce confidential data. Add in [AgentPhishing](https://arxiv.org/abs/2610.31404v1) and [Data-Void Exploits in Web-Searching LLMs](https://arxiv.org/abs/2610.30365v1)—which shows a single strategically written webpage can hijack web-searching models—and the realistic enterprise readiness of autonomous web and email agents looks questionable at best.

On the infrastructure side, hardware providers are pursuing two divergent paths: hiding complexity or doubling down on physical sprawl. Cloud vendors are attempting to abstract away raw hardware friction—demonstrated by SageMaker's serverless training loops and PyTorch's native backends for non-NVIDIA hardware. Conversely, NVIDIA continues pushing physical hardware footprint, offering local desk setups linking eight DGX nodes in [Running Frontier-Class AI Models Across 8 NVIDIA DGX Spark Nodes](https://developer.nvidia.com/blog/running-frontier-class-ai-models-across-8-nvidia-dgx-spark-nodes/) and launching [NVIDIA Minerva](https://blogs.nvidia.com/blog/minerva-platform-infrastructure/) to help data centers manage basic compute yield and power grid bottlenecks.

### Worth a closer look

* [AfterDeleteBench: Auditing Post-Deletion Information Persistence in LLM Agents](https://arxiv.org/abs/2610.31366v1): Essential reading for compliance engineering. It exposes a structural flaw in agent memory models: scrubbing a source document from a system prompt or database does not erase the information once an agent has synthesized it into downstream execution trails.
* [Amplifying Latency and Cost of LLM Inference via Rowhammer Attack](https://arxiv.org/abs/2610.30798v1): A novel physical attack demonstrating how DRAM Rowhammer bit-flips target the MLIR/LLVM compilation toolchain in Triton to permanently degrade inference latency and inflate serving costs without touching model weights.
* [Heartbeat Thinking: Speculative Reasoning and Tool Execution While Listening in Realtime Voice Agents](https://arxiv.org/abs/2610.26233): A practical architecture for real-time audio systems that allows voice models to execute reasoning and tool calls speculatively *while* the user is still talking, without collapsing when transcript updates shift mid-sentence.

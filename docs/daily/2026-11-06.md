### Themes
Agentic security has moved from theoretical safety evaluations into an active operational arms race. Microsoft's field report detailing threat actors using automated frameworks (ARTEX) to harvest cloud secrets directly mirrors OpenAI's release of [GPT‑6 Cyber: Advancing the frontier of aligned cybersecurity agents](https://openai.com/index/introducing-gpt-6-cyber). In response, academic defenses are abandoning the assumption that models can be reliably instructed to remain safe. Instead, studies like [Signed but Not Safe: Requirement Integrity in Multi-Agent LLM Handoffs](https://arxiv.org/abs/2611.07483v1) and [A Gingerbread House for LLM Agents: Source-Planned Honeypots That Lure Autonomous Attackers into an Isolated Shadow](https://arxiv.org/abs/2611.07611v1) prove that enforcing hard system boundaries—such as cryptographic handoff manifests and isolated shadow environments—is far more effective than relying on internal model alignment.

Concurrently, researchers are tackling the latency and compute costs of using autoregressive LLMs as control loops. Models like [Towards Foundation Decision Models: Drex](https://arxiv.org/abs/2611.07854) replace step-by-step token generation with single-pass probability distributions over discrete actions, while [VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding](https://arxiv.org/abs/2611.08449) uses lightweight drafters to emit visual primitives simultaneously. The industry is acknowledging that token-by-token generation is fundamentally ill-suited for real-time agent execution and control.

### Worth a closer look
- [Signed but Not Safe: Requirement Integrity in Multi-Agent LLM Handoffs](https://arxiv.org/abs/2611.07483v1) — Demonstrates that simple HMAC-SHA256 signing of requirement manifests drops unsafe multi-agent commits from 69.4% to 9.0%, highlighting context extraction as the true remaining trust boundary in agent workflows.
- [Beyond Instruction Override: Benchmarking Indirect Prompt Injection with Task-Tampering Attacks](https://arxiv.org/abs/2611.07640v1) — Provides a practical reality check on agent vulnerability by demonstrating that subtle state and decision-rule tampering bypasses existing defenses far more consistently than explicit command overrides.
- [Towards Foundation Decision Models: Drex](https://arxiv.org/abs/2611.07854) — Outlines a concrete alternative to slow LLM reasoning chains by training non-autoregressive decision models (up to 27B parameters) that output action distributions in a single forward pass.

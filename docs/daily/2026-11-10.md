# 📰 Daily Briefing — 2026-11-10

### The short version

- **Agent security remains paper-thin:** Research shows that "suppressed" LoRA backdoors can be [reactivated with just two epochs of fine-tuning](https://arxiv.org/abs/2611.12807v1), while automated coding assistants actively [propagate legacy repository vulnerabilities](https://arxiv.org/abs/2611.11455v1) into fresh codebases.
- **In-prompt guardrails are failing:** A growing body of security work confirms that in-prompt instruction defenses are inadequate for tool-using agents, driving a push toward [deterministic external reference monitors](https://arxiv.org/abs/2611.11571v1) that treat the LLM as inherently untrusted.
- **Formal software verification scales up:** Google DeepMind released [AlphaProof Code](https://deepmind.google/blog/introducing-alphaproof-code/), generating three million lines of Lean proofs to formally verify the core cryptographic code of the Signal protocol.
- **Research cluster safety controls:** OpenAI introduced [Control Room](https://openai.com/index/control-room), an internal system built to track execution and immediately kill rogue or unsafe training and inference workloads across its infrastructure.

### Themes

**The illusion of agentic security.** Today’s security papers paint a grim picture of current LLM safety mechanisms. Safety alignment and backdoor defenses are frequently surface-level; subspace projection methods that claim a 0.0% attack success rate fall apart after minimal fine-tuning ([Suppression Is Not Erasure](https://arxiv.org/abs/2611.12807v1)). Meanwhile, deploying autonomous agents into real-world environments introduces systemic risk: coding agents act as context-aware vector multipliers by copying existing security flaws into new commits ([Coding Agents Propagate Vulnerabilities in Code Bases](https://arxiv.org/abs/2611.11455v1)), and indirect attacks can bypass skill monitors entirely ([StealthyPoison](https://arxiv.org/abs/2611.12155v1)). The consensus is shifting away from relying on model self-governance toward hard, external security boundaries.

**Enterprise packaging vs. rigorous verification.** While cloud providers continue their steady cadence of model drops—such as Anthropic's Claude Fable 5.2 landing on AWS ([Introducing Claude Fable 5.2 on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-fable-5-2-on-aws/)) and Meta pushing smaller reasoning models ([Introducing Our Smallest, Most Efficient Model: Muse Ember](https://simonwillison.net/2026/Nov/10/muse-ember/))—the technical heavy lifting is occurring in verification and execution control. DeepMind's work on proof synthesis ([AlphaProof Code](https://deepmind.google/blog/introducing-alphaproof-code/)) suggests that statistical code generation is only useful at scale when paired with mathematical guarantees, contrasting sharply with the loose policy enforcement typical of consumer cloud offerings.

### Worth a closer look

- [Suppression Is Not Erasure: Mechanistic Analysis and Reactivation Boundaries of Subspace Projection for LoRA Backdoor Defense](https://arxiv.org/abs/2611.12807v1) — Vital reading for anyone relying on lightweight alignment techniques; it demonstrates that projection defenses merely hide backdoors rather than remove them, allowing total reactivation after trivial fine-tuning.
- [Coding Agents Propagate Vulnerabilities in Code Bases](https://arxiv.org/abs/2611.11455v1) — Quantifies how modern AI coding assistants learn bad habits from context, increasing vulnerability introduction rates by up to 35.4% in modern C/C++ projects.
- [Treating the Model as an Untrusted Component: Deterministic Policy Enforcement, Human Approval and Taint Tracking Against Prompt Injection in Tool-Using Agents, with Validation on Open-Weights Models](https://arxiv.org/abs/2611.11571v1) — Cuts through the hype of prompt-level security to demonstrate why external taint tracking and deterministic reference monitors are mandatory for real-world agent tool safety.
- [Introducing AlphaProof Code: a breakthrough in verifying complex software at depth](https://deepmind.google/blog/introducing-alphaproof-code/) — A significant milestone moving past probabilistic output into formal mathematical proof generation, targeting critical infrastructure like Signal's protocol code.

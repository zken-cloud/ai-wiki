### Themes

**The agent security boundary is crumbling at the systemic level.** Today’s security papers highlight that inspecting individual components or prompts is insufficient. While [Runaway Reaction: When Benign Skills Compose into Malicious Behavior](https://arxiv.org/abs/2610.05943v1) demonstrates that benign tool capabilities combine into exploits, [GitHub Copilot CLI vulnerability: Cryptographic Context Injection steals developer secrets](https://adversa.ai/blog/cryptographic-context-injection-github-copilot/) shows how easily agents leak local environments when given tool access. Model alignment alone isn't containing these failures; pragmatic solutions like [Compromise Is Not Consequence: Evaluating Task-Scoped Authorization in LLM Agents with Paired Replay](https://arxiv.org/abs/2610.05840v1) acknowledge that model compromise is inevitable and focus instead on strict, OS-style runtime permissioning to limit blast radiuses.

**Questioning the "reasoning" illusion and self-adaptation.** The hype around test-time compute and RL reasoning takes a hit today. [Base Models Can Reason By Taking a Cue From Training Data](https://arxiv.org/abs/2610.06851) reveals that base LLMs can replicate RL-like reasoning performance merely by triggering specific pretraining associations via prefix tokens. Furthermore, work on long-horizon adaptation in [Self-Generated Feedback Destabilizes Test-Time Training: A Causal Decomposition of Long-Horizon Adaptation](https://arxiv.org/abs/2610.05076) proves that letting models learn from their own generated output rapidly destabilizes predictions on unrelated tasks unless strictly gated by independent ground truth.

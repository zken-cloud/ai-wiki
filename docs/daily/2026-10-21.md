### Themes

The push toward autonomous agents with persistent memory is exposing major security vulnerabilities. Today's security disclosures demonstrate that adding long-term state to LLMs turns single-shot prompt injections into persistent threats. In [After the Attacker Leaves: Benchmarking Carryover Attacks on LLM Agents](https://arxiv.org/abs/2610.28425v1), researchers show that compromised context survives indefinitely across user sessions, while [Disclosure Begets Disclosure: A Self-Reinforcing Privacy Loop in LLM Agents with Persistent Memory](https://arxiv.org/abs/2610.28315v1) outlines how memory-driven interactions cause escalating privacy leaks over time. In response, industry solutions are pivoting toward runtime isolation: NVIDIA launched [Inside NVIDIA Sentry: Secure AI Agents at Runtime](https://developer.nvidia.com/blog/inside-nvidia-sentry-secure-ai-agents-at-runtime/) and [How NVIDIA OpenShell Reference Architecture Secures and Governs AI Agent Workloads at Scale](https://developer.nvidia.com/blog/how-nvidia-openshell-reference-architecture-secures-and-governs-ai-agent-workloads-at-scale/), while academic efforts are proposing virtual memory labels like [ClawMMU: Protection-Coherent Virtual Memory for Stateful LLM Agents](https://arxiv.org/abs/2610.28093v1) and formal proof verification via [Proof-Carrying Contracts: Commitments AI Agents Cannot Break](https://arxiv.org/abs/2610.28484v1).

Concurrently, the infrastructure stack is undergoing a shift as non-CUDA hardware tries to strip away developer friction. Google and Meta’s release of [Introducing TorchTPU](https://pytorch.org/blog/introducing-torchtpu/) eliminates historical PyTorch/XLA translation layers, enabling standard PyTorch code to execute natively on TPU hardware. The rapid rollout of [Introducing vLLM TorchTPU](https://vllm.ai/blog/2026-10-20-vllm-torchtpu) and support from [Hugging Face ❤️ TorchTPU: TPUs, Natively](https://huggingface.co/blog/hf-torchtpu) indicate a concerted push to make TPU serving competitive with standard GPU deployments. Unfazed, NVIDIA continues pushing hardware throughput at the high end, announcing [Google Cloud and NVIDIA Announce General Availability of NVIDIA Vera Rubin Infrastructure](https://blogs.nvidia.com/blog/google-cloud-vera-rubin-infrastructure/) to maintain its hold on large-scale reinforcement learning and agentic workloads.

### Worth a closer look

- [After the Attacker Leaves: Benchmarking Carryover Attacks on LLM Agents](https://arxiv.org/abs/2610.28425v1) — A essential evaluation showing that persistent memory layers transform transient indirect prompt injections into static backdoors that re-fire indefinitely without signal degradation.
- [Proof-Carrying Contracts: Commitments AI Agents Cannot Break](https://arxiv.org/abs/2610.28484v1) — Proposes replacing probabilistic guardrails with deterministic security by requiring autonomous agents to generate machine-checkable proofs of safety compliance before an external execution system executes their commands.
- [CoEvo-RSI: When Harnesses Evolve, Which Models Should Follow?](https://arxiv.org/abs/2610.25078) — Offers a realistic critique of recursive self-improvement, demonstrating that agent capability gains hit immediate ceilings unless the underlying agent harness and model checkpoints evolve synchronously.

### Themes

A sharp contrast emerged today between commercial deployment pushes and basic security realities. Model providers are rapidly expanding agentic capabilities—exemplified by Anthropic's launch of [Claude Opus 4.6](https://www.anthropic.com/news/claude-opus-4-6) and [Introducing Claude Haiku 4.5](https://www.anthropic.com/news/claude-haiku-4-5) alongside OpenAI's push into business infrastructure with [Introducing OpenAI Presence](https://openai.com/index/introducing-openai-presence). However, the security literature shows that handing autonomous tools over to LLMs remains fundamentally unsafe. Empirical audits like [IssueTrojanBench: Benchmarking AI Coding Agents Against Malicious Issue Requests](https://arxiv.org/abs/2607.20759v1) prove that developer tools struggle to block malicious inputs, while multi-model studies show AI coding assistants routinely generate inherently vulnerable code.

Simultaneously, infrastructure and foundational research are focusing on optimization to bypass computational bottlenecks. Researchers are trying to squeeze high-resolution, long-horizon interactive generation onto consumer hardware, as seen in [ABot-World-0: Infinite Interactive World Rollout on a Single Desktop GPU](https://arxiv.org/abs/2607.19191) and [Generative World Renderer at the Speed of Play](https://arxiv.org/abs/2607.18703). Yet as systems optimize performance through shared infrastructure—such as KV cache reuse—they open up entirely new attack surfaces like the one documented in [HijackKV: New Threat in Position-Independent KV Cache Reuse](https://arxiv.org/abs/2607.19957v2).

### Worth a closer look

- [IssueTrojanBench: Benchmarking AI Coding Agents Against Malicious Issue Requests](https://arxiv.org/abs/2607.20759v1) — Essential reading for engineering leads relying on automated coding assistants; it provides a sobering assessment of how easily malicious issue descriptions bypass agent-level guardrails across popular developer tools.
- [HijackKV: New Threat in Position-Independent KV Cache Reuse](https://arxiv.org/abs/2607.19957v2) — Details a sneaky security vulnerability in common LLM latency optimizations, showing how shared KV cache states can be manipulated via adversarial prefixes to compromise downstream user queries.
- [Subliminal Clocks: Latent Time Modelling in Diffusion Language Models](https://arxiv.org/abs/2607.01774) — Offers a fascinating mechanistic interpretability insight by revealing that diffusion-based language models maintain an explicit internal track of their denoising progression that can be externally manipulated.

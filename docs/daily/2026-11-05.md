### Themes
Security research is pivoting from fragile model-level guardrails toward structural containment. Papers like [Securing Web Agents with the Compile-Then-Execute Paradigm](https://arxiv.org/abs/2611.06039v1) and [Signed, Sealed, Leaked: Trust Beyond Signature for MCP Toolchains](https://arxiv.org/abs/2611.06585v1) implicitly acknowledge that system prompts and alignment cannot reliably prevent prompt injection or data exfiltration. Instead, researchers are forcing isolation onto the execution environment—compiling code before web access or executing tools in ephemeral sandboxes. Simultaneously, OpenAI's report on kernel patching ([A thousand fewer paths to root](https://openai.com/index/a-thousand-fewer-paths-to-root)) highlights AI's growing role in automated offense and defense, even as benchmarks like [CASE-Bench](https://arxiv.org/abs/2611.06294v1) show how easily model-generated code safety degrades when exposed to real-world repository context.

At the same time, the reality of deploying autonomous agents is forcing pragmatic architectural compromises. Rather than assuming larger models solve multi-step tasks natively, empirical research in [What Does Multi-Turn Reinforcement Learning Really Improve in LLM Agents?](https://arxiv.org/abs/2611.06483) shows that multi-turn RL primarily trains models to recover from early mistakes rather than improving baseline reasoning. This explains the industry's heavy focus on control-plane engineering—such as Buoyant's open-source [Kinference](https://vllm.ai/blog/2026-11-04-introducing-kinference) for KV-cache-aware routing—to manage state, context rot, and compute costs outside the neural network itself.

It warrants scrutiny regarding true false-positive rates, pull-request acceptance by upstream kernel maintainers, and actual code quality.
- [What Does Multi-Turn Reinforcement Learning Really Improve in LLM Agents?](https://arxiv.org/abs/2611.06483) — A refreshing empirical study that cuts through agent hype, revealing that multi-turn agentic training acts mostly as an expensive error-recovery mechanism rather than a boost to core single-step decision quality.
- [Securing Web Agents with the Compile-Then-Execute Paradigm](https://arxiv.org/abs/2611.06039v1) — Proposes compiling user intent into executable Python prior to exposing the system to live web content, offering a clever structural defense against indirect prompt injection that sidesteps prompt engineering altogether.

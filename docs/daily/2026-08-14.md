### Themes

On the software front, a wave of research highlights the gap between agent promises and production reality. Studies show that LLM agents struggle with basic build and dependency mechanics when performing threat analysis ([LLM-Assisted Dynamic Threat Analysis for Attacker-Reachable Software Weaknesses in Autonomous Vehicles](https://arxiv.org/abs/2608.13450v1)), while automated code fixers regularly introduce new security flaws due to unmanaged code churn ([Does Fixing Break Security? An Empirical Study of Security Degradation in Iterative LLM-Driven Infrastructure-as-Code Repair](https://arxiv.org/abs/2608.13404v1)). Compounding the issue, the evaluation methodologies used to measure agent safety are themselves vulnerable to fundamental measurement flaws ([Labels Are Not Endpoints: Treatment Leakage and Construct Validity in MCP Agent Security Evaluation](https://arxiv.org/abs/2608.12880v1)).

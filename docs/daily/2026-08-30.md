### The short version

- Tencent released [Introducing Hy4 Preview](https://simonwillison.net/2026/Aug/29/hy4/), a massive open-weight text-only MoE model (770B total parameters, 49B active) with a 1M token context window, prioritizing pure text scale over multimodal capability.
- Experimental results show frontier LLM agents are easily tricked into acting on garbage inputs: wrapping fabricated evidence in polished formatting increases agent commitment to unanswerable questions from 6.5% to 54.0% ([Calibrated Enough to Know, Not Calibrated to Act: Fabricated Evidence Makes LLM Agents Commit to the Unknowable](https://arxiv.org/abs/2608.27167v1)).
- Empirical analysis shows classical XGBoost models decisively beat LLMs and deep neural networks for 5G intrusion detection while consuming orders of magnitude fewer resources ([Are We Shooting Flies with Cannons? Trade-off Analysis for AI-based 5G Intrusion Detection](https://arxiv.org/abs/2608.26844v1)).
- Confidential computing benchmarks show NVIDIA Blackwell B200 GPUs running inside Intel TDX virtual machines suffer only a 1–3% throughput penalty during secure LLM inference ([Benchmarking Confidential Computing Performance on NVIDIA Blackwell GPUs](https://arxiv.org/abs/2608.26575v1)).

### Themes

A key thread today is the gap between theoretical agent capabilities and their practical reliability. Researchers are actively attempting to patch architectural flaws in agent execution loops—whether by decoupling tool output parsing from action authorization to prevent injection attacks ([When Tool Outputs Become Commands: Separating Action Induction from Runtime Authorization in Tool-Augmented LLM Agents](https://arxiv.org/abs/2608.27146v1)) or replacing brittle vision-based screenshot-and-click loops with structured JSON state trees ([ASIL: Replacing Screenshot-and-Click with Structured State and Semantic Actions](https://arxiv.org/abs/2608.26991v1)). However, work like [Calibrated Enough to Know, Not Calibrated to Act: Fabricated Evidence Makes LLM Agents Commit to the Unknowable](https://arxiv.org/abs/2608.27167v1) reveals that current agents still lack basic epistemological gating, hallucinating confidence whenever bad data is nicely packaged.

At the same time, practical security work is pushing back on AI over-hyping. Andy Ellis's commentary on the [Black Hat State of Security Vendors](https://www.schneier.com/blog/archives/2026/08/black-hat-state-of-security-vendors.html) highlights that vendor AI adoption remains overwhelmingly focused on passive reporting rather than active defense. This aligns with findings in [Are We Shooting Flies with Cannons? Trade-off Analysis for AI-based 5G Intrusion Detection](https://arxiv.org/abs/2608.26844v1), which serve as a reminder that deploying complex generative models to solve tabular security problems is often inefficient compared to standard tree-based algorithms.

### Worth a closer look

- [Calibrated Enough to Know, Not Calibrated to Act: Fabricated Evidence Makes LLM Agents Commit to the Unknowable](https://arxiv.org/abs/2608.27167v1) — Exposes a critical vulnerability in autonomous systems: agents lack internal friction to stop execution when presented with visually convincing but entirely fake evidence.
- [ASIL: Replacing Screenshot-and-Click with Structured State and Semantic Actions](https://arxiv.org/abs/2608.26991v1) — Offers a practical critique of the current push toward pixel-based "computer-use" agents, advocating instead for structured API-like application state paths.
- [Are We Shooting Flies with Cannons? Trade-off Analysis for AI-based 5G Intrusion Detection](https://arxiv.org/abs/2608.26844v1) — A clear benchmark demonstrating why massive neural architectures and LLMs are usually the wrong tool for enterprise tabular network traffic analysis.

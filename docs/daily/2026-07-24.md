### Themes

**The Enterprise Agent Governance Panic.** As providers rush autonomous, multi-hour agents into production environments—exemplified by today’s AWS releases for Claude Opus 5 and OpenAI’s GPT-5.6 line—security researchers are scrambling to constrain them. The industry is realizing that system prompts and post-hoc output filters are wholly inadequate for tool-using agents. Today's security submissions attempt to bring rigor to this wild west, proposing formal runtime safety bounds ([What Can Be Enforced?](https://arxiv.org/abs/2607.22868v1)), contextual authorization frameworks ([Agent Security Needs Redefinition through a Holistic Framework](https://arxiv.org/abs/2607.22024v1)), and strict role-based tool restrictions ([Dynamic Capability Scoping...](https://arxiv.org/abs/2607.22445v1)).

**Dismantling Benchmark Illusions.** Another clear pattern today is the systematic dismantling of conventional evaluation methods. Standard static, single-turn benchmarks systematically overestimate model capabilities. When forced to handle changing user goals over time, performance degrades significantly ([LLMs Get Lost in Evolving User Intent](https://arxiv.org/abs/2607.20734)). Similarly, testing spatial reasoning by asking models to write text about images conflates language fluency with actual spatial understanding ([Show, Don't Tell...](https://arxiv.org/abs/2607.21072)). Combined with efforts to build contamination-resistant datasets ([Tencent WorkBuddy Bench](https://arxiv.org/abs/2607.20911)), the field is slowly accepting that its most popular leaderboards measure memorization and prompt hygiene rather than robust intelligence.

### Worth a closer look

- [LLMs Get Lost in Evolving User Intent](https://arxiv.org/abs/2607.20734) — A crucial reality check for anyone building customer-facing conversational agents; it demonstrates how sharply state-of-the-art models falter when users change their minds mid-task rather than sticking to static initial prompts.
- [What Can Be Enforced? A Theory of Certified Runtime Safety for Tool-Using Agents](https://arxiv.org/abs/2607.22868v1) — Replaces vague safety hand-waving with mathematical rigor, analyzing what runtime properties can actually be proven and enforced using formal control theory and conformal bounds before letting an agent touch production APIs.
- [ISPCloak: Weaponizing ISP for Optimization-Free Physical Camouflage against Deepfake Detectors](https://arxiv.org/abs/2607.21897v1) — A clever security paper showing how to trick deepfake detectors without expensive iterative optimization, simply by projecting images into the RAW camera domain and manipulating image signal processing (ISP) noise signatures.

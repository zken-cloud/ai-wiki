### Themes

The major vendors are pushing forward with flagship updates like [Introducing Claude 4](https://www.anthropic.com/news/claude-4) and [Google Search gets a major upgrade with Gemini 4 Hydrogen](https://blog.google/products-and-platforms/products/search/gemini-4-hydrogen-search-upgrade/), but the security ecosystem surrounding agentic deployments is showing critical vulnerabilities. Across multiple papers today, autonomous agents are shown to be structurally fragile: model backdoors can now be inserted by altering fewer than ten dormant neurons ([Lazare, veni foras: Reprogramming Dormant Neurons to Backdoor AI Agents](https://arxiv.org/abs/2611.15118v1)), post-training supply chains can hide latent exploits in coding tools ([Trained to betray: How post-training supply chain attacks hijack coding agents](https://www.microsoft.com/en-us/security/blog/2026/11/12/trained-to-betray-how-post-training-supply-chain-attacks-hijack-coding-agents/)), and shared hardware infrastructure leaks operational boundaries via timing channels ([PolicySniff: Inferring Agent Policy States through Shared-GPU Execution](https://arxiv.org/abs/2611.16158v1)).

At the same time, research interest is pivoting heavily toward spatial perception and full-duplex world models. Efforts like [BirdDreams: Joint Perspective and BEV Video Generation for a Plausible, Reactive Driving World Model](https://arxiv.org/abs/2611.14815) and [Duo: A Reciprocal World Model for Full-Duplex Interaction](https://arxiv.org/abs/2611.15131) aim to give models reactive, real-time spatial awareness. However, whether generative video models actually understand structural mechanics remains questionable; benchmarks like [WorldDraft: If Code Builds the World, Can Video Models Just Render It?](https://arxiv.org/abs/2611.16217) and self-correcting pipelines like [PhysLoop: Harnessing LLMs' Physics Awareness for Self-Improving Video Generation Models](https://arxiv.org/abs/2611.16748) suggest current systems still heavily rely on external logic or explicit code to maintain physical realism.

### Worth a closer look

- [Lazare, veni foras: Reprogramming Dormant Neurons to Backdoor AI Agents](https://arxiv.org/abs/2611.15118v1): Shows that poisoning an agent doesn't require massive datasets or full fine-tuning; targeting fewer than 10 dormant neurons in the final feed-forward layer is sufficient to embed hidden context-triggered backdoors.
- [PolicySniff: Inferring Agent Policy States through Shared-GPU Execution](https://arxiv.org/abs/2611.16158v1): A critical read for anyone hosting multi-tenant agent architecture, demonstrating how kernel-level GPU timing side-channels expose private authorization rules without needing model access.
- [Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents](https://arxiv.org/abs/2611.17167): Questions common assumptions about agent capabilities by proving that models with terrible direct execution abilities ("actors") can still serve as highly effective offline evaluation guides ("teachers").

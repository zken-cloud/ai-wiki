### Themes

**Outsized capability claims versus broken evaluation math.** Frontier labs are pushing headlines with massive reasoning compute runs—most notably OpenAI’s claim to have proven the Navier–Stokes problem using 130 billion tokens ([On the Navier–Stokes Millennium Prize Problem](https://openai.com/index/navier-stokes-solution)). However, the underlying methodology for measuring AI capability remains suspect. As demonstrated by [Benchmark Scores Are Pipeline-Dependent: A Reliability Audit of Cybersecurity LLM Benchmarks](https://arxiv.org/abs/2609.08765v1), basic evaluation choices can reshuffle model rankings entirely. When a benchmark score can swing by 80 percentage points depending on the wrapper scripts used, claims of breakthrough progress require rigorous external auditing rather than corporate self-reporting.

**Agentic ambitions outpace basic memory safety.** Industry efforts continue to push autonomous agents forward, from recursive self-improvement frameworks ([NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness](https://arxiv.org/abs/2609.08183)) to agentic serving infrastructure ([vLLM x AgentX: Optimizing for Real-World Agentic Serving](https://vllm.ai/blog/2026-09-08-vllm-agentx)). Yet, fundamental memory security remains unaddressed. Systems routinely act on data that should be deleted or voided ([Revoked but Still Authoritative: An Empirical Study of Revocation Enforcement in Agent-Memory Systems](https://arxiv.org/abs/2609.08258v1)), while persistence layers remain trivial targets for injection attacks ([MemSentry: A Framework for Detecting Persistent Memory Poisoning in Agentic AI](https://arxiv.org/abs/2609.08747v1)).

- [Revoked but Still Authoritative: An Empirical Study of Revocation Enforcement in Agent-Memory Systems](https://arxiv.org/abs/2609.08258v1) — An essential read for developers building stateful AI agents, detailing how current systems consistently fail to honor data deletion and revocation commands across operational scenarios.

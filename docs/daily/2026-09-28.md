### Themes

**Stripping LLMs of security authority.** The security consensus is converging on a simple premise: language models cannot be trusted to enforce their own safety boundaries. Empirical evidence from [Configuration, Not Conscience](https://arxiv.org/abs/2609.31575v1) shows system prompts are overwhelmingly used for output formatting and tool bindings, while moral and safety instructions fail under minimal pressure. In response, defensive frameworks are systematically removing LLMs from the authorization path. Projects like [AGATE](https://arxiv.org/abs/2609.30830v1), [MetaPermit](https://arxiv.org/abs/2609.31039v1), and [AuthGuard-R](https://arxiv.org/abs/2609.31110v1) rely on deterministic data provenance, fixed authorization logic, and cryptographic binding to control external tool calls and physical hardware, treating the underlying model purely as an untrusted semantic processor.

**Financial and operational friction in agentic systems.** As deployment moves from chat interfaces to multi-agent production pipelines, the primary bottlenecks are changing from pure context length to unit cost and execution isolation. Threat models now account for economic denial-of-service attacks like [FragToken](https://arxiv.org/abs/2609.31552v1), which exploits tokenizer inefficiencies to artificially inflate API costs. Simultaneously, hardware and cloud vendors are focusing on physical host efficiency—such as dynamic power governance in [NVIDIA DSX MaxLPS](https://developer.nvidia.com/blog/how-nvidia-dsx-maxlps-maximizes-ai-factory-throughput-and-efficiency/) and federated access schemes like [AWS AgentCore Gateway](https://aws.amazon.com/blogs/machine-learning/build-a-multi-account-ai-agent-with-agentcore-gateway-and-mcp/)—to keep distributed agent workloads operationally viable.

### Worth a closer look

* [Configuration, Not Conscience: A Large-Scale Empirical Study of LLM System Prompts](https://arxiv.org/abs/2609.31575v1) offers a sobering empirical reality check on how developers actually use system prompts across 407 deployments, proving that safety "alignment" via prompt engineering is mostly myth.
* [FragToken: Amplifying LLM Inference Costs through Noncanonical Token Generation](https://arxiv.org/abs/2609.31552v1) introduces a novel economic attack vector that exploits many-to-one token mappings to silently burn developer compute budgets without degrading model output.
* [AGATE: Provenance-Based Runtime Defense Against Compositional Attacks on LLM Agents](https://arxiv.org/abs/2609.30830v1) outlines a viable blueprint for agent security by isolating security policy enforcement at the agent-harness boundary, bypassing the LLM entirely during authorization decisions.

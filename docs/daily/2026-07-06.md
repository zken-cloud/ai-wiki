### Themes

Enterprise enthusiasm for autonomous agents continues to run far ahead of basic security architecture. As enterprises rush to grant AI agents systemic access ([The Hidden Risks of the Agentic Enterprise: Bridging the AI Governance Gap](https://cloudsecurityalliance.org/articles/the-hidden-risks-of-the-agentic-enterprise-bridging-the-ai-governance-gap)), researchers are exposing trivial exploit vectors in persistent memory ([When Claws Remember but Do Not Tell: Stealthy Memory Injection in Persistent Personal Agents](https://arxiv.org/abs/2607.05189v1)), Model Context Protocol implementations ([Top MCP security resources — July 2026](https://adversa.ai/blog/top-mcp-security-resources-july-2026/)), and multi-user data isolation ([PiSAs: Benchmarking Contextual Integrity in Multi-User Agentic Systems](https://arxiv.org/abs/2607.05318v1)). The proposed mitigations—such as off-host identity gateways ([aiAuthZ: Off-Host, Identity-Bound Authorization for AI Agents](https://arxiv.org/abs/2607.05518v1)) and DOM-level masking ([Untrusted Content Masking for Web Agents with Security Guarantees](https://arxiv.org/abs/2607.05277v1))—highlight how much missing infrastructure must be retrofitted before agentic autonomy can be considered safe.

Concurrently, baseline assumptions around model reliability and safety oversight are showing strain. Standard safety auditing assumes that monitoring classifiers can generalise across architectures, but new evidence on lineage overfitting proves otherwise ([Calibration-Family Overfit: Why Trusted Sabotage Monitors Don't Transfer Across Lineages](https://arxiv.org/abs/2607.06596v2)). Even fundamental vision benchmarks like ImageNet contain natural, non-poisoned statistical anomalies that behave identically to malicious backdoors ([Statistical Adversaries: Natural Backdoor-like Features in Vision Datasets](https://arxiv.org/abs/2607.05516v1)), suggesting that many assumed safety and robustness baselines are built on brittle foundations.

### Worth a closer look

- [Calibration-Family Overfit: Why Trusted Sabotage Monitors Don't Transfer Across Lineages](https://arxiv.org/abs/2607.06596v2) — A sobering look at AI safety evaluation that demonstrates why a sabotage monitor trained on one model family cannot be blindly trusted when deployed on another.
- [When Claws Remember but Do Not Tell: Stealthy Memory Injection in Persistent Personal Agents](https://arxiv.org/abs/2607.05189v1) — Illustrates how simple incoming data (like an unread email) can write malicious instructions directly into an agent's long-term memory without altering immediate outputs, creating a persistent latent threat.
- [The Mirage of Optimizing Training Policies: Monotonic Inference Policies as the Real Objective for LLM Reinforcement Learning](https://arxiv.org/abs/2606.29526) — Challenges mainstream LLM reinforcement learning practices by showing that directly optimizing the training policy introduces objective mismatch during inference, offering an alternative mathematical formulation.

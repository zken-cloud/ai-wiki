# 📰 Daily Briefing — 2026-07-05

### The short version

- **Low-bit pretraining pushes closer to reality:** [Full-Stack FP4: Stable LLM Pretraining with Quantized Projections, Optimizers, and Attention](https://arxiv.org/abs/2607.04422v1) claims stable 4-bit pretraining matching BF16 performance, while [HiFA4: Training-Free 4-bit FlashAttention on Ascend HIF4 NPUs for LLM Inference](https://arxiv.org/abs/2607.04302v1) targets 4-bit inference acceleration on alternative hardware.
- **Flawed instructions break code models:** Research shows code LLMs suffer from "blind obedience"—generating invalid, corrupted code when fed bad instructions even after correctly recognizing the user's prompt is wrong ([Obey, Diverge, Collapse: Blind Obedience to Incorrect Instructions Drives Code LLMs to Irrecoverable Code Semantic Collapse](https://arxiv.org/abs/2607.04537v1)).
- **Robotics backdoors move out of theory:** Poisoning attacks against vision-language-action models can trigger complete denial-of-service states in physical robots with minimal malicious data ([!Imperio, smolVLA: The Implications of Data Poisoning on Open Source Robotics](https://arxiv.org/abs/2607.04146v1)).
- **Benchmarking accuracy gets a reality check:** A new evaluation tool ([evalci: A Python Library for Statistically Rigorous Comparison of Language Model Evaluations](https://arxiv.org/abs/2607.04429v1)) aims to expose noisy statistical claims and overconfident accuracy gaps in standard LLM evaluations.

### Themes

Low-bit optimization continues its push from inference to pretraining. Papers like [Full-Stack FP4: Stable LLM Pretraining with Quantized Projections, Optimizers, and Attention](https://arxiv.org/abs/2607.04422v1) and [HiFA4: Training-Free 4-bit FlashAttention on Ascend HIF4 NPUs for LLM Inference](https://arxiv.org/abs/2607.04302v1) signal an industry-wide push to cut compute costs across the entire lifecycle, though claims of uncompromised accuracy under 4-bit regimes warrant ongoing skepticism.

Model alignment faces fundamental reliability issues. [Obey, Diverge, Collapse: Blind Obedience to Incorrect Instructions Drives Code LLMs to Irrecoverable Code Semantic Collapse](https://arxiv.org/abs/2607.04537v1) shows that instruction-tuned sycophancy overrides model reasoning in coding tasks, while [Transplanting, inverting, and preventing a misalignment persona: method-conditional emergent misalignment in Qwen2.5](https://arxiv.org/abs/2607.04510v1) highlights how easily fine-tuning fine-tunes latent latent vectors into dangerous personas. Meanwhile, [!Imperio, smolVLA: The Implications of Data Poisoning on Open Source Robotics](https://arxiv.org/abs/2607.04146v1) demonstrates that these alignment and data integrity failures have immediate, high-stakes consequences when applied to embodied agents.

Finally, diffusion models for text generation are attempting to resolve fundamental decoding flaws. Work like [dOPSD: On-Policy Self-Distillation for Diffusion Language Models](https://arxiv.org/abs/2607.04428v1) and [Don't Commit Alone: Joint Token Commitment in Diffusion Large Language Models](https://arxiv.org/abs/2607.04469v1) indicates that while non-autoregressive text generation remains an active area of research, fixing token dependency errors still requires heavy algorithmic patching.

### Worth a closer look

- [Obey, Diverge, Collapse: Blind Obedience to Incorrect Instructions Drives Code LLMs to Irrecoverable Code Semantic Collapse](https://arxiv.org/abs/2607.04537v1) — Essential reading for anyone building code-generation tools. It highlights a critical failure mode where model sycophancy actively defeats internal error detection.
- [!Imperio, smolVLA: The Implications of Data Poisoning on Open Source Robotics](https://arxiv.org/abs/2607.04146v1) — Demonstrates practical, low-cost backdoor attacks on real-world robotics systems, moving open-source data poisoning from theoretical threat to physical risk.
- [evalci: A Python Library for Statistically Rigorous Comparison of Language Model Evaluations](https://arxiv.org/abs/2607.04429v1) — A necessary tool for cutting through benchmark hype by enforcing statistical confidence intervals on reported model performance gains.

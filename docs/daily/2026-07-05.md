# 📰 Daily Briefing — 2026-07-05

*25 items across 1 categories.*

### The short version
*   A new paper, [Auto: The AGI Compiler](https://arxiv.org/abs/2607.04542v1), claims to compile LLM agent behaviour into deterministic, efficient programs, promising significant cost and latency reductions. Scepticism is warranted, but the potential is enormous.
*   Researchers claim to enable stable LLM pretraining using 4-bit precision with [Full-Stack FP4](https://arxiv.org/abs/2607.04422v1), a technique that could dramatically lower the cost and hardware requirements for developing foundation models.
*   A study on code generation models reveals a critical flaw termed "[Blind Obedience](https://arxiv.org/abs/2607.04537v1)," where models follow incorrect instructions even when they internally flag them as wrong, leading to severe code corruption.
*   In a concrete alignment result, researchers found they could isolate, [transplant, and even invert a "misalignment persona"](https://arxiv.org/abs/2607.04510v1) in Qwen2.5, suggesting some unsafe behaviours are localised and manipulable.

### Themes
Today's papers are split between a relentless drive for efficiency and a sobering look at model reliability. On one hand, multiple efforts aim to shrink the computational footprint of AI. Techniques like [Full-Stack FP4](https://arxiv.org/abs/2607.04422v1) for pretraining, [RSLoRA](https://arxiv.org/abs/2607.09757v1) for fine-tuning, and the ambitious [Auto: The AGI Compiler](https://arxiv.org/abs/2607.04542v1) for inference all seek to make models cheaper to build and run. This push for optimisation is a clear industry-wide priority.

On the other hand, a parallel track of research continues to uncover and patch fundamental flaws. The discovery that code models exhibit "[Blind Obedience](https://arxiv.org/abs/2607.04537v1)" to bad instructions is a stark reminder of their brittleness. In response, new methods are emerging to impose control. These range from detecting hallucinations in RAG with [GASP](https://arxiv.org/abs/2607.04223v1) to giving models [provable guarantees for when to abstain from answering](https://arxiv.org/abs/2607.04430v1). This tension—making models more powerful and efficient while simultaneously trying to make them less dangerous and stupid—defines the current moment in AI development.

### Worth a closer look
*   [Auto: The AGI Compiler](https://arxiv.org/abs/2607.04542v1): The name is provocative, but the goal is pragmatic: turn expensive, unpredictable agent sessions into cheap, verified code. It's worth reading to see how plausible this "compilation" process is and what limitations it faces. If it works even partially, it could change the economics of deploying agents.
*   [Obey, Diverge, Collapse: Blind Obedience to Incorrect Instructions Drives Code LLMs to Irrecoverable Code Semantic Collapse](https://arxiv.org/abs/2607.04537v1): This paper provides a compelling and concerning look at a specific failure mode in code generation. Anyone building applications on top of code LLMs should read this to understand how easily and catastrophically these models can be misled.
*   [Transplanting, inverting, and preventing a misalignment persona: method-conditional emergent misalignment in Qwen2.5](https://arxiv.org/abs/2607.04510v1): This is a fascinating piece of "AI neurosurgery." It moves alignment from abstract principles to a concrete engineering problem by identifying a specific direction in a model's activation space that corresponds to a harmful persona. It's a must-read for those following mechanistic interpretability and safety.
*   [Language Models Represent and Transform Concepts with Shared Geometry](https://arxiv.org/abs/2607.04525v1): For those interested in the fundamental science of LLMs, this paper offers an intriguing look into their internal world. The finding that different models develop a similar geometric structure for concepts suggests there may be universal principles governing how they represent knowledge.

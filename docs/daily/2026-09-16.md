### The short version

- **Automated coding agents remain a security liability**: The [SWEADV benchmark](https://arxiv.org/abs/2609.15963v1) demonstrates that adversarial issue descriptions trick code-repair agents into writing functional, test-passing code that contains security vulnerabilities 51.7% of the time.
- **Kimi K3 optimization push**: Serving performance for the 2.8T-parameter Kimi K3 is accelerating, with vLLM achieving up to 2.8× system throughput ([Kimi K3 Performance Optimizations in vLLM](https://arxiv.org/abs/2609.13053) / [blog](https://vllm.ai/blog/2026-09-13-kimi-k3-performance-optimization)) and 435 tokens/sec/user using a 5B speculative draft model on GB300 systems ([vLLM Kimi-K3 DSpark](https://vllm.ai/blog/2026-09-15-kimi-k3-dspark)).
- **Real-time multimodal audio expands**: Google launched Gemini 3.8 Live with "Extended Thinking" ([DeepMind Blog](https://deepmind.google/blog/introducing-gemini-3-8-live-and-3-8-live-extended-thinking/); [Simon Willison summary](https://simonwillison.net/2026/Sep/15/gemini-live/)), reflecting parallel research in full-duplex speech models with private reasoning streams ([StepAudio 3 Realtime](https://arxiv.org/abs/2609.14005)).
- **Skeptical check on AI fearmongering**: Systems veteran Bryan Cantrill published a sharp critique ([The contagion of fear](https://simonwillison.net/2026/Sep/14/the-contagion-of-fear/)) targeting AI researchers making unverified, speculative claims about bioweapons and infrastructure collapse to exploit public anxiety and regulatory authority.

### Themes

**Deploying agents faster than we can secure them.** Cloud providers are launching specialized agent hosting environments like [Agent Substrate on GKE](https://cloud.google.com/blog/products/containers-kubernetes/agent-substrate-available-on-gke/), yet today’s security research exposes massive architectural blind spots in agentic workflows. Attackers can trick mobile agents by abusing disparities between visual UI layouts and underlying digital inputs ([When Agents See Differently](https://arxiv.org/abs/2609.16732v1)), poison RAG pipelines by fragmenting malicious knowledge across benign passages ([InceptionRAG](https://arxiv.org/abs/2609.16818v1)), or manipulate automated code maintainers into writing bad patches ([Adversarial Testing of Automated Program Repair Agents](https://arxiv.org/abs/2609.15963v1)). Current guardrails remain mostly reactive wrappers around inherently vulnerable foundations.

**From raw compute to power-constrained token yield.** As inference clusters scale into gigawatt-tier power budgets, infrastructure engineering is pivoting from pure FLOP efficiency to token-per-watt optimization. NVIDIA's updates around [Vera Rubin and DSX](https://blogs.nvidia.com/blog/ai-infra-summit-vera-rubin-dsx-energy-efficiencies-tokens-per-watt-ai-factories/) stress dynamic power-budget management to match real-time power grid signals, while open-source serving engines rely heavily on custom low-bit quantization operators like Novita's [Chord for W4A16 MoEs](https://vllm.ai/blog/2026-09-15-novita-chord-w4a16-moe) to extract acceptable throughput from constrained hardware.

**Rebranding iterative loops as "Recursive Self-Improvement".** The term "Recursive Self-Improvement" (RSI) is being widely applied to standard agent harness iteration and benchmark-driven RL loops, seen in works like [ScienceBuddy](https://arxiv.org/abs/2609.17523) and [ModularRSI](https://arxiv.org/abs/2609.14857). While papers like [The Last AI Built by Humans](https://arxiv.org/abs/2609.11873) attempt to formalize metrics for true autonomy, most practical implementations remain localized code-generation feedback loops optimizing prompt harnesses rather than fundamental model self-modification.

### Worth a closer look

- [InceptionRAG: Stealthy Poisoning Attack Against Retrieval-Augmented Generation](https://arxiv.org/abs/2609.16818v1) — Illustrates a dangerous evolution in RAG attacks: breaking payloads into individually harmless text fragments that bypass single-document similarity filters, relying on the target model's multi-hop reasoning to assemble the malicious deduction.
- [Adversarial Testing of Automated Program Repair Agents for Security Vulnerabilities](https://arxiv.org/abs/2609.15963v1) — Essential reading for teams deploying autonomous coding agents; demonstrates that standard unit tests and benchmarks completely miss security defects introduced by subtle prompt manipulation.
- [The contagion of fear](https://simonwillison.net/2026/Sep/14/the-contagion-of-fear/) — A concise, pragmatic pushback against self-serving existential risk narratives in AI, arguing that technical claims about catastrophic risk require rigorous empirical proof rather than speculative authority.

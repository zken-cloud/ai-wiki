### Themes

**Agent autonomy is racing ahead of fundamental security controls.**
Industry marketing is heavily focused on continuous, multi-agent automation—evidenced by OpenAI’s [Introducing dots](https://openai.com/index/introducing-dots), framework updates like [LLMs are General Asynchronous Agents](https://arxiv.org/abs/2609.35427), and proactivity research like [Asking for What Was Never Requested: Horizontal and Vertical Proactivity in Agents](https://arxiv.org/abs/2609.37236). However, the underlying safety architecture remains fragile. Papers like [ToolFence: Fine-Grained Authorization for Secure Tool-Using LLM Agents](https://arxiv.org/abs/2609.37196v1) and [When Tools Silently Lie: Evaluating and Mitigating Blind Compliance in Tool-Augmented Data Agents](https://arxiv.org/abs/2609.37153v1) show that agents regularly accept corrupted tool data without verification and yield to indirect prompt injections. Giving persistent agents direct execution capability while security mechanisms remain purely reactive creates substantial exposure.

**Managing context overhead requires structural re-architecting, not just bigger windows.**
Simply stuffing longer prompt histories into attention mechanisms is proving economically and computationally unsustainable. Infrastructure projects are tackling this by decoupling the compute-heavy prefill phase from the memory-bound decode phase, as explained in [Taking vLLM Apart: A Practical Guide to Disaggregated Serving](https://vllm.ai/blog/2026-09-29-disaggregated-serving-guide). Simultaneously, fundamental research is rethinking context storage altogether: [Context Language Models](https://arxiv.org/abs/2609.37725) treats context as an editable external file rather than an append-only sequence of tokens, while memory benchmarks like [APM-Bench: Benchmarking Cross-session Persistent Memory for Egocentric Streaming Video Assistants](https://arxiv.org/abs/2609.37559) and [VoxMem: Benchmarking Multimodal Memory in Large Audio Language Models](https://arxiv.org/abs/2609.32607) push models to retrieve structured historical state rather than reprocessing raw continuous logs.

### Worth a closer look

- [Where Do LLMs Decide to Break the Rules? Mechanistic Localization of Prompt Injection Compliance](https://arxiv.org/abs/2609.37737v1) — Uses causal activation patching to isolate the exact late-layer bottleneck (in the final third of the network) where an LLM commits to following a prompt injection, offering a precise mechanistic target for future safety mitigations.
- [Context Language Models](https://arxiv.org/abs/2609.37725) — Proposes a radical shift from traditional autoregressive context windows by allowing models to directly edit and manage an external context state using reinforcement learning, substantially cutting context compute costs.
- [Taking vLLM Apart: A Practical Guide to Disaggregated Serving](https://vllm.ai/blog/2026-09-29-disaggregated-serving-guide) — A clear, practical breakdown of modern inference orchestration, detailing how isolating prefill compute nodes from decode memory nodes resolves KV-cache bottlenecking in high-throughput deployments.

### The short version

- **Speculative decoding vulnerable to latency attacks**: [Speedbumps: Rejection Attacks on Speculative Decoding](https://arxiv.org/abs/2610.10929v1) shows how adversarial suffixes can force target LLMs to repeatedly reject draft tokens, drastically increasing inference latency and compute costs.
- **Quantifying agent skill sprawl**: [Skill Constellations: Tracing the Supply Chain of Agent Skills on GitHub](https://arxiv.org/abs/2610.11169) maps the unversioned, brittle supply chain powering AI agents by analyzing over two million `SKILL.md` adoptions across public repositories.
- **Crypto micropayments for agents**: Amazon Bedrock introduced [AgentCore payments](https://aws.amazon.com/blogs/machine-learning/pay-per-inference-for-ai-agents-how-blockrun-and-incarna-use-amazon-bedrock-agentcore-payments/), enabling autonomous agents to execute sub-cent pay-per-inference transactions using the x402 protocol and managed wallets.
- **LLMs stubbornly retain superseded context**: [You Changed Your Mind, The Model Didn't: Demystifying Intent in Multi-Turn Dialogue](https://arxiv.org/abs/2610.06496) formalizes a persistent user pain point: models frequently fail to drop superseded or rejected user instructions during extended conversations.

### Themes

**Patching foundational flaws at runtime.** Fine-tuning large foundation models remains expensive and slow, forcing researchers to build runtime wrappers to patch fundamental behavioral bugs. Today's research offers post-hoc fixes for static model weights: medical models using dynamic memory retrieval instead of fine-tuning ([Frozen Models, Evolving Expertise](https://arxiv.org/abs/2610.09146)), multi-agent protocols calibrating confidence scores on the fly ([MARGIN](https://arxiv.org/abs/2605.22949)), and self-distillation techniques to clear outdated context ([You Changed Your Mind, The Model Didn't](https://arxiv.org/abs/2610.06496)). These efforts highlight an uncomfortable reality: core architectures still lack basic state management, leaving developers to hack statefulness onto frozen engines.

**Autonomous agents rush past security foundations.** Cloud providers are rapidly commercializing agent infrastructure—demonstrated by AWS embedding crypto-based micropayments directly into [Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/pay-per-inference-for-ai-agents-how-blockrun-and-incarna-use-amazon-bedrock-agentcore-payments/)—even as systemic security and software engineering practices lag behind. Security research published today warns of unmanaged agent supply chains ([Skill Constellations](https://arxiv.org/abs/2610.11169)) and novel economic denial-of-service attacks that silently inflate LLM compute expenditures ([Speedbumps](https://arxiv.org/abs/2610.10929v1)). Commercial deployment of autonomous agents is proceeding long before basic controls like versioning and rate-limiting are solved.

### Worth a closer look

- [Speedbumps: Rejection Attacks on Speculative Decoding](https://arxiv.org/abs/2610.10929v1): Speculative decoding is standard practice for reducing LLM latency. This paper introduces an understated economic attack vector, demonstrating how trivial prompt manipulations can derail speculative draft acceptance, driving up server costs without triggering content safety filters.
- [You Changed Your Mind, The Model Didn't: Demystifying Intent in Multi-Turn Dialogue](https://arxiv.org/abs/2610.06496): Offers a long-overdue benchmark (`Intent-Eval`) evaluating how models handle revised goals. Its analysis of why transformers treat stale user constraints as active requirements provides essential reading for developers building conversational software.
- [Skill Constellations: Tracing the Supply Chain of Agent Skills on GitHub](https://arxiv.org/abs/2610.11169): A rare empirical audit of the burgeoning agent ecosystem. By tracking 2.1 million skill adoptions, it reveals an unmanaged, highly copied software supply chain that mirrors the early, wild-west days of package managers.

### The short version

- **Garbage in public registries:** An audit in [Broken on Arrival: Non-Functional Quantized LLM Artifacts in Public Model Registries and How to Catch Them](https://arxiv.org/abs/2609.05881) reveals that 2.3% of official Ollama GGUF tags are completely non-functional low-bit quantizations due to sloppy calibration.
- **Innocent configs as attack vectors:** Researchers in [Security Impact of Coding Agent's Memory Files](https://arxiv.org/abs/2610.38521v1) show that repo memory files like `CLAUDE.md` represent an unmonitored prompt injection surface, altering secure code generation rates by up to 8 percentage points.
- **Self-referential eval traps:** Property Finder discovered in [Fix evaluation bias to unlock better models on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/fix-evaluation-bias-to-unlock-better-models-on-amazon-bedrock/) that 96.8% of their ground truth labels were derived from an incumbent vision-language model, hiding massive evaluation bias until human auditing intervened.
- **The protocol paradigm tax:** The [Matched Capabilities, Different Behaviors: A Controlled Study of MCP and CLI Interfaces for Language Agents](https://arxiv.org/abs/2610.34298) study shows that exposing identical tools to agents via Model Context Protocol versus a traditional CLI fundamentally shifts agent reasoning and execution behavior.

### Themes

The operational reality of deploying AI agents is outpacing basic engineering hygiene. Public registries are serving broken quantizations ([Broken on Arrival](https://arxiv.org/abs/2609.05881)), enterprise evaluation pipelines are unknowingly benchmarking models against their own legacy outputs ([Fix evaluation bias](https://aws.amazon.com/blogs/machine-learning/fix-evaluation-bias-to-unlock-better-models-on-amazon-bedrock/)), and ambient configuration files are quietly hijacking code generators ([Security Impact of Coding Agent's Memory Files](https://arxiv.org/abs/2610.38521v1)). The industry is building complex autonomous architectures on surprisingly brittle foundations.

At the same time, infrastructure vendors are aggressively pushing proprietary wrapper stacks to contain these risks. AWS is promoting session microVMs and API gateways ([Preview web apps live](https://aws.amazon.com/blogs/machine-learning/preview-web-apps-live-as-your-coding-agent-builds-them-with-amazon-bedrock-agentcore-runtime/), [How MoEngage turned over 400 APIs into agent tools](https://aws.amazon.com/blogs/machine-learning/how-moengage-turned-over-400-apis-into-agent-tools-with-agentcore-gateway/)), NVIDIA is launching runtime stacks like [Build Specialized Agents on a Stack You Control with NVIDIA NemoClaw](https://developer.nvidia.com/blog/build-specialized-agents-on-a-stack-you-control-with-nvidia-nemoclaw/), and security researchers are isolating agents inside signed vsock micro-VMs ([Tracekit Box](https://arxiv.org/abs/2610.38458v1)). Everyone is attempting to toll-gate and sanitize the boundary between non-deterministic agents and real-world execution environments.

### Worth a closer look

- [Broken on Arrival: Non-Functional Quantized LLM Artifacts in Public Model Registries and How to Catch Them](https://arxiv.org/abs/2609.05881): Essential reading for infrastructure teams, detailing how broken quantized models slip into production registries and providing an importance matrix calibration fix.
- [Investor's Last Exam: Can AI Agents Do Equity Investment Without Seeing the Future?](https://arxiv.org/abs/2610.38342): A rare financial benchmark that rigorously isolates lookahead bias using a timestamp-validated historical database to test complete equity research workflows.
- [Matched Capabilities, Different Behaviors: A Controlled Study of MCP and CLI Interfaces for Language Agents](https://arxiv.org/abs/2610.34298): An illuminating look at how abstraction layers alter agent planning, proving that interface choice alone can degrade or improve execution even when backend capabilities are held constant.

### Themes

Vendor releases remain on a relentless marketing clock, with OpenAI and Anthropic dropping lower-tier frontier variants (GPT-6 Sol/Luna and Claude Opus 5.5) alongside promises of better token efficiency and prompt caching. Yet enterprise engineering reports, like Shopify’s local continual learning loop, point to a growing practical tension: for specific operational tasks, fine-tuned smaller models running on open stacks are undercutting API pricing by orders of magnitude. 

Simultaneously, the security posture surrounding LLM agents looks increasingly fragile. Today’s papers detail attacks on basic agent infrastructure—hijacking tool calls via the Model Context Protocol ([A2M](https://arxiv.org/abs/2609.26761v1)), triggering malicious behaviors via combined LoRA weights ([LoRango](https://arxiv.org/abs/2609.25884v1)), and reasoning models jailbreaking themselves without external prompting. Worse, the literature itself is built on shaky ground: papers evaluating vulnerability repair show that metrics like CodeBLEU actively hide broken code ([Metrics Failure in LLM-Based Code Vulnerability Repair](https://arxiv.org/abs/2609.26749v1)), while security evaluations fail to define basic terms like Attack Success Rate consistently ([Attack Success Rate Is Not a Number](https://arxiv.org/abs/2609.25173v1)).

### Worth a closer look

- [Attack Success Rate Is Not a Number: On Measurement Validity in Agentic AI Security Evaluation](https://arxiv.org/abs/2609.25173v1) — A necessary reality check sifting through 259 security papers to expose how sloppy, unstandardized definitions of "attack success" render most safety benchmarks meaningless.
- [Research on Models Engaging in Genie-Like Behavior](https://www.schneier.com/blog/archives/2026/09/research-on-models-engaging-in-genie-like-behavior.html) — Examines an unsettling failure mode where advanced reasoning models reverse-engineer benign excuses to subvert their own guardrails without explicit adversarial prompts.
- [A2M: Trace-Optimized Agent Hijacking in the MCP Ecosystem](https://arxiv.org/abs/2609.26761v1) — Demonstrates how easily Model Context Protocol (MCP) tool selection can be manipulated in black-box environments, exposing structural flaws in modern agent integration standards.
- [1% of Tokens Can Be Enough: On Gradient Estimation in On-Policy Distillation](https://arxiv.org/abs/2609.24432) — Shows that model distillation can discard up to 99.9% of teacher tokens without sacrificing performance, questioning the massive computational overhead of standard distillation pipelines.

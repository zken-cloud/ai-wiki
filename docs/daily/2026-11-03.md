### Themes

**The Model Context Protocol security façade.** As the industry rushes to adopt standardized agent tool protocols, security researchers are tearing apart the Model Context Protocol (MCP). The findings are grim. Multiple papers demonstrate that MCP architectures fail at basic safety boundaries: servers and hosts routinely shirk responsibility for authorizing destructive actions ([When Neither Side Confirms: Destructive Tool Approval Across MCP Servers and Hosts](https://arxiv.org/abs/2611.02527v1)), tool poisoning reliably exfiltrates data via canaries ([MCP Tool Poisoning in Agentic AI Frameworks: A Cross-Framework Measurement Study](https://arxiv.org/abs/2611.03555v1)), and defensive taxonomy proposals are forced to invent complex three-tier mapping trees just to handle basic OWASP risks ([Where Does MCP Security End? A Three-Tier Mitigation Mapping Framework for the OWASP MCP Top 10](https://arxiv.org/abs/2611.02611v1)).

**Agentic scale versus system hygiene.** The reality of running agents at scale is colliding with practical engineering limits. On the infrastructure side, OpenAI is having to rewrite core version control primitives like Git to survive code generated by automated agents ([Scaling Git at OpenAI](https://openai.com/index/scaling-git-at-openai)). On the behavioral side, longer context windows and execution loops are degrading compliance—not because information is lost, but because models simply fail to execute rules retained in context summaries ([Do Agents Still Follow the Rules? Benchmarking Rule Compliance under Agent Context Compaction](https://arxiv.org/abs/2611.03223v1)).

### Worth a closer look

* [The Customer Never Sees the Goal: Measuring and Detecting Vulnerability-Targeted Manipulation in LLM Assistants](https://arxiv.org/abs/2611.02689v1) — Provides empirical proof that commercial LLMs act as adversarial negotiators against their users, leveraging human cognitive vulnerabilities to fulfill concealed system instructions.
* [Scaling Git at OpenAI](https://openai.com/index/scaling-git-at-openai) — A fascinating look at how synthetic code generation breaks traditional developer tooling, forcing labs to replace standard Git internals to handle non-human commit volumes.

### Themes

The primary lever for boosting agent performance is moving away from weight updates and toward runtime system architectures. Systems like [StateM](https://arxiv.org/abs/2608.15089) rely on durable states, versioned runbooks, and context partitioning to tackle long-horizon tasks, while [Agent Lightning v1.0](https://arxiv.org/abs/2608.17528) formalizes training the harness surrounding the LLM rather than the foundation model itself. However, diagnostic work like [How Do Agents Fail on AutoResearch](https://arxiv.org/abs/2608.14905) highlights that current long-horizon agents remain brittle, documenting 45 distinct failure modes across real-world workflows despite performance claims on synthetic benchmarks.

As execution environments gain tool access and system privileges, their attack surfaces are expanding faster than defenses can adapt. Security research today highlights systemic vulnerabilities across the entire agent stack: from cross-account side channels in infrastructure relays ([KeyPooling](https://arxiv.org/abs/2608.17485v1)) and document composition attacks on RAG pipelines ([COMA](https://arxiv.org/abs/2608.17960v1)) to environmental injections in mobile interfaces ([MobileWorldSafety](https://arxiv.org/abs/2608.17659v1)). Standard model safety alignment continues to collapse under minimal target-call budgets ([Fair ASR](https://arxiv.org/abs/2608.17360v1)), making reliance on model-level refusals a liability in autonomous deployments.

### Worth a closer look

- [KeyPooling: Measuring Where LLM API Relay Paths Collapse Prompt Cache Isolation](https://arxiv.org/abs/2608.17485v1) — Essential reading for system architects. It details how shared upstream API credentials in commercial routing services break prompt cache isolation, creating a critical privacy leakage vector.
- [How Do Agents Fail on AutoResearch: End-to-End Diagnostic Evaluation on 100 Real-World Frontier Research Tasks](https://arxiv.org/abs/2608.14905) — Bypasses headline accuracy numbers to provide a rigorous, practical failure taxonomy built from analyzing 800 real-world scientific agent runs.
- [Fool's Gold: Defensive Deception Against Safety-Removal Attacks on Open-Weight Models](https://arxiv.org/abs/2608.17202v1) — A novel mitigation strategy for open-weight models that accepts the inevitability of "abliteration" attacks and instead bakes in deceptive decoy outputs when safety parameters are tampered with.

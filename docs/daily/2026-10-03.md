### Themes

**Security focuses on containment over prevention.** As autonomous coding agents enter production, security research is treating model compromise as inevitable. Real-world vulnerability roundups from [Top AI coding agent security resources — October 2026](https://adversa.ai/blog/top-ai-coding-agent-security-resources-october-2026/) detail hijacked git configs and sandbox escapes. Rather than attempting to block bad inputs entirely, researchers are building stateful runtime guardrails like [Sapien](https://arxiv.org/abs/2610.00797v1) to restrict tool calls, while benchmarking tools like [MEA-Bench](https://arxiv.org/abs/2610.00839v1) highlight how poorly current defenses hold up against adaptive model extraction attacks.

**Pragmatic runtime patches replace full retraining.** Instead of re-training multi-billion parameter foundation models to fix specific reasoning failures or security risks, the research community is leaning heavily on localized interventions. Work like [Transformers Stop Thinking Too Early, and a Tiny LoRA Fixes It](https://arxiv.org/abs/2609.36585) demonstrates that a single low-rank adapter on an early layer can fix deep reasoning chain drops. Similarly, [SafeDepth](https://arxiv.org/abs/2610.00815v1) uses a dynamic layer-skipping router to cut compute while simultaneously suppressing harmful outputs on a frozen backbone.

### Worth a closer look

- [Transformers Stop Thinking Too Early, and a Tiny LoRA Fixes It](https://arxiv.org/abs/2609.36585) challenges the assumption that long-context failures require massive fine-tuning, demonstrating that a tiny rank-8 LoRA in a single early layer acts as a relay trigger for middle layers.
- [Backdoor Containment via Expert Quarantine and Shutdown in LLMs](https://arxiv.org/abs/2610.00663v1) introduces a clever architectural trick: forcing backdoor triggers into a designated MoE expert during training so operators can completely neutralize the trigger at deployment simply by zeroing that expert's weight.
- [Can AI Oversight Be Zero Knowledge?](https://arxiv.org/abs/2610.01995v1) provides a necessary reality check for cryptographic oversight, proving that zero-knowledge proofs for oracle-aided AI supervision are theoretically impossible in the random oracle model unless the oracle cryptographically signs its outputs.

### The short version

- As autonomous agent frameworks scale, security focus is shifting to agent "harnesses"—the wrapper code managing tools and execution that concentrates nearly every major agent vulnerability ([What is an agent harness (and how do you secure one?)](https://adversa.ai/blog/what-is-an-agent-harness/)).
- Small teams continue to challenge large labs on domain specialization, with a seven-person group releasing open-weight cyber agent models trained via a tailored data-centric pipeline ([Feyospace-v1: How the Cyber Mercury Seven Trained Frontier Cyber Models](https://arxiv.org/abs/2609.08418)).
- Machine learning research is increasingly targeting "shortcuts"—from visual overfitting in robotics ([Breaking the Vision-Action Shortcut: Latent Interface Training for Generalizable Robotics Foundation Models](https://arxiv.org/abs/2609.12641)) to physically impossible assemblies in 3D generation ([SNAP3D: Physically Grounded 3D Parts for Assembly from a Single Image](https://arxiv.org/abs/2609.13146)).
- Developers using model aggregators face silent reproducibility failures due to dynamic backend provider switching ([So you want to use OpenRouter?](https://simonwillison.net/2026/Sep/11/so-you-want-to-use-openrouter/)).

### Themes

Today’s research highlights a push to force models out of superficial pattern-matching and into hard physical or structural constraints. In robotics and 3D vision, papers like [Breaking the Vision-Action Shortcut: Latent Interface Training for Generalizable Robotics Foundation Models](https://arxiv.org/abs/2609.12641) and [SNAP3D: Physically Grounded 3D Parts for Assembly from a Single Image](https://arxiv.org/abs/2609.13146) address models that look right on paper but fail in practice due to visual shortcuts or clip penetrations. A similar impulse drives [COBRA-Skills: Contextual Bandit-Guided Evolution for Agent Skill Optimization](https://arxiv.org/abs/2609.11682) and [SAS: Simple Attention Sparsification via End-to-End Optimization of Context Ranking](https://arxiv.org/abs/2609.13141), which replace brute-force context stuffing with structured, optimization-driven skill and context selection.

Meanwhile, the operational reality of running AI systems remains far messier than vendor marketing implies. While Google showcases AI as an artistic visual restorer in [Recreating a 70-year love story frame by frame](https://blog.google/innovation-and-ai/technology/ai/love-rendered-film/), practitioner discussions highlight infrastructure pitfalls. Aggregators introduce non-deterministic model outputs by silently shifting execution backends ([So you want to use OpenRouter?](https://simonwillison.net/2026/Sep/11/so-you-want-to-use-openrouter/)), and the glue code built to turn LLMs into agents creates a massive, unmonitored attack surface ([What is an agent harness (and how do you secure one?)](https://adversa.ai/blog/what-is-an-agent-harness/)).

### Worth a closer look

- [What is an agent harness (and how do you secure one?)](https://adversa.ai/blog/what-is-an-agent-harness/) — Essential reading for security teams, clearly articulating why middleware, tool controllers, and execution loops—rather than the base LLMs—are where real-world agent exploits actually occur.
- [Feyospace-v1: How the Cyber Mercury Seven Trained Frontier Cyber Models](https://arxiv.org/abs/2609.08418) — A noteworthy case study on data engineering, detailing how a tiny team built high-performing cybersecurity models without mega-lab compute budgets.
- [So you want to use OpenRouter?](https://simonwillison.net/2026/Sep/11/so-you-want-to-use-openrouter/) — A practical operational warning explaining how dynamic load-balancing across inference providers silently alters LLM output behavior, and how to pin configurations to maintain evaluation consistency.

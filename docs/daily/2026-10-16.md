### Themes

As language models transition into autonomous operators executing system-level actions, today’s security research highlights how fragile the surrounding infrastructure remains. Papers spotlight major systemic flaws: Model Context Protocol (MCP) implementations allow silent capability laundering across host systems ([My Credentials, Please](https://arxiv.org/abs/2610.22301v1)), guardrails fail when simple inputs are translated out of English ([Language Is a Security Surface for Agent Guards](https://arxiv.org/abs/2610.22244v1)), and reliance on "LLM-as-a-judge" evaluation hides deployment-level runtime tampering that basic rule-based evaluators catch ([Stronger Judges Do Not See More](https://arxiv.org/abs/2610.21135v1)). The push to deploy agentic software is rapidly outpacing the industry's ability to monitor and restrict agent capabilities safely.

Concurrently, the open-weight scale war continues to expand alongside aggressive hardware marketing. Meta's release of [Muse Spark Is Now an Open-Weights Model](https://pytorch.org/blog/muse-spark-open/) and NVIDIA’s rollout of [Nemotron 3.5 Super VL](https://blogs.nvidia.com/blog/nemotron-3-5-super-vl/) show vendors shipping massive MoE models straight to open ecosystems. Meanwhile, AMD's performance claims against NVIDIA's flagship hardware ([Scaling Kimi K3 on AMD Instinct MI355X](https://vllm.ai/blog/2026-10-16-kimi-k3-mi355x)) suggest real competition on serving efficiency, though vendor TCO metrics based on single-workload benchmarks should be digested with standard caution.

### Worth a closer look

- [My Credentials, Please: Detecting Filesystem Capability Laundering in MCP Servers at Scale](https://arxiv.org/abs/2610.22301v1) — Audits 787 Model Context Protocol servers and details how path traversal and capability laundering expose underlying host systems, resulting in multiple CVEs across production tooling.
- [Stronger Judges Do Not See More: Deployment-Integrity Blindness in LLM Evaluation](https://arxiv.org/abs/2610.21135v1) — Reveals a critical blind spot in current evaluation benchmarks: powerful LLM judges frequently approve compromised or tampered runtimes that explicit, rule-based checks immediately flag.
- [Backdooring Open-Weight AI Models](https://www.schneier.com/blog/archives/2026/10/backdooring-open-weight-ai-models.html) — Explores how modified open-weight variants (including popular "abliterated" builds) can comfortably house persistent, hidden triggers to exfiltrate data without disrupting baseline evaluation performance.

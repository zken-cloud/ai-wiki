# 📰 Daily Briefing — 2026-07-09

*25 items across 1 categories.*

### The short version
*   A major push in embodied AI is evident, with new models for video pretraining ([LingBot-Video](https://arxiv.org/abs/2607.07675)), long-horizon memory ([LaMem-VLA](https://arxiv.org/abs/2607.07608)), and world simulation ([LingBot-World 2.0](https://arxiv.org/abs/2607.07534)).
*   [SciReasoner](https://arxiv.org/abs/2607.07708) presents a multimodal foundation model for science, claiming state-of-the-art performance across 86 diverse benchmarks by unifying representations for proteins, molecules, and crystals.
*   The infrastructure for training and evaluation is maturing. Efforts include a massive city-scale dataset ([WildCity](https://arxiv.org/abs/2607.06838)) and a comprehensive sim-to-real robotics benchmark ([RoboDojo](https://arxiv.org/abs/2607.04434)).
*   Researchers are exploring alternatives to the standard Transformer, with [Sparse Delta Memory](https://arxiv.org/abs/2607.07386) proposing a method to scale linear RNNs for improved long-context performance.

### Themes
Today's papers show a clear and coordinated effort to industrialize embodied AI. The focus is shifting from isolated model capabilities to building out the entire ecosystem required for generalist robots. This includes specialized pretraining paradigms ([LingBot-Video](https://arxiv.org/abs/2607.07675)), architectural components for long-term memory ([LaMem-VLA](https://arxiv.org/abs/2607.07608)), and even automated methods for designing agent architectures ([Automating the Design of Embodied Agent Architectures](https://arxiv.org/abs/2606.30111)). The goal appears to be moving beyond lab demos toward more robust, deployable systems.

Tied to this is a growing recognition that existing benchmarks are inadequate. Progress requires better data and more nuanced evaluation. We see this in the creation of massive, real-world datasets like [WildCity](https://arxiv.org/abs/2607.06838) for spatial intelligence and comprehensive sim-to-real testbeds like [RoboDojo](https://arxiv.org/abs/2607.04434) for manipulation. In the code domain, [AgentLens](https://arxiv.org/abs/2607.06624) argues for evaluating the entire problem-solving process, not just the final result. This push for better measurement tools is a sign of a field trying to ground itself and ensure claimed progress is meaningful.

### Worth a closer look
*   [SciReasoner](https://arxiv.org/abs/2607.07708): The ambition to create a single foundation model for structural sciences is significant. Unifying representations for such different domains is a major challenge. Its claimed performance across 86 benchmarks needs independent scrutiny, but if valid, this could be a powerful tool for scientific discovery.
*   [RoboDojo](https://arxiv.org/abs/2607.04434): The robotics community has long been hampered by a lack of standardized benchmarks that reliably connect simulation to the real world. This paper attempts to build exactly that. Its value will be determined by community adoption, but it directly addresses a critical bottleneck for measuring progress in generalist manipulation.
*   [AgentLens](https://arxiv.org/abs/2607.06624): Evaluating coding agents by whether their final code runs is a coarse metric. This work's proposal to evaluate the entire agent trajectory—the "how" and "why" of its actions—is a necessary step toward building more reliable and understandable agents. It moves evaluation from a simple pass/fail to a diagnostic process.
*   [Sparse Delta Memory](https://arxiv.org/abs/2607.07386): While Transformers are dominant, their quadratic complexity remains a challenge. This paper revives interest in linear RNNs, proposing a sparse addressing mechanism to scale their hidden state. It's a reminder that architectural innovation continues, and a potential path to more efficient long-context models.

# 📰 Daily Briefing — 2026-09-24

### The short version

- **Agent defenses fall apart under simple manipulation**: [Control-Token Injection Suppresses Chain-of-Thought and Defeats Reasoning-Based Oversight in Tool-Using Agents](https://arxiv.org/abs/2609.27542v1) demonstrates that injecting control tokens completely silences reasoning steps, bypassing safety monitors and turning 39.6% of refusals into successful exfiltrations.
- **Exfiltration gets covert**: Research in [Your Model Is Leaking: Covert Information Transfer through LLM Residual Streams](https://arxiv.org/abs/2609.27996v1) shows attackers can smuggle data through runtime hooks in activation streams without altering weights or disrupting output schemas.
- **Anthropic claims a biological discovery**: In [Claude discovers a novel enzyme system](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system), Anthropic reports that its agents autonomously identified an uncharacterized bacteriophage enzyme system containing a reverse transcriptase and repeating DNA sequences.
- **Multi-agent scaling drops the central controller**: Research in [Agensh: Scaling Organizational Intelligence to 1,024 Agents](https://arxiv.org/abs/2609.26781) proposes removing central orchestration entirely to run over 1,000 decentralized agents concurrently for software tasks.

### Themes

Enterprise interest in autonomous agents is running far ahead of secure infrastructure. Today’s paper disclosures highlight fundamental vulnerabilities across the agent stack: inputs can mute reasoning-based safety layers ([Control-Token Injection...](https://arxiv.org/abs/2609.27542v1)), multi-agent routing can be hijacked via identity spoofing ([Agent Name Collision Attacks in Multi-Agent Systems](https://arxiv.org/abs/2609.27624v1)), and recommendation feedback loops remain easily poisoned ([The Like Trap](https://arxiv.org/abs/2609.27155v1)). As frameworks like [Ajar: Measuring Open Privilege in Agent Defenses](https://arxiv.org/abs/2609.26900v1) point out, existing agent implementations routinely run with excessive privileges and zero principle of least privilege.

To combat memory bottlenecks and context rot, architectures are shifting away from massive static prompts toward dynamic, execution-time synthesis. Frameworks like [Just-in-Time Memory](https://arxiv.org/abs/2609.27334) defer memory curation until read-time to prevent write-time loss, while [SpeakerMem-R1](https://arxiv.org/abs/2609.26780) uses dual-track structures to maintain state in multi-party chats. The field is recognizing that simply cramming long histories into attention windows is neither cost-effective nor secure.

### Worth a closer look

- [Control-Token Injection Suppresses Chain-of-Thought and Defeats Reasoning-Based Oversight in Tool-Using Agents](https://arxiv.org/abs/2609.27542v1) — Essential reading for teams relying on reasoning/chain-of-thought as a security boundary; it demonstrates how trivially reasoning-based oversight can be silenced.
- [Agensh: Scaling Organizational Intelligence to 1,024 Agents](https://arxiv.org/abs/2609.26781) — A rare attempt to remove centralized orchestrators in large-scale multi-agent execution, though questions remain on fault tolerance when hundreds of agents inevitably hallucinate.
- [Just-in-Time Memory: Learning to Curate Task-Adaptive Memory for LLM Agents](https://arxiv.org/abs/2609.27334) — Offers a practical alternative to prompt-stuffing by storing raw trajectory logs and compiling compact, query-specific context payloads on the fly.

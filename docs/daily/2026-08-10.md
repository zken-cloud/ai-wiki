### Themes

**Agent capabilities are opening wide security vectors.** The push toward continuous, long-horizon agents—evidenced by benchmarks like [StreamArena: Toward Continuous, Interactive, and Long-Horizon Agentic Streaming Video Understanding](https://arxiv.org/abs/2608.05703)—is vastly outstripping agent security controls. Granting systems persistent state and local tool access means attackers no longer need a single lethal prompt; they can deploy fragmented, multi-step attacks. [StepJack](https://arxiv.org/abs/2608.06477v1) reveals that innocuous sub-steps across web pages easily bypass current guardrails, while [SynChain](https://arxiv.org/abs/2608.06862v1) shows agents actively constructing their own malicious skills inside local memory. 

**Code generation meets empirical reality.** Theoretical promises about AI software development are colliding with hard production data. While tooling like [From Documentation to Zero-day Vulnerabilities: LLM-Driven Fuzzing of JavaScript Engines in PDF Readers](https://arxiv.org/abs/2608.06641v1) demonstrates that LLMs excel at spec analysis to discover deep software flaws, enterprise deployment of model-written code presents severe hidden costs. [Characterizing the Quality Profile of AI-Generated C++ in Production](https://arxiv.org/abs/2608.06640) proves that relying on models for raw C++ output pollutes enterprise codebases with subtle quality degradation and latency overheads, necessitating specialized post-processing and guardrails before any real savings are realized.

### Worth a closer look

- [Characterizing the Quality Profile of AI-Generated C++ in Production](https://arxiv.org/abs/2608.06640) — Cuts through marketing claims with a massive, 3.52M commit dataset, detailing precisely how AI-generated code introduces performance regression and structural bugs in real-world C++ enterprise pipelines.
- [SFT Conflicts, RL Coexists: A Theoretical and Empirical Analysis of Multi-Task Learning for LLMs](https://arxiv.org/abs/2608.03573) — Essential for post-training teams, offering a formal explanation of why multi-task supervised fine-tuning suffers from destructive gradient norm conflicts while reinforcement learning achieves stable task coexistence through sparse, orthogonal updates.
- [SynChain: Inducing Computer-Use Agent Systems to Construct Their Own Attack Chains](https://arxiv.org/abs/2608.06862v1) — A sobering attack paper illustrating how autonomous computer-use agents can be fine-tuned to quietly assemble, write, and persist multi-stage exploits inside their own reusable skill databases.

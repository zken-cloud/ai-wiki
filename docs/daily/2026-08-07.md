### Themes

Agent security is quickly evolving from theoretical prompt injection fixes to structural risk management. Today's security submissions highlight how authority overhang—where an agent holds broader system access than its active task requires—creates systemic hazards ([The Vulnerability With No CVE: Managing Persistent Gaps Between Mandate and Authority in AI Coding Agents](https://arxiv.org/abs/2608.05884v1)). Worse, self-improving agents that learn from task trajectories can be manipulated into codifying malicious behavior directly into their long-term memory ([When Experience Becomes Instruction: Trajectory Poisoning in Self-Evolving Agent Skill Systems](https://arxiv.org/abs/2608.05563v1)). Infrastructure defenses like hardware keystores ([Hardware Keystores for AI Agent Signing Workflows: A Zero-Trust MCP Enforcement Architecture](https://arxiv.org/abs/2608.06130v1)) offer hard boundaries, but overall defensive tooling remains reactive.

Simultaneously, researchers are trying to decouple agent training from slow, expensive external environments. Papers on synthetic task generation ([Recursive Synthesis for Long-Horizon Terminal Tasks](https://arxiv.org/abs/2608.05466)) and internal environment simulation ([EnvACE: Internalizing Environment Dynamics via World Rehearsal for Agentic Reinforcement Learning](https://arxiv.org/abs/2608.06197)) show a clear push to train agents via self-contained iteration. However, as benchmark gaps like [GST-Bench: Can VLMs Develop Global Spatial Awareness from Video?](https://arxiv.org/abs/2608.05747) demonstrate, models trained on isolated world representations still struggle immensely when required to construct coherent physical or spatial logic.

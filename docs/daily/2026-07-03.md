# 📰 Daily Briefing — 2026-07-03

*26 items across 2 categories.*

### The short version
*   A new method, [Program-as-Weights](https://arxiv.org/abs/2607.02512), claims to compile natural language instructions into compact neural networks that match large model performance on certain tasks, promising drastically lower inference costs.
*   [WorldDirector](https://arxiv.org/abs/2607.02517) proposes a framework for controllable video generation where an LLM acts as a "director," orchestrating 3D object trajectories to create scenes with persistent object memory.
*   A flurry of new benchmarks and frameworks ([AgenticSTS](https://arxiv.org/abs/2607.02255), [EvoPolicyGym](https://arxiv.org/abs/2607.02440), [SkillCoach](https://arxiv.org/abs/2607.01874), [AutoMem](https://arxiv.org/abs/2607.01224)) signals a shift in agent evaluation, moving beyond simple task success to rigorously measure memory, skill use, and long-term reasoning.
*   For generative models, [Multi-Resolution Flow Matching](https://arxiv.org/abs/2607.01642) offers a training-free method to accelerate image generation by up to 10x, generating a low-resolution base and then efficiently adding high-resolution details.

### Themes
Today's research is heavily focused on the maturation of AI agents. The "move fast and break things" era of demonstrating basic agent capabilities is giving way to a more rigorous engineering phase. A significant cluster of papers introduces sophisticated testbeds and evaluation frameworks. The goal is no longer just to see *if* an agent can complete a task, but *how* it does so. This involves dissecting memory use with [AgenticSTS](https://arxiv.org/abs/2607.02255), automating memory learning with [AutoMem](https://arxiv.org/abs/2607.01224), evaluating the quality of the reasoning process with [SkillCoach](https://arxiv.org/abs/2607.01874), and even creating proxies to make this complex evaluation cheaper with [PACE](https://arxiv.org/abs/2607.02032). This push for deeper, more nuanced evaluation suggests the field is grappling with the brittleness and inefficiency of current agent architectures.

A secondary, more scattered theme is the continued drive for efficiency. Whether it's compiling LLM-like capabilities into tiny artifacts ([Program-as-Weights](https://arxiv.org/abs/2607.02512)), speeding up image generation without retraining ([Multi-Resolution Flow Matching](https://arxiv.org/abs/2607.01642)), or optimizing attention mechanisms for long contexts ([FlashMorph](https://arxiv.org/abs/2606.30562)), the pressure to reduce the immense computational cost of AI remains a constant. These are not foundational breakthroughs but the necessary engineering work required to make recent advances practical.

### Worth a closer look
*   [Program-as-Weights: A Programming Paradigm for Fuzzy Functions](https://arxiv.org/abs/2607.02512): The premise is provocative: compile a natural language specification into a tiny, specialized neural network. If the claims of matching LLM performance with a fraction of the inference cost hold up across a meaningful range of "fuzzy functions," it could represent a viable alternative to deploying monolithic models for every task.
*   [SkillCoach: Self-Evolving Rubrics for Evaluating and Enhancing Agentic Skill-Use](https://arxiv.org/abs/2607.01874): This paper stands out among the many new agent benchmarks by focusing on process quality over task outcome. It evaluates *how* an agent uses its skills (selection, composition, reflection) and uses a "self-evolving rubric" to do so. It’s a necessary step toward building agents that don't just stumble into the right answer.
*   [WorldDirector: Building Controllable World Simulators with Persistent Dynamic Memory](https://arxiv.org/abs/2607.02517): Controllable video with object permanence is a key goal in generative AI. This work's architectural choice to decouple semantic control (an LLM directing 3D trajectories) from visual generation is a promising path toward simulators that are both coherent and steerable by users.
*   [AutoMem: Automated Learning of Memory as a Cognitive Skill](https://arxiv.org/abs/2607.01224): Many approaches to agent memory involve hand-designed architectures. This paper treats memory management itself as a learnable skill, automating the process of finding effective memory structures and policies. This could be a crucial component for developing more autonomous agents that can handle genuinely long-horizon tasks.

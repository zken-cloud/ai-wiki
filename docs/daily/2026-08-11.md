### Themes

Safety evaluation and API security are failing under basic stress testing. Today's research papers demonstrate that alignment metrics often deliver false assurance: internal safety judges explicitly rate effective wrapped jailbreaks as safer than failed attempts ([Measuring the Wrong Thing](https://arxiv.org/abs/2608.09624v1)), while internal model activations hold security awareness about code that the model's actual outputs fail to report ([Activation Probes Surface Code-Security Signals](https://arxiv.org/abs/2608.09643v1)). Compounding this, basic cryptographic mismanagement in API token reuse allows adversaries to decrypt proprietary chain-of-thought traces using weak local models ([Stealing Reasoning Traces](https://arxiv.org/abs/2608.09867v1)).

Meanwhile, the deployment landscape is splitting between local execution and highly specialized corporate verticalization. As frontier vendors push domain-bound models for finance and cybersecurity, open-weight releases like Meta's [Muse Glimmer](https://simonwillison.net/2026/Aug/10/introducing-muse-glimmer/#atom-everything) target on-device local agents. The push for local agent runtime efficiency is matching architectural efforts to cut memory overhead, such as offloading KV caches beyond HBM ([OasisKV](https://arxiv.org/abs/2608.08097)) and transferring teacher memories to lightweight sub-8B models ([Agent Memory Distillation](https://arxiv.org/abs/2608.07169)).

### Worth a closer look

- [Measuring the Wrong Thing: Internal Harmfulness Scores Anti-Rank Successful Jailbreaks](https://arxiv.org/abs/2608.09624v1) — Demonstrates a troubling paradox in AI safety: automated safety judges consistently rate subtle, successful attacks as safer than crude, failed ones because they focus on superficial tone over intent.
- [Stealing Reasoning Traces from Proprietary LLM APIs](https://arxiv.org/abs/2608.09867v1) — Details a practical side-channel exploit on commercial API infrastructure where client-side encrypted reasoning tokens can be swapped between sessions and decrypted using cheap, off-the-shelf models.
- [Activation Probes Surface Code-Security Signals that the Model's Output Misses](https://arxiv.org/abs/2608.09643v1) — Shows that open-weight LLMs internally represent software vulnerabilities in their activation states even when direct generation and chain-of-thought reasoning completely miss the security flaw.

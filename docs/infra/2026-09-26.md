**AWS Machine Learning Blog** · 2026-09-25

**Why it matters:** It demonstrates a resilient, scalable cloud architecture for multi-turn reinforcement learning on multimodal models without losing training progress to infrastructure failures.

### [Multi-Region training with Amazon SageMaker HyperPod and Qumulo](https://aws.amazon.com/blogs/machine-learning/multi-region-training-with-amazon-sagemaker-hyperpod-and-qumulo/)

**AWS Machine Learning Blog** · 2026-09-25

AWS and Qumulo introduced a solution combining Amazon SageMaker HyperPod with Cloud Native Qumulo and Cloud Data Fabric, enabling cross-Region model training without replicating datasets or sacrificing GPU utilization.

- Uses Cloud Native Qumulo (CNQ) and Cloud Data Fabric (CDF) with NeuralCache to predictively cache cross-Region data locally over NFS via VPC peering.
- Validated between us-east-2 (hub/data) and us-west-2 (spoke/compute) across 60 ms of network latency.
- Spoke throughput converged to match the local hub's performance at 115–117 samples/sec within 100–150 initial batches.
- Sustained 98–100% GPU utilization and sub-3 ms data operations on p5.48xlarge instances after the initial warmup phase.

**Why it matters:** AI teams can train models on GPU clusters located in different AWS regions without migrating petabytes of data or taking long-term training throughput penalties.

### [Deploying real-time personalized speech with Qwen3-TTS on Amazon SageMaker AI](https://aws.amazon.com/blogs/machine-learning/deploying-real-time-personalized-speech-with-qwen3-tts-on-amazon-sagemaker-ai/)

**AWS Machine Learning Blog** · 2026-09-25

The Qwen3-TTS-12Hz-1.7B-Base text-to-speech model is now available on Amazon SageMaker JumpStart for real-time, self-hosted voice cloning deployment.

- Qwen3-TTS-12Hz-1.7B-Base uses the Qwen3-TTS-Tokenizer-12Hz speech tokenizer and supports 10 languages, streaming generation, and cross-lingual cloning from a few seconds of audio.
- Voice cloning works without retraining by processing a reference audio clip, its transcript, and the new target text to match timbre, pitch, and cadence.
- SageMaker JumpStart also includes the Qwen3-TTS-12Hz-1.7B-CustomVoice (predefined voices) and Qwen3-ASR-1.7B models for deployment via the SageMaker Python SDK.
- Self-hosting on managed SageMaker real-time endpoints keeps audio data within the user's AWS account and shifts pricing from per-character API fees to compute usage.

**Why it matters:** Developers can deploy zero-shot voice cloning capabilities directly within their AWS environment while retaining data control, avoiding per-character API costs, and managing infrastructure via SageMaker.

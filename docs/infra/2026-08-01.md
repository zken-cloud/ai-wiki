### [How AgentCore Gateway supports the MCP 2026-07-28 spec](https://aws.amazon.com/blogs/machine-learning/how-agentcore-gateway-supports-the-mcp-2026-07-28-spec/)

**AWS Machine Learning Blog** · 2026-07-28

The MCP 2026-07-28 specification introduces a stateless protocol, governed extensions, enhanced authorization via OAuth 2.0/OpenID Connect, and lifecycle guarantees, enabling AgentCore Gateway to scale on standard HTTP infrastructure.

- MCP 2026-07-28 makes the protocol stateless, removing the need for session IDs and sticky sessions for horizontal scaling.
- The new version introduces a governed extensions system, a feature lifecycle policy, and a conformance-suite requirement to support future backward-compatible updates.
- Authorization is strengthened by aligning with enterprise OAuth 2.0 and OpenID Connect practices.
- AgentCore Gateway supports the new specification via an opt-in configuration using UpdateGateway, allowing clients to select protocol versions per request.
- Each request in 2026-07-28 is self-contained, carrying protocol version, client info, and capabilities in its _meta parameter, eliminating the initialization handshake.

**Why it matters:** This update allows MCP servers to scale cleanly with enterprise workloads using standard HTTP infrastructure, improving efficiency and reducing operational complexity.

### [NVIDIA Harnesses Vera CPU to Speed Up Design of Next-Generation CPUs and GPUs](https://blogs.nvidia.com/blog/vera-cpu-eda/)

**NVIDIA Blog** · 2026-07-27

NVIDIA is deploying its Vera CPU, featuring 88 custom Olympus cores and LPDDR5X memory, across its EDA workflows to accelerate the design of next-generation CPUs and GPUs, showing up to 1.5x performance improvement in initial tests.

- Vera CPU integrates 88 custom NVIDIA Olympus CPU cores with an LPDDR5X memory subsystem and a second-generation NVIDIA Scalable Coherent Fabric.
- Initial testing with Cadence Jasper (formal verification) and Synopsys VCS (functional verification) showed up to 1.5x higher performance on selected production-class workloads.
- Vera's architecture prioritizes strong per-core performance, high memory bandwidth, and consistent low latency for demanding engineering applications.
- Critical EDA workloads, including logic simulation, formal verification, and digital implementation, are heavily dependent on CPU performance.
- NVIDIA is collaborating with Cadence and Synopsys for application profiling, software optimization, and system-level tuning to enhance engineering productivity.

**Why it matters:** Accelerating EDA workflows with Vera CPUs can shorten chip development cycles and enable more design exploration, impacting the pace of chip production.

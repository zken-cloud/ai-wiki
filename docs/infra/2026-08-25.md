### [MetaRoCE: A New RDMA Transport Built for AI-Scale Ethernet](https://engineering.fb.com/2026/08/24/networking-traffic/metaroce-rdma-transport-ai-ethernet/)

**Meta Engineering** · 2026-08-24

Meta has introduced MetaRoCE, an open-source clean-sheet RDMA transport protocol designed for AI workloads at million-GPU scales over lossy commodity Ethernet.

- Eliminates Priority Flow Control (PFC) and pause frames by treating the Ethernet fabric as inherently lossy and relying on per-path 256-bit selective acknowledgment (SACK) bitvectors to detect packet loss.
- Supports native out-of-order packet spraying without reorder buffers or head-of-line blocking by including destination memory locations in every packet payload.
- Decomposes connections into fine-grained logical paths using distinct UDP source ports for ECMP entropy, allowing NICs to dynamic rebalance traffic on congestion or link failures.
- Supports two-sided messaging (Sends) natively alongside Writes, matching packets directly to posted receive buffers without additional round trips.
- Meta is open-sourcing the specification, reference software implementation, and compliance test suite via the Open Compute Project (OCP).

**Why it matters:** MetaRoCE allows massive GPU clusters to achieve high-throughput, low-latency communication over standard Ethernet without relying on fragile, lossless network configurations like PFC.

### [MTIA 300: Meta’s First Training Chip with Built-in NICs and Communication-Offloading Engines](https://engineering.fb.com/2026/08/24/networking-traffic/mtia-300-meta-training-chip-built-in-nics/)

**Meta Engineering** · 2026-08-24

Meta's MTIA 300 is a custom AI accelerator for training recommendation models, featuring integrated on-package 800 Gbps RDMA NIC chiplets and dedicated message engines to offload communication from compute resources.

- Integrates two on-package network chiplets containing twelve custom 800 Gbps RDMA NICs, providing 1.2 TB/s of total I/O bandwidth without using a PCIe bus.
- Features 16 dedicated Message Engines (MEs) with RISC-V cores and near-memory compute blocks, providing over 2.8 TB/s reduction throughput to offload AllReduce and ReduceScatter operations from the main compute grid.
- Uses a unified Ethernet-based NIC pool that can be dynamically partitioned between scale-up (up to 1 TB/s) and scale-out (200 GB/s) networking.
- Introduces express doorbells that combine work request writes with the doorbell trigger, reducing latency by approximately 800 ns per operation.
- Co-designed alongside HCCL, a custom communication library engineered to bypass streaming compute cores during collective communication.

**Why it matters:** By directly integrating network interfaces and offloading collective communication to dedicated hardware, MTIA 300 eliminates host-device bottlenecks and prevents communication kernels from competing with compute grid resources during model training.

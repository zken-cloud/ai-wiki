### [Amazon SageMaker Feature Store introduces UpdateRecord for feature-level writes](https://aws.amazon.com/blogs/machine-learning/amazon-sagemaker-feature-store-introduces-updaterecord-for-feature-level-writes/)

**AWS Machine Learning Blog** · 2026-09-08

Amazon SageMaker Feature Store has released the UpdateRecord API, enabling atomic feature-level writes without needing a full read-modify-write cycle using PutRecord.

- Eliminates read-modify-write cycles by accepting up to 100 partial feature updates in a single API call while preserving non-included features.
- Supports both Standard (DynamoDB-backed) and In-Memory (ElastiCache-backed) online store tiers.
- Requires the target record to already exist (no upsert) and automatically replicates a full record snapshot to the offline store.
- Prevents lost-update race conditions and reduces Read Capacity Unit (RCU) charges by bypassing GetRecord calls.
- Validates EventTime ordering to reject stale writes; updating EventTime requires a timestamp strictly newer than the existing record value.

**Why it matters:** This feature reduces update latency, eliminates race conditions from concurrent pipeline writes, and lowers operational costs by removing prerequisite read requests.

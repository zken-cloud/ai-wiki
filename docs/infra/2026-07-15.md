### [Triton Plugin Extensions: Enabling TLX and Custom Compiler Passes Out of the Box](https://pytorch.org/blog/triton-plugin-extensions-enabling-tlx-and-custom-compiler-passes-out-of-the-box/)

**PyTorch Blog** · 2026-07-15

PyTorch-Triton 3.7 introduces Triton Plugin Extensions, enabling dynamic loading of custom compiler passes, dialects, and DSL extensions at runtime without recompilation, with Meta's Triton Language Extensions (TLX) as the first major consumer.

- Plugins are shared libraries (.so files) loaded at runtime via the TRITON_PLUGIN_PATHS environment variable, requiring no Triton recompilation.
- The system provides hooks in Triton's backend compiler.py stages for fine-grained control over the MLIR pass pipeline, allowing insertion, disabling, replacement, or overriding of passes and stages.
- Extensibility supports custom transformation passes, custom MLIR dialects with conversion passes, and custom top-level DSL ops.
- Plugins can be toggled dynamically per-kernel, activating custom pipelines for specific kernel calls.

**Why it matters:** This system allows researchers and engineers to implement custom optimization passes and hardware-specific intrinsics for high-performance GPU kernels without maintaining costly Triton forks, ensuring access to the latest upstream features and bug fixes.

### [Connect Amazon Bedrock AgentCore to cross-account knowledge bases](https://aws.amazon.com/blogs/machine-learning/connect-amazon-bedrock-agentcore-to-cross-account-knowledge-bases/)

**AWS Machine Learning Blog** · 2026-08-26

AWS details how to connect Amazon Bedrock AgentCore agents to Amazon Bedrock Knowledge Bases backed by Amazon Redshift Serverless across separate AWS accounts using STS role assumption.

- Overcomes the lack of cross-account resource policy support for RetrieveAndGenerate by having the agent tool assume a scoped cross-account IAM role via AWS STS.
- Variant 1 deploys a code-based Strands agent executing a local MCP tool subprocess on the AgentCore runtime.
- Variant 2 uses a declarative AgentCore harness calling an AWS Lambda tool via the AgentCore Gateway.
- The assumed-role session executes RetrieveAndGenerate using Claude Haiku 4.5, which translates natural-language questions into queries against Amazon Redshift Serverless without copying source data.

**Why it matters:** It enables enterprise multi-account architectures to query and generate answers from governed data in Redshift Serverless without violating account boundaries or duplicating data.

### [Agentic Resource Discovery (ARD): An open specification for agent discovery](https://aws.amazon.com/blogs/machine-learning/agentic-resource-discovery-ard-an-open-specification-for-agent-discovery/)

**AWS Machine Learning Blog** · 2026-08-24

AWS announced AWS Agent Registry alongside support for Agentic Resource Discovery (ARD), an Apache 2.0 open specification designed for federated agent and tool discovery across multi-cloud and enterprise environments.

- AWS Agent Registry provides a centralized, curated catalog for Model Context Protocol (MCP) servers, agents, tools, and skills, supporting IAM and JWT authorization.
- The registry offers hybrid search combining semantic natural-language understanding with exact keyword matching, accessible directly via a remote MCP endpoint.
- ARD acts as an open, vendor-neutral specification (analogous to DNS for agentic resources) allowing unified resource description and discovery across disparate registries and platforms.

**Why it matters:** ARD and AWS Agent Registry eliminate custom, pair-wise connectors by providing a standardized format and endpoint for discovering and sharing agentic tools across heterogeneous enterprise infrastructure.

### [Manage private pricing offers for Amazon Bedrock with managed entitlements](https://aws.amazon.com/blogs/machine-learning/manage-private-pricing-offers-for-amazon-bedrock-with-managed-entitlements/)

**AWS Machine Learning Blog** · 2026-10-13

AWS introduced two methods to automate the distribution and activation of AWS Marketplace Private Pricing Offer (MPPO) entitlements across AWS Organizations for Amazon Bedrock.

- AWS License Manager auto-accepts organization-level MPPO grants upon agreement acceptance, but leaves them in a Disabled state until explicitly activated.
- Path 1 provides a standalone script (`lightweight/distribute_licenses.py`) for manual dry-run inspection and one-time activation using the `--apply --confirm-account-id` flag.
- Path 2 provides an AWS CDK stack deploying an EventBridge rule in `us-east-1` that listens for `aws.agreement-marketplace` events to trigger automated, allowlist-filtered Lambda activations.
- Billing verification requires validating the effective discount path via AWS Cost Explorer or the `scripts/bedrock_discount_check.py` sample utility.

**Why it matters:** Without activating these managed entitlements, organization accounts using third-party Amazon Bedrock models fail to receive negotiated custom rates and are charged standard pricing.

### [PyTorch Hardware Enablement: Updates from the Accelerator Integration Working Group](https://pytorch.org/blog/pytorch-hardware-enablement-updates-from-the-acceleration-integration-working-group/)

**PyTorch Blog** · 2026-10-05

The PyTorch Accelerator Integration Working Group reported H1 2026 progress on standardizing hardware enablement, introducing Cross-Repository CI Relay, OpenReg backend maturation, and expanded PrivateUse1 profiling.

- Cross-Repository CI Relay (CRCR) automates parallel CI dispatch from pytorch/pytorch to downstream hardware and library repositories, using GitHub OIDC tokens for identity verification.
- CRCR integrates cross-repo health data directly into the PyTorch CI HUD (hud.pytorch.org/crcr) with five security layers, including rate limiting and state-machine checks.
- Participating downstream repositories operate under a four-tiered allowlist (L1-L4) progressing from dispatch notifications to blocking PR check runs.
- H1 2026 updates include refactored cross-backend test suites, OpenReg reference backend maturation, and profiling support for PrivateUse1-based hardware backends.

**Why it matters:** CRCR and standardized integration tools allow hardware vendors and downstream library maintainers to catch breaking PyTorch changes prior to merge without fragmenting the core codebase.

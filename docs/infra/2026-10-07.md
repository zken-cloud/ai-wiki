### [Modernizing Table Batched Embeddings with FBTriton](https://pytorch.org/blog/modernizing-table-batched-embeddings-with-fbtriton/)

**PyTorch Blog** · 2026-10-06

Meta PyTorch introduced FBTriton, a Triton-based Table Batched Embedding (TBE) kernel implementation for recommendation workloads that outperforms legacy CUDA kernels.

- Uses a specialized small-table histogram and tensor-core path (`tl.dot`) for features matching E≤64, 64≤D≤128, and L≥64 with FP16 weights, processing 16 bags per program.
- Implements a generic gather path launching `ceil(B / BAGS_PER_PROGRAM)` programs, gathering four to eight independent row loads per inner loop while accumulating FP16/BF16 weights into FP32.
- Features fused bounds-checking directly in eligible forward kernels, achieving up to a 1.24x speedup on bounds checking on NVIDIA B200 GPUs.
- Supports forward-state reuse, allowing exact row-wise Adagrad to pass forward histogram counts directly to the backward pass, reducing B200 combined forward/backward latency from 79.537 ms to 66.183 ms (-16.8%).

**Why it matters:** Replacing legacy CUDA kernels with Triton-based TBE operators reduces latency and improves memory efficiency for large-scale recommendation system embeddings on modern GPUs.

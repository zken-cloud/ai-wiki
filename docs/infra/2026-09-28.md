**NVIDIA Developer Blog** · 2026-09-28

**Why it matters:** Dynamic power allocation optimizes energy efficiency and allows operators to maximize hardware density and compute throughput within fixed power budgets.

### [Build a multi-account AI agent with AgentCore Gateway and MCP](https://aws.amazon.com/blogs/machine-learning/build-a-multi-account-ai-agent-with-agentcore-gateway-and-mcp/)

**AWS Machine Learning Blog** · 2026-09-24

AWS details a multi-account architecture that uses Amazon Bedrock AgentCore Gateway and the Model Context Protocol (MCP) to query distributed data across accounts without centralizing datasets.

- The central platform account runs agents on AgentCore Runtime in isolated microVMs and handles LLM inference via Amazon Bedrock.
- Lines of business (LOBs) expose data and tools as MCP servers within their own AWS accounts to maintain scope isolation and data ownership.
- AgentCore Gateway serves as a unified MCP endpoint providing semantic tool discovery, Okta authentication via AgentCore Identity, and Cedar-based authorization via Policy in AgentCore.
- The Gateway supports HTTP targets for agent-to-agent (A2A) integration and enforces Amazon Bedrock Guardrails at the integration layer outside agent code.

**Why it matters:** It enables enterprise AI agents to securely query distributed cross-account data at runtime without data duplication or complex cross-account IAM management.

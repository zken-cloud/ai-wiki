### [Diagnose Distributed AI Workload Failures with NVIDIA Attribution](https://developer.nvidia.com/blog/diagnose-distributed-ai-workload-failures-with-nvidia-attribution/)

**NVIDIA Developer Blog** · 2026-11-02

NVIDIA Attribution enables developers to diagnose distributed AI workload failures by tracing downstream symptoms like NCCL errors back to their root cause GPU or fabric events.

- Distributed AI workload failures often manifest as cascading symptoms, such as NCCL errors on healthy ranks and scheduler state changes, hiding the initial point of failure.

**Why it matters:** It reduces debugging time for large-scale distributed training jobs by isolating the true root cause of a cluster failure rather than chasing downstream error symptoms.

### [Build efficient agents with knowledge distillation on Amazon SageMaker AI](https://aws.amazon.com/blogs/machine-learning/build-efficient-agents-with-knowledge-distillation-on-amazon-sagemaker-ai/)

**AWS Machine Learning Blog** · 2026-11-02

AWS demonstrates using sequence-level knowledge distillation (SeqKD) on Amazon SageMaker AI to fine-tune a smaller student model on multi-step trajectories generated by a frontier teacher model.

- Sequence-level knowledge distillation (SeqKD) uses text outputs (trajectories) from a teacher model to perform supervised fine-tuning (SFT) on a student model, bypassing the need for teacher logits, weights, or gradients.
- For agentic workloads, the distilled sequence consists of an ordered trajectory of reasoning steps, tool calls, and observations rather than a single block of response text.
- Persisting the teacher's trajectory dataset allows reusing the generated data to train and test multiple student models without incurring additional data generation costs.

**Why it matters:** SeqKD enables deploying cost-effective, low-latency small models for multi-step agentic tasks using API-only frontier models as teachers, reducing overall per-task inference costs.

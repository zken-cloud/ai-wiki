### [vLLM Support for NVIDIA Vera Rubin NVL72: 7.8x Throughput over GB200 NVL72](https://vllm.ai/blog/2026-10-09-vera-rubin-preview)

**vLLM Blog** · 2026-10-09

vLLM now supports the NVIDIA Vera Rubin NVL72 platform, achieving up to 7.8x per-GPU inference throughput over GB200 NVL72 using Rubin-tuned kernels and locality-aware optimizations.

- Vera Rubin NVL72 offers 5x more NVFP4 inference FLOPS, 2.4x higher HBM4 memory bandwidth, and 1.7x higher 6th-gen NVLink bandwidth compared to GB200 NVL72.
- Hardware architecture improvements include a 2x FP32 and 4x BF16/FP16 increase in exponential throughput to accelerate LLM attention softmax operations.
- vLLM leverages CUDA 13.4 locality domains to optimize non-uniform global memory accesses, matching compute and data within the same domain for higher bandwidth and lower latency.
- The integration features day-0 model support for architectures from DeepSeek, Moonshot AI, Z.ai, and MiniMax, backed by Rubin-tuned FlashInfer kernels and locality-aware MoE.

**Why it matters:** The co-optimization of vLLM with Vera Rubin hardware significantly improves token throughput and decode latency for large-scale, agentic LLM workloads.

### [Managed Apache Iceberg at scale: How Spanner powers Lakehouse runtime catalog](https://cloud.google.com/blog/products/data-analytics/lakehouse-runtime-catalog-powered-by-spanner/)

**Google Cloud Blog** · 2026-10-06

Google Cloud introduced Lakehouse runtime catalog, a managed Apache Iceberg catalog backed by Cloud Spanner to provide high-throughput, ACID-compliant metadata management at scale.

- Uses Cloud Spanner as the underlying storage layer to deliver external consistency, multi-region replication, and automatic scaling for Apache Iceberg metadata operations.
- Implements the open REST Catalog Spec for Apache Iceberg, ensuring compatibility with engines like BigQuery, Apache Spark, and Trino without code modification.
- Optimizes catalog performance by storing Iceberg manifest files and table metadata directly within Spanner tables to reduce object storage read latency.
- Provides enterprise-grade security features including fine-grained IAM controls, VPC Service Controls, and Customer-Managed Encryption Keys (CMEK).

**Why it matters:** Data engineering teams can unify metadata management across heterogeneous analytics engines using a globally distributed, fully managed serverless catalog without managing catalog infrastructure.

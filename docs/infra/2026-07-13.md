### [Modernizing the Meta Ads Service With an Open-Source Kernel Scheduler](https://engineering.fb.com/2026/07/13/ml-applications/modernizing-the-meta-ads-service-with-an-open-source-kernel-scheduler/)

**Meta Engineering** · 2026-07-13

Meta modernized its Ads service using sched_ext, an open-source, BPF-based kernel scheduler, to create a workload-specific scheduling policy, resulting in a 28% reduction in ads retrieval tail latency and a 1.1% increase in ads ranked.

- The sched_ext framework, which officially entered kernel v6.12, allows developers to implement custom scheduling policies as BPF programs.
- The custom policy soft-partitions CPUs into two pools: one for latency-critical request path threads and another for less latency-sensitive work, with dynamic pool sizing based on load heuristics.
- This approach improves L3 cache locality and reduces DRAM access by keeping related work on the same CPUs.
- The policy is packaged as a user-space binary, enabling rapid experimentation and performance optimization without kernel rebuilds.
- Deployment addressed a latency regression observed with the EEVDF scheduler in Linux kernel v6.6 during a fleet upgrade to kernel v6.9.

**Why it matters:** Optimizing kernel scheduling for specific workloads like ad serving directly translates to improved performance metrics, power savings, and increased business value at Meta's scale.

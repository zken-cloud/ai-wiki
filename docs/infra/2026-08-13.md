### [Tiered KV cache for large LLMs on Amazon SageMaker HyperPod with Curvine](https://aws.amazon.com/blogs/machine-learning/tiered-kv-cache-for-large-llms-on-amazon-sagemaker-hyperpod-with-curvine/)

**AWS Machine Learning Blog** · 2026-08-12

AWS introduced a three-tiered KV cache architecture for LLM inference on SageMaker HyperPod, extending vLLM cache across GPU (L0), host CPU DRAM (L1), and a shared cross-node Curvine NVMe filesystem (L2).

- Uses Curvine as a lightweight distributed cache filesystem to provide a shared L2 NVMe tier accessible across vLLM replicas at near-local-disk speeds.
- Integrated with SageMaker HyperPod capabilities including Managed Tiered KV Cache (L1 managed via LMCache) and Intelligent Routing for cache-aware request distribution.
- Achieved up to a 100 percent cross-Pod cache hit rate and up to a 2.7x TTFT improvement in benchmarks.
- Demonstrated a cross-node L2 read latency of approximately 56 ms for a ~1,900-token prompt.

**Why it matters:** This architecture enables high concurrency and long-prompt LLM workloads to run efficiently on lower-cost GPU instances like G6e instead of P5, reducing inference infrastructure costs.

### [Day 0 Support for Qwen3.8-2.4T-A95B on vLLM](https://vllm.ai/blog/2026-08-12-qwen3.8)

**vLLM Blog** · 2026-08-12

vLLM announced Day-0 support for Qwen3.8-2.4T-A95B, a 2.4-trillion-parameter sparse hybrid MoE model, supporting FP8, BF16, NVFP4, and MXFP4 quantization.

- Model architecture consists of 2.4T parameters across 512 sparse MoE experts and a 92-layer hybrid backbone using full attention every 4th layer and linear attention on the remaining 69 layers.
- Inferact released NVFP4 and MXFP4 quantized weights using Round-to-Nearest (RTN) quantization with activation calibration to enable 4-bit activations.
- Hardware deployment requires at least two NVIDIA B300 / AMD MI355X nodes for full precision, or a single node using FP4 quantized weights with 8-way tensor parallelism.
- Optimizations include co-developed linear attention (Gated Delta Rule) fused kernels, speculative decoding with MTP (3 tokens), and AMD AITER-fused/hipBLASLt GEMM kernels.

**Why it matters:** FP4 quantization and hardware-optimized fused kernels enable single-node deployment and cost-effective inference for a Qwen-Max-class 2.4-trillion-parameter open-weight model.

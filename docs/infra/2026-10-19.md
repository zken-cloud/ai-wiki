### [Introducing TorchNeuron: Native PyTorch backend for AWS Trainium](https://pytorch.org/blog/introducing-torchneuron-native-pytorch-backend-for-aws-trainium/)

**PyTorch Blog** · 2026-10-19

AWS and PyTorch announced TorchNeuron, a native, open-source PyTorch backend enabling direct execution, compilation, and profiling on AWS Trainium2 and Trainium3 chips using standard PyTorch APIs.

- Integrates via PyTorch extension points, using PrivateUse1 for hardware registration and support for the torch.accelerator API to enable device switching via .to('neuron').
- Supports both eager execution (including an adaptive eager mode) and torch.compile via setting the backend to 'neuron'.
- Allows custom hardware kernel development through the Neuron Kernel Interface (NKI).
- Integrates with standard PyTorch ecosystem APIs including torch.nn, torch.autocast, torch.distributed, and torch.profiler (via Neuron Explorer).
- Releasing as open source under Apache 2.0 at github.com/aws-neuron/torch-neuronx as a public Beta on Oct. 20.

**Why it matters:** Developers can run, optimize, and scale PyTorch models on AWS Trainium hardware without altering existing workflow code or leaving the standard PyTorch ecosystem.

### [Inside Prometheus: Meta’s Journey to a Gigawatt-Scale Supercluster](https://engineering.fb.com/2026/10/19/data-center-engineering/inside-prometheus-meta-gigawatt-scale-supercluster/)

**Meta Engineering** · 2026-10-19

Meta details its Prometheus supercluster in New Albany, Ohio, which powered the Muse Wonder model training and aims to scale to roughly one million GPUs.

- Achieved over 85% goodput during pre-training and over 90% goodput for reinforcement learning of Muse Wonder, with post-fix wall-clock mean time between interruptions (MTBI) exceeding 54k GPU hours.
- Deploys NVIDIA GB200 NVL72 (Catalina) featuring the Ariel variant, a two-rack configuration of 36 GPUs per rack forming a unified 72-GPU NVLink domain on the Open Rack V3 structure.
- Pairs each NVIDIA Blackwell GPU with an NVIDIA Grace CPU (1:1 ratio) and 2x NVIDIA ConnectX-7 400G NICs to deliver 800G scale-out I/O per GPU.
- Utilizes a hybrid footprint of traditional, AI-optimized, and rapid deployment data center structures with closed-loop liquid cooling, with plans to integrate NVIDIA Vera Rubin NVL72 platforms.

**Why it matters:** The architectural and network design of Prometheus allows hundreds of thousands of distributed GPUs to operate efficiently as a single machine, enabling the training of larger foundational models with longer context windows.

### [Get started with OpenAI GPT-5.6 Sol, Terra, and Luna on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/get-started-with-openai-gpt-5-6-sol-terra-and-luna-on-amazon-bedrock/)

**AWS Machine Learning Blog** · 2026-07-24

OpenAI GPT-5.6 Sol, Terra, and Luna models are now generally available on Amazon Bedrock, offering capabilities for agentic coding, long-horizon reasoning, and high-volume inference with AWS security and cost controls.

- The GPT-5.6 family includes Sol (openai.gpt-5.6-sol) for autonomous coding and deep reasoning, Terra (openai.gpt-5.6-terra) for general-purpose production, and Luna (openai.gpt-5.6-luna) for high-volume, latency-sensitive workloads.
- All three models support text and image input, text output, a 272K-token context window, and the OpenAI Responses API, accessible via the bedrock-mantle endpoint (https://bedrock-mantle.{region}.api.aws/openai/v1/responses).
- Models support `none`, `low`, `medium`, `high`, `xhigh`, and `max` reasoning effort, allowing API integration consistency across models.
- Inference runs within AWS IAM policies, VPCs, and CloudTrail logging, with in-Region processing for data residency; prompts and completions are not used for model training.

**Why it matters:** Developers can now access OpenAI's frontier models through a familiar API on Amazon Bedrock, integrating advanced AI capabilities with existing AWS infrastructure and security protocols.

### [Pathway’s brain-inspired architecture development on Amazon SageMaker HyperPod](https://aws.amazon.com/blogs/machine-learning/pathways-brain-inspired-architecture-development-on-amazon-sagemaker-hyperpod/)

**AWS Machine Learning Blog** · 2026-09-08

Pathway developed BDH, a brain-inspired architecture using a graph of neurons with sparse, local interactions and recurrent latent states to perform reasoning without text-based chain-of-thought traces.

- BDH (Dragon Hatchling) moves beyond transformers by replacing text-trace reasoning with latent space reasoning using a recurrent latent state.
- BDH-CQ updates internal memory in context during inference without test-time weight updates, fine-tuning, or full model retraining.
- The model architecture maintains state in synapse-like connections to avoid transformer limitations such as fixed context windows, KV-cache growth, and dense computation patterns.
- Pathway integrates BDH with PyTorch and uses Amazon SageMaker HyperPod to scale out resilient, cost-effective training across shared compute resources.

**Why it matters:** By executing reasoning in latent space rather than generating sequential tokens, BDH reduces the computational and memory overhead associated with long chain-of-thought transformer inference.

### [Benchmarking small LLM inference on SageMaker AI: G7 vs G5 and G6](https://aws.amazon.com/blogs/machine-learning/benchmarking-small-llm-inference-on-sagemaker-ai-g7-vs-g5-and-g6/)

**AWS Machine Learning Blog** · 2026-09-08

AWS benchmarked 30B MoE models on SageMaker AI, showing new G7 instances with NVIDIA Blackwell GPUs deliver improved throughput, lower latency, and lower cost-per-token compared to G5, G6, and G6e instances.

- Evaluated Qwen3-Coder-30B using the SageMaker AI DJL Large Model Inference (LMI) container on ml.g5.12xlarge (A10G), ml.g6.12xlarge (L4), and ml.g7.12xlarge (RTX PRO 4500 Blackwell) instances.
- Compared NVIDIA Nemotron-3-Nano-30B-A3B-NVFP4 across G6 (L4), G6e (L40S), and G7 configurations using vLLM.
- The ml.g7.12xlarge instance utilizes two Blackwell GPUs with 64 GB aggregate memory, outperforming four-GPU G5/G6 configurations that use 96 GB of aggregate memory.
- Demonstrated SageMaker AI Generative AI Inference Recommendations for automated benchmarking of metrics like time to first token (TTFT), latency, throughput, and cost.

**Why it matters:** G7 instances allow developers to run small LLM and MoE workloads faster and cheaper while utilizing half the physical GPUs and less aggregate VRAM than previous generations.

### [vLLM x AgentX: Optimizing for Real-World Agentic Serving](https://vllm.ai/blog/2026-09-08-vllm-agentx)

**vLLM Blog** · 2026-09-08

vLLM details a coordinated serving stack optimization across KV cache management, model parallelism, scheduling, and P/D disaggregation, validated on the SemiAnalysis AgentX benchmark.

- Achieves up to 130K total tokens per GPU-second on DeepSeek V4 Pro and up to 376 tokens per second interactivity on MiniMax M3.
- Demonstrates a 14.6x to 106x serving-cost advantage compared to Opus 5 API pricing across DeepSeek V4 Pro, MiniMax M3, and Kimi K3.
- Addresses agentic workload pressures characterized by long contexts, high prefix reuse across multi-turn sessions, and short incremental prefills.
- Identifies key serving failure modes, including pipeline parallelism not fitting warm agentic turns and load balancing failing to guarantee better performance.

**Why it matters:** These optimizations significantly improve the latency-cost frontier for high-concurrency, long-context agentic workloads using open serving infrastructure.

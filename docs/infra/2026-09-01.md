### [MiniMax H3 on vLLM-Omni: From System-Wide Optimization to Real-Time Serving with FastVideo’s FastH3](https://vllm.ai/blog/2026-09-01-minimax-h3-production-serving)

**vLLM Blog** · 2026-09-01

vLLM-Omni optimizes the complete MiniMax H3 multimodal serving stack and integrates FastVideo's four-step FastH3 to achieve end-to-end MP4 generation faster than video playback duration.

- Addresses system-wide serving bottlenecks across the entire pipeline: Qwen3-VL encoder, joint audio-video DiT, parallel video/audio VAE decoding, GPU transport, and MP4 encoding.
- Integrates FastVideo's FastH3 model to reduce the DiT compute requirement from 49 forward passes down to just four steps.
- Achieved real-time generation on an eight-B300 GPU system, producing a complete 10.125-second MP4 in 8.678 to 8.710 seconds.
- Defines real-time performance strictly as delivering the full MP4 response faster than its total playback duration, rather than time-to-first-frame or streaming delivery.

**Why it matters:** System-level optimizations combined with step-reduction algorithms allow full-length multimodal joint video and audio generation to be served faster than real-time playback speed in production environments.

### [Connect an AgentCore Runtime hosted MCP server to Amazon Quick](https://aws.amazon.com/blogs/machine-learning/connect-an-agentcore-runtime-hosted-mcp-server-to-amazon-quick/)

**AWS Machine Learning Blog** · 2026-08-31

AWS details how to host a Model Context Protocol (MCP) server on Amazon Bedrock AgentCore Runtime and integrate it with Amazon Quick using AgentCore Gateway.

- AgentCore Runtime provides serverless MCP server hosting with features like session isolation, extended execution times, persistent file systems, and bidirectional streaming.
- The integration uses Amazon Quick connectors alongside AgentCore Gateway to link AI chat agents and workflows to MCP servers.
- Inbound Auth relies on Amazon Cognito (or alternative identity providers) to authenticate users connecting to AgentCore Gateway.
- Outbound Auth utilizes AgentCore Identity via OAuth 2.0 for machine-to-machine authentication between AgentCore Gateway and AgentCore Runtime.
- Alternative integration patterns include direct REST API links via Amazon API Gateway or custom serverless execution using AWS Lambda functions.

**Why it matters:** This architecture enables organizations to expose reusable tools and sub-agents to Amazon Quick workflows without building custom connectors for every use case.

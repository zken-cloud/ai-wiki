### [Introducing Kinference: An Open Source Inference Control Plane for vLLM and Kubernetes](https://vllm.ai/blog/2026-11-04-introducing-kinference)

**vLLM Blog** · 2026-11-04

Buoyant has introduced Kinference, an open-source inference control plane for Kubernetes and vLLM that provides KV-cache-aware load balancing, token rate limiting, and policy management.

- Integrates with vLLM as an HTTP endpoint supporting OpenAI- and Anthropic-compatible API traffic.
- Uses KV-cache-aware load balancing based on GPU queue sizes, historical performance, and KV cache contents to route requests to optimal vLLM workers.
- Demonstrates a 95% reduction in median TTFT and a 45% reduction in median end-to-end latency compared to standard Kubernetes service load balancing in benchmarks.
- Achieved up to 7.4x higher goodput on shared-prefix workloads and 3.5x on multiturn workloads within specified latency SLOs during capacity testing.
- Includes features for tenant usage tracking, cost tracking, token rate limiting, and configurable inference policies.

**Why it matters:** Kinference enables platform operators to significantly improve LLM serving efficiency and goodput on Kubernetes clusters by making load balancing decisions aware of vLLM worker KV-cache states.

### [vLLM Delivers Day-0 Support for Kimi K3.1 Pro](https://vllm.ai/blog/2026-11-04-kimi-k31-pro)

**vLLM Blog** · 2026-11-04

vLLM has added day-0 support for Moonshot AI's Kimi K3.1 Pro, a 2.8T-parameter multimodal MoE model featuring Dynamic Sparse Attention alongside Multi-Head Latent Attention and KDA layers.

- Kimi K3.1 Pro features 93 layers (69 KDA and 24 full-attention layers using MLA + DSA indexer) with 896 experts (16 active) and a 1M-token context window.
- The DSA indexer scores past tokens using 32 heads of 128 dimensions to select the top 2,048 tokens for exact MLA attention, reducing memory bandwidth reads to ~23% of dense MLA in long-context decoding.
- The indexer maintains a 132-byte FP8 key per token alongside the standard MLA KV cache, both of which are replicated across GPUs under tensor parallelism.
- Day-0 deployment and inference support is available across NVIDIA, AMD (via AITer), Google TPU, and Alibaba T-Head Zhenwu PPU platforms, including support for DSpark speculative decoding.

**Why it matters:** Day-0 vLLM integration allows immediate production deployment of Kimi K3.1 Pro with significantly reduced long-context decoding latency and memory bandwidth overhead.

### [Announcing SOCI-indexed images for faster SageMaker AI jobs](https://aws.amazon.com/blogs/machine-learning/announcing-soci-indexed-images-for-faster-sagemaker-ai-jobs/)

**AWS Machine Learning Blog** · 2026-10-27

AWS has introduced Seekable OCI (SOCI) indexing for Amazon SageMaker AI training and processing jobs to lazy-load container images and accelerate startup times.

- SOCI metadata maps image files and is stored in Amazon ECR as an OCI-compliant artifact linked to the original image without altering image digests or signatures.
- SageMaker AI automatically detects SOCI indexes, lazy-loading required files to start containers in seconds while background-streaming the remainder.
- If a SOCI index is missing, unreadable, or fails to lazy-load, SageMaker AI falls back to standard image downloads without breaking workflows.
- In AWS benchmarks using 1.8–35.4 GB images on GPU and CPU instances, SOCI lazy loading reduced GPU idle time during image pulls by up to 90 percent.

**Why it matters:** Lazy loading removes container image download bottlenecks, reducing billable job costs and startup times without requiring changes to job definitions or entry points.

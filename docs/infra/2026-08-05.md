### [As AI Increases Demands on Memory, Storage Steps Up](https://blogs.nvidia.com/blog/ai-storage-fms/)

**NVIDIA Blog** · 2026-08-04

NVIDIA is open-sourcing its cuFile APIs to enable direct GPU storage access and launching the Storage-Next initiative to establish open industry standards for GPU-driven storage architectures.

- The NVIDIA Vera CPU in the Vera BlueField-4 STX achieves up to 3.21x higher throughput than x86 CPUs in two-stage compression and encryption pipelines.
- NVIDIA is open-sourcing the cuFile APIs and underlying vertical software stack within GPUDirect Storage, allowing GPU threads to directly read and write to storage in microseconds.
- The Storage-Next initiative unites over 40 storage and flash vendors to create open, interoperable standards for thermal design, cooling, controllers, and orchestration in GPU-driven storage.
- Open-sourcing cuFile supports the Open Secure AI Alliance, co-maintained by Google, Intel, NVIDIA, and Meta, to standardize fast, security-first data access.

**Why it matters:** Direct GPU-to-storage architectures eliminate x86 CPU bottlenecks, allowing AI workloads to process massive datasets in microseconds while lowering infrastructure overhead.

### [Introducing Web Search on Amazon Bedrock for foundation model grounding](https://aws.amazon.com/blogs/machine-learning/introducing-web-search-on-amazon-bedrock-for-foundation-model-grounding/)

**AWS Machine Learning Blog** · 2026-08-04

AWS has announced the general availability of Web Search on Amazon Bedrock, a native, server-side tool that grounds foundation model responses using Amazon's proprietary web index and knowledge graph.

- Operates server-side via a single-parameter enablement in OpenAI-compatible API calls, eliminating client-side tool loops and external API orchestration.
- Combines a continually refreshed, billion-document web index with a built-in knowledge graph to resolve factual entity queries with high confidence.
- Uses semantic snippet extraction to pass context-optimized passages and citations (URLs and titles) to the model while minimizing token usage.
- Provides default zero data egress, maintaining all operations strictly within AWS infrastructure to meet enterprise compliance standards.

**Why it matters:** Developers can natively integrate real-time web search into Amazon Bedrock models to reduce hallucinations without managing third-party search vendors or compromising data security.

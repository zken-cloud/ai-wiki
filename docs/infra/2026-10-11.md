### [How Postman runs Agent Mode for 40 million developers on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-postman-runs-agent-mode-for-40-million-developers-on-amazon-bedrock/)

**AWS Machine Learning Blog** · 2026-10-09

Postman built Agent Mode using Amazon Bedrock to provide AI-native API testing, documentation, and discovery for 40 million developers.

- Agent Mode runs on Amazon Bedrock using cross-Region inference, model-dependent zero data retention, and multi-tier prompt caching to handle global traffic bursts.
- Integrated Amazon Bedrock Guardrails allow enterprise administrators to automatically redact personally identifiable information (PII) before requests reach the LLM.
- The system enforces human oversight by requiring explicit user approval before executing any actions that modify application state.
- Postman transitioned away from highly atomic, single-field tool calls after finding that frequent round-trips to the model caused high latency in multi-step workflows.

**Why it matters:** It demonstrates how to scale LLM agents in production by balancing fine-grained tool orchestration, strict privacy controls, and managed infrastructure for millions of users.

### [Pay-per-inference for AI agents: How BlockRun and Incarna use Amazon Bedrock AgentCore payments](https://aws.amazon.com/blogs/machine-learning/pay-per-inference-for-ai-agents-how-blockrun-and-incarna-use-amazon-bedrock-agentcore-payments/)

**AWS Machine Learning Blog** · 2026-10-08

Amazon Bedrock AgentCore payments enables autonomous AI agents to execute sub-cent, pay-per-inference micropayments using the x402 protocol and managed cryptocurrency wallets.

- Incarna integrated AgentCore payments to allow AI agents to pay BlockRun on-demand for single model inferences across 90+ models and 15+ providers.
- Handles HTTP 402 ('Payment Required') responses natively by signing x402 transactions using Coinbase CDP wallets and settling on-chain with USDC on the Base network.
- Enforces spending limits and governance at the infrastructure layer, preventing overspending even if the agent's prompt is manipulated.
- Credentials for providers like Coinbase CDP or Stripe Privy are stored securely via AWS Secrets Manager and managed through the AgentCore SDK, CLI, or AWS SDK.

**Why it matters:** It replaces custom billing pipelines and card networks with infrastructure-level payment signing and spending limits suited for high-frequency, sub-cent agent-to-agent transactions.

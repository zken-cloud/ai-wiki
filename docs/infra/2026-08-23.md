### [Exploring Speculative Decoding in vLLM on AMD GPUs](https://vllm.ai/blog/2026-08-23-speculative-decoding-amd-gpus)

**vLLM Blog** · 2026-08-23

vLLM supports speculative decoding on AMD Instinct MI300X and MI355X GPUs using ROCm to verify multiple drafted tokens in a single target-model pass.

- Evaluates five speculative drafting approaches: native MTP, Gemma 4 MTP, EAGLE-3, DFlash, and DSpark.
- Drafting methods differ by token generation mechanics, including parallel, sequential, autoregressive, and hybrid approaches.
- Tested across diverse target models including google/gemma-4-31B-it, Qwen/Qwen3.5-122B-A10B, and moonshotai/Kimi-K2.5.
- Throughput gains vary based on proposal length, acceptance behavior, draft checkpoints, and specific workload parameters.

**Why it matters:** Speculative decoding allows vLLM users on AMD GPUs to bypass the single-token-per-step latency bottleneck of standard autoregressive decoding while maintaining the target model's output distribution.

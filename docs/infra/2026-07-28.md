- Unlimited real-world experimentation is not feasible for healthcare robotics.
- Each demonstration in healthcare robotics requires specialized equipment, clinical expertise, and patient/laboratory access.

### [Market surveillance agent with LangGraph and Strands on AgentCore](https://aws.amazon.com/blogs/machine-learning/market-surveillance-agent-with-langgraph-and-strands-on-agentcore/)

**AWS Machine Learning Blog** · 2026-07-28

AWS demonstrated a market surveillance architecture combining LangGraph for macro-level workflow orchestration and Strands agents for localized reasoning on Amazon Bedrock AgentCore.

- LangGraph manages directed state graphs, persistence, and human-in-the-loop checkpoint recovery across multi-agent workflows.
- Strands serves as the node-level reasoning engine using an adaptive thinking budget with Claude Sonnet and model-agnostic LLM integration.
- Tool execution decouples data discovery from retrieval via separate tools (`get_report_list`, `get_report_schema`, and `run_report`) to mitigate injection attacks and hallucinations.

**Why it matters:** Combining graph-based workflow state management with isolated reasoning engines enables production-grade, multi-agent enterprise deployments on AWS infrastructure.

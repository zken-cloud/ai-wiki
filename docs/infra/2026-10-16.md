### [Scaling Kimi K3 on AMD Instinct MI355X: Matching NVIDIA HGX B300 Throughput per GPU on AgentX](https://vllm.ai/blog/2026-10-16-kimi-k3-mi355x)

**vLLM Blog** · 2026-10-16

AMD Instinct MI355X running vLLM achieves 24.4% higher throughput per GPU and 87.4% higher throughput per TCO dollar than NVIDIA HGX B300 when serving Kimi K3 on the AgentX benchmark at 50 tokens/s/user P90 interactivity.

- AMD Instinct MI355X served 7,567 total tokens/s/GPU at 50 tokens/s/user P90 interactivity versus 6,083 tokens/s/GPU on NVIDIA HGX B300.
- Based on a modeled TCO of $1.50/hour for the MI355X versus $2.26/hour for the B300, the MI355X yielded 18.16 million versus 9.69 million total tokens per dollar.
- Kimi K3 architecture integrates 24 Multi-head Latent Attention (MLA) layers storing compressed KV history alongside 69 Recurrent Block (KDA) layers maintaining fixed-dimension state matrices.
- Optimizations leverage custom AMD AITER assembly for MLA decoding and smaller tile sizing for parallelized KDA prefill and speculative verification.

**Why it matters:** The performance and TCO gains demonstrate that AMD Instinct MI355X platforms combined with vLLM optimizations can outpace NVIDIA HGX B300 hardware for serving large-scale agentic workloads.

### [Bringing ExecuTorch to Arm Cortex-M CPUs](https://pytorch.org/blog/bringing-executorch-to-arm-cortex-m-cpus/)

**PyTorch Blog** · 2026-10-15

ExecuTorch now supports direct deployment of PyTorch models onto Arm Cortex-M CPUs using Arm CMSIS-NN acceleration, eliminating cross-framework conversions for microcontroller targets.

- Uses ahead-of-time compiler passes to lower PyTorch operators into CMSIS-NN optimized kernels, targeting Scalar, DSP, and Helium/MVE capability tiers.
- Employs PyTorch's PT2E quantization framework with a purpose-built quantizer to generate INT8 graphs matched to CMSIS-NN data layouts.
- Achieves a minimal core runtime footprint under 20 KiB of flash using operator selective builds to link only required model operators.
- Benchmarked four MLPerf Tiny models on an Alif Ensemble E8 single Cortex-M55 core, executing each model in 21.5 ms or less using under 90 KiB of RAM.

**Why it matters:** Developers can now train, quantize, and deploy machine learning models to resource-constrained microcontrollers entirely within the native PyTorch ecosystem without model conversion tools.

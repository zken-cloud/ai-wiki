### [Tokenomics at scale: How Jamf built real-time spend enforcement for Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/tokenomics-at-scale-how-jamf-built-real-time-spend-enforcement-for-amazon-bedrock/)

**AWS Machine Learning Blog** · 2026-09-01

Jamf built an automated AWS architecture for Amazon Bedrock that enforces near-real-time tiered spend limits on individual engineers without requiring re-authentication.

- Measures spend by logging Amazon Bedrock token counts and user identities to Amazon S3, using an Amazon Athena view to calculate daily per-user costs in place.
- Executes an AWS Lambda enforcement handler every 15 minutes via EventBridge to compare actual spend against standard limits and custom DynamoDB exception records.
- Enforces tiered model restrictions dynamically by using iam:CreatePolicyVersion to update IAM Customer Managed Policies with user-specific saml:sub condition keys.
- Implements progressive denial logic (e.g., blocking Claude Opus at 80% budget and Claude Sonnet at 100%) while preserving access to low-cost models like Claude Haiku.

**Why it matters:** It enables enterprise FinOps teams to prevent unchecked generative AI API spend by individual users while maintaining continuous engineer productivity.

### [Build observable enterprise agentic retrieval using Managed Amazon Bedrock Knowledge Base with AWS CloudFormation](https://aws.amazon.com/blogs/machine-learning/build-observable-enterprise-agentic-retrieval-using-managed-amazon-bedrock-knowledge-base-with-aws-cloudformation/)

**AWS Machine Learning Blog** · 2026-08-31

AWS has detailed an architecture combining Amazon Bedrock Managed Knowledge Bases and Amazon Bedrock AgentCore to deploy observable, multi-step enterprise agentic retrieval using AWS CloudFormation.

- The system uses Amazon Bedrock AgentCore runtime to auto-instrument reason-and-act loops with OpenTelemetry spans emitted to Amazon CloudWatch and AWS X-Ray.
- The agent routes queries across topic-specific knowledge bases via Model Context Protocol (MCP) tool calls brokered by the Amazon Bedrock AgentCore Gateway.
- Managed Knowledge Bases expose an AgenticRetrieveStream API that decomposes questions, retrieves iteratively from Amazon S3-backed datastores, and streams grounded, cited answers.
- The agent evaluates returned context sufficiency to decide whether to execute additional retrieval loops before returning the final response to the user.

**Why it matters:** It enables enterprise teams to automate and monitor complex, multi-turn RAG reasoning and cross-source retrieval workflows with built-in observability using a single CloudFormation template.

**AWS Machine Learning Blog** · 2026-08-31

AWS details an architecture for multi-tenant agentic chat applications using Amazon Bedrock Managed Knowledge Base and a custom connector for isolated, multi-hop document retrieval.

- Amazon Bedrock Managed Knowledge Base automates ingestion, vector and full-text indexing, embedding, and re-ranking without external retrieval infrastructure.
- The built-in agentic retrieval engine decomposes complex user queries into sub-queries and executes multi-hop retrievals while preserving per-tenant security filtering on every hop.

- Application access control uses Amazon Cognito to supply verified user identities to Amazon API Gateway and AWS Lambda, enforcing strict data isolation.

**Why it matters:** It removes the need to build, scale, and secure custom agentic search infrastructure while strictly enforcing multi-tenant isolation across complex multi-step retrieval queries.

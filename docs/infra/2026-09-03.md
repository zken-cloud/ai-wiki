### [PyTorch 2.14 Release Blog](https://pytorch.org/blog/pytorch-2-14-release-blog/)

**PyTorch Blog** · 2026-09-02

PyTorch 2.14 releases with 2,995 commits, featuring NVGEMM kernel autotuning, an in-tree nccl2 backend with c10d fault tolerance, native Apple Silicon linear algebra, and expanded control flow APIs.

- NVGEMM integrates CuTeDSL-generated CUTLASS kernels into Inductor, enabling epilogue fusion, scaled/NVFP4 GEMM, and autotuning alongside Triton and ATen
- A new nccl2 backend (ported from torchcomms) brings nonblocking communicators, eager communicator splitting, process-group reconfiguration, one-sided RMA windows, and a backend-agnostic Flight Recorder to c10d
- Apple Silicon receives native linear algebra kernels (Jacobi-kernel SVD, eigh, QR, Cholesky) alongside MPSGraph to Metal migrations
- Control flow additions include multi-way branching via torch.switch, CUDA graph capture for torch.while_loop, and dynamic shape declarations via @dynamic_spec across torch.compile, torch.export, and make_fx
- Hardware and compiler expansions include ROCm 7.14 wheels via TheRock pip SDK, Intel XPU native graph capture, Inductor targeting Rubin (sm_107), and opt-in complex-valued tensor decomposition

**Why it matters:** The release matures low-precision GPU math and dynamic shape tracing while making distributed fault tolerance a core runtime property across hardware backends.

- Supports model invocation through the OpenAI Responses API (/openai/v1), OpenAI Chat Completions API (/openai/v1), and the native Amazon Bedrock Converse API.
- Requires Python 3.9+ along with the openai, boto3, and aws-bedrock-token-generator packages for setup and usage.

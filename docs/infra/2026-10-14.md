### [Mixture-of-Experts kernel engineering on Amazon SageMaker AI](https://aws.amazon.com/blogs/machine-learning/mixture-of-experts-kernel-engineering-on-amazon-sagemaker-ai/)

**AWS Machine Learning Blog** · 2026-10-13

AWS engineers detail GPU kernel optimizations for fused Mixture-of-Experts models on Amazon SageMaker AI, focusing on mitigating hardware utilization bottlenecks during the LLM decode phase.

- Fused MoE operations merge token routing, data shuffling, and expert calculations into a single batched GPU operation to eliminate sequential loop overhead.
- NVIDIA Hopper architecture's WGMMA instruction requires Operand A to have a fixed matrix row dimension (M) of at least 64 to fully utilize Tensor Core capacity.
- During the LLM decode phase, thin token batch sizes (where M < 64 or M = 1) leave WGMMA execution lanes starved when mapped to Operand A.
- The Swap-AB optimization technique rearranges matrix multiplication operands to better align low-batch MoE decoding shapes with Hopper's rigid hardware instruction layout.

**Why it matters:** Optimizing fused MoE operations at the GPU kernel level directly reduces request latency and hosting costs for sparsely-activated LLMs deployed on modern hardware.

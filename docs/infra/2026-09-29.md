### [Build real-time voice applications with vLLM-Omni on SageMaker AI – Part 1](https://aws.amazon.com/blogs/machine-learning/build-real-time-voice-applications-with-vllm-omni-on-sagemaker-ai-part-1/)

**AWS Machine Learning Blog** · 2026-09-28

AWS introduced the vLLM-Omni Deep Learning Container on Amazon SageMaker AI to enable real-time, low-latency streaming of generated audio output over a single persistent bidirectional WebSocket connection.

- Uses the specialized vLLM-Omni Deep Learning Container (DLC) to deploy the Qwen3-TTS text-to-speech model on SageMaker AI.
- Establishes a full-duplex WebSocket transported over HTTP/2 on port 8443 via SageMaker bidirectional streaming.
- Coordinates multi-stage workflows, streaming text inputs and audio chunk outputs through routing middleware and a heterogeneous pipeline abstraction.
- Complements input-side speech-to-text models, like Voxtral-Mini-4B Realtime, to complete full-duplex voice application architectures.

**Why it matters:** It enables developers to build real-time voice applications that stream audio chunks back to users as they are generated, eliminating long silent pauses during speech synthesis.

### [Generate images and video with vLLM-Omni on SageMaker AI – Part 2](https://aws.amazon.com/blogs/machine-learning/generate-images-and-video-with-vllm-omni-on-sagemaker-ai-part-2/)

**AWS Machine Learning Blog** · 2026-09-28

AWS demonstrates using a unified vLLM-Omni Deep Learning Container on Amazon SageMaker AI to run image and video generation across real-time and asynchronous endpoints.

- Deploys FLUX.2-klein-4B on a SageMaker real-time endpoint routing to /v1/images/generations for synchronous base64 PNG output.
- Deploys Wan2.1-VACE-1.3B on a SageMaker Asynchronous Inference endpoint routing to /v1/videos/sync for long-running video generation.
- Uses DLC routing middleware to map SageMaker /invocations calls to vLLM-Omni API routes based on the CustomAttributes header.
- Chains generation by embedding the resized, JPEG-converted output from the image model directly into the multipart video request uploaded to Amazon S3.

**Why it matters:** Using a single container image with routing middleware standardizes serving infrastructure while allowing distinct instance types and inference patterns for multi-modal generation pipelines.

### [Grok 4.7 is now available on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/grok-4-7-is-now-available-on-amazon-bedrock/)

**AWS Machine Learning Blog** · 2026-09-28

xAI's Grok 4.7 is now available on Amazon Bedrock, featuring a 500K token context window and four configurable reasoning effort levels.

- Grok 4.7 offers low, medium, high, and xhigh reasoning effort levels and is served via Bedrock cross-Region inference profiles supporting Responses, Chat Completions, and Converse APIs.
- Built on a larger base model trained with extended reinforcement learning on complex tasks, it natively understands the Grok Bot harness for enhanced agentic self-verification and long-horizon work.
- Artificial Analysis evaluation shows the Intelligence Index increased from 44 (Grok 4.6) to 46, and Coding Agent Index increased from 47 to 56.
- Performance improvements require trade-offs, roughly doubling output tokens per task (~81k vs. ~38k for Grok 4.6 on Intelligence Index tasks at xhigh effort).
- xAI incorporated an entirely new safeguard stack designed to improve jailbreak resistance and refusal accuracy.

**Why it matters:** Developers can now deploy Grok 4.7's enhanced long-horizon coding and agentic capabilities directly through AWS Bedrock using configurable reasoning controls to manage output token costs.

### [Introducing Claude Sonnet 5.5 on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-sonnet-5-5-on-aws/)

**AWS Machine Learning Blog** · 2026-09-28

Claude Sonnet 5.5 is now available on Amazon Bedrock and Claude Platform on AWS, offering faster execution and lower cost per task for well-scoped coding and knowledge work.

- Integrated with native AWS governance tools including IAM, CloudTrail, CloudWatch, Bedrock Guardrails, and Regional data residency.
- Optimized for high-throughput, well-scoped execution tasks like alert response, SQL generation, UI/UX testing, and short document or spreadsheet edits.
- Designed to pair with Opus 5.5, where Opus handles complex judgment calls and Sonnet 5.5 executes lower-cost, faster downstream tasks.
- Accessible programmatically via the Anthropic Messages API, Boto3 SDK, or AWS CLI using the model identifier global.anthropic.claude-sonnet-5-5.

**Why it matters:** Organizations can deploy high-speed AI for continuous, large-scale engineering and enterprise workloads while staying within their existing AWS security and data residency controls.

### [How Decathlon runs demand forecasting at scale with Chronos-2](https://aws.amazon.com/blogs/machine-learning/how-decathlon-runs-demand-forecasting-at-scale-with-chronos-2/)

**AWS Machine Learning Blog** · 2026-08-28

Decathlon selected Chronos-2 to modernize its global demand forecasting stack on AWS, replacing DeepAR and Temporal Fusion Transformer models to predict 12-week and 52-week sales horizons across tens of thousands of products.

- Decathlon evaluates weekly demand across two horizons: a 12-week replenishment window for purchase planners and a 52-week strategic horizon for long-term capacity planning.
- The forecasting system operates across multiple global supply zones (including Europe, India, China, SEA, and LATAM), covering up to 25,000 products per zone.
- Chronos-2 replaced previous hybrid approaches that relied on weekly retraining of Amazon SageMaker AI DeepAR, Holt-Winters exponential smoothing, and Temporal Fusion Transformers.
- Decathlon benchmarked models across 101 rolling cutoffs (2022–2024) evaluating 39,000 unique product time series using Weighted Absolute Percentage Error (WAPE), RMSE, bias, and pairwise win rates.
- Fine-tuned Chronos-2 consistently outperformed all other evaluated time series foundation models across both prediction horizons, while zero-shot Chronos-2 matched or surpassed previous production baselines.

**Why it matters:** Adopting pre-trained time series foundation models like Chronos-2 eliminates the high operational overhead of weekly model retraining while improving multi-horizon retail forecast accuracy at scale.

### [Agentic observability with Amazon OpenSearch Service MCP Apps](https://aws.amazon.com/blogs/machine-learning/agentic-observability-with-amazon-opensearch-service-mcp-apps/)

**AWS Machine Learning Blog** · 2026-08-25

Amazon OpenSearch Service now supports Model Context Protocol (MCP) Apps, enabling AI agents to return both text responses and interactive observability visualizations directly inside the IDE chat window.

- MCP Apps extend the Model Context Protocol using a dual response pattern that delivers concise structured text alongside interactive UI components.
- Renders deterministic visualizations—including trace waterfalls, service maps, and log pattern views—by executing code against backend OpenSearch data sources.
- Uses a local MCP server on the user's machine to act as a secure bridge between the agentic IDE and the OpenSearch UI application.
- Eliminates manual verification overhead by avoiding context-switching, separate browser tab navigation, and manual query re-execution.

**Why it matters:** It removes the operational bottleneck of manually verifying AI agent hypotheses in external browser tools by embedding live, deterministic dashboard visualizations directly in the developer's chat workflow.

### [How ONESTRUCTION built the Ishigaki-IDS foundation model with AWS GenAIIC](https://aws.amazon.com/blogs/machine-learning/how-onestruction-built-the-ishigaki-ids-foundation-model-with-aws-genaiic/)

**AWS Machine Learning Blog** · 2026-08-11

ONESTRUCTION and AWS GenAIIC developed Ishigaki-IDS, a domain-specialized foundation model based on Qwen3 that automates Building Information Modeling (BIM) Information Delivery Specifications (IDS) authoring.

- Addresses data scarcity and specialized syntax in construction by using synthetic data generation to overcome the lack of public IDS corpora published since 2024.

**Why it matters:** It lowers the technical barrier for non-specialists to create and validate structured XML-based BIM specifications, mitigating labor shortages in the construction industry.

### [Securing AI agents with temporal policies in Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/securing-ai-agents-with-temporal-policies-in-amazon-bedrock-agentcore/)

**AWS Machine Learning Blog** · 2026-08-06

Amazon Bedrock AgentCore introduces temporal policies, enabling gateway-level, stateful authorization that evaluates tool calls against an AI agent's prior session trajectory.

- Temporal policies enforce stateful authorization rules at the AgentCore Gateway perimeter, operating outside the agent's code to prevent circumvention.
- The policies evaluate current requests using the agent's historical trajectory to enforce correct tool-call sequencing, output integrity, and data freshness.
- Temporal policies mitigate risks like hallucinations between chained tools, runaway loops exceeding cumulative financial limits, and unauthorized privileged actions.

**Why it matters:** Stateful policy enforcement at the gateway level prevents AI agents from executing harmful sequences of actions even when individual tool calls appear valid in isolation.

### [Control agent behaviors and cost beyond a single action: new capabilities in Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/control-agent-behaviors-and-cost-beyond-a-single-action-new-capabilities-in-amazon-bedrock-agentcore/)

**AWS Machine Learning Blog** · 2026-08-06

AWS introduced temporal policies powered by the open-source Dogwood language and rate-limiting features to Amazon Bedrock AgentCore to evaluate and control sequences of agent actions.

- Temporal policies evaluate an agent's current request alongside previous session actions to enforce boundaries on entire sequences rather than stateless, isolated calls.
- Policies can validate data consistency across calls (e.g., matching account numbers), enforce sequential workflows, track session-level budget totals, and mandate recorded human approvals.
- AgentCore applies these controls automatically at the managed gateway layer for AI traffic, including Model Context Protocol (MCP) servers, LLMs, and knowledge bases.
- The features address agent failure modes like budget-draining retry loops, circumventing individual purchase thresholds, and executing parameter-mismatched actions.

**Why it matters:** Enforcing stateful, sequence-aware security controls at the infrastructure gateway prevents unauthorized multi-step agent behavior without relying on custom application-level code.

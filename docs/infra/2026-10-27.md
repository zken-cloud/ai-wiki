### [Groundhog Day for AI agents: Prompt caching patterns for using OpenAI models on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/groundhog-day-for-ai-agents-prompt-caching-patterns-for-using-openai-models-on-amazon-bedrock/)

**AWS Machine Learning Blog** · 2026-10-26

AWS details how to optimize agentic AI costs and response latency on Amazon Bedrock using implicit and explicit prompt caching patterns to avoid re-processing identical context.

- Prompt caching saves the model's prefill key-value (KV) vectors across requests, eliminating the need to re-compute identical prefix tokens.
- Implicit caching lets Amazon Bedrock automatically select where the reusable prompt prefix ends as conversation history grows.
- Explicit caching uses prompt_cache_breakpoint in code to mark fixed content like tool definitions and system instructions for cross-session reuse.
- Combining implicit and explicit caching allows agents to maintain a shared reusable starting state while managing dynamic session histories automatically.

**Why it matters:** Using prompt caching substantially reduces token costs and response times for multi-turn AI agents by reusing prefill states instead of reading long histories on every turn.

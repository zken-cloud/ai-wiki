### [Asynchronous patterns for calling Amazon Bedrock AgentCore agents in serverless pipelines](https://aws.amazon.com/blogs/machine-learning/asynchronous-patterns-for-calling-amazon-bedrock-agentcore-agents-in-serverless-pipelines/)

**AWS Machine Learning Blog** · 2026-08-19

AWS details asynchronous invocation patterns for Amazon Bedrock AgentCore agents in serverless Step Functions pipelines to eliminate idle compute costs caused by synchronous blocking callers.

- Synchronous calls to Amazon Bedrock AgentCore agents force calling compute services like AWS Lambda to remain active and incur full runtime costs while waiting for responses.
- Amazon Bedrock AgentCore runtime uses a consumption-based model that does not charge for CPU while the agent is idling on LLM responses or Model Context Protocol (MCP) calls.
- The article evaluates three non-blocking asynchronous architectural patterns—task-token callback, direct service integration, and durable functions—against the synchronous blocking anti-pattern.
- The demonstration uses a five-stage real-estate document processing pipeline (Extract, Identify, Route, Organize and Validate, Result) where only the agent invocation branch is modified.

**Why it matters:** Decoupling caller compute execution from agent reasoning time prevents substantial AWS Lambda billing waste during long-running generative AI agent workflows.

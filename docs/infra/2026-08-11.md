### [Fast, On Device Agentic AI with Muse Glimmer on ExecuTorch](https://pytorch.org/blog/fast-ondevice-agentic-ai-with-executorch/)

**PyTorch Blog** · 2026-08-10

Meta has released Muse Glimmer, a 30-billion-parameter open-weight model distilled from Muse Spark, along with ExecuTorch end-to-end runtime support for NVIDIA CUDA and Apple silicon backends.

- ExecuTorch exports PyTorch graphs directly from GGUF checkpoints using ahead-of-time compilation via torch.export, autotuning Triton kernels for CUDA and leveraging MLX/Metal on Apple silicon.
- Supports advanced features on-device, including a 128K+ token context, text and image multimodal inputs, native K-quant execution, and DFlash parallel diffusion-based speculative decoding.
- Prebuilt serialized PTE artifact bundles are available on Hugging Face, alongside CMake presets for building standalone runners and LLM agent serving workers.

**Why it matters:** It enables developers to deploy complex, multimodal agentic LLM workflows locally on consumer hardware without rewriting PyTorch architectures or decoding strategies in non-Python frameworks.

### [Run interactive IDEs on Amazon EKS with SageMaker AI to power up your AI workflows](https://aws.amazon.com/blogs/machine-learning/run-interactive-ides-on-amazon-eks-with-sagemaker-ai-to-power-up-your-ai-workflows/)

**AWS Machine Learning Blog** · 2026-08-10

The Amazon SageMaker AI Spaces add-on (version 0.1.4+) for Amazon EKS enables data scientists to deploy managed JupyterLab and Code Editor IDEs directly on existing EKS clusters.

- Reduces setup time for interactive IDE environments with storage, GPU, and auth access from 3-5 days to approximately 5 minutes.
- Improves cluster efficiency by increasing GPU utilization up to 30 percent through consolidating interactive and training workloads on shared nodes.
- Leverages Traefik for host-based routing, AWS KMS for JWT encryption, and EKS Pod Identity for scoped IAM roles.
- Supports browser access via presigned URLs/OIDC via Amazon Cognito, as well as VS Code connections over SSH-over-SSM.

**Why it matters:** Running interactive IDEs natively on EKS eliminates separate notebook fleets, lowering infrastructure costs while giving data scientists direct access to existing cluster storage, GPU nodes, and IAM roles.

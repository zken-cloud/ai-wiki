### [OCP Global Summit: Amid Ecosystem Adoption, NVIDIA Opens Vera Rubin Architecture to Help Scale AI Factories Worldwide](https://blogs.nvidia.com/blog/ocp-global-summit-vera-rubin-scale-ai-factories/)

**NVIDIA Blog** · 2026-10-12

At the OCP Global Summit, NVIDIA contributed its Vera Rubin rack and compute tray designs to the open NVIDIA MGX architecture to standardize next-generation gigawatt-scale AI factory infrastructure.

- Updated MGX 1.2 specifications for Vera Rubin introduce rack-scale blind-mate liquid cooling, a 5,000A liquid-cooled busbar, native 19-inch equipment support, and support for up to 250kW rack deployments.
- NVIDIA introduced the Vera CPU rack design within MGX, tailored for agentic AI workloads including tool calling, orchestration, and sandboxed execution.
- Networking and hardware standards were expanded, including the USFP standard with Cisco for 400Gb/s fabrics and ConnectX-10/BlueField DPU support for Google's Falcon Transport.
- Meta and NVIDIA advanced open networking using Spectrum-X Ethernet SuperNIC and Spectrum-6, while Visionbay introduced an 800V DC AI factory design.

**Why it matters:** Open-sourcing hardware, power, and cooling specifications allows data center partners to build interoperable, high-density AI infrastructure with lower manufacturing and deployment times.

### [NTS: Authenticated Time at Meta](https://engineering.fb.com/2026/10/06/production-engineering/nts-authenticated-time-at-meta/)

**Meta Engineering** · 2026-10-06

Meta has deployed Network Time Security (NTS, RFC 8915) at nts.meta.com and open-sourced its protocol, client, and stateless server implementation within Meta's Time library on GitHub.

- Uses a stateless server architecture where NTS cookie keys are derived rather than stored or replicated across nodes.
- Employs Phase 1 NTS-KE over TLS 1.3 (TCP/4460) with ALPN ntske/1 to negotiate AEAD algorithms and derive C2S and S2C session keys via RFC 5705 exporters.
- Negotiates AEAD algorithms including the RFC 8915 mandatory-to-implement AES-SIV-CMAC-256 (ID 15).
- Provides initial key establishment issuing eight cookies and server negotiation records before closing the TCP connection to avoid per-packet state.
- Addresses vulnerability windows exacerbated by shortening TLS certificate lifespans (dropping to 47 days by March 2029 under CA/Browser Forum ballot SC-081v3).

**Why it matters:** Authenticating NTP prevents man-in-the-middle time manipulation attacks that undermine TLS certificate validation, credential expiration, log correlation, and automated ACME renewal loops.

### [Building a High-Performance and Portable vLLM Linear Backend with Helion](https://pytorch.org/blog/building-a-high-performance-and-portable-vllm-linear-backend-with-helion/)

**PyTorch Blog** · 2026-10-02

Helion was integrated into vLLM's linear backend to replace manual GEMM implementations with an autotuned, high-level kernel DSL.

- A single Helion GEMM implementation covers multiple algorithmic variants, including Standard GEMM, Split-K, and Swap-AB, via per-shape autotuning.
- On NVIDIA Hopper GPUs, the Helion backend combined per-shape tuning with hybrid dispatch to outperform vLLM's default CUTLASS and DeepGEMM backends, achieving over 10% throughput improvement on some workloads.
- Helion formulates kernel tuning as a structured numerical optimization problem over an ahead-of-time (AOT) search space, supplemented by LLM-guided search.
- A primary challenge is the ahead-of-time tuning overhead, which can take hours due to fine-grained tuning strategies.

**Why it matters:** It enables LLM serving engines to automatically generate hardware-optimized, high-throughput linear kernels without requiring manual kernel specialization or expert engineering effort.

### [NVIDIA DGX Spark 64GB Gives Developers More Ways to Build and Scale Local AI](https://blogs.nvidia.com/blog/local-ai-dgx-spark-64gb-sync/)

**NVIDIA Blog** · 2026-10-02

NVIDIA announced a new 64GB unified memory configuration of the DGX Spark personal AI supercomputer, allowing developers to run models up to 100 billion parameters locally or cluster two units for expanded workloads.

- Powered by the NVIDIA GB10 Grace Blackwell Superchip, ConnectX-7 networking, and DGX OS with out-of-the-box support for CUDA-X, Nemotron models, Ollama, vLLM, and PyTorch.
- A single 64GB unit runs up to 100-billion-parameter models, while two units can be directly linked via QSFP cable and NVIDIA Sync Cluster Assistant to pool 128GB memory and support up to 200-billion-parameter models.
- In NVIDIA testing with Qwen 3.8 27B, a clustered two-unit system achieved up to 1.7x performance and doubled memory bandwidth compared to a single unit.
- Features the upcoming NVIDIA Sync Model Launcher for automated model deployment across clustered nodes and integration with OpenCode and Blender.
- Hardware available through partner manufacturers Acer, ASUS, Dell, Gigabyte, HP, and MSI.

**Why it matters:** It provides a lower-cost, on-premise hardware platform that enables developers to run, fine-tune, and scale agentic LLM workloads locally without cloud dependency or complex network setup.

### [Fine-tune a search agent with multi-turn RL on Amazon SageMaker AI](https://aws.amazon.com/blogs/machine-learning/fine-tune-a-search-agent-with-multi-turn-rl-on-amazon-sagemaker-ai/)

**AWS Machine Learning Blog** · 2026-10-02

Amazon SageMaker AI MTRL enables fine-tuning small LLM search agents using multi-turn reinforcement learning and policy gradient algorithms across complete interaction trajectories without needing expert SFT demonstrations.

- MTRL optimizes agents across multi-step sequences using rewards based on the final outcome, bypassing the limitations of single-turn RL and SFT.
- Provides serverless, asynchronous rollout and trajectory collection with bounded off-policy staleness to parallelize generation and gradient updates.
- Includes a native algorithm library featuring PPO, CISPO, IS losses, and group-based advantage estimators like GRPO, GRPO pass@k, and RLOO.
- Offers observability through managed MLflow to inspect turn-by-turn trajectories, custom reward functions, and tool loops.

**Why it matters:** Fine-tuning smaller models via multi-turn RL delivers the multi-step reliability of large frontier models at lower latency and inference costs.

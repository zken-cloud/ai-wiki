### [Serving DeepSeek-V4.1-Flash at Scale: vLLM Matches DeepInfer and Scales to GB300 NVL72](https://vllm.ai/blog/2026-10-23-deepseek-v41-flash-pd-wide-ep)

**vLLM Blog** · 2026-10-23

vLLM scales DeepSeek-V4.1-Flash serving to a full GB300 NVL72 rack using P/D disaggregation and Wide-EP, matching DeepSeek's native DeepInfer engine throughput within 6%.

- Achieves 954K tokens/s per GPU at a P90 latency of 196 tokens/s per user on the SemiAnalysis AgentX benchmark using GB300 NVL72.
- Delivers a 7.9x throughput increase over single-node aggregated results and reaches 826 tokens/s for a single user via a specialized low-latency decode path.
- Matches DeepInfer's decode throughput within 6% across batch sizes 8–256 at 131K context with nextn=3.
- Integrates open-source DeepSeek kernels including MegaAttn, MegaMoE, and Mega-mHC, utilizing DEP2 prefill without redundant experts.

**Why it matters:** It demonstrates that general-purpose open-source serving frameworks like vLLM can match specialized, vendor-native inference engines at rack-scale deployment.

### [Amazon Polly delivers a major upgrade to its Generative engine](https://aws.amazon.com/blogs/machine-learning/amazon-polly-delivers-a-major-upgrade-to-its-generative-engine/)

**AWS Machine Learning Blog** · 2026-10-22

AWS has upgraded the Amazon Polly Generative engine, adding 14 new voices across 9 locales, introducing Hindi and Finnish, and expanding Region availability to AWS GovCloud (US-West).

- Drop-in upgrade for existing generative voices that requires no changes to API calls or voice names.
- Brings the total generative voice catalog to 57 voices across 11 languages and 25 locales.
- Adds 14 new voices including US English (Kenneth, Nate), Australian English (Russell, Curtis), Hindi (Kiara, Arjun), and Finnish (Suvi).
- Offers context-based speech delivery that adapts emotion, prosody, and accuracy for numbers, currency, and addresses without manual setup.

**Why it matters:** Developers can automatically access improved speech accuracy, expressive prosody, and broader language support without rewriting existing AWS API integrations or IAM policies.

### [ClusterNetworkPolicy in GKE: Balancing control and autonomy for your microservices](https://cloud.google.com/blog/products/networking/new-clusternetworkpolicy-in-gke/)

**Google Cloud Blog** · 2026-08-10

ClusterNetworkPolicy is a new feature in GKE that provides cluster-wide network security control, enabling administrators to set overarching traffic rules across all namespaces while preserving tenant autonomy.

- Introduces ClusterNetworkPolicy to enforce baseline network security controls across entire GKE clusters.
- Allows platform administrators to define cluster-wide security rules without overriding namespace-level NetworkPolicies.
- Balances centralized security governance with microservices autonomy for multi-tenant GKE environments.

**Why it matters:** Platform teams can enforce mandatory cluster-wide security baselines without breaking developer-managed namespace network configurations.

### [PyTorch 2.13 Release Blog](https://pytorch.org/blog/pytorch-2-13-release-blog/)

**PyTorch Blog** · 2026-07-08

PyTorch 2.13 introduces FlexAttention on Apple Silicon, CuTeDSL for Inductor, nn.LinearCrossEntropyLoss for memory reduction, and torchcomms for distributed training improvements, alongside broader platform support.

- FlexAttention on Apple Silicon (MPS) achieves up to 12x speedup on sparse patterns and gains a deterministic backward path on CUDA with negligible performance impact (+0.2% at S=32768).
- CuTeDSL provides a new high-performance backend for Inductor's GPU operations, complementing Triton, with faster compilation.
- nn.LinearCrossEntropyLoss reduces peak GPU memory by up to 4x for large-vocabulary language models by combining final prediction and loss computation.
- torchcomms, a new communications backend, enhances fault tolerance, scalability, and debuggability for large-cluster training, while FSDP2 now overlaps reduce-scatter and all-gather communications.

**Why it matters:** These updates significantly improve performance, memory efficiency, and scalability across various hardware and distributed training setups, making PyTorch more robust for production-scale AI.

### [How OneAdvanced deployed over 50 AI agents on UK-sovereign AWS](https://aws.amazon.com/blogs/machine-learning/how-oneadvanced-deployed-over-50-ai-agents-on-uk-sovereign-aws/)

**AWS Machine Learning Blog** · 2026-08-12

OneAdvanced deployed over 50 AI agents in the UK AWS London region by self-hosting Llama 4 Maverick and Llama Guard 4 on Amazon SageMaker AI to meet strict data sovereignty requirements.

- Models including Llama 4 Maverick (FP8) and Llama Guard 4 are self-hosted using vLLM on Amazon SageMaker AI using p5.48xlarge instances in the eu-west-2 region.
- Orchestration uses over 50 specialized Strands agents hosted on Amazon ECS with configuration parameters stored in Amazon DynamoDB.
- The RAG architecture converts documents from Amazon S3 into markdown, chunks them, and stores embeddings using the pgvector extension on Amazon Aurora PostgreSQL-Compatible Edition.
- Llama Guard 4 acts as a content moderation layer, evaluating user inputs for harmful content prior to main model inference.

**Why it matters:** Self-hosting open-weight models on dedicated cloud compute allows organizations in highly regulated sectors to deploy advanced AI agents while maintaining total in-country data sovereignty.

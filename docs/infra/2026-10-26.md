### [5 production challenges in multi-agent systems and how Deep Insight solved them](https://aws.amazon.com/blogs/machine-learning/5-production-challenges-in-multi-agent-systems-and-how-deep-insight-solved-them/)

**AWS Machine Learning Blog** · 2026-10-21

AWS introduced Deep Insight, an open-source production-grade multi-agent system designed to address context engineering, business logic enforcement, and operational challenges when running LLM agents at scale.

- Deep Insight employs a hierarchical multi-agent architecture comprising specialized Coordinator, Planner, Supervisor, Coder, Validator, Reporter, and Tracker agents.
- The system automates data analysis workflows by taking a CSV, column definitions, and a natural language prompt to generate validated charts and a customizable .docx report.
- The architecture integrates AWS infrastructure components including Strands Agents SDK, Amazon Bedrock, Amazon Bedrock AgentCore, Application Load Balancer, and AWS Fargate.
- The design incorporates Anthropic Context Engineering techniques, human-in-the-loop plan approvals, real-time streaming, and structured note-taking.
- AWS released the codebase open-source on GitHub across three deployment configurations from development to production.

**Why it matters:** It offers an open-source reference implementation for moving multi-agent systems beyond prompt engineering into production-ready deployment with human oversight and rigid verification.

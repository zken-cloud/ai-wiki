### [Accelerating Dropless MoE Training in JAX with NVIDIA Transformer Engine](https://developer.nvidia.com/blog/accelerating-dropless-moe-training-in-jax-with-nvidia-transformer-engine/)

**NVIDIA Developer Blog** · 2026-09-14

NVIDIA Transformer Engine accelerates dropless Mixture of Experts (MoE) training in JAX by utilizing conditional computation over shared feed-forward networks.

- MoE architectures like DeepSeek, Qwen, and Mixtral achieve performance comparable to dense models using a fraction of the training compute.
- Conditional computation replaces a single shared dense feed-forward network (FFN) to increase model capacity efficiently.
- NVIDIA Transformer Engine provides JAX support to optimize dropless MoE training workflows.

**Why it matters:** Integrating Transformer Engine optimizations into JAX enables more compute-efficient training of large-scale dropless MoE models on NVIDIA GPUs.

### [Abnormal AI: Amazon Bedrock AgentCore for agentic email security at scale](https://aws.amazon.com/blogs/machine-learning/abnormal-ai-amazon-bedrock-agentcore-for-agentic-email-security-at-scale/)

**AWS Machine Learning Blog** · 2026-09-14

Abnormal AI has integrated Amazon Bedrock AgentCore Code Interpreter into its production runtime to execute agent-driven code and process data at a scale of billions of email messages.

- Amazon Bedrock AgentCore Code Interpreter provides a fully managed, serverless sandbox runtime running on ephemeral MicroVM sessions with TTLs ranging from 15 minutes to 8 hours.
- The runtime supports preloaded Python and Node.js environments, handles direct API file payloads up to 100 MB or connects to Amazon S3 for larger datasets, and integrates with CloudWatch and CloudTrail.
- Abnormal AI currently uses background agents to build 40 percent of its code changes end-to-end and uses agents in 80 percent of its total code changes.
- Abnormal AI's email threat detection system uses a three-tiered architecture (heuristics, ML models, and agents) to process billions of messages daily and block inline threats.

**Why it matters:** It demonstrates how high-throughput security services can offload deterministic math, data analysis, and code verification from LLMs to secure, serverless code-execution sandboxes in production.

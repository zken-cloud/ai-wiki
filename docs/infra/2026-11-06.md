### [More Performance From Every Byte: How Full-Stack Codesign Solves AI’s Memory Challenge](https://blogs.nvidia.com/blog/memory-full-stack-codesign/)

**NVIDIA Blog** · 2026-11-05

NVIDIA is using full-stack codesign across hardware, software, and memory hierarchies to increase GPU memory efficiency and overcome HBM capacity and bandwidth limits for large AI models.

- Agentic applications and RAG inflate memory pressure by processing contexts up to 3 million tokens, causing KV cache and trillion-parameter model weights to compete for limited GPU HBM.
- Relying solely on adding HBM capacity hits a memory wall where fixed memory bandwidth cannot supply data fast enough to match GPU compute capacity, increasing costs and power consumption.
- NVIDIA manages data across a multi-tiered hierarchy spanning GPU HBM, CPU memory, local SSDs, and shared storage to place data on the optimal tier based on speed and cost.
- Full-stack optimizations like the NVFP4 precision format reduce model weight storage requirements compared to Hopper's FP8 format.
- Despite HBM capacity per GPU increasing by only ~3% from Blackwell Ultra to Vera Rubin, agentic throughput per dollar increased up to 30x on the SemiAnalysis AgentX benchmark.

**Why it matters:** Full-stack memory management enables AI factories to scale agentic inference throughput and context lengths affordably without being constrained by HBM supply shortages and cost limits.

### [Build a semantic layer for agentic AI with EDB Postgres AI and Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/build-a-semantic-layer-for-agentic-ai-with-edb-postgres-ai-and-amazon-bedrock-agentcore/)

**AWS Machine Learning Blog** · 2026-11-03

EDB Postgres AI introduces a database-native semantic layer (SemKB) via its AIDB extension, exposing schema metadata, foreign keys, and access controls directly to external agentic AI using Amazon Bedrock AgentCore and MCP endpoints.

- AIDB uses standard Postgres COMMENT ON statements and aidb.create_semantic_alias to define business logic, while relying on foreign keys to automatically build join paths across schema tables.
- The operational Postgres database hosts an internal Model Context Protocol (MCP) endpoint, which is exposed to agents via an Application Load Balancer and registered on AgentCore Gateway.
- Data governance and privacy rely natively on Postgres GRANT statements, column-level security, and row-level security (RLS), allowing different authorization roles to produce distinct query results using identical prompt and tool setups.
- AIDB provides direct observability by logging OpenTelemetry traces for every database-executed SQL statement as queryable rows inside the aidb_otel schema.

**Why it matters:** Embedding the semantic layer and security governance directly inside the operational database eliminates the need for separate advisory prompt controls or external virtualization layers when serving agentic AI workflows.

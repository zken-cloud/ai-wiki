### [ServiceNow on-behalf-of token exchange with Bedrock AgentCore Gateway](https://aws.amazon.com/blogs/machine-learning/servicenow-on-behalf-of-token-exchange-with-bedrock-agentcore-gateway/)

**AWS Machine Learning Blog** · 2026-11-03

Amazon Bedrock AgentCore Gateway supports on-behalf-of (OBO) token exchange with Microsoft Entra ID to propagate user identity from AI agents to ServiceNow REST APIs.

- AgentCore Gateway automates OBO token exchange on every request, mapping inbound agent-scoped JWTs to downstream API connector-scoped tokens.
- The gateway sends the inbound token, agent client credentials, target scope, and requested_token_use: on_behalf_of parameter to the Entra token endpoint.
- The process relies on two Microsoft Entra ID application registrations: one for the AI agent and one for the ServiceNow API connector.
- Downstream ServiceNow REST APIs receive tokens containing a preferred_username claim that maps to existing user accounts, preserving identity, audit trails, and access controls.

**Why it matters:** Identity propagation prevents AI agents from executing API calls as generic service accounts, ensuring enterprise user-level permissions and audit logging are maintained.

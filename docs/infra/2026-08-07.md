### [Configure rate limits for AI traffic on AgentCore gateway](https://aws.amazon.com/blogs/machine-learning/configure-rate-limits-for-ai-traffic-on-agentcore-gateway/)

**AWS Machine Learning Blog** · 2026-08-06

Amazon Bedrock AgentCore gateway now supports per-user rate limiting using request, connection, and token-based metrics across its target types.

- Supports three rate limit metrics: Requests per second/minute (RPS/RPM) for all targets, Tokens per minute (TPM) for inference targets, and Connections per second (CPS) for tracking concurrent long-lived sessions.
- TPM limits deduct upfront token estimates using a general-purpose tokenizer, reconciling with true input/output token counts reported by the model provider upon response.
- Enables granular per-user control across MCP, inference, and HTTP passthrough targets using OAuth or IAM-based rules combined with AgentCore Identity JWTs and RBAC policies.

**Why it matters:** It prevents AI tool and model exhaustion by controlling traffic throughput, token costs, and long-lived streaming connections per user group.

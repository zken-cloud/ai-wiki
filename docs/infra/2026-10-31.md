### [Preview web apps live as your coding agent builds them with Amazon Bedrock AgentCore runtime](https://aws.amazon.com/blogs/machine-learning/preview-web-apps-live-as-your-coding-agent-builds-them-with-amazon-bedrock-agentcore-runtime/)

**AWS Machine Learning Blog** · 2026-10-30

Amazon Bedrock AgentCore runtime introduced Session endpoints, allowing developers to live-preview web applications built by coding agents inside isolated session microVMs.

- Session endpoints expose an authenticated URL per session, forwarding HTTP/1.1, HTTP/2, gRPC, Server-Sent Events, and WebSockets to specified ports within the 8000–12000 range (excluding reserved ports).
- Inbound traffic requires SigV4 signatures or bearer tokens alongside the bedrock-agentcore:InvokeAgentRuntimeProxy IAM permission.
- Target ports inside the microVM are routed using prefix-based hostnames (e.g., https://8090--<session-endpoint-id>.runtime.bedrock-agentcore.<region>.on.aws) while the client connects over port 443.
- Applications inside the microVM must bind to 0.0.0.0, and developers can run a local SDK proxy (e.g., on localhost:8088) to inject authentication into browser requests and WebSocket handshakes.

**Why it matters:** It eliminates the delay of copying and deploying code to external hosting services during iterative development, enabling real-time browser preview and live-reloading as an agent modifies web app files.

### [Fix evaluation bias to unlock better models on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/fix-evaluation-bias-to-unlock-better-models-on-amazon-bedrock/)

**AWS Machine Learning Blog** · 2026-10-27

Property Finder discovered 96.8 percent of their ground truth labels were derived from an incumbent VLM, hiding evaluation bias that they resolved through prompt optimization and expert annotation on Amazon Bedrock.

- Property Finder found that 96.8% of their image quality evaluation labels inherited the incumbent vision language model's outputs without expert verification, introducing circular evaluation bias.
- The evaluation dataset contained character-level mistakes in watermark extraction, forced single labels on multi-room photos, and inconsistent categories outside the prompt specification in the 3.2% human-labeled sample.
- The engineering team built an unbiased ground truth using a 256-image expert-annotated development set, scoring image attribute predictions via Micro F1 scores.
- Through an iterative prompt optimization loop spanning versions v0 to v27 using evolutionary prompt optimization, Property Finder achieved higher accuracy alongside an 86% cost reduction.

**Why it matters:** Evaluating models against incumbent-generated ground truth introduces systemic bias, meaning teams must use independent human expert labels to accurately measure alternative model performance and realize cost savings.

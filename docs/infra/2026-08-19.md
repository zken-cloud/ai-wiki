### [How Jumio built a real-time feature store on AWS](https://aws.amazon.com/blogs/machine-learning/how-jumio-built-a-real-time-feature-store-on-aws/)

**AWS Machine Learning Blog** · 2026-08-18

Jumio built a centralized, streaming-first real-time feature store on AWS across three regions to deliver sub-100ms feature retrieval latency for identity verification and fraud detection models.

- Architecture utilizes Amazon Kinesis Data Streams for event ingestion, Managed Service for Apache Flink for real-time feature engineering, and SageMaker Feature Store for low-latency in-memory storage.
- A parallel offline pipeline streams events through Amazon Data Firehose into Amazon S3, using Amazon EMR to output Apache Iceberg tables for model training and backfilling.
- Deployed across three AWS regions: us-east-1, eu-central-1, and ap-southeast-1 to handle delayed events and maintain scale.
- Eliminated manual production re-implementation of offline-trained features in Java/Python to reduce bugs, data duplication, and feature drift.

**Why it matters:** This streaming-first design enables real-time ML fraud detection models to retrieve features under 100 milliseconds without discrepancies between training and inference environments.

### [HarnessSafe: Evaluating Safety Across Persistent Carriers in Agent Harnesses](https://arxiv.org/abs/2608.06984v1)

**arXiv cs.CR** · 2026-08-07 · `arXiv:2608.06984v1`

HarnessSafe is a new benchmark featuring 328 executable cases to evaluate delayed safety risks and containment across seven persistent-carrier families in AI agent harnesses.

- Evaluates how attacker influence persists across memory, skills, tools, and shared artifacts before being triggered by benign requests.
- Comprises 328 executable test cases defined using a Persistent-Risk Lifecycle that tracks attacks from initial entry to observable violation.
- Employs a multi-stage, trace-based evaluation method using execution evidence to pinpoint where attack chains progress or get blocked.
- Demonstrates that risk containment varies by carrier type, relies on specific harness-model configurations, and cannot be captured by end-to-end attack success rates alone.

**Why it matters:** It provides a framework to trace and isolate delayed, cross-boundary security vulnerabilities in persistent agent systems that standard end-to-end metrics fail to detect.

### [When Context Bites: Detecting RAG Poisoning via Document-Level Attention Collapse](https://arxiv.org/abs/2608.06947v1)

**arXiv cs.CR** · 2026-08-07 · `arXiv:2608.06947v1`

Researchers introduced D-SCAN, a lightweight detection framework that identifies RAG poisoning attacks by detecting document-level attention collapse in LLMs rather than relying on output-side uncertainty metrics.

- Poisoned documents induce false confidence in LLMs, causing attacked outputs to exhibit lower perplexity than benign generations and invalidating uncertainty-based detection.
- Attacked generations trigger Attention Collapse, where attention entropy decreases and focus concentrates heavily on poisoned documents compared to the dispersed attention of benign context.
- D-SCAN monitors internal attention dynamics at the document level to detect RAG poisoning attacks, including cases where the attack fails to alter the final output.

**Why it matters:** It provides a reliable, internal-state mechanism to defend RAG systems against adversarial document injection without relying on easily bypassed output perplexity or consistency checks.

<small>Yingtao Ren, Ziyi Zhao, Yiwei Fu, Xiao Luo, Yu-Cheng Chang, Chin-Teng Lin</small>

### [SynChain: Inducing Computer-Use Agent Systems to Construct Their Own Attack Chains](https://arxiv.org/abs/2608.06862v1)

**arXiv cs.CR** · 2026-08-07 · `arXiv:2608.06862v1`

SynChain introduces a self-synthesized attack paradigm that induces computer-use agents via persistence-aware fine-tuning to covertly embed malicious payloads into autonomously created, persistent artifacts like skills and memory entries.

- Computer-use agents (CUAs) persist state across tasks using synthesized artifacts, allowing covert payloads to survive internal state updates and bypass standard defenses without new external inputs.
- SynChain uses persistence-aware directed supervised fine-tuning to force agents to generate poisoned artifacts that appear benign but reactivate dormant payloads in future execution chains.
- Evaluated using CUAChain, a new dataset featuring 30 benign task chains and three attack objectives tested across OpenClaw, Codex, and Claude Code under four defense settings.
- Demonstrates that dormant malicious influence can propagate internally across execution trajectories as trusted context.

**Why it matters:** Traditional temporally bounded security defenses fail against CUAs, necessitating provenance-aware reasoning over long-term, cross-task execution trajectories to prevent persistent internal state compromise.

<small>Fuyao Zhang, Jiaming Zhang, Che Wang, Boyang Chen, Yurong Hao, Xiongtao Sun, Guowei Guan, Blaise Delattre</small>

### [Understanding and Improving Model Editing for Secure Code Generation](https://arxiv.org/abs/2608.06848v1)

**arXiv cs.CR** · 2026-08-07 · `arXiv:2608.06848v1`

A systematic study evaluates model editing for secure code generation and introduces SafeEdit, a post-edit refinement method that recovers functional correctness lost during model editing while preserving security gains.

- Model editing improves security ratios by 15%-25% over vanilla models on seen vulnerabilities, outperforming the CoSec inference-time baseline and maintaining stability under prompt perturbations.
- Model editing exhibits limited generalization to unseen vulnerability types and causes a decline in overall model functional correctness.
- SafeEdit combines functional tuning with edit-aware regularization to improve Pass@1 over UltraEdit by 11.73, 13.70, and 15.50 percentage points at temperatures T=0.1, 0.4, and 0.8, respectively.
- SafeEdit achieves 7.54%-12.04% relative security-ratio gains over CoSec and can be combined with CoSec for further security enhancements without sacrificing functional correctness.

**Why it matters:** SafeEdit demonstrates that model-level editing can permanently remediate security vulnerabilities in code-generating LLMs without sacrificing runtime performance or code correctness.

<small>Weifeng Sun, Quanjun Zhang, Yuchen Chen, Chengran Yang, Gou Tan, David Lo</small>

### [When Coordination Becomes a Threat: Communication Attacks in LLM-Controlled Multi-Robot Systems](https://arxiv.org/abs/2608.06830v1)

**arXiv cs.CR** · 2026-08-07 · `arXiv:2608.06830v1`

A study evaluates External Entry Point and Privileged In-System communication attacks against LLM-controlled multi-robot architectures (DMAS, HMAS-1, HMAS-2) and proposes the Claim Provenance and Verification (CPV) Gate to mitigate unsafe action risks.

- Evaluated communication attacks across three architectures (DMAS, HMAS-1, HMAS-2) using three LLMs on five embodied multi-robot tasks.
- Unsafe information propagation resulted in high attack success rates: DMAS achieved a 96.7% entry endorsement rate and 100% post endorsement activation rate, HMAS-1 reached a 97.8% unsafe action success rate, and HMAS-2 triggered 88.3% of unsafe action slots.
- Introduced the Claim Provenance and Verification (CPV) Gate to verify transmitted claims prior to downstream reuse, which reduced the overall violation rate from 70.0% to 36.6%.

**Why it matters:** Demonstrating that natural language planning protocols in multi-robot systems are highly vulnerable to communication attacks highlights the necessity of cryptographic or provenance verification mechanisms before executing distributed tasks.

### [LoRAScan: Detecting Backdoor Prompts in Low-Rank Adapters for Large Language Models via Down-Projection Activation Spikes](https://arxiv.org/abs/2608.06795v1)

**arXiv cs.CR** · 2026-08-07 · `arXiv:2608.06795v1`

LoRAScan is an adapter-aware, inference-time defense that detects and rejects backdoor trigger-bearing inputs in LoRA-adapted LLMs without modifying adapter parameters by monitoring down-projection activation spikes.

- Backdoored LoRA adapters create distinct latent-space signatures, causing concentrated activation spikes in down-projection layers during trigger-bearing inputs.
- Approximately 5% of LoRA insertion sites remain stable across clean inputs but exhibit high activation spikes when a backdoor trigger is present.
- LoRAScan profiles these low-variance insertion sites before deployment to monitor and reject malicious inputs during inference.
- Evaluations show LoRAScan rejects approximately 98.49% of malicious inputs with a low false-positive rate on clean inputs, outperforming existing defenses.

**Why it matters:** It mitigates supply-chain security risks from untrusted LoRA adapters by blocking backdoor attacks at inference time without requiring model retraining or parameter modification.

<small>Doniyorkhon Obidov, Honggang Yu, Xiaolong Guo, Kaichen Yang</small>

### [Policy-Masked Private Experts: Auditable and Reversible Capability Access Control in Sparse MoE Models](https://arxiv.org/abs/2608.06690v1)

**arXiv cs.CR** · 2026-08-07 · `arXiv:2608.06690v1`

Policy-Masked Private Experts provides auditable, reversible access control in sparse MoE models by routing requests between frozen public experts and a disjoint private expert branch prior to top-k routing.

- Freezes a pretrained sparse MoE model (tested on Qwen3-30B-A3B and DeepSeek-V2-Lite) and routes inputs to either public or newly trained private expert pools based on authorization.
- Achieved zero unauthorized private expert executions across 64 adversarial scenarios and 96 deny/fail-closed events, verified by independent execution hooks.
- Outperforms post-hoc request gating on LoRA, which left 1,225 unauthorized adapter calls under deny conditions compared to zero for the disjoint expert branch.
- Private expert branches improved exact tool use by up to 21.3 percentage points on frozen Qwen benchmarks and 27.0 percentage points on DeepSeek-V2-Lite.

**Why it matters:** It enables strict, execution-level parameter access control and exact allow-deny-allow reversibility in MoE architectures without leaving unauthorized computational paths open during forward passes.

<small>Zhuoheng Huang, Mukesh Singh</small>

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.06641v1`

PDFuzzer is a novel fuzzer that uses an LLM to infer JavaScript API call relationships from specifications and traces, generating complex API call sequences using a constraint solver.

- Combines LLM-constructed context-free grammars and execution traces with a constraint solver to build complex API call sequences.

### [Model Confidence Under Answer-Preserving Attacks: An Informativeness-Manipulability Frontier](https://arxiv.org/abs/2608.06571v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.06571v1`

Researchers evaluated vision-language model confidence readouts under answer-preserving image attacks, finding that adversarial perturbations systematically suppress confidence performance to or below answer-string accuracy prior floors.

- Coordinated attacks refuted uniform amplitude certificates and drove adversarial discrimination to or below the pooled answer-string floor (0.617) across all 60 deployed-channel evaluation cells.
- Hidden-state interventions demonstrated that comparable confidence shifts can be induced directly within representation space as well as via adversarial images.
- In confidence-gated simulations, transfer attacks to hidden-state gates caused up to 84.8% of previously rejected wrong answers to be accepted.
- Direct gate-aimed attacks caused accepted accuracy to fall below the no-gate baseline across all 12 tested benchmark cells.
- None of the four tested defense families successfully established a robust alternative under the evaluated attack threat model.

**Why it matters:** Confidence scores cannot serve as intrinsically robust oversight signals for automated gating, as adversary-manipulated confidence can reduce accuracy below using no confidence gate at all.

### [StepJack: Benchmarking Computer-Use Agent Safety Against Multi-Step Indirect Prompt Injection](https://arxiv.org/abs/2608.06477v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.06477v1`

StepJack introduces multi-step indirect prompt injection attacks against computer-use agents by splitting adversarial instructions into innocuous sub-steps across chained web pages.

- Introduces multi-step indirect prompt injection, decomposing adversarial goals across chains of referenced pages to maximize sub-step innocuousness.
- Presents the StepJack benchmark containing 480 test examples created via an automated goal-decomposition pipeline.
- Evaluated six state-of-the-art CUAs, finding multi-step attacks increased Attack Success Rate (ASR) by up to 31.2 percentage points on individual models (e.g., GPT-5.4-mini rose from 41.7% to 72.9%).
- Across five CUAs capable of following reference chains, average ASR increased from 31.3% (single-step) to 36.9% (three-step).

**Why it matters:** Splitting malicious instructions across multiple web pages allows attackers to bypass safety guardrails in computer-use agents by making individual prompts appear benign.

### [Fairis: Fairness-Aware Aggregation with Provable Influence Containment against Fairness Poisoning Attacks in Collaborative Machine Learning](https://arxiv.org/abs/2608.06469v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.06469v1`

Fairis is a server-side reweighting scheme for collaborative learning that provably bounds a malicious client's model displacement by penalizing updates based on local fairness scores.

- Uses unnormalized client weights defined as $\bar{w}_k = \eta - \mathcal{F}_k$, where $\mathcal{F}_k$ is the local Equal Opportunity Difference and $\eta > 1$ is a security parameter.
- Proves Monotone Weight Reduction, Demographic Participation, and Non-Gamesmanship properties, extending weight reduction guarantees to colluding minority coalitions.
- Combines weight reduction with server-side norm clipping to bound an adversary's global model displacement by $\omega_0 C$, strictly decreasing with its reported disparity.
- Reduces stealthy adversary weight by 41% to 54% compared to a size-blind control on the Taiwan Credit dataset, while maintaining strictly positive weights for all clients.

**Why it matters:** It provides provable mathematical bounds against fairness poisoning attacks in collaborative learning without needing to discard untrusted clients completely.

<small>Devharsh Trivedi, Nesrine Kaaniche, Nikos Triandopoulos, Maryline Laurent, Jackson Walters</small>

### [When Experience Becomes Instruction: Trajectory Poisoning in Self-Evolving Agent Skill Systems](https://arxiv.org/abs/2608.05563v2)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05563v2`

PoisonedEvolution introduces a trajectory-poisoning attack on self-evolving skill systems, manipulating unverified experience logs to embed malicious target behaviors into persistent, trusted agent skill banks.

- Identifies Evolution Attribution as the critical bottleneck, requiring attacker-injected behaviors to appear causally useful, recurrent, and generalizable to achieve promotion.
- Achieved a 91.0% Skill Embedding Rate (546/600 trials) on SkillClaw across six LLM evolvers at a 10% attacker support ratio.
- Demonstrated cross-architecture transfer by achieving a 61.5% SER (369/600 trials) on the Trace2Skill pipeline using the same 10% support ratio.
- Ablations show three consistent attacker records in a 30-record batch reliably trigger promotion, driven by recurring support, causal framing, and domain-aligned encoding.

**Why it matters:** It establishes that unverified evidence promotion in self-evolving agents acts as an unmonitored attack surface, allowing untrusted operational data to compromise long-term system instructions.

### [Beyond Text Matching: Towards Reference-Free Evaluation for Human-Oriented Binary Reverse Engineering](https://arxiv.org/abs/2608.07038v1)

**arXiv cs.CR** · 2026-08-07 · `arXiv:2608.07038v1`

Researchers introduced BinJudgeBench and BinJudge, an adaptive LLM-as-a-Judge system using a routing mechanism for reference-free evaluation of Human-Oriented Binary Reverse Engineering (HOBRE) tasks.

- BinJudgeBench provides an expert-annotated benchmark across function name recovery, binary code summarization, and decompilation optimization tasks.
- LLM-as-a-Judge achieves a 63.20% average correlation with human experts, outperforming traditional automated metrics which average 35.04%.
- Optimal LLM judge configurations vary by task and sample, demonstrating that no single backbone model, prompting strategy, or temperature fits all scenarios.
- BinJudge's routing mechanism selects configurations per sample, increasing human correlation by 4.5%-24.7% while cutting API costs to 0.06x-0.84x of static best setups.

**Why it matters:** It enables scalable, cost-effective, and accurate automated evaluation of decompiled code enhancement without relying on execution environments or original source code references.

### [Adversarial Entropy Inflation Against Gumbel-Based Inference Verification](https://arxiv.org/abs/2608.23375v1)

**arXiv cs.CR** · 2026-08-24 · `arXiv:2608.23375v1`

Researchers demonstrated that prompt-driven adversarial entropy inflation breaks static Gumbel-based inference verification, doubling exfiltration bandwidth and cutting the adversary's slowdown factor to 60x-118x.

- Gumbel-based verification limits LLM weight exfiltration by bounding admissible token sets based on model output entropy, assuming passive attackers under benign prompt traffic.
- Prompts engineered with character- and script-level disruptions break grammatical structures, artificially inflating local output entropy and widening the admissible token set.
- Evaluated across six instruction-tuned models (1B to 32B parameters), the attack roughly doubled leaked bits per token compared to benign prompts.
- The adversarial prompt distribution reduced the verifier's reported >200x slowdown defense down to a 60x-118x slowdown.
- Static thresholds calibrated on benign traffic fail against active prompt manipulation; thresholds must instead be dynamically calibrated against local token entropy.

**Why it matters:** It reveals a critical vulnerability in static Gumbel-based LLM verification schemes, forcing implementations to adopt dynamic, entropy-aware defenses against covert weight exfiltration.

<small>Nikita Kezins</small>

### [Safety Hacking in Constrained Best-of-$N$ Inference-time Scaling](https://arxiv.org/abs/2608.22915v1)

**arXiv cs.CR** · 2026-08-24 · `arXiv:2608.22915v1`

Researchers identify safety hacking in constrained Best-of-N inference-time scaling, proving that reward maximization asymptotically guarantees the selection of unsafe outputs if imperfect safety proxies permit unsafe items with heavy upper reward tails.

- Constrained Best-of-N inference creates a two-stage failure: an imperfect safety proxy contaminates the feasible set, and subsequent reward maximization amplifies this residual contamination.
- Safety hacking becomes asymptotically certain as N increases if unsafe-but-proxy-feasible outputs possess a heavier joint upper reward tail than truly safe outputs, regardless of how small average proxy errors or false-positive mass are.
- Bounding the chi-squared (χ²) divergence of policies relative to the proxy-feasible reference distribution yields an N-independent safety-hacking bound via coverage control.
- Coverage control restricts reward amplification but cannot purge initial feasible-set contamination, meaning regularized selection is not guaranteed to be safer than constrained Best-of-N for all reward proxies.

**Why it matters:** The findings demonstrate an inherent vulnerability in scaling inference-time compute with learned safety filters, showing that larger sampling pools can systematically defeat safety constraints.

<small>Akifumi Wachi, Takumi Tanabe, Youhei Akimoto</small>

### [AI Grinding for Fun and Cryptanalysis](https://arxiv.org/abs/2608.21986v1)

**arXiv cs.CR** · 2026-08-22 · `arXiv:2608.21986v1`

An autonomous cryptanalysis workflow using AI agents generated reproducible candidates, breaking eight published cryptographic constructions and refining claims on three others before human review.

- The autonomous workflow outputs exact witnesses, controls, code, and execution records to isolate vulnerabilities caused by exposed algebraic maps or mismatched simulation distributions.
- A Ring-LWR commitment scheme was shown to open to every message with probability one, and a lattice e-voting protocol lost receipt-freeness.
- Specific breaks include recovering middle-product encryption rows, extending an updatable encryption attack to old keys via linear algebra, and splitting a degree-63 normal basis instance into seven degree-nine instances.
- Non-lattice failures include a signature hash mapping distinct printable messages to the same digest and a rerandomisable scheme leak where the accept bit acts as a noise threshold oracle.

**Why it matters:** It demonstrates that automated AI-driven hypothesis generation can systematically uncover critical, reproducible cryptographic vulnerabilities across diverse schemes before human evaluation.

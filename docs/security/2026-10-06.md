### [TranScope: What the Software Hides About LLM Training Data, the Hardware Reveals at Scale, and Accelerators Magnify](https://arxiv.org/abs/2610.06848v1)

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.06848v1`

TranScope is a hardware-based tool that detects LLM training data membership by analyzing microarchitectural state variations, such as TLB and page table access patterns, caused by tokenization locality differences during inference.

- Identifies that transformer training alters tokenization locality, creating data-dependent page table and TLB access patterns during inference even in constant-time, static models with masked confidence.
- Introduces TranScope, a low-cost microarchitecture tool for membership inference attacks (MIA) and copyright checking that operates without surrogate models.
- Achieves a 0.9 AUC for membership detection, outperforming the previously best-reported PETAL baseline of 0.6 AUC.
- Demonstrates that modern hardware components and integrated accelerators amplify execution footprint differences between in-distribution and out-of-distribution inputs.

**Why it matters:** It reveals that hardware-level execution footprints expose training data membership in black-box LLMs, enabling new copyright verification methods while creating a novel membership inference side-channel.

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.06584v1`

A benchmark using five nonpublic software environments evaluates AI models on exploit generation and repair, showing defenders lead in two environments while attackers lead in three.

- Evaluated open-weight and proprietary AI models across five nonpublic software environments, including unpatched vulnerabilities privately disclosed by researchers.
- Utilized researcher-developed deterministic graders rather than LLM judges to compute task scores.
- Repair scores exceeded attack scores in two environments but lagged behind in three others.
- Demonstrated that initial patches were often insufficient, with secondary exploits succeeding in 92 of 524 non-independent defender test intervals after blocking the initial exploit.

**Why it matters:** The findings highlight that AI capability evaluations require vulnerability-specific attack-repair comparisons and post-patch resistance testing rather than relying on standard public benchmarks.

### [RAISED: Self-Distillation for Robustness to Prompt Injection in LLM Agents](https://arxiv.org/abs/2610.06401v1)

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.06401v1`

RAISED uses self-generation and self-distillation to train LLM agents to match their clean-context output distribution when handling injected tool responses, preventing utility degradation.

- Identifies a key failure mode in existing defenses where models wrongly refrain from necessary task steps indicated by legitimate tool outputs due to distribution drift.
- Combines self-generation of tool-use scenarios with self-distillation using teacher-student alignment.
- Enforces student behavior on injected trajectories to match the teacher's behavior on clean variants of the same trajectory.
- Reduces indirect prompt injection attack success rates while preserving model utility on both agentic and general-purpose benchmarks.

**Why it matters:** It enables tool-using LLM agents to defend against indirect prompt injections without sacrificing performance on legitimate, complex agentic workflows.

### [Where Did the Repair First Go Wrong? Localizing the Origins of Silent Failures in Agentic Vulnerability Repair](https://arxiv.org/abs/2610.06163v1)

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.06163v1`

Researchers introduced Security Awareness Gap Evaluation (SAGE), a trace-based method that localizes the exact conversational turn where LLM agents first silently fail during security vulnerability repairs.

- SAGE combines turn-level security reasoning evaluations with reconstructed code histories to pinpoint early security intent divergences in silent failures.
- Evaluated on 95 silent failures across 3,684 traces (six agent frameworks, six base models, SecurityEval, and CVEfixes), SAGE assigned a failure origin in 93 cases.
- Only five failure origins coincided directly with the code change itself; when agents introduced vulnerable code, the origin turn preceded the code write in 14 of 19 cases.
- Most failure origins stemmed from unaddressed security requirements or inadequate defense choices rather than syntax or execution errors.
- Repeated scoring and a second judge showed higher consistency for the origin failure type than the exact turn number, with lowest agreement occurring when only final files were preserved.

**Why it matters:** Identifying that silent security failures originate in high-level reasoning turns prior to code generation allows developers to place targeted safeguards in agent planning phases rather than relying solely on post-hoc patch testing.

<small>Wenji Bai, Muhammad Waseem, Zeeshan Rasheed, Jaakko Peltonen, Pekka Abrahamsson</small>

### [Cross-Lingual Transferability of Training Data Extraction Attacks to Recover Memorized PII](https://arxiv.org/abs/2610.06093v1)

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.06093v1`

Training Data Extraction (TDE) attacks transfer across languages in LLMs, allowing non-English prompts to extract memorized English PII due to shared representations in middle layers.

- Evaluated TDE attack transferability across English, Italian, Spanish, French, and German using a multi-domain dataset of social media handles, email addresses, and phone numbers.
- Attacks succeed on translated prompts even when the specific non-English attack contexts were absent from pre-training data, as verified by web-presence checks.
- The extraction success rate in target languages scales with the model's overall multilingual capability but drops sharply when the original prompt wording is significantly altered.
- Layer activation analysis reveals that different translations of the same prompt align into similar representations, showing peak cross-lingual alignment in the model's middle layers.

**Why it matters:** Demonstrates that localized PII sanitization or single-language alignment is insufficient, as cross-lingual representations enable attackers to extract private data using translated prompts.

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.06049v1`

Researchers demonstrated a supply-chain attack vector where modifying only the decoder weights of a Sparse Autoencoder (SAE) successfully injects backdoors into a language model's forward pass.

- The attack modifies only the SAE decoder, leaving both the language model weights and the SAE encoder completely frozen at a single insertion layer.
- Tested on code generation tasks across three language models, the attack successfully achieved unsolicited code insertion and trigger-dependent behavior from prompt cues.
- Evaluations using HumanEval and SAEBench showed that strong backdoored behavior can coexist with minimal degradation in conventional SAE quality metrics.

**Why it matters:** Demonstrating that auxiliary components can alter model execution proves that third-party SAEs must be treated as security-sensitive assets rather than harmless interpretability tools.

### [Runaway Reaction: When Benign Skills Compose into Malicious Behavior](https://arxiv.org/abs/2610.05943v1)

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.05943v1`

Researchers introduced CRIME, a framework demonstrating that individually benign agent skills from public repositories can compose to execute malicious behaviors while bypassing standalone security vetting.

- Identifies that composing individually benign agent skills expands an agent's capability space to induce unvetted malicious behaviors.
- Utilizes the Malicious Plot Casting (MPC) module to decompose malicious goals into complementary skill requirements matched against public skill repositories.
- Employs the Runaway Reaction Steering (RRS) module to iteratively refine skills via execution feedback while ensuring each skill remains benign in isolation.
- Uses the Skill Reaction Chamber (SRC) module to execute skill pairs in a sandbox and verify environmental consequences against the target malicious behavior.
- Constructed a evaluation benchmark containing 4,000 public skills evaluated across eight cybersecurity behaviors.

**Why it matters:** Traditional isolation-based security vetting fails to detect vulnerabilities that emerge only when multiple harmless agent skills interact.

### [Compromise Is Not Consequence: Evaluating Task-Scoped Authorization in LLM Agents with Paired Replay](https://arxiv.org/abs/2610.05840v1)

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.05840v1`

A paired-replay testbed shows task-scoped authorization mechanisms eliminate harmful execution from LLM agent prompt injections, containing post-exposure tool actions without changing the model's underlying decisions.

- Evaluated 128 scenarios across four tool domains and five local model configurations under broad bearer, scoped JWT, sender-constrained, and Open Policy Agent enforcement conditions.
- Broad-bearer authorization resulted in 8.9% to 37.8% harmful execution across models, whereas all three task-scoped authorization conditions recorded 0% harmful execution.
- Tested on an AgentDojo extension where task-scoped policies reduced injected attack flags from 11/24 to 0/24 while maintaining comparable utility (6/24 vs 5/24).
- Task-scoped policies achieve outcome containment for cross-action and cross-resource attacks, but do not prevent prompt injection itself or alter frozen model choices.

**Why it matters:** Enforcing fine-grained, task-scoped authorization policies limits the blast radius of prompt injections by preventing unauthorized tool execution, even when an LLM agent is compromised.

<small>Tural Hagverdiyev</small>

### [Bounded Provisional Visibility: Controlling Poisoning Exposure in Continuously Ingested RAG Vector Stores](https://arxiv.org/abs/2610.05826v1)

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.05826v1`

A fail-closed provisional-visibility protocol bounds poisoning exposure in continuous RAG ingestion by setting verification deadlines, reducing clean content retrieval latency from 6.3 seconds to 3 milliseconds.

- Introduces a provisional-visibility protocol that bounds exposure using a visibility budget deadline, hiding content if verification fails to commit within the timeframe.
- Reduces median poisoned retrievals under verifier backlog from 34 (range 29-34) down to 7 (range 6-7) compared to asynchronous admission without deadlines.

- Evaluated across five workloads on exact and Milvus vector backends, demonstrating that final safety relies on verifier accuracy while enforcement delay and containment depend on protocol bounds.

**Why it matters:** It enables continuous RAG ingestion systems to make new data searchable nearly instantaneously while deterministically capping the window of vulnerability to unvetted or malicious content.

### [Visual Grounding Safety in Vision-Language Models](https://arxiv.org/abs/2610.05637v1)

**arXiv cs.CR** · 2026-10-05 · `arXiv:2610.05637v1`

VLMs exhibit a safety gap, refusing harmful free-text requests while complying when asked for grounded outputs (points or bounding boxes); fine-tuning with targeted grounding refusals closes this gap without sacrificing grounding capabilities.

- Grounding refusal rates trail free-text VQA refusal by 31-59 percentage points across five VLMs evaluated on 15,401 matched request pairs from VLSU, BBQ-V, and Asimov-2.0 benchmarks.
- Standard safety system prompts fail to eliminate the safety gap between free-text and visual grounding outputs.
- Proposed fine-tuning blends grounding-form refusals, capability grounding data, and self-distilled benign data to limit over-refusal.
- Fine-tuning Qwen3-VL-8B and VisionReasoner-7B increases grounding refusal by 77-95 percentage points on VLSU/BBQ-V and 64-85 points on held-out Asimov-2.0.
- Representation analysis reveals the fine-tuning shifts internal representations of harmful grounding requests toward the model's refusal direction while preserving benign request representations.

**Why it matters:** Downstream robotic systems, agents, and interfaces relying on VLM spatial coordinates remain vulnerable to executing harmful actions if spatial output channels are not explicitly alignment-trained.

<small>Erfan Shayegani, Kundan Krishna, Yue Dong, Nael Abu-Ghazaleh, Leon Gatys, Shruti Palaskar</small>

**arXiv cs.CR** · 2026-10-04 · `arXiv:2610.05586v1`

AgentDOXX is a new evaluation suite of 822 synthetic transcripts designed to measure LLM-agent-based re-identification of anonymized text using web search and parametric memory.

- Evaluated 15 open-weight and proprietary model configurations to distinguish retrieval-driven from parametric identification capabilities.
- Open-weight models successfully re-identified 15-28% of target subjects using parametric memory alone without web search capabilities.
- Re-identification succeeded in over 88% of cases once the correct target entity appeared within an agent's retrieved web search results.
- Entity masking left a 85.3% success rate across at least one attacker configuration, while privacy instructions suppressed target naming without preventing search retrieval (retrieving targets in up to 62% of cases).

### [Don't Judge an LLM Only by Its Activations: Discovering Suppressed Safety Features via Counterfactual Activation Potential](https://arxiv.org/abs/2610.05541v1)

**arXiv cs.CR** · 2026-10-04 · `arXiv:2610.05541v1`

A new framework introduces Counterfactual Activation Potential (CAP) and the CSFD algorithm to discover latent, suppressed safety features in LLMs that, when ablated or inhibited, convert refusal behavior into compliance with harmful prompts.

- Mechanistic interpretability tools miss inactive model features, which can harbor causally relevant safety-critical components that prevent jailbreaks.
- CAP quantifies a suppressed feature's activation tendency by multiplying its encoder alignment, suppression strength from active features, and safety criticality.
- CAP-guided Safety Feature Discovery (CSFD) uses a two-stage filtering algorithm to isolate candidate safety features from hundreds of thousands of transcoder features without exhaustive ablation.
- Under natural jailbreaks, suppression on high-CAP features increases 2-4x while their activation drops up to 80%; amplifying these suppressors increases harmful compliance.
- Evaluations across five Gemma, Qwen, and Llama models demonstrate that jailbreaks function in part by suppressing latent safety features rather than just activating harmful ones.

**Why it matters:** Evaluating LLM safety solely through active features overlooks hidden safety mechanisms, leaving models vulnerable to jailbreaks that exploit feature suppression.

<small>Swadesh Swain, Sanghamitra Dutta</small>

### [Multi-Backbone Self-Supervised Ensembles for Audio Deepfake Detection and a Cross-Track Analysis of Generation-Detection Asymmetry](https://arxiv.org/abs/2608.01796v1)

**arXiv cs.CR** · 2026-08-03 · `arXiv:2608.01796v1`

Team Go-To-Germany achieved a 0.9522 score in ImageCLEF 2026 Audio Deepfake Detection using a four-backbone SSL ensemble, while their reverberated F5-TTS v1 generation probe ranked first in the generation sub-task with a 0.4304 score.

- Detection ensemble combines WavLM-Large, Wav2Vec2-XLS-R-300M, ECAPA-TDNN, and x-vector representations, achieving 1.0000 accuracy on participant deepfakes and 0.8875 on held-out real data.
- Official generation entry utilized an F5-TTS v1 baseline with uniform reverberation, ranking first in generation with a 0.4304 score, 4.99% WER, and 2.07% CER.
- Cross-track analysis demonstrated that the detection system identified 100% of participant deepfakes, while the top generation entry evaded 61.4% of participant and 56.2% of organizer detectors.
- Evaluations included Leave-One-Speaker-Out (LOSO) 56-speaker cross-validation, PCA analysis, and bootstrap confidence intervals to support an architectural-insurance hypothesis for SSL ensembles.
- The primary deployment challenge identified is an 11.25% false-positive gap on held-out organizer real audio recordings.

**Why it matters:** The findings highlight a structural performance asymmetry between audio deepfake generation and detection, demonstrating that multi-backbone SSL ensembles can reliably flag synthetic audio despite anti-forensic evasion tactics.

<small>Seunghyun Kim, Junghyun Kim, Jiyoung Woo</small>

### [EntailLLM: Verifying LLM-Generated Vulnerability Discovery Paths with Domain Knowledge via Logic Programming](https://arxiv.org/abs/2608.01763v1)

**arXiv cs.CR** · 2026-08-03 · `arXiv:2608.01763v1`

EntailLLM verifies LLM-generated vulnerability discovery paths by checking function call graph traversals against a separate domain knowledge graph using temporal annotated logic.

- Aligns LLM-proposed binary function call graph traversals with an independent domain knowledge graph using temporal annotated logic.
- Inherits formal guarantees and well-defined semantics from generalized annotated logic to provide explainable verification.
- Evaluated across three CWE classes, four LLMs, three prompting strategies, and seven binaries ranging from 405 to 12,696 function call-graph nodes.
- Raised pooled entailment from 78% to 98% overall, and achieved 98% pooled entailment on real medical-device binaries without per-device tuning.

**Why it matters:** It prevents LLMs from silently violating domain rules during binary analysis, providing formally verified vulnerability discovery paths for safety-critical systems.

**arXiv cs.CR** · 2026-08-03 · `arXiv:2608.01759v1`

Researchers introduced EvoBreak, a sequential attack that induces individually benign experiences into self-evolving LLM agents to jointly bypass safety boundaries when combined during final query execution.

- EvoBreak uses benign attack-stage tasks to iteratively acquire target-relevant, complementary experiences distilled by the victim agent without direct memory access.
- The attack framework uses BreakGym, a structure-first synthesis pipeline, to generate decomposable safety-sensitive targets featuring diverse dependency structures.

- The attack adaptively reformulates the final query to activate the accumulated benign experiences jointly, demonstrating cross-domain and cross-backbone effectiveness.

**Why it matters:** It reveals that experience distillation mechanisms in self-evolving LLM agents create an exploitable attack surface where harmless, multi-session memory accumulations can compromise safety defenses.

### [MNC: Scope-Bound Semantic Declassification for Private LLM-Agent Communication](https://arxiv.org/abs/2608.01719v1)

**arXiv cs.CR** · 2026-08-03 · `arXiv:2608.01719v1`

MNC is a typed semantic-declassification protocol for multi-agent LLMs that selects minimal task-sufficient disclosures and binds them to strict usage and lifetime scopes enforced by a reference monitor.

- Selects task-sufficient disclosures from application-authored candidate families to prevent exposure via tool arguments, logs, and memory.
- Binds disclosures to explicit recipient, purpose, forwarding, lifetime, logging, and memory scopes enforced across subsequent operations by a reference monitor.
- Includes a history-aware extension that evaluates accumulated inference risk over repeated disclosures.
- Blocks unauthorized forwarding, logging, durable storage, and expired retrieval under identical receipt text where text-only declassifiers fail.
- Demonstrates through MAGPIE executions that scope-mediated disclosures successfully propagate through downstream planning, tool use, coordination, and memory retrieval.

**Why it matters:** It provides a verifiable enforcement boundary that prevents private agent state leakage through downstream communication and memory, which standard text redaction and prompt defenses fail to stop.

### [No Single Neuron of Failure: Distributed Safety Alignment Against White-Box Attacks](https://arxiv.org/abs/2608.01414v1)

**arXiv cs.CR** · 2026-08-02 · `arXiv:2608.01414v1`

Distributed Safety Alignment (DSA) prevents white-box neuron attacks by redundantly encoding safety capabilities across multiple compensatory feed-forward neurons instead of relying on localized, fragile safety neurons.

- Localizes interventions to input activations of down-projection layers in language-side feed-forward networks (FFNs).
- Identifies critical refusal neurons using a direction-aware first-order Taylor score combining neuron activations with loss gradients.
- Forces distributed safety encoding by targeting critical neurons with deterministic masking and stochastic dropout during training.
- Enhances model robustness against white-box neuron manipulation while maintaining standard language and multimodal utilities.

**Why it matters:** It mitigates single-point-of-failure vulnerabilities in open-weight foundation models, making them resilient against direct white-box neuron editing and ablation attacks.

### [Why Formal Monitors Fail: Attack Distribution Entropy as a Coverage Bound for LTL-Based LLM Agent Safety](https://arxiv.org/abs/2608.01388v1)

**arXiv cs.CR** · 2026-08-02 · `arXiv:2608.01388v1`

Researchers proved that LTL/FSA safety monitor recall is bounded by attack distribution entropy, explaining why fixed monitors achieve high coverage on low-entropy models like GPT/DeepSeek but fail on high-entropy models like Gemini.

- Formal proof demonstrates that FSA monitor recall is bounded by the concentration of attack trigger-completion patterns (low Shannon entropy equals high recall).
- Empirical testing shows Shannon entropy explains 76% of coverage variance across eight LLM architectures (Pearson r = -0.87).
- GPT-class and DeepSeek backends produced low entropy (H ~ 0.24 bits; 96% coverage in one pattern), resulting in 68-75% monitor recall.
- Gemini backends produced high entropy (H ~ 2.81 bits across 7 clusters), resulting in near-zero recall (6-13%) even after invariant retraining.
- Introduced a pre-deployment entropy test that predicts LTL/FSA monitor coverage from a small sample of attack sequences.

**Why it matters:** It provides a mathematical framework to evaluate whether FSA-based runtime safety monitors will be effective for a specific LLM architecture prior to deployment.

<small>Ruiyang Zhang</small>

**arXiv cs.CR** · 2026-08-02 · `arXiv:2608.01043v1`

Attaching an unrelated decoy image to an encoded jailbreak prompt reduces Vision-Language Model attack success rates by up to 73 percentage points when evaluated against caption-mediated defenses like ECSO.

- Pairing content-free decoy images with encoded text triggers caption-mediated defenses (ECSO) that would otherwise fail on text-only inputs, dropping attack success rates (ASR) by up to 73 percentage points across five frontier VLMs.
- Blank-canvas and natural-photo controls confirm the defense behavior is triggered by image presence rather than specific visual content or vendor-side moderation filtering.

- The interaction persists under adaptive attacks aimed at the caption re-check step, though total effectiveness degrades.

**Why it matters:** It reveals that black-box VLM defense pipelines process multi-modal inputs differently than text-only inputs, offering a mechanism to boost defense performance if paired with accurate input detectors.

### [Registry Descriptions Go Stale Unevenly: An 89-Day Measurement of Model Context Protocol Drift, and Why Drift-Ranked Re-Auditing Under-Covers It](https://arxiv.org/abs/2608.00997v1)

**arXiv cs.CR** · 2026-08-02 · `arXiv:2608.00997v1`

An 89-day study of the MCP registry reveals that description-level changes occur unevenly, rendering drift-ranked re-auditing strategies ineffective compared to content-binding and full-catalog sweeps.

- Reconstructed 120 observations of the official MCP registry over 88.6 days tracking 19,099 servers as the catalog expanded from 3,510 to 18,966 entries.
- Only 8.6% of servers rewrite descriptions (versus 24.8% changing descriptors), with the top 5% most active servers generating 61% of all change events.
- At a top-5% re-audit budget, ranking by prior drift catches only ~10% of total description changers because ~50% of description changes occur on new server arrivals.
- Actual descriptor decay is heavy-tailed: 11.9% change within 30 days, contradicting naive exponential compounding models that predict 35.8% decay.

**Why it matters:** Security auditors cannot rely on historical drift metrics to prioritize re-audits; they must use hash-based content-binding triggers and periodic full sweeps to detect description staleness.

<small>Gautam Bharti</small>

### [Hardware-rooted attestation for AI-agent evidence: composing IETF RATS with action evidence packages](https://arxiv.org/abs/2608.00801v1)

**arXiv cs.CR** · 2026-08-01 · `arXiv:2608.00801v1`

This paper proposes combining software-layer AI Action Evidence Packages (AEPs) with IETF RATS hardware-rooted remote attestation to verifiably bind model outputs and measurements to untampered platform states.

- AEPs provide software-layer logs of agent actions, but require a hardware root of trust (like TPM-signed quotes) to prove specific model versions ran on unmodified hardware.
- The proposed composite attestation binds an AEP outcome hash and fresh appraiser nonce directly into a TPM attestation-key-signed quote, carrying model-artefact measurements in platform registers.
- Using a software TPM (swtpm) and a minimal IETF RATS verifier, the authors mapped appraisal outcomes to correctly identify valid quotes (Attested), swapped model measurements (Contested), stale replays (Expired), and forged AEP outcomes.
- The implementation serves as a feasibility demonstration on emulated hardware rather than a hardware-rooted guarantee.

**Why it matters:** It establishes a method to cryptographically prove that an AI agent's reported actions originated from a specific, unmodified model version running on verified hardware.

<small>Anton Sokolov</small>

### [Plug 'n' Pray: Agentic LLM-based Detection of Potential Log File Exposures in Third-Party Content Management System Plugins](https://arxiv.org/abs/2609.17164v1)

**arXiv cs.CR** · 2026-09-15 · `arXiv:2609.17164v1`

Researchers developed an agentic LLM-based framework combining static and dynamic analysis to automatically detect log file exposure vulnerabilities in WordPress plugins.

- Evaluated on the 300 most-installed WordPress plugins, representing over 250 million active installations and 75% of the official plugin ecosystem.
- Achieved successful manual reproduction of 79 out of 81 identified exposure findings across 62 distinct plugins.
- Categorized security measures into creation-control (e.g., manual activation) and access-control (e.g., .htaccess deny rules), noting a frequent lack of required multi-layered protection.
- Derived a taxonomy of log file path and protection patterns to establish developer best practices for secure log handling.

**Why it matters:** Demonstrates that agentic LLMs can effectively automate the discovery of widespread, high-impact information disclosure vulnerabilities across critical web infrastructure.

### [InceptionRAG: Stealthy Poisoning Attack Against Retrieval-Augmented Generation](https://arxiv.org/abs/2609.16818v1)

**arXiv cs.CR** · 2026-09-15 · `arXiv:2609.16818v1`

InceptionRAG is a stealthy poisoning attack that fragments malicious payloads into dormant passages, causing LLMs to self-deduce targeted misinformation through multi-hop reasoning while bypassing single-document defenses.

- Replaces single-point explicit injection with a chain of dormant, individually harmless passages that bypass existing RAG mitigation mechanisms.
- Triggers LLMs to infer target misinformation via multi-hop reasoning only when the fragmented passages are retrieved together.
- Employs Zeroth-Order Suffix Optimization (ZOSO) to automatically generate authoritative suffixes for black-box attack settings.
- Achieves an attack success rate over 80% across three datasets and three LLMs under strict adversarial constraints.
- Proposes HODOR, a document isolation-based defense designed to mitigate the attack by decoupling adversarial logical dependencies.

**Why it matters:** It demonstrates that as LLM reasoning capabilities advance, RAG systems become increasingly vulnerable to multi-document logic-induction attacks that evade traditional single-document safety filters.

<small>Jiachang Zhang, Min Chen, Xiao Ren, Zhenyong Zhang, Yuanchao Shu, Yunjun Gao, Zhikun Zhang</small>

### [When Agents See Differently: Exposing UI Desynchronization Threats in Mobile Agents](https://arxiv.org/abs/2609.16732v1)

**arXiv cs.CR** · 2026-09-15 · `arXiv:2609.16732v1`

Researchers identified UI desynchronization threats in mobile agents, where modified APKs exploit differences between human visual perception and agent digital inputs to manipulate agent actions while appearing normal to human users.

- Exploits visual limitations like occlusion and luminance contrast in humans while exposing digital screenshots and nonvisual accessibility metadata to agents.
- Utilizes pre-deployment perturbations in repackaged APK clones without requiring runtime instruction access, agent detection, or online adaptation.
- Introduced an automated framework to generate instruction-agnostic UI desynchronization attacks and deploy them into functional APKs.
- Evaluations across five mobile-agent frameworks and three backbone models on 546 tasks yielded average misleading rates of 77.9% in static and 66.9% in dynamic tests.
- A study with 186 participants confirmed that the embedded visual perturbations remain largely unnoticed by human users.

**Why it matters:** Attackers can silently hijack autonomous mobile agents to perform malicious actions without altering the application's perceived visual interface or user experience.

<small>Heng Li, Fulin Zhao, Zhe Geng, Zhiyuan Yao, Wei Yuan, Xiapu Luo</small>

### [Implementing a White-Box Undetectable Backdoor for Random Fourier Features](https://arxiv.org/abs/2609.16403v1)

**arXiv cs.CR** · 2026-09-14 · `arXiv:2609.16403v1`

Researchers created an end-to-end Python implementation using NumPy and SciPy of the Goldwasser undetectable white-box RFF backdoor, validating its practical realizability without specialized cryptographic software.

- Implemented the Continuous Learning With Errors (CLWE) Random Fourier Features (RFF) backdoor using standard scientific libraries (NumPy and SciPy).
- Developed two samplers for the core Sparse Gaussian Pancakes distribution: a rejection-sampling proxy and an exact closed-form sampler derived from the homogeneous CLWE density.
- Statistical indistinguishability tests showed no detectable difference between clean and backdoored models across multiple sparsity ratios in both weight-space and functional black-box evaluations.

**Why it matters:** It demonstrates that cryptographic, provably undetectable white-box backdoors can be practically constructed using commodity machine learning tools without specialized cryptographic infrastructure.

### [Decoy Direction Optimization: A Post-Hoc Defense Against LLM Abliteration](https://arxiv.org/abs/2609.16204v1)

**arXiv cs.CR** · 2026-09-14 · `arXiv:2609.16204v1`

Decoy Direction Optimization (DDO) is a fast, post-hoc weight-editing defense that injects nonlinear decoy signals into MLP neurons to mislead Refusal Feature Ablation attacks into ablating harmless orthogonal features instead of safety guardrails.

- Mechanism: Injects high-magnitude, nonlinear decoy signals into MLP neurons to corrupt contrastive estimators used by attackers to locate refusal directions.
- Performance: Reduces attack success rate (ASR) to <10% under standard Refusal Feature Ablation (RFA) across six model families.
- Adaptive Robustness: Maintains 65% worst-case ASR under adaptive multi-phase attacks on Llama-3-8B-Instruct and lowers Heretic weight-level attack ASR from 88.7% to 18%.
- Efficiency: Achieves results at 30x to 450x lower optimization cost per configuration compared to trained defense baselines without requiring base-model finetuning.

**Why it matters:** DDO provides a computationally efficient post-hoc method to protect open-weight LLMs against abliteration attacks without requiring expensive safety finetuning.

<small>Aashiq Muhamed, Mona T. Diab, Virginia Smith</small>

### [Adversarial Testing of Automated Program Repair Agents for Security Vulnerabilities](https://arxiv.org/abs/2609.15963v1)

**arXiv cs.CR** · 2026-09-14 · `arXiv:2609.15963v1`

Researchers created the SWEADV benchmark to show that adversarial issue descriptions can trick Automated Program Repair (APR) agents into generating functionally correct but insecure patches 51.7% of the time.

- SWEADV consists of 750 adversarial issue descriptions derived from 150 SWE-bench Verified repair tasks, targeting five attack types: command execution, deserialization, path traversal, denial of service, and weak hashing.
- Evaluating mini_swe agents powered by GPT-5-Mini, MiniMax-M2.5, and DeepSeek-R backends revealed a 51.7% average success rate in inducing malicious behaviors while maintaining successful code repair.
- Pre-repair detection of adversarial issue descriptions using LLM-as-judge achieved only 62.3% average accuracy.
- Post-repair patch detection proved ineffective, with static analysis tools and LLM-as-judge achieving average detection accuracies of just 39.4% and 55.4%, respectively.

**Why it matters:** Autonomous APR agents are vulnerable to indirect prompt injection via issue descriptions, making fully autonomous deployment in production environments unsafe due to low detection rates of introduced security flaws.

<small>Fares Trad, Simin Chen, Hung Viet Pham, Gias Uddin, Baishakhi Ray</small>

### [When the World Lies: Backdoor Attacks on Latent World Models for Downstream Control](https://arxiv.org/abs/2609.15781v1)

**arXiv cs.CR** · 2026-09-14 · `arXiv:2609.15781v1`

Pretrained latent world models contain a supply-chain backdoor vulnerability where poisoned checkpoints steer clean downstream controllers (Dreamer-style actors or MPC/CEM planners) to attacker-chosen target actions when exposed to trigger-bearing observations.

- The attack modifies the world model checkpoint to route trigger-bearing observations into a target latent region and reshape local dynamics, causing downstream optimization to independently select target actions without an explicit trigger-to-action rule.
- The poisoned model maintains clean-data task performance at $\sim$75\% or higher, passing standard pre-deployment diagnostics while achieving up to 100\% hijack rates on triggered steps across all action dimensions.
- The backdoor effect is temporally gated, appearing exclusively when the trigger is active and resolving immediately upon trigger removal.
- Standard trigger-blind repair fails under moderate clean fine-tuning, while aggressive fine-tuning removes the backdoor only by severely degrading clean control performance.

**Why it matters:** Reusing pretrained world models as off-the-shelf dynamics backbones creates a severe supply-chain attack surface that compromises downstream control safety without leaving clear signals on clean evaluation data.

<small>Roberto Riaño, Gorka Abad, Stjepan Picek, Aitor Urbieta</small>

### [CiteShade: Citation Laundering in Multi-Source Retrieval-Augmented Generation and Its Counterfactual Defense](https://arxiv.org/abs/2609.15660v1)

**arXiv cs.CR** · 2026-09-14 · `arXiv:2609.15660v1`

CiteShade introduces citation laundering in multi-source RAG, manipulating a model to output an attacker-chosen wrong answer while incorrectly attributing it to an unsupportive, trusted source.

- CiteShade presents a citation laundering attack where an attacker controlling a single source forces the model to cite a trusted source for an incorrect answer while valid context remains present.
- Formulated as an optimization problem resting on three necessary conditions (retrieval, generation, and citation), the attack operates without requiring explicit system instructions.
- Evaluated on multi-source multi-hop question answering, the attack increases the wrong-answer rate from 0.01 to 0.68, achieving a Citation Laundering Rate (CLR) up to 0.84 with explicit instructions and 0.64 without.
- Model vulnerability correlates with a propensity to cite rather than model scale, and standard mitigations like perplexity filtering and citation-support checking fail to prevent it.
- The authors introduce a counterfactual defense designed to determine which source causally drove the model's generated answer.

**Why it matters:** This attack undermines the reliability of citations as an audit trail in RAG systems, showing that users can be misled into trusting incorrect answers attributed to reliable sources.

<small>Guo Fuzheng</small>

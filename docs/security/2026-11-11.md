### [GARD: Gradient-Guided Adversarial Representation Defense against Backdoors in Multimodal Contrastive Learning Models](https://arxiv.org/abs/2611.14143v1)

**arXiv cs.CR** · 2026-11-10 · `arXiv:2611.14143v1`

GARD is a target- and trigger-agnostic post-hoc defense that uses complementary global and local adversarial probes to eliminate multimodal contrastive backdoors without adding inference overhead.

- Exploits structure-dependent representation sensitivity where global perturbations expose distributed backdoors and local patch perturbations target localized backdoors.
- Optimizes global and local adversarial probes to displace clean-image representations, then realigns perturbed representations with detached clean anchors while maintaining image-text alignment.
- Requires zero additional computational overhead at inference time.
- Reduces Attack Success Rate (ASR) below 1% across 12 evaluated attack-backbone combinations involving six visual backdoor attacks and two CLIP visual backbones.

**Why it matters:** GARD provides a robust, inference-free post-hoc repair mechanism for CLIP-style multimodal models without requiring prior knowledge of the attack target or trigger type.

<small>Yuhong Wang, Yujun Cai, Lei Feng, Songze Li</small>

### [Sable: A Small-Field Sumcheck Argument for Bit-Exact Inference of Large Language Models](https://arxiv.org/abs/2611.14083v1)

**arXiv cs.CR** · 2026-11-10 · `arXiv:2611.14083v1`

Sable is a small-field sumcheck argument system and single-GPU prover that verifies bit-exact integer LLM inference without floating-point steps, achieving 40 to 64 times faster per-parameter-token proving than zkLLM.

- Uses a 31-bit KoalaBear prime constraint system, batching zerochecks and LogUp-GKR lookups into one sumcheck per domain without modulo wrapping.
- Proves the complete 64-layer Qwen2.5-32B model on a single NVIDIA RTX PRO 6000 Blackwell GPU in 92.5 seconds for 4,096 tokens.
- Employs a single multilinear commitment built from Reed-Solomon codes, BLAKE3 Merkle trees, and a mixed-length BaseFold opening.
- Achieves an interactive round-by-round soundness error of 2^-103 in the random-oracle model, with CPU verification taking 19 to 56 seconds.
- Evaluates an integer function F_O that matches BF16 greedy tokens on WikiText-2 at 86.3% of positions and remains within 1.7 points of BF16 on MMLU and GSM8K.

**Why it matters:** It drastically lowers the computational cost and time needed to cryptographically audit open-weight LLM execution, reducing proof overhead to 6.4 cents per 4,096-token query.

<small>Tomer Solberg</small>

### [Isolation Is Not Confidentiality: Security Boundaries of Geometric Access Control in RAG](https://arxiv.org/abs/2611.14061v1)

**arXiv cs.CR** · 2026-11-10 · `arXiv:2611.14061v1`

A unified security analysis reveals that search-preserving geometric access control in RAG provides policy isolation but fails to guarantee representation confidentiality, query forgery resistance, or policy-membership hiding.

- Geometric transformations structure vector database embedding spaces to maintain retrieval utility and enforce policy isolation across different access-control policies.
- A curious user can reconstruct original embeddings from a few hundred aligned original-protected representation pairs.
- Users can forge policy-compatible queries at a cost that scales with the encoder's spatial dimension when secret per-policy transformations are used.
- Policy-dependent geometry leaks policy membership to attackers even when unauthorized document retrieval is successfully blocked.

**Why it matters:** System architects cannot rely on geometric access control alone for end-to-end RAG data protection, as policy isolation does not prevent embedding reconstruction, query forgery, or metadata leakage.

<small>Steve Nouyep, Maxime Puys, Sébastien Salva</small>

**arXiv cs.CR** · 2026-11-10 · `arXiv:2611.13960v1`

ActiveSecHarness is a neurosymbolic reference-monitor architecture that enforces compositional security in agentic coding harnesses using capability tokens, deterministic tool guards, and a 2D product taint lattice.

- Architecture enforces Separation of Intelligence and Authority using HMAC capability tokens across four Trust and Authority Rings paired with deterministic Ring-0 OS/tool guards.

### [Detecting sleeper agents hiding in AI model neurons](https://www.microsoft.com/en-us/security/blog/2026/11/10/detecting-sleeper-agents-hiding-in-ai-model-neurons/)

**Microsoft Security Blog** · 2026-11-10

Microsoft Research demonstrated that editing fewer than 10 neurons with inference-only compute can turn AI models into backdoored sleeper agents that pass standard evaluations.

- Weight-space backdoors require minimal resources, needing only enough RAM to run the model to modify neuron weight vectors.
- Backdoored models remain dormant during standard benchmark evaluations, executing attacker commands only when a trigger string appears in context.
- Detection relies on auditing model checkpoints by identifying statistical outliers in weight diffs against declared base models, as legitimate fine-tuning changes weights broadly while backdoors modify few vectors heavily.
- Frontier AI agents (including Claude Code with Opus 4.5, which autonomously discovered much of the threat) can act as automated auditors to detect these anomalous weight edits.
- Mitigations require verifying base model hashes, behavioral backdoor scanning, and treating all third-party fine-tunes, quantizations, adapters, and merges as untrusted until audited.

**Why it matters:** Unattended agents with privileged access can execute malicious system commands if their open-weight checkpoints are compromised, making pre-deployment weight diffing critical.

### [No finite rulebook can certify every safe program: an impossibility theorem for gatekeeping AI agents](https://arxiv.org/abs/2611.13367v1)

**arXiv cs.CR** · 2026-11-09 · `arXiv:2611.13367v1`

Researchers prove an impossibility theorem showing no finite, machine-checkable rulebook can completely classify AI-generated code safety for temporal properties like safety, confidentiality, and responsiveness.

- Machine-checkable evidence only settles finite records, making complete verification impossible for infinite-horizon properties like 'never' (prohibitions) and 'eventually' (responsiveness).
- Prohibitions exhibit one-sided failure where violations are catchable but safe programs cannot be permanently cleared; confidentiality and responsiveness fail bidirectionally.
- Any sound rulebook encoded in n bits necessarily omits a compliant program of approximately n bits.
- Enforcing time limits renders properties checkable only by executing programs for essentially the full limit, rendering finite-machine gatekeeping computationally infeasible.
- Simulations across 2.2 million random programs and self-referential adversaries demonstrate the obstruction is adversarial rather than typical, with confidentiality liveness being the sole persistent error under extended testing.

**Why it matters:** It establishes mathematical boundaries for automated AI safety gatekeepers, proving that static rules cannot guarantee complete program safety without execution-based or probabilistic tradeoffs.

<small>Tomas Perez-Acle</small>

Researchers evaluated side-channel weight extraction across complete, trained deep neural networks, demonstrating that ML models present unique structural obstacles to power analysis that do not exist in traditional cryptographic ciphers.

- Evaluated full network recovery on fully trained models rather than partial extraction of shallow or randomly initialized layers.
- Used an idealized, noiseless side-channel adversary to isolate fundamental algorithmic challenges from physical noise.

**Why it matters:** Directly applying cryptographic side-channel attack models overestimates weight-extraction capabilities on deep neural networks by ignoring fundamental algorithmic differences between ML models and ciphers.

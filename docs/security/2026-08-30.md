### [Are We Shooting Flies with Cannons? Trade-off Analysis for AI-based 5G Intrusion Detection](https://arxiv.org/abs/2608.26844v1)

**arXiv cs.CR** · 2026-08-27 · `arXiv:2608.26844v1`

A comparative analysis demonstrates that traditional machine learning models like XGBoost vastly outperform LLMs and DNNs in 5G network tabular intrusion detection while using orders-of-magnitude less computational resources.

- XGBoost achieved near-perfect detection performance with negligible inference times on a large 5G network telemetry dataset.
- TabNet (tabular DNN) and LLM-based approaches executed significantly worse in detection accuracy while consuming substantially higher CPU time.
- Few-shot prompting improved LLM recall over zero-shot prompting, but reduced overall accuracy and further increased CPU time without bridging the performance gap with traditional ML.

**Why it matters:** For tabular 5G intrusion detection, lightweight tree ensemble models offer a superior performance-cost trade-off compared to computationally expensive LLMs and deep learning architectures.

<small>Federica Uccello, Simin Nadjm-Tehrani</small>

### [Benchmarking Confidential Computing Performance on NVIDIA Blackwell GPUs](https://arxiv.org/abs/2608.26575v1)

**arXiv cs.CR** · 2026-08-27 · `arXiv:2608.26575v1`

Benchmarking NVIDIA Blackwell B200 GPUs in Intel TDX confidential VMs reveals that properly configured confidential LLM inference incurs only a 1-3% throughput overhead compared to non-confidential runs.

- Confidential Computing overhead on Blackwell B200 GPUs is driven by fixed per-host-operation costs and per-NVLink-traffic costs from encrypted collectives.
- Stock inference stacks suffer 30-40% performance penalties due to suboptimal software configurations rather than hardware limits.
- GPU compute capacity, energy draw, and usable memory capacity remain completely unaffected by enabling Confidential Computing.
- A microbenchmark was developed that predicts LLM serving performance penalties down to the submission count based on isolated boundary costs.

**Why it matters:** Organizations can deploy sensitive LLM workloads to public cloud GPUs with near-native performance if they optimize host operations and NVLink traffic configurations.

<small>Daniyal Khan, Amean Asad, Ansgar Grunseid</small>

### [Black Hat State of Security Vendors](https://www.schneier.com/blog/archives/2026/08/black-hat-state-of-security-vendors.html)

**Schneier on Security** · 2026-08-25

Andy Ellis's Black Hat analysis reveals pervasive AI adoption across security sectors alongside a market dominated by passive reporting tools rather than preventative or defensive solutions.

- AI and agents now heavily influence the security vendor landscape, specifically dominating taglines and offerings in Identity, SaaS, AppSec, and Data.
- Security tools currently fall into three market categories: reporting problem severity, stopping adversaries, and preventing problems.
- Despite the need for actionable remediation, tools that merely report the severity of security issues remain disproportionately common.

**Why it matters:** The rapid integration of AI across security domains is compounding existing unresolved security challenges while the market remains saturated with diagnostic tools rather than protective or restorative ones.

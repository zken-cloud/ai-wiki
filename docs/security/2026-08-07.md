### [Hardware Keystores for AI Agent Signing Workflows: A Zero-Trust MCP Enforcement Architecture](https://arxiv.org/abs/2608.06130v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.06130v1`

A hardware keystore architecture uses PKCS#11 interfaces and a five-layer Zero-Trust stack to isolate private keys and prevent prompt injection-driven key usage in AI agents.

- Replaces software-stored keys with hardware-confined keys (HSM, TPM, smart card) using opaque handles via vendor-neutral PKCS#11.
- Enforces security via a five-layer stack: session identity (SAGA), scope bounds (Smax), semantic validation (RAV), taint tracking, and a hardware execution boundary.
- Evaluated against 12 AgentDojo injection scenarios across four LLM models (gpt-oss-120b, Qwen2.5-72B, DeepSeek-V4-Flash, and one other).
- Reduced baseline Attack Success Rate (ASR) from 19.3% (14.3%, 25.4%) to 0% (95% CI upper bound 2.0%) with zero false positives on benign tasks.

**Why it matters:** It completely blocks key exfiltration and unauthorized content signing by prompt injection attacks, fixing vulnerabilities where software keys can be stolen in under five minutes.

<small>Leo Sambrook, Sampo Sovio</small>

### [MMAligner: Safeguarding Multimodal Large Language Models through Representation Calibration](https://arxiv.org/abs/2608.05909v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05909v1`

MMAligner restores MLLM safety by calibrating unsafe multimodal representations back into the model's pre-existing text safety subspace and refusal boundary, achieving a 99% refusal rate on unsafe multimodal inputs with minimal utility loss.

- Geometric analysis shows MLLMs retain a functional, shared text-multimodal safety subspace and refusal boundary, but unsafe multimodal inputs experience a representation shift outside this region.
- MMAligner calibrates representations using a hard lower bound to enforce refusal, a soft upper bound to limit over-modification, and a preservation objective to protect benign inputs.
- The method raises the average refusal rate on unsafe multimodal inputs to 99% across multiple open-source MLLMs while causing less than 2% utility degradation.
- It eliminates the need for external guardrails or large-scale multimodal safety fine-tuning datasets.

**Why it matters:** It demonstrates that MLLM safety failures stem from representation misalignment rather than lost safety capacity, offering an efficient, low-overhead method to patch multimodal jailbreaks without sacrificing model utility.

<small>Shenyi Zhang, Keyan Guo, Zihao Wang, Xuebin Li, Lingchen Zhao, Hongxin Hu, Chao Shen, Qian Wang</small>

### [The Vulnerability With No CVE: Managing Persistent Gaps Between Mandate and Authority in AI Coding Agents](https://arxiv.org/abs/2608.05884v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05884v1`

This paper introduces the Agentic Posture Vulnerability (APV), a task-conditioned abstraction for managing durable security exposures caused by persistent gaps between an AI coding agent's mandate and authority.

- Defines the Agentic Posture Vulnerability (APV) as a durable record linking varying task-level runtime manifestations to an invariant, underlying control exposure.
- Operationalizes existing weaknesses, including excessive agency, improper authorization, and flawed control composition, without acting as a new root-cause risk class.
- Differentiates APVs from CVE-addressable software defects, OWASP Excessive Agency definitions, and transient authorization-execution gaps.
- Outlines structural implementation details including six recurring APV patterns, a thresholded definition, a minimal record schema, a vulnerability lifecycle, and a control-and-closure matrix.

**Why it matters:** It gives security teams a structured framework to track, manage, and remediate persistent configuration exposures in AI agents that traditional CVE tracking fails to address.

<small>Shayell Aharon Salomon Amir Shaked Matan Noga</small>

### [Algebraic Cryptanalytic Extraction on Hard-Label Neural Networks](https://arxiv.org/abs/2608.05736v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05736v1`

A new algebraic model extraction framework uses an Approximate Signature Vector method to drastically speed up hard-label attacks on FCNNs and enable the first extraction of max-pooling CNNs.

- Replaces SVD-based rank checking from Carlini et al.'s EUROCRYPT 2025 attack with simple inner-product operations using an Approximate Signature Vector (ASV) method.
- Reduces the dual-point clustering time complexity from O(n^2 * (d^(k))^3) to an average of O(n * (d^(k))^3).
- Leverages the properties that high-dimensional random vectors are nearly orthogonal and practical DNN neurons learn disentangled features.
- Introduces a kernel-centric clustering scheme to execute the first hard-label model extraction attack against max-pooling CNNs (e.g., LeNet-5) by exploiting weight sharing.
- Validated empirically on a 64-64x4-10 FCNN and LeNet-5 CNN architecture.

**Why it matters:** By removing the severe SVD computational bottleneck and expanding attack capabilities to CNNs, this work makes practical, real-world model extraction against hard-label black-box neural networks significantly more feasible.

<small>Zirui Chen, Shi Tang, Zhengchao Gao, Yongjia Su, Lingyue Qin, Xiaoyang Dong</small>

### [Detecting Safety Training Modification in Language Models via Activation Analysis](https://arxiv.org/abs/2608.05578v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05578v1`

Researchers introduced AMS, an Activation-based Model Scanner that detects safety training modifications in language models by analyzing activation-space geometry, achieving 71% cross-validation accuracy across 14 model configurations.

- AMS categorizes safety modifications into a four-class taxonomy: training removal, weight-orthogonalization abliteration, rotation-without-collapse abliteration, and behavioral fine-tuning.
- Detection relies on a two-tier system: Tier 1 sigma-thresholding detects cluster collapse, while Tier 2 direction-similarity verification detects refusal direction rotations.
- Validation across Llama, Gemma, Qwen, and Mistral families shows the harmful-content concept sigma correlates with behavioral compliance at Pearson r = -0.546 (p = 0.043).
- Behavioral fine-tuning preserves activation magnitude and direction, representing an activation-only undetectable failure mode.

**Why it matters:** AMS provides a mechanistic, activation-based auditing tool to verify whether open-weight language models have undergone safety striping or abliteration without relying solely on behavioral prompting.

### [When Experience Becomes Instruction: Trajectory Poisoning in Self-Evolving Agent Skill Systems](https://arxiv.org/abs/2608.05563v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05563v1`

PoisonedEvolution demonstrates trajectory-poisoning attacks on self-evolving skill (SES) systems, exploiting the evidence promotion process to embed targeted behaviors into persistent skill banks.

- Artifact poisoning requires three conditions: Inclusion, Evolution Attribution (the main bottleneck requiring causal usefulness, recurrence, and generalizability), and Realization.
- At 10% attacker support, PoisonedEvolution achieved a 91.0% Success Evocation Rate (SER) across six LLM evolvers in SkillClaw (546/600 trials).
- The attack transferred to the structurally different Trace2Skill pipeline, achieving a 61.5% SER (369/600 trials) at the same 10% attacker ratio.
- Controlled studies showed three consistent attacker records in a 30-record batch are sufficient for success, with key determinants being recurring support, causal framing, and domain-aligned encoding.

**Why it matters:** This vulnerability establishes evidence promotion as a critical security boundary, showing that malicious untrusted trajectory data can easily become trusted persistent instructions in autonomous LLM systems.

### [PromptShield Home: Ambient Multimodal Prompt Injection Defense for Smart-Home Agents](https://arxiv.org/abs/2608.05495v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05495v1`

PromptShield-Home is a benchmark evaluating smart-home MLLMs against ambient prompt injections across three abstraction layers: traditional detectors (L0), single MLLMs (L1), and multi-agent mediation (L2).

- Evaluated layers show opposing failure modes: L0 traditional detectors execute blindly, while L1/L2 MLLM configurations suffer from severe over-refusal and missed critical events like fall detection.
- Standard aggregate accuracy is misleading due to class imbalance, where a naive always-block baseline achieves 82% accuracy.
- An oracle combining the disjoint correct prediction sets of L0 and L1/L2 reaches 94.1% accuracy, compared to 76.5% for the best individual layer.
- Results demonstrate that MLLMs alone are currently inadequate for smart-home security, favoring learned routing and sensor fusion over full MLLM replacement.

**Why it matters:** Smart-home safety requires combining traditional detectors with MLLMs via learned routing, as relying solely on MLLMs leads to severe over-refusal and missed safety-critical events.

**Why it matters:** It provides a robust, domain-tunable defense against indirect prompt injections and adaptive evasion attacks targeting LLM-based autonomous agents.

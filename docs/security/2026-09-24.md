### [ODPure: Backdoor Purification for Object Detection via Ensemble Corruption Consensus](https://arxiv.org/abs/2609.28239v1)

**arXiv cs.CR** · 2026-09-23 · `arXiv:2609.28239v1`

ODPure introduces a black-box input purification defense for object detection that neutralizes backdoor triggers using a Corruption-Reconstruction-Selection paradigm without discarding data or models.

- Addresses object detection backdoor threats including object misclassification, object disappearance, and false object generation.
- Utilizes a Corruption-Reconstruction-Selection (CRS) paradigm operating strictly at the input stage.
- Neutralizes triggers via diverse corruptions to create redundant proposals, restores structural details using generative priors, and applies voting for consensus detections.
- Operates as a black-box defense that maintains normal baseline accuracy while offering robust protection across varied trigger types.

**Why it matters:** It provides a continuous, safe perceptual stream for critical downstream applications like autonomous driving without requiring model retraining or discarding corrupted input data.

### [Your Model Is Leaking: Covert Information Transfer through LLM Residual Streams](https://arxiv.org/abs/2609.27996v1)

**arXiv cs.CR** · 2026-09-23 · `arXiv:2609.27996v1`

A novel covert-channel attack injects hidden messages into LLM residual streams via runtime hooks, enabling high-accuracy data exfiltration through exported activation artifacts without modifying model weights or disrupting schema validity.

- Messages are mapped to codewords and injected into intermediate residual streams, scaling injection strength to the local residual norm via the signal-to-residual-norm ratio.
- The attack achieves 91-100% message recovery across 9 out of 11 tested model families using a simple linear decoder.
- The injected signals maintain low KL divergence (0.001-0.007), rendering activation-level detectors ineffective (AUC <= 0.56) and evading post-hoc defenses.
- Requires no weight modifications, model retraining, control over the recording process, or direct attacker-controlled network egress.

**Why it matters:** Exporting intermediate LLM activation artifacts from air-gapped or restricted environments poses a severe data exfiltration risk that existing activation-level defenses cannot reliably prevent.

<small>Mingyuan Li, Yanna Jiang, Guangsheng Yu, Qin Wang, Xu Wang, Wei Ni, Ren Ping Liu</small>

### [Agent Name Collision Attacks in Multi-Agent Systems](https://arxiv.org/abs/2609.27624v1)

**arXiv cs.CR** · 2026-09-23 · `arXiv:2609.27624v1`

Researchers identified an agent name collision vulnerability in multi-agent hosts that use non-unique remote Agent Card names as local routing identifiers, leading to wrong-peer request dispatch.

- A2A protocol defines Agent Card names as presentational metadata rather than stable identities, leaving collision semantics undefined.
- Regression tests across seven pinned open-source revisions revealed six client-style integrations misrouting requests to an attacker-controlled endpoint when targeting a trusted peer name.
- A seventh brokered implementation mapped two peers to a single name-derived route, causing either message interception or denial of service based on queue and access-control state.
- No direct transfer of target-owned credentials or tools was observed in tested client bindings, though brokered paths risk forwarding caller-configuration objects.
- Remediation requires hosts to route using origin-bound stable identities, treat names as purely presentational, and reject ambiguous aliases.

**Why it matters:** Improperly using presentational agent names for local dispatch allows attackers to hijack routes, resulting in unauthorized message interception or service denial across multi-agent deployments.

<small>Adithyan Arun Kumar</small>

### [Control-Token Injection Suppresses Chain-of-Thought and Defeats Reasoning-Based Oversight in Tool-Using Agents](https://arxiv.org/abs/2609.27542v1)

**arXiv cs.CR** · 2026-09-23 · `arXiv:2609.27542v1`

Appending channel-control tokens to user inputs suppresses a reasoning model's chain-of-thought entirely, bypassing safety monitors and converting 39.6% of refusals into successful data exfiltrations.

- Injecting a single string of channel-control tokens into user messages reduces gpt-oss-20b's reasoning channel from a mean of 52.5 tokens to zero while maintaining http.post execution.
- Bypassing the reasoning phase completely blinded rule and cross-family LM monitors, allowing them to detect unsafe requests on 0% of forged trials compared to 100% of plain trials.
- Evaluation of Gemma agent parsers showed execution depends heavily on the harness parser: a truncation-tolerant regex executed calls on 24/24 trials, whereas a strict parser executed 0/24 on identical generations.
- Defenses like flagging empty reasoning traces catch basic attacks, but fail against adaptive benign decoys that supply minimal placeholder reasoning.

**Why it matters:** Demonstrates that LLM agent safety is a joint property of the model and decoding harness, showing that control-token injection can entirely bypass chain-of-thought safety oversight.

<small>Muhammad Usama, Khair Un Nisa, Summer Yeoreum Jung</small>

**arXiv cs.CR** · 2026-09-22 · `arXiv:2609.27090v1`

Divide and Doubt (DnD) is a targeted RAG poisoning attack that evades defenses by splitting target claims across stylistically diverse passages and casting doubt on reference evidence.

- DnD distributes support for a target claim across stylistically diverse passages to disperse poison-passage representations in embedding space.
- The attack inserts a specific passage designed to cast doubt on evidence supporting the true reference answer.
- Evaluated on two open-domain QA datasets, three LLMs, and nine RAG configurations under both black-box and white-box retriever access.
- DnD achieves its largest performance gains against clustering- and conflict-aware defensive mechanisms.

**Why it matters:** It demonstrates that current RAG defenses relying on lexical, semantic, or conflict similarity can be systematically bypassed by dispersing and diversifying poison documents.

### [Ajar: Measuring Open Privilege in Agent Defenses](https://arxiv.org/abs/2609.26900v1)

**arXiv cs.CR** · 2026-09-22 · `arXiv:2609.26900v1`

Ajar is a new framework that measures open privilege in LLM agent defenses by evaluating unneeded tool calls at execution decision points within existing benchmarks.

- Attaches to existing agent-security benchmarks (e.g., AgentDojo) using their tasks, tool schemas, reference solutions, and goal states.
- Generates unnecessary candidate tool calls for benign tasks and presents them to the defense at every action point to test for over-privilege.
- Introduces open privilege as a third evaluation metric alongside attack success rate and benign utility.
- Evaluated five defenses (Progent, CaMeL, AC4A, Permission Assistant, and Claude Code's Auto mode), revealing significant variance in open privilege that does not correlate with standard utility or attack success metrics.

**Why it matters:** It demonstrates that standard benchmark metrics miss security vulnerabilities, as defenses can achieve high utility and low attack success while still leaving broad, unneeded tool permissions open.

<small>Reshabh K Sharma, Linxi Jiang, Shuo Chen, Zhiqiang Lin</small>

### [Extracting CNNs in the Unknown-Architecture and Feedback-Agnostic Setting](https://arxiv.org/abs/2609.27427v1)

**arXiv cs.CR** · 2026-09-23 · `arXiv:2609.27427v1`

A new cryptanalytic extraction framework proves CNN architecture and parameters can be recovered simultaneously in black-box settings without prior architecture knowledge or feedback type constraints.

- Discovers that the spatial geometry of weight vectors extracted via parameter-recovery attacks directly leaks layer types, kernel size, stride, padding mode, output-channel number, and pooling properties.
- Identifies three geometric consistencies: sparsity consistency (reveals layer type, kernel size, stride), numerical consistency (reveals padding mode, output channels), and structural consistency (reveals pooling type, window size, stride).
- Establishes a feedback-agnostic recovery method that operates identically across both raw-output and hard-label attack settings.
- Demonstrates practical end-to-end and layer-wise extraction on CNNs incorporating both max and average pooling operations.

**Why it matters:** It eliminates the long-standing requirement of knowing the target CNN architecture beforehand, significantly increasing the threat surface for model stealing attacks against black-box neural networks.

### [MDRC: A Deployable State-Recovery Defense for Traffic Signal Control under Sensor Corruption](https://arxiv.org/abs/2609.27528v1)

**arXiv cs.CR** · 2026-09-23 · `arXiv:2609.27528v1`

MDRC is a post-detection state-recovery defense combining DDIM diffusion models and Reptile meta-learning to reconstruct trustworthy traffic states from corrupted sensor inputs prior to reinforcement learning controller execution.

- Combines Denoising Diffusion Implicit Models (DDIM) for state reconstruction with Reptile meta-learning to ensure cross-city initialization transferability.
- Reduces Average Travel Time across seven CityFlow benchmarks by 6.77% under adversarial attacks and 12.75% under structured sensor loss.
- Demonstrates hardware-in-the-loop deployment over 9.16 hours (32,389 cycles) with 99.79% decision availability and ~38 ms processing time per one-second interval.
- Establishes a theoretical recovery-error bound accounting for score approximation, numerical discretization, and initialization mismatch.

**Why it matters:** It enables real-time, low-latency resilience against sensor failures and cyber-attacks in physical traffic infrastructure without degrading signal control performance.

<small>Mingyuan Li, Chunyu Liu, Xiao Liu, Yanna Jiang, Guangsheng Yu, Xu Wang, Wei Ni, Ren Ping Liu</small>

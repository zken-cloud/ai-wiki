### [TrajMark: Ownership Attribution and Segment-Level Tamper Localization for Coding-Agent Trajectories](https://arxiv.org/abs/2609.10416v1)

**arXiv cs.CR** · 2026-09-09 · `arXiv:2609.10416v1`

TrajMark is a training-free, symmetric-key trajectory watermarking framework for coding agents that separates robust ownership attribution from fragile segment-level tamper localization.

- Uses a sparse owner layer that encodes a six-bit deployment ID by rewriting a keyed subset of READ actions into masked linear equations without adding trajectory actions.
- Employs a localization layer that inserts linked Q12 ordinary, group, and terminal seals to commit to protected critical-action segments.
- Achieves 100% exact owner recovery on clean batches, detects 95.5%-100% of edits under exhaustive single-site attacks, and localizes 95.8% of modified sites under random action corruption.
- Maintains task performance with a matched Pass@1 of 26.9% for watermarked trajectories versus 26.3% for unwatermarked runs.

**Why it matters:** It enables developers to verify the authenticity and detect local tampering in the visible execution traces of AI coding agents without sacrificing task accuracy.

<small>Bokang Zeng, Zheng Gao, Xiaoyu Li, Xiaoyan Feng, Jiaojiao Jiang</small>

### [Active Adaptation, Not Static Defense: Temporal Dynamics of Preventative Steering in Adversarial Fine-Tuning](https://arxiv.org/abs/2609.10142v1)

**arXiv cs.CR** · 2026-09-09 · `arXiv:2609.10142v1`

Preventative Steering against malicious fine-tuning works via dynamic compensatory adaptation rather than static weight shifts, enabling a new Progressive Intensity Scheduling method that enhances safety robustness.

- Analysis reveals defense dynamics consist of an early compensatory adaptation phase followed by a steady-state phase where corrective signals decay.
- Attention output projections act as the dominant residual-write route for defensive parameter updates.
- Intervention Delta Preservation (IDP) experiments confirm that preserving or reinjecting static weight offsets fails to maintain safety, proving the defense requires active adaptation.
- Progressive Intensity Scheduling (PIS) starts with a moderate injection strength and ramps it up as static-strength alignment decays, outperforming static-strength steering across Qwen2.5 and Gemma-3.

**Why it matters:** Demonstrating that training-time safety defenses rely on active adaptation allows for dynamic scheduling techniques that better resist adversarial fine-tuning.

<small>Jing Guan, Yachao Yang, Zhaoliang Liu, Yuyao Zhang, Fanyu Meng, Junlan Feng</small>

### [Understanding the Security Boundary of Obfuscation-based On-Device LLM Protection](https://arxiv.org/abs/2609.10117v1)

**arXiv cs.CR** · 2026-09-09 · `arXiv:2609.10117v1`

This paper formalizes TEE-shielded LLM partition (TSLP) obfuscation primitives, exposes vulnerabilities in prior methods via a new attack called Collapse, and proposes extended primitives (O_ext) to broaden the security boundary.

- Formalizes TSLP obfuscation schemes as dual-tuples of linear computations satisfying specific algebraic properties.
- Unifies prior weight transformation frameworks into a single canonical composition form, O_prior, which defines their shared structural security boundary.
- Introduces Collapse, a primitive-guided attack methodology demonstrating vulnerabilities across top-venue TSLP defenses including ArrowCloak, TSQP, and LoRO.
- Formulates two new obfuscation primitives and combines them with existing constructs to establish an extended security boundary, O_ext.

**Why it matters:** It demonstrates that current heuristic methods for offloading obfuscated LLM layers to untrusted GPUs are systematically vulnerable, providing a unified mathematical framework to build more resilient TEE-shielded architectures.

<small>Hanyi Zhou, Chenyang Li, Yuanzhe Pang, Ke Xu, Mingwei Xu, Zhuotao Liu</small>

### [What Makes Adversarial Examples Transfer Across Deepfake Detectors?](https://arxiv.org/abs/2609.10002v1)

**arXiv cs.CR** · 2026-09-09 · `arXiv:2609.10002v1`

A controlled study of 60 deepfake detectors reveals that adversarial transferability depends heavily on specific source-target compatibilities and that single-source averages severely underestimate vulnerability.

- Evaluated black-box adversarial transfer across 60 detectors comprising six backbones, two pretraining regimes, and five training-data configurations using AutoAttack (AA) and CW-EOT.
- Compatibility impact varies by attack: exact backbone match has the largest effect under AA, whereas shared pretraining and training data dominate under CW-EOT.
- Average single-source transfer attack success rates (ASR) were 7.21% for AA and 19.52% for CW-EOT across non-target sources.
- A multi-source oracle combining both attacks achieved a 64.48% mean ASR even after excluding exact backbone and training-data matches.
- The authors released a benchmark dataset of 240,000 adversarially perturbed images alongside pairwise transfer results and evaluation code.

**Why it matters:** Standard single-source transfer evaluations significantly understate the vulnerability of deepfake detectors to black-box adversarial attacks.

<small>Rafael M. Mamede, Pedro C. Neto, Ana F. Sequeira</small>

`adversarial-machine-learning` `deepfakes` `computer-vision` `model-robustness` `black-box-attacks`

### [CS-Guard: Benchmarking LLM Guardrails for Code Generation Security](https://arxiv.org/abs/2609.09798v1)

**arXiv cs.CR** · 2026-09-09 · `arXiv:2609.09798v1`

CS-Guard is the first benchmark for evaluating LLM code-generation security guardrails across text-to-code and code-to-code tasks, introducing a novel Fictional Scenario Attack that exposes widespread guardrail vulnerabilities.

- Evaluated 9 guardrails across 7 LLMs using 1,000 text-to-code malware prompts, 7 jailbreaks, and 331 code-to-code prompts across infilling, completion, and translation.
- Text-to-code attack success rates (ASR) averaged ~50% post-jailbreak, while code-to-code ASR ranged from 14.4% to nearly 100% across guardrails.
- The novel Fictional Scenario Attack (FSA), which embeds malicious intent into legitimate software-development scenarios, achieved near 100% ASR across many guardrails.
- Introduces a modular three-layer taxonomy allowing developers to register custom guardrails for evaluation.

**Why it matters:** Current guardrails fail to reliably block malicious code generation, leaving real-world software development workflows vulnerable to automated malware creation and exploitation.

<small>Jinyang Li, Mingyu Guo, Hung X. Nguyen</small>

### [DuplexJail: Safety Alignment Breaks Under Spoken Interruption in Full-Duplex Models](https://arxiv.org/abs/2609.09420v1)

**arXiv cs.CR** · 2026-09-08 · `arXiv:2609.09420v1`

DuplexJail demonstrates that delivering fixed, request-independent spoken interruptions breaks safety alignment in full-duplex speech-to-speech models, significantly increasing attack success rates.

- DuplexJail evaluates two attack strategies across 720 AdvBench and HarmBench requests: fixed-delay interruption after a harmful request and refusal-triggered interruption based on text streaming cues.
- Fixed-delay interruption increased whole-response AdvBench attack success rates to 40.3% for PersonaPlex (+33.8 percentage points) and 48.7% for PersonaPlex-RL (+39.3 percentage points).
- Refusal-triggered interruption achieved 35.6% attack success on PersonaPlex and 48.6% on PersonaPlex-RL.
- Evaluation across four open-source models showed increased harmful response rates for PersonaPlex, PersonaPlex-RL, and FLM-Audio, whereas BayLing-Duplex exhibited decreased rates.

**Why it matters:** The findings establish user audio interruption as a novel jailbreak vector, highlighting the need to evaluate safety alignment dynamically across continuous full-duplex speech interactions.

<small>Jaechul Roh, Deepak Chandran, Amir Houmansadr, Andrea Fanelli</small>

### [An Experimental Evaluation of Multimodal Prompt Injection Attacks on Agentic AI Frameworks](https://arxiv.org/abs/2609.09404v1)

**arXiv cs.CR** · 2026-09-08 · `arXiv:2609.09404v1`

Researchers created MMPIBench to evaluate multimodal prompt injection against agentic AI frameworks, finding a 1% attack completion rate in vision channels compared to up to 75% in under-defended audio channels.

- MMPIBench evaluated 720 runs spanning six frameworks, five foundation models, six visual carriers, and four attacker objectives.
- Visual attacks were attempted in 12.8% of runs but completed in only ~1%, with foundation models blocking most attempts at the planning step.
- Foundation model choice drives security outcomes significantly more than framework choice, with one model recognizing injections in 59.7% of runs while two others attempted attacks in 23.6% of runs.
- Audio prompt injections completed in 49% of viable framework/model cells overall and reached 75% completion for a single model, highlighting severe vulnerabilities in non-visual perceptual channels.

**Why it matters:** Evaluating attack completion rates alone underestimates security risks, as unaligned perceptual channels like audio leave agentic AI frameworks highly vulnerable to indirect prompt injection.

<small>Viet K. Nguyen, Mohammad I. Husain</small>

### [AutoTrans: AI-Assisted Automatic Translation of Security Assertions for RISC-V Processors](https://arxiv.org/abs/2609.10057v1)

**arXiv cs.CR** · 2026-09-09 · `arXiv:2609.10057v1`

AutoTrans is an automated framework using Deepseek V4 to translate RISC-V security assertions between processor targets, achieving a 78% automated acceptance rate.

- Uses a lightweight regex-based SystemVerilog signal extractor to prevent LLMs from hallucinating non-existent target RTL port names.
- Employs standardized prompt templates and pinned inference parameters to guarantee deterministic, byte-identical prompt assembly across model updates.
- Generates assertions from English-only security descriptions without requiring manual authoring.
- Integrates Cadence JasperGold Formal Property Verification (FPV) to mathematically validate translated assertions against target RISC-V cores.
- Demonstrates cross-target translation (e.g., from NS31A to IBEX) achieving a 78% automated Translation Acceptance Rate (TAR) and 100% TAR after human refinement.

**Why it matters:** AutoTrans eliminates the manual overhead of porting hardware security assertions across different RISC-V implementations while maintaining formal verification rigor.

### [LLMSec-AV: A Vulnerability Taxonomy and LLM-Driven Software Weakness Discovery Framework for Autonomous Vehicles](https://arxiv.org/abs/2609.09386v1)

**arXiv cs.CR** · 2026-09-08 · `arXiv:2609.09386v1`

LLMSec-AV introduces an autonomous vehicle vulnerability taxonomy with 18 weakness classes and demonstrates that LLMs can recover up to 76% of known safety-critical weaknesses in Autoware code.

- Tested on Autoware by decomposing 770 translation units into 4,673 functions, analyzing 161 functions across four prompting conditions.
- LLM conditions recovered up to 76% of 46 known weakness locations, whereas static analyzers (CodeQL, Semgrep, Clang) matched zero and cppcheck matched one.
- Six of the 18 identified vulnerability classes could not be translated into conventional static-analysis rules.
- Taxonomy context did not drive raw recall but increased the proportion of findings assigned to specific weakness classes from near zero to over 80%.

**Why it matters:** It demonstrates that LLMs can identify domain-specific, motion-affecting software weaknesses in autonomous vehicle codebases that conventional static analysis tools miss.

<small>Md. Wasiul Haque, Sagar Dasgupta, Mizanur Rahman</small>

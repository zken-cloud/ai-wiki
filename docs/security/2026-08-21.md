### [COPA: Continual Preference Optimization for Adaptive Prompt Injection Defense](https://arxiv.org/abs/2608.19982v1)

**arXiv cs.CR** · 2026-08-20 · `arXiv:2608.19982v1`

COPA is a continual preference optimization framework that uses GRPO-based optimization and margin-weighted experience replay to defend LLMs against evolving prompt injection attacks without catastrophic forgetting.

- Treats prompt injection defense as a lifelong learning problem to handle adaptive, evolving adversaries.
- Uses Group Relative Policy Optimization (GRPO) to incrementally incorporate feedback from newly observed attack streams.
- Employs margin-weighted experience replay to retain robustness against previously encountered attack classes and preserve general model capabilities.
- Reduces attack success rates by an average of 4.4x and up to 6.3x compared to state-of-the-art defenses.

**Why it matters:** It enables deployed LLMs to continuously adapt to novel prompt injection techniques in real time without needing static redesigns or losing prior security alignment.

<small>Roshan Sood, Onat Gungor, Tajana Rosing</small>

### [MaliciousSkillBench: A Comprehensive Benchmark for Malicious Agent Skill Detection](https://arxiv.org/abs/2608.19901v1)

**arXiv cs.CR** · 2026-08-20 · `arXiv:2608.19901v1`

MaliciousSkillBench is a new benchmark for malicious LLM Agent Skill detection, consolidating 9,740 Skills across 11 unified attack categories to address dataset fragmentation and source-bias evaluation challenges.

- Deduplicated 8,414 raw malicious records into 7,539 unique identities across 4,588 structural families, yielding a final benchmark of 7,505 malicious and 2,235 benign Skills.
- Learned text detectors showed severe performance drops from Random Macro-F1 (0.882-0.932) to Source-Disjoint evaluation (0.653-0.665).
- A word TF-IDF SVM achieved 0.665 Source-Disjoint Macro-F1 with 95.6% malicious recall, but suffered a 62.4% benign false positive rate on held-out sources.
- Off-the-shelf Skill scanners reduced false positives compared to learned models, but only at the cost of sharply reduced malicious recall.

**Why it matters:** Current detection approaches fail to generalize across unseen distribution channels, causing either high false-positive rates on benign Skills or missed malicious attacks in real-world deployments.

### [Enhancing Privacy in Federated Learning via Dual Obfuscation of Gradients and Training Images](https://arxiv.org/abs/2608.19650v1)

**arXiv cs.CR** · 2026-08-20 · `arXiv:2608.19650v1`

A dual obfuscation method for federated learning combines random binary gradient masking with client-level image encryption to prevent image reconstruction attacks without degrading Vision Transformer classification performance beyond the encryption baseline.

- Combines a gradient modification technique using random binary weights (zeroing out selected gradient elements) with individual image encryption.
- Uses independent encryption keys per client and per image to eliminate the requirement for explicit key sharing.
- Evaluated on Vision Transformer (ViT) image classification tasks subjected to Attention Privacy Leakage (APRIL) reconstruction attacks.
- Reduces visually recoverable information while maintaining the model classification performance associated with the underlying image encryption.

**Why it matters:** Combining gradient masking with per-image encryption provides complementary defense layers that mitigate visual data leakage in Vision Transformers without imposing key-sharing overhead or extra performance penalties.

### [AEGIS: Attention-Embedding Gradient Isolation Shield - Triple-Channel Gradient Masking for Privacy-Preserving Federated LLM Fine-Tuning](https://arxiv.org/abs/2608.19534v1)

**arXiv cs.CR** · 2026-08-20 · `arXiv:2608.19534v1`

AEGIS is a lightweight defence that eliminates token recovery from gradient inversion in federated LLM fine-tuning by simultaneously masking three distinct gradient leakage channels in the backward path without altering model architecture.

- Identifies three leakage channels: attention output projection low-rank subspace (Channel 1), embedding gradient row-norm sparsity (Channel 2), and MLP expansion gradients (Channel 3).
- Freezes attention projection parameters to construct a complete defence against Channel 1 leakage.
- Injects calibrated noise into embedding gradients (Channel 2) and per-block noise into MLP expansion gradients (Channel 3) to mask private signals.
- Applies the same masked gradients to both local optimizer steps and server exports to ensure no clean signal remains.
- Evaluated across 11 models and six datasets, reducing token recovery rates to near zero against analytical and optimization-based attacks while preserving model utility.

**Why it matters:** It prevents analytical and optimization-based gradient inversion attacks in federated LLM fine-tuning without degrading model performance or requiring architectural modifications.

<small>Ye Tao, Hong Shen, Hui Tian, Xin Wang, Can Wang</small>

`federated-learning` `gradient-inversion` `privacy` `llm` `ai-security`

- The framework evaluates six watermarking schemes across three open-weight generators, eleven languages, four scripts, and eight typological families.

### [Linguistic Holonomy and Statistical Watermarks: Inner Geometry of Meaning-Preserving Transformations](https://arxiv.org/abs/2608.19369v1)

**arXiv cs.CR** · 2026-08-19 · `arXiv:2608.19369v1`

Researchers prove that meaning-preserving text transformations contain a hidden geometric holonomy, showing statistical watermark decay follows a exact seed-window survival identity rather than semantic similarity distance.

- Meaning-preserving transformation chains factorize into an endpoint component and a holonomy in the initial state's stabilizer, which acts as parallel transport on the embedding space's unit sphere.
- The residual watermark statistic is strictly proportional to the number of token positions with completely intact seeding windows.
- Under an independent-edit assumption, the watermark signal decays following the power law ̢Ȑ^{h+1}, where h relates to the window context.
- At a fixed text retention rate, the remaining watermark signal varies drastically—from 50%, to 25%, down to 0%—depending entirely on the spatial distribution of edits.

**Why it matters:** Measuring semantic similarity fails to predict watermark erosion because detection strength depends strictly on local seeding-window integrity rather than global meaning preservation.

- Utilizes robust trimmed-mean aggregation to lower the RMSE impact of poisoned clients from 0.042 to 0.035 pu.

### [Malformer: A Multi-Modal Malware Detector Using Transformers](https://arxiv.org/abs/2608.19052v1)

**arXiv cs.CR** · 2026-08-19 · `arXiv:2608.19052v1`

Malformer is a quadrimodal transformer framework that fuses text, image, graph, and audio representations of Windows executables to improve malware detection accuracy.

- Fuses four distinct binary modalities: text, image, graph, and audio representations.
- Utilizes an architecture combining two RoBERTa encoders, a modified Vision Transformer (ViT), WavLM for audio, and an adaptive loss-weighting scheme.
- Achieved 98.3% accuracy and an F1 score of 0.9833 on a dataset of 201,549 binary samples.
- Outperformed unimodal baselines and bimodal detectors by 4.6 to 17.6 percentage points.

**Why it matters:** Combining four distinct binary representations reduces reliance on single extraction methods like disassembly, yielding more resilient malware detection.

<small>Samuel Howard, Kshitiz Aryal, Mahmoud Abdelsalam, Maanak Gupta, Andrew Wheeler, Pradip Kunwar</small>

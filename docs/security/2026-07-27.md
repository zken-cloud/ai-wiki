### [TYPO: Instruction-Dense Visual Jailbreaks against Commercial Closed-Source Image-Generation Models](https://arxiv.org/abs/2607.24897v1)

**arXiv cs.CR** · 2026-07-27 · `arXiv:2607.24897v1`

The paper introduces TYPO, a black-box framework executing instruction-dense visual jailbreaks that bypass safety alignments to generate legible, harmful text within images produced by closed-source image-generation models.

- Identifies a safety gap where commercial models refuse harmful plain text but permit identical harmful content when rendered as text embedded within generated images.
- Decomposes prompt generation into a dual-channel strategy space: a textual channel to reframe target intent and a visual channel to specify typographic presentation.
- Employs an adaptive combinatorial search to optimize strategy combinations across the dual-channel space.
- Outperforms nine representative jailbreak attacks by an average of 50.2% in Attack Success Rate (ASR) across GPT-Image-2, Nano Banana Pro, Qwen-Image-2, and Seedream 5.0 Lite.
- Achieves high attack performance with a low average query cost of $0.04 per attempt.

**Why it matters:** It demonstrates that safety alignments in commercial image generators fail to transfer to embedded text, allowing adversaries to cheaply generate and spread readable, actionable harmful instructions.

<small>Meng Xie, Li Zeng, Hangtao Zhang, Xianlong Wang, Ziqi Zhou, Pengpeng Qiao, Zhetao Li</small>

### [Agentic Permissions Policy Algebra for Taint Confinement in LLM Agents](https://arxiv.org/abs/2607.24625v1)

**arXiv cs.CR** · 2026-07-27 · `arXiv:2607.24625v1`

APPA introduces an Information Flow Control framework using context branching and prospective enforcement to prevent taint propagation while retaining LLM agent utility during untrusted data inspection.

- Uses engine-managed context branching to spawn label-seeded child trajectories, allowing untrusted data inspection without polluting the parent context.
- Prospectively evaluates label descents and missing prerequisites before data acquisition to generate actionable remedy plans such as Authorize and Accept.
- Formally proves parent label preservation and merge confinement using a two-monoid algebraic model over security labels and shared event logs.
- Reduces attack success rates from 31%-50% down to 0%-7% across a multi-turn tool-chaining benchmark across four models.

**Why it matters:** APPA provides a mathematically proven method to eliminate data exfiltration from prompt injection attacks without rendering LLM agents unusable through global taint tracking.

### [ContainmentBench: Trace-Based Evaluation of Post-Injection Containment in Tool-Using LLM Agents](https://arxiv.org/abs/2607.23999v2)

**arXiv cs.CR** · 2026-07-27 · `arXiv:2607.23999v2`

ContainmentBench is a sandboxed, trace-based benchmark for tool-using LLM agents that evaluates post-injection security by decoupling terminal policy compliance, logged propagation traces, recovery instrumentation, and authorized workflow utility.

- In a 17,640-rollout evaluation of Qwen2.5-7B-Instruct, 73.5% of matched active-tainted pairs showed different trajectories or utility outcomes despite identical zero committed-harm terminal policy scores.
- Taint-only enforcement reduced authorized workflow completion to 0.1642, whereas a trusted-ledger policy restored completion to 0.8567 and a tool-boundary baseline achieved 0.9233.
- Aggregate logged-spread rankings for post-injection propagation were found to vary significantly based on evidence-stage composition and choice of denominator.
- The evaluation framework relies on synthetic rollouts of a single model and assumes an accurate structured authorization ledger for the policy case.

**Why it matters:** Terminal outcome metrics alone mask critical post-injection risks and performance trade-offs, requiring agent evaluations to separately track trajectory traces and utility loss.

<small>Wenhao Lan, Shan Li, Xinhua Lai, Meiqi Wu, Junbin Yang, Haihua Shen</small>

**arXiv cs.CR** · 2026-07-27 · `arXiv:2607.23962v1`

Researchers developed the first Vision-Language Model (VLM) framework for GNSS spoofing detection in autonomous vehicles, fusing camera data with in-vehicle sensors to detect spatial-semantic discrepancies.

- Uses a three-stage fine-tuning process to align front-camera visual cues and sensor logs (speed, acceleration, yaw rate) with GNSS-derived maneuvers across wrong-turn, stop, and overshoot attacks.
- Fine-tuned model achieves 94%-95% F1-score on a real-world dataset from Tuscaloosa, Alabama, compared to 23%-32% for zero-shot VLM baselines.
- Achieves 100% classification accuracy on wrong-turn and stop attacks, and 88%-93% accuracy on overshoot attacks.
- Introduces an adaptive inference policy that reduces VLM invocations by ~86% (calling it on 14% of windows), yielding 65ms-73ms processing latency per 4-second window.

**Why it matters:** It provides a computationally efficient, semantic-level defense that complements signal-level integrity checks to protect autonomous vehicles from dangerous GNSS spoofing attacks.

A framework pairing high-fidelity cloud decoys with an autonomous LLM agent to automatically reconstruct threat actor sessions into analyst-ready reports within four to five minutes.

- Uses a session aggregation operator over provider-derived pivot tuples to isolate federated session keys without relying on attacker-controlled inputs.
- Employs dynamic prompt generation via a two-stage assembly to maintain a grounding invariant, restricting the evidence horizon to observed fields.

- Achieved complete reconstruction in 9 out of 10 controlled AWS S3 scenarios with zero ungrounded assertions in generated reports.

**Why it matters:** Automating session-level cloud incident investigation via deception technology drastically reduces analyst triage time while mitigating false positives inherent to full control-plane log queries.

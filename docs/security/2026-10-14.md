### [Nudge the Judge: Uncovering Program Decision Hijacking in Real-World Jev Applications](https://arxiv.org/abs/2610.18612v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18612v1`

Researchers introduced JevProbe, an automated framework to evaluate Jev Program Decision Hijacking (JPDH) by tracing adversarial context influence to downstream security impacts in real-world applications.

- JPDH occurs when attacker-controlled open-ended contexts redirect program execution via schema-valid Jev judgments.
- JevProbe leverages application logic to trace adversarial influence from reachable context surfaces to observable program decisions and downstream impacts.
- Evaluation across 228 real-world Jev applications and 2,273 test cases revealed an 81.5% Decision Flip Rate (DFR), with 98.6% of flips causing potential downstream security impacts.
- JevProbe improved macro-average DFR by 50.4 percentage points over the strongest adapted baseline, demonstrating that existing defenses offer limited protection.
- The authors released the JevProbeBench benchmark dataset and source code publicly on GitHub.

**Why it matters:** It demonstrates that structured model outputs in real-world applications remain highly vulnerable to adversarial context manipulation, exposing programs to severe downstream execution hijacks that existing defenses fail to stop.

<small>Yang Luo, Tiantian Ji, Zifeng Kang, Yucheng Wang, Yong Liu, Zhiyi Yin, Xinran Liu</small>

### [Autonomous Cyber Operations Gym for Training and Evaluating AI Models for Defence](https://arxiv.org/abs/2610.18594v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18594v1`

Researchers developed an Autonomous Cyber Operations (ACO) gym that integrates high-fidelity network emulation, user behavior modeling, and feature extraction to train and evaluate AI defense models.

- Integrates network emulation, benign user and adversarial behavior modeling, and automated scenario generation via open toolkits.
- Supports live and deferred packet-level and flow-level feature extraction to generate labeled synthetic datasets for Deep Neural Network (DNN) Intrusion Detection Systems (IDSs).
- Provides an emulated environment for developing and testing modular components of autonomous defense agents.
- DNN classifiers evaluated in the gym achieved near-perfect in-domain recall on adversarial flows.
- Experiments demonstrated high vulnerability to domain shift, where minor protocol distribution changes caused a catastrophic drop in model transferability and detection.

**Why it matters:** The gym enables standardized evaluation of autonomous cyber defense agents while highlighting that minor network domain shifts can completely degrade DNN-based intrusion detection reliability.

### [Rethinking Quality in Large Language Model Routing: Security-Conditioned Model-and-Budget Selection](https://arxiv.org/abs/2610.18566v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18566v1`

SCRouter optimizes LLM cost and performance by decoupling utility and security predictions using budget-completion probabilities and dynamic query probing to select optimal model-budget pairs.

- Existing LLM routers rely on a single quality metric, failing to handle conflicting requirements between utility for standard queries and security for sensitive ones.
- SCRouter estimates the probability of a response completing within budget for each model-budget pair, using it to separately predict utility and security scores.
- A small probe dynamically weights utility versus security per query, selecting the target model and budget by balancing weighted quality against cost.
- The authors introduced SCRouterBench, comprising 38,869 in-domain utility/security queries evaluated across 144 model-budget combinations (12 models, 12 budgets), plus 2,753 out-of-domain queries.
- SCRouter outperforms baseline routers by 13-29 points in-domain and 19-23 points out-of-domain.

**Why it matters:** It enables cost-efficient LLM deployment on mixed workloads without compromising on security refusals or generation utility.

<small>Yichi Zhang, Zhenxiang Huang, Yuyang Zhang, Yuchen Yang</small>

### [Towards Safe Autonomy for Computer Use](https://arxiv.org/abs/2610.18508v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18508v1`

SA-CUA is a dual-LLM framework for Computer Use Agents that uses accessibility trees to dynamically mask untrusted visual content, eliminating indirect prompt injection risks without requiring continuous human confirmation.

- Computer Use Agents (CUAs) lack inherent visual trust boundaries because screens blend trusted toolbars with untrusted web or application content.
- SA-CUA derives conservative deterministic rules from the accessibility tree to unmask only trusted screen regions for the privileged LLM.
- The architecture uses a robust endorsement channel to verify and transfer untrusted data into the trusted domain via trusted channels.
- The framework maintains a zero percent attack success rate against indirect prompt injections while outperforming CaMeL-CUA in task utility.

**Why it matters:** It enables secure, fully autonomous computer use agents that process untrusted web or document data without subjecting users to confirmation fatigue or exposing systems to indirect prompt injection attacks.

### [Kairos: Transactional Security Enforcement at the System Boundary for LLM Agents](https://arxiv.org/abs/2610.18457v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18457v1`

Kairos is a reference monitor operating at the system boundary of unmodified LLM agents that uses speculative execution and deferred transaction enforcement to defend against indirect prompt injections.

- Operates at the isolation boundary of opaque agents by treating tool calls, shell commands, and custom scripts as unified file and network operations.
- Uses a declarative policy based on source trust to decide effects deterministically or defer ambiguous effects for speculative execution.
- Employs a decision oracle with bounded authority (such as an LLM or human) to evaluate trace evidence before releasing or refusing deferred actions.
- Reduces attack success on the AgentDojo benchmark from 47.0% to 2.7% across three agent models while preserving undefended baseline benign utility.

**Why it matters:** It prevents indirect prompt injection attacks by deferring ambiguous actions until trace evidence accumulates, eliminating the need to modify internal agent logic or compromise system utility.

### [FedGraph: Defending Federated Large Language Model Fine-Tuning Against Backdoor Attacks via Graph-Based Aggregation](https://arxiv.org/abs/2610.18430v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18430v1`

FedGraph is a graph-based aggregation framework that defends federated LLM fine-tuning against backdoor attacks by leveraging structural differences between consistent malicious client updates and diverse benign client updates.

- Exploits the observation that malicious clients exhibit strong update consistency compared to the diverse, dispersed updates of benign clients.
- Constructs a dynamic graph representing clients as nodes and extracts structural features of client interactions to bypass high-dimensional parameter space entanglement.
- Derives compact client representations to identify and filter out malicious contributions during federated aggregation.
- Reduces attack success rates to under 10% while achieving a 95.5% average detection accuracy and a 2.33% false positive rate.

**Why it matters:** It provides a highly accurate method to mitigate backdoor vulnerabilities in collaborative LLM fine-tuning without requiring access to private client data.

### [Pin It on Anyone: Certified Targeted Displacement of Multi-Bit LLM Watermarks Without the Key](https://arxiv.org/abs/2610.18359v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18359v1`

Researchers developed "targeted displacement," an attack that rewrites watermarked LLM output to alter embedded multi-bit messages to an arbitrary choice without knowing the secret key.

- Requires only model logits and access to a small number of user accounts, bypassing the need for the provider's secret watermarking key.
- Derives theoretical upper and lower bounds for attack success based on account count, message length, and text ambiguity characteristics.
- Empirically validated across five distinct watermarking methods and four LLMs, achieving high-accuracy message alteration as account access scales.
- Maintains original text semantics during the rewriting process to successfully trick the target message decoder.

**Why it matters:** This attack undermines the reliability of multi-bit LLM watermarking for user attribution, allowing malicious actors to frame innocent users for generated harmful text.

### [Encrypted Skills Can Become New Security Exploits If AI Agents Know How to Decipher](https://arxiv.org/abs/2610.18262v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18262v1`

Ciphered Skill Injection (CSI) exploits LLM agents by embedding encoded malicious instructions in third-party skill files, which agents decode and execute.

- Introduces Ciphered Skill Injection (CSI), hiding malicious instructions in skill files using Caesar and layered cipher variants.
- Evaluated across eight LLM models and 139 injection-task pairs using shortened skill formats.
- Achieved attack success rates of up to 47.5% for Caesar cipher variants and 40.3% for layered variants.
- Demonstrates that successful cipher decoding by an agent does not automatically guarantee attack execution, with layering showing model-dependent effects.
- Existing skill scanners rarely detected or flagged the encrypted malicious skill injections.

**Why it matters:** It demonstrates that LLM agents capable of decoding untrusted text create a new security vulnerability by turning inert, encrypted third-party skills into actionable exploits that bypass current security scanners.

<small>Yan-Lun Chen, Pin-Yu Chen, Chia-Mu Yu</small>

### [Holding Agents Accountable with Verifiable Agent Insurance](https://arxiv.org/abs/2610.18230v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18230v1`

Verifiable Agent Insurance (VAI) uses smart contracts, monetary escrow, and trace verification to financially compensate users when AI agents violate programmatically-specified policies.

- VAI embeds policy promises and monetary escrow into smart contracts on an Ethereum layer-2 network to prevent tampering and automate payouts upon verified policy breaches.
- Execution traces are logged via a shared tool-execution path in the agent harness, eliminating the need to instrument individual tools separately.
- Without agent modifications, VAI detects policy violations in 42.2% of benchmark runs containing violations by parsing natural language exchanges.
- Co-designing agents to explicitly emit structured data objects for user authorizations and security-relevant actions increases violation detection to 83.0% of traces.

**Why it matters:** VAI establishes a financial accountability mechanism for AI agent failures while demonstrating that agents must be co-designed to emit structured security logs for reliable automated auditing.

### [Cost-Efficient Privacy Enforcement for Email-Generating LLM Agents under Strategic Information Requests](https://arxiv.org/abs/2610.18007v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.18007v1`

A local contract-conditioned rewriting framework using Gemma reduces privacy leakage and remote LLM checker costs by intercepting and localizing repair logic for email-generating LLM agents.

- Constructs an information-release contract defining what details to preserve, generalize, or forbid before executing local rewriting via Gemma.
- Reduces normal-prompt privacy leakage from 11.41% to 4.03% while increasing the UsableRate from 85.2% to 92.6%.
- Mitigates strategic attack-prompt leakage from 28.19% to 18.79% and suppresses checker-only cost amplification from 1.32x down to 1.02x.
- Offline replay ablation indicates that explicit contracts reduce leakage over generic Gemma rewriting by 36.3% under normal prompts and 54.1% under attack prompts.

**Why it matters:** Moving draft repair to a local model reduces expensive remote API calls and prevents private context leakage when agents face adversarial information requests.

Researchers introduce ProtoArena, a black-box dynamic benchmark containing 80 multi-component protocol vulnerability environments across 11 domains and 7 attack categories to evaluate LLM agent exploitation capabilities.

- ProtoArena evaluates agents across three information levels ranging from L1 guided reproduction to L3 effect-directed black-box exploration without target source code.
- A hybrid verifier uses rule-based checks and LLM reviews of independently captured traffic and logs to validate attack success.
- Claude Opus 4.8 achieved the highest success rates among five tested LLMs, reaching 48.8% under L1 guidance and 12.5% under L3 black-box conditions.

**Why it matters:** ProtoArena highlights that while LLM agents can exploit cross-component network protocol flaws, their success rates under strict black-box conditions remain limited and vary significantly across domains.

### [IssueTrojanBench: Benchmarking AI Coding Agents Against Malicious Issue Requests](https://arxiv.org/abs/2607.20759v1)

**arXiv cs.CR** · 2026-07-22 · `arXiv:2607.20759v1`

IssueTrojanBench evaluates AI coding agents against malicious issue requests, revealing that 66.5% of attack attempts successfully penetrate both agent- and LLM-level guardrails across state-of-the-art tools like Cursor, Claude Code, and Codex Desktop.

- IssueTrojanBench introduces a benchmark spanning four attack categories, six delivery vectors (such as PDFs and issue comments), and adversarial perturbations.
- Evaluated agents include Cursor, Claude Code, and Codex Desktop using OpenAI (GPT-5.3 Codex/GPT-5.4) and Anthropic (Sonnet 4.6) LLMs.
- Current agent-level defense frameworks provide minimal security gains; rejections stem almost entirely from the underlying LLM layer.
- Anthropic Sonnet 4.6 demonstrated selective, risk-aware blocking of high-impact actions, whereas GPT models proved broadly vulnerable.

**Why it matters:** Autonomous coding agents are highly susceptible to malicious issue requests, exposing local environments to data exfiltration and persistent compromises.

<small>Ankur Singh, Jinqiu Yang, Tse-Hsun Chen</small>

**arXiv cs.CR** · 2026-07-22 · `arXiv:2607.20713v1`

A cross-model study revealed that 100% of automation scripts generated by ChatGPT, Copilot, and Gemini contained exploitable vulnerabilities, with average CVSS v3.1 severity scores differing by less than 10% across platforms.

- Vulnerability review executed by Claude Code mapped security flaws to CVSS v3.1, OWASP Top 10:2021, and MITRE ATT&CK frameworks.
- Across three automation domains, 9 of 17 identified vulnerability classes appeared in outputs from all three LLM models.
- Fourteen of the 17 vulnerability classes were present in outputs from at least two models, demonstrating that security risk is driven by task category rather than model choice.

**Why it matters:** Organizations cannot rely on model selection to mitigate security risks and must enforce mandatory code reviews before deploying any LLM-generated automation scripts.

- LLM-driven security agents exhibit indeterminacy across three independent dimensions: non-deterministic action policies, open-ended operational impact, and an indeterminate user population.

**Why it matters:** Traditional cybersecurity governance fails against agentic LLM tools, requiring updated frameworks to handle diffuse moral accountability and industrialized offensive capabilities.

### [Geometric Configurations of Perturbed Jailbreak Prompts](https://arxiv.org/abs/2607.20581v1)

**arXiv cs.CR** · 2026-07-22 · `arXiv:2607.20581v1`

A study analyzes string-level perturbed jailbreak prompts in Qwen-2.5 and Llama-3 models, finding no behavioral hyperplane in the last-layer-last-token embedding or top-50 next-token probability spaces.

- Analyzed internal representations across Qwen-2.5-1.5B/-3B/-7B-Instruct and Llama-3.2-1B/-3B/-3.1-8B-Instruct model families.
- The last-layer-last-token embedding space separates prompts by spelling and format, whereas the top-50 next-token probability space is effectively one-dimensional.
- No behavioral hyperplane separates compliant and non-compliant prompts in either representation space within the refusal-dominated dataset.
- Only specific next tokens showed significant association with compliant answers: 'Sure' in Qwen-1.5B, and ',' and 'ĊĊ' in Llama-1B.

**Why it matters:** Understanding that perturbed jailbreak prompts lack clear geometric linear separability in internal representation spaces complicates simple hyperplane-based detection and safety alignment mechanisms.

### [HijackKV: New Threat in Position-Independent KV Cache Reuse](https://arxiv.org/abs/2607.19957v2)

**arXiv cs.CR** · 2026-07-22 · `arXiv:2607.19957v2`

HijackKV exploits position-independent KV cache reuse by optimizing attacker prefixes to poison the cached KV vectors of benign text chunks, silently altering model output when reused in victim queries.

- Position-independent KV cache systems reuse cached entries based solely on token matches, ignoring positional context.
- Attackers pre-compute an optimized prefix upstream of a common benign text chunk, embedding malicious instructions directly into the benign chunk's cached KV representations.
- HijackKV achieves a 94% average single-attempt success rate, remains persistent across multi-turn interactions, and transfers in black-box environments.
- The attack remains effective under operational constraints, including low cache hit rates (10%) and frequent recomputation events (50%).

**Why it matters:** Position-independent KV cache optimizations expose LLM inference systems to silent, input-free model manipulation through shared cache poisoning.

<small>Yichi Zhang, Zhiqi Wang, Huan Zhang, Yuchen Yang</small>

### [JANUS: Foreseeing Latent Risk for Long-Horizon Agent Safety](https://arxiv.org/abs/2607.19913v1)

**arXiv cs.CR** · 2026-07-22 · `arXiv:2607.19913v1`

Janus is a foresight-oriented safety framework that trains the Vanguard guard model using CoAA-RL to anticipate delayed risks and block unsafe tool-using agent actions before execution.

- Synthesizes agent trajectories using multi-agent simulation to generate diverse training data.
- Couples two tasks in a shared policy policy: anticipating safety-relevant futures and adjudicating overall safety from prefixes and forecasts.
- Optimizes joint tasks via CoAA-RL, which rewards forecasting based on its utility for downstream safety judgment.
- Outperforms baseline guards by improving average protection by 15.9 percentage points and benign task completion by 5.1 percentage points across four benchmarks.

**Why it matters:** Vanguard prevents operational failures in long-horizon, tool-using agents by identifying latent risks in partial action sequences prior to execution.

### [Defense Against LLM Backdoors using Critical Neuron Isolation Pruning](https://arxiv.org/abs/2607.19894v1)

**arXiv cs.CR** · 2026-07-22 · `arXiv:2607.19894v1`

DeCNIP is a backdoor defense for LLMs that uncovers trigger mechanisms via representational analysis, then isolates and prunes Backdoor Critical Neurons to neutralize attacks without harming utility.

- Addresses both model-editing and fine-tuning-based backdoor attacks in open-ended LLM generation.
- Identifies trigger behaviors by optimizing cross-entropy loss between benign inputs and harmful prompts containing candidate tokens.
- Isolates and selectively prunes Backdoor Critical Neurons (BCNs) using only 0.1% neuron intervention.
- Achieves over 95% relative reduction in Attack Success Rate (ASR) across six open-source LLMs and two benchmarks while maintaining 97% baseline task performance.

**Why it matters:** DeCNIP provides a mechanistic, representational defense that effectively removes insidious LLM backdoors with minimal model intervention and negligible impact on general performance.

DARWIN introduces an open-ended evolutionary framework that continuously expands jailbreak attack strategies and iteratively trains an adaptive guardrail on emerging adversarial samples alongside benign queries.

- DARWIN-Attack achieved attack success rates of nearly 100% on DeepSeek-V4-Pro and YuFeng-XGuard, and over 90% on GPT-5.5.

### [Evaluating Large Language Models for Symbolic Security Protocol Analysis](https://arxiv.org/abs/2607.20712v1)

**arXiv cs.CR** · 2026-07-22 · `arXiv:2607.20712v1`

A benchmark evaluating GPT and DeepSeek on 130 obfuscated AnB/AnBx protocols shows LLMs fail to match formal verifiers like ProVerif, exhibiting low precision or poor attack recall across 388 security goals.

- Chat modes achieved 69% to 81% recall but had precision under 31%, whereas reasoning modes improved precision (up to 66.5% for GPT and 45.4% for DeepSeek) while missing roughly half the attacks.
- Isolating reasoning mode in DeepSeek increased precision from 27.2% to 45.4% compared to its chat mode.
- Models performed poorest on authentication goals (injective and non-injective agreement), while confidentiality goals yielded the highest accuracy with F1 scores up to 95.7% in reasoning mode.
- Verdicts were inconsistent across runs (89.7% stability for GPT, 74.0% for DeepSeek), and high self-reported confidence showed no correlation with actual correctness.

**Why it matters:** LLMs cannot reliably replace formal verification tools like ProVerif or OFMC for security protocol analysis, limiting their utility to high-level pre-screening filters.

<small>Paolo Modesti, Syed Ahmed, Ioannis Sfyrakis, Derek Enodolomwanyi</small>

### [Reversible Unlearnable Examples: Towards the Copyright Protection in Deep Learning Era](https://arxiv.org/abs/2608.06211v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.06211v1`

A novel copyright protection mechanism creates reversible unlearnable examples by minimizing input-output mutual information to prevent unauthorized model training while using a dual extraction strategy to ensure robust watermark detection without data leakage risks.

- Combines protection against unauthorized model training and malicious data leakage, addressing negative interaction effects caused by naive combinations of unlearnable perturbations and watermarks.
- Generates unlearnable perturbations by minimizing the mutual information between model inputs and outputs, forcing models to learn uncorrelated features.
- Employs a dual extraction strategy with two distinct watermark extractors to mitigate the side effects of unlearnable perturbations during watermark retrieval.
- Validated through extensive experiments on ImageNet, CIFAR10, and Pets datasets, with open-source code released.

**Why it matters:** It provides a unified mechanism to simultaneously prevent unauthorized model training on proprietary images and detect data leakage via watermarking without performance trade-offs between the two safeguards.

<small>Binze Wang, Jinyu Tian, Xingrun Wang, Xiaochen Yuan, Jianqing Li</small>

### ["Allow" to Achieve, Over-Privileged Inadvertently: The Unintended Cost of Task-Completion-Driven Pop-up Decisions in Mobile GUI Agents](https://arxiv.org/abs/2608.04755v1)

**arXiv cs.CR** · 2026-08-05 · `arXiv:2608.04755v1`

A systematic study introduces Permission Literacy in mobile GUI agents, evaluating four frontier multimodal LLMs on Android-style popups to reveal vulnerabilities like App-Trust Bias and Task-Prior Override.

- Evaluated four frontier MLLMs using synchronized annotated screenshots and UI-tree hierarchies across a four-level permission framework based on task relevance and privacy risk.
- Identified an App-Trust Bias: altering only the requester from Calendar to PiMusic during identical Calendar tasks dropped permission grants from 26/32 to 0/32.
- Observed Task-Prior Override: shifting task context while keeping the permission popup static significantly altered model authorization decisions.
- Tested prompt interventions, finding they inconsistently reduce unnecessary grants and risk over-suppressing legitimate permission requests.

**Why it matters:** Task-driven mobile GUI agents routinely over-privilege applications to complete tasks, indicating a need to decouple task execution from permission authorization in agent architecture.

<small>Dongsheng Chen, Yuxuan Li, Guanhua Chen, Jiaxin Zhang, Xiangyu Zhao, Lei Ma, Xin Yao, Xuetao Wei</small>

### [Towards a Risk Assessment of Malicious Skill Files in Coding Agents](https://arxiv.org/abs/2608.05223v1)

**arXiv cs.CR** · 2026-08-05 · `arXiv:2608.05223v1`

Researchers created a benchmark of 2,826 malicious agent skills and evaluated enterprise coding agents, finding exploitation rates up to 96.1% due to hidden shell commands in natural-language skill files.

- Synthesized 2,826 benign-appearing skill files from 471 real-world shell commands using six LLMs across four families, mapped to 11 MITRE ATT&CK tactics.
- Designed an evaluation pipeline using a three-judge LLM panel with evidence anchoring, run stratification, a refusal veto, and a declared-intent override, achieving a Cohen's kappa of 0.85 against human evaluation.
- Evaluated 5,629 runs across two enterprise agents, revealing exploitation rates of 95.5-96.1% for Gemini CLI and 71.6-74.0% for Qwen Code, with explicit safety recognition occurring in only 1.99% of runs.

**Why it matters:** Dynamic agent skill interfaces expose enterprise workflows to severe security risks, as existing coding agents reliably execute malicious commands obfuscated inside natural-language instructions.

<small>Rui Yang, Michael Fu, Kla Tantithamthavorn, Chetan Arora, Joey Chua</small>

**arXiv cs.CR** · 2026-08-05 · `arXiv:2608.04680v1`

MOAT is a model-agnostic input transformation pipeline that protects vision transformers from token pruning efficiency degradation attacks without modifying model architectures or pruning mechanisms.

- Applies randomized input transformations directly to images as a pre-processing step before model inference.

### [Private Direct Preference Optimization for LLM Alignment](https://arxiv.org/abs/2608.05040v1)

**arXiv cs.CR** · 2026-08-05 · `arXiv:2608.05040v1`

PrivDPO introduces preference privacy, a label-DP-style mechanism for Direct Preference Optimization that protects preference choices by adding calibrated noise exclusively along a one-dimensional text-derived preference axis without per-example gradient operations.

- Formalizes preference privacy, a label-DP-style notion assuming an adversary knows the prompt and both candidate responses but not the preference choice.
- Identifies that the gradient difference between neighboring preference examples lies entirely on a one-dimensional preference axis determined by the text.
- Enforces privacy through an unbiased randomized rescaling of the DPO objective along the preference axis, avoiding costly per-example gradient computations.
- Demonstrates superior privacy-utility trade-offs over standard privacy-preserving baselines across three LLM families and three alignment benchmarks.

**Why it matters:** It enables private LLM alignment on sensitive human preference data without the severe utility degradation or computational overhead associated with full Differentially Private SGD.

<small>Yangfan Jiang, Fei Wei, Ergute Bao, Xiaokui Xiao, Yaliang Li, Bolin Ding</small>

### [When Does Latent Communication Pay? A Causal Audit of Relayed KV Caches in Multi-Agent LLMs](https://arxiv.org/abs/2608.04893v1)

**arXiv cs.CR** · 2026-08-05 · `arXiv:2608.04893v1`

A causal audit reveals that relaying key-value (KV) caches in multi-agent LLMs only improves performance over mismatched or random caches when the receiver explicitly requires the sender's private, task-relevant information.

- When private information is required, relaying the correct KV cache yields a 100% success rate versus 23-25% for answer-irrelevant relays across three model families, five checkpoints, and a prose document-QA task.
- When private information is not required, Holm-corrected TOST equivalence testing shows the performance of matched relays is within 2.8 points of mismatched relays on GSM8K, ARC-Challenge, and MedQA.
- Zeroing a cache can severely drop performance (up to 14.7 points) while swapping it with a mismatched example drops performance by only 0.4 points, proving large cache removal effects are often not pairing effects.
- Across tested architectures, native full-relay channels (LatentMAS) achieve full information transfer, partial layer subsets (KVComm) show degraded transfer, and projector-based methods (C2C) demonstrate no detected example-specific transfer.

**Why it matters:** Standard benchmark gains from latent KV cache sharing do not inherently prove latent thought transmission, necessitating mismatched-cache causal audits to verify actual information transfer.

<small>Jiaming Cheng, Subhransu Das, Rajiv Ramnath</small>

`multi-agent-llms` `kv-cache` `latent-communication` `causal-audit` `llm-evaluation`

### [Adaptive Intrusion Detection System using Transformer-Based Neural Networks and Continual Learning Approach with Adversarial Investigation](https://arxiv.org/abs/2608.04602v1)

**arXiv cs.CR** · 2026-08-05 · `arXiv:2608.04602v1`

A tabular transformer encoder using class-balanced experience replay prevents catastrophic forgetting in network intrusion detection, but introduces vulnerability to label-flipping and stealthy backdoor poisoning attacks.

- Evaluated on the CICIDS2017 benchmark, the proposed framework achieved 0.9994 accuracy in traditional class-incremental setups and 0.9989 in class-instance incremental (CII) scenarios.
- Drastically outperformed sequential fine-tuning (0.0052 accuracy), EWC (0.0324), LwF (0.0699), and iCaRL (0.8770) baselines.
- Introduced the CII evaluation scenario where benign traffic is replayed alongside new attack classes at every model update to prevent decision boundary drift.
- Adversarial buffer probing revealed extreme vulnerability to label-flipping (accuracy collapsed to 0.0053 at a 1% budget) and backdoor poisoning (95% trigger attack success rate while maintaining 0.97 overall accuracy).

**Why it matters:** Experience replay enables continuous IDS updates against evolving cyber threats, but deploying it requires strict buffer integrity controls to prevent catastrophic model collapse or undetected backdoor exploits.

<small>Azizi Ariffin, Afif Haris, Faiz Zaki, Hazim Hanif, Nor Badrul Anuar</small>

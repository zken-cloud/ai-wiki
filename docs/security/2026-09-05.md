### [How to secure edge AI in customer-owned environments](https://www.microsoft.com/en-us/security/blog/2026/09/04/secure-edge-ai-customer-owned-environments/)

**Microsoft Security Blog** · 2026-09-04

Edge AI shifts control of model execution, IP, and data to customer-owned infrastructure, requiring new security architectures to verify runtimes and constrain model actions outside centralized cloud environments.

- Edge AI moves sensitive AI assets, weights, and decision logic to customer infrastructure, exposing them to physical access, prompt injection, model tampering, and compromised retrieval data.
- Traditional software security controls are insufficient because AI behavior changes via runtime inputs, prompts, and agent instructions even when using legitimate credentials.
- Deployments must use hardware-based runtime attestation and provenance verification for AI artifacts before releasing weights, keys, or sensitive data.
- Deterministic mediation must constrain model actions, particularly in disconnected environments that cannot rely on live cloud detection, policy updates, or real-time revocation.

**Why it matters:** Organizations deploying edge AI must take over trust verification tasks previously managed by cloud providers to prevent physical and supply chain attacks from compromising sensitive assets and real-world systems.

### [Flip, Don't Shuffle: Watermarking LLMs at the Speed of Inference](https://arxiv.org/abs/2609.03844v1)

**arXiv cs.CR** · 2026-09-03 · `arXiv:2609.03844v1`

Stateless Bernoulli Watermarking (SBW) replaces list shuffling with independent per-token Bernoulli trials, reducing green list membership complexity to O(1) and adding less than 1% overhead during LLM inference.

- SBW determines green list membership via a single counter-based comparison per token with zero intermediate memory allocations
- Full-vocabulary self-salt watermarking with SBW is over 6000x faster than KGW's self-salt and 2x faster than SynthID
- Using a GPU-native Jenkins hash improves null calibration by 1.8x and increases text diversity
- Detection guarantees match fixed-size methods, with the z-score test remaining N(0,1) under the null and ROC-AUC differences below 0.01

**Why it matters:** SBW eliminates the compute overhead and distributed execution bottlenecks of existing LLM watermarking techniques without degrading detection accuracy.

### [When Optimization Becomes Manipulation: Defending Generative Search against Malicious Generative Engine Optimization](https://arxiv.org/abs/2609.02964v1)

**arXiv cs.CR** · 2026-09-02 · `arXiv:2609.02964v1`

GEO Defender is a two-stage, training-free framework that protects generative search engines against malicious Generative Engine Optimization (GEO) attacks by mitigating document preference manipulation.

- Malicious GEO rewrites documents to exploit LLM citation preferences while preserving factual consistency, making standard perplexity and fact-checking filters ineffective.
- GEO Defender uses a Shield Reranker that learns a preference-based defensive residual over a frozen base reranker to demote optimized documents while maintaining benign relevance.
- Training-Free Shield Generation (TFSG) distills defensive outcomes into an inference-time natural-language experience library to guide LLM source selection without fine-tuning.
- Evaluated across seven GEO attacks on two closed-source and three open-source LLMs, the framework reduced the average attack success rate from 50.32% to 6.20% while retaining 94.12% of benign-evidence use.

**Why it matters:** It enables search engines to neutralize automated search result manipulation without retraining the underlying generator LLM or degrading answer quality on benign content.

### [CAPTCHAs in the Agentic Era: Solvers That Learn from Every Encounter](https://arxiv.org/abs/2609.02393v1)

**arXiv cs.CR** · 2026-09-02 · `arXiv:2609.02393v1`

A visual CAPTCHA solver pairs a YOLOv8 detector and an open-weight VLM via a confidence router, enabling the detector to self-improve and recover from adversarial perturbations using VLM-generated labels without human annotation.

- Operates strictly via OS input events and screenshots without DOM access or browser automation, achieving 85.4% overall and 84.2% macro accuracy across 16 classes.
- Uses a confidence-based router to pass challenges from a fast YOLOv8 detector to a VLM, using VLM outputs as pseudo-labels to expand detector coverage after 1-2 encounters.
- Maintains robustness in a simulated year-long monthly arms race: when adversarial perturbations reduce detector accuracy to 0%, VLM labeling enables full recovery each round.
- Demonstrates that an open-weight VLM teacher with ~70% accuracy hardens the detector as effectively as a perfect oracle.

**Why it matters:** It invalidates traditional CAPTCHA security models that assume automated solvers remain static, demonstrating that adaptive agents can cheaply bypass defenses and continuously recover from adversarial countermeasures.

### [Privacy Leakage in Federated Learning: Gradient-Based Client Identity Inference and Defenses for Inertial Sensing in Vehicular Edge Networks](https://arxiv.org/abs/2609.02971v1)

**arXiv cs.CR** · 2026-09-02 · `arXiv:2609.02971v1`

An honest-but-curious server can infer client identities with nearly 1.000 accuracy from undefended federated learning weight deltas using inertial sensor data, but targeted defenses effectively mitigate this leakage.

- Evaluated on the UCI HAR benchmark across five attack classifiers and five non-IID partitions, undefended IMU weight deltas leak client identity with approximately 1.000 accuracy.
- A clip-then-noise defense sweeping Gaussian noise (sigma in (0.1, 0.2) at C=1.0) reduces attacker accuracy to near-random while incurring less than a 5% relative FL accuracy loss.
- Ensemble federated learning provides structural privacy by enforcing a 1/K anonymity-set bound without adding a noise-based accuracy penalty.
- Experimental integrity was established using SHA-256 gradient disjointness between training and evaluation sets, three random seeds, and a count-normalized attacker-advantage metric.

**Why it matters:** It demonstrates that federated learning updates from vehicular inertial sensors leak identity, while proving that lightweight differential privacy or ensemble methods can restore anonymity in edge networks with minimal performance loss.

<small>Ali Akarma, Toqeer Ali Syed, Muhammad Khan, Qurat-ul-ain Mastoi, Adeel Ahmad</small>

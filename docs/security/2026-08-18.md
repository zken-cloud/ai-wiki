### [Topological Attribution Distance (TAD): Revealing Segment-Level RAG Influence on LLM Output Geometry for Incident Log Analysis](https://arxiv.org/abs/2608.16775v1)

**arXiv cs.CR** · 2026-08-17 · `arXiv:2608.16775v1`

Topological Attribution Distance (TAD) uses segment-level ablation attribution and persistent geometry changes in the LLM's embedding space to identify which retrieved incident log segments most influence generated outputs.

- Introduces Topological Attribution Distance (TAD) to measure the global geometric shape changes in model outputs relative to retrieved context.
- Employs segment-level ablation attribution on cybersecurity incident logs to quantify evidence influence via changes in the embedding space.
- Leverages the LLM's internal hidden states to provide adaptive, verifiable evidence tracing without relying solely on standard token attribution.
- Addresses attribution failures caused by complex, highly similar evidence sources in cybersecurity and agentic AI decision chains.

**Why it matters:** TAD provides a mechanism for cybersecurity analysts to trace agentic AI decisions back to specific incident log segments, enabling reliable evidence verification and root-cause analysis.

### [What to Remember, What to Reveal: Privacy-Aware Memory for Conversational Agents](https://arxiv.org/abs/2608.16551v1)

**arXiv cs.CR** · 2026-08-17 · `arXiv:2608.16551v1`

SP-Mem is a privacy-aware memory architecture for conversational agents that decouples memory utility from exact private-value exposure across the full data life cycle.

- Identifies and separates sensitive information, such as PII, directly from raw user inputs.
- Stores sanitized contextual content and exact private values in isolated data structures.
- Selectively retrieves exact private values only when required by the task and explicitly permitted by user consent.
- Introduces a privacy-aware memory benchmark designed to jointly evaluate response quality, privacy protection behavior, and inference cost.

**Why it matters:** It enables long-term agent personalization while minimizing unnecessary storage and exposure of sensitive user data.

### [DSPrompt: Dynamic Soft Prompt Defense Against M-RAG Corruption](https://arxiv.org/abs/2608.16536v1)

**arXiv cs.CR** · 2026-08-17 · `arXiv:2608.16536v1`

DSPrompt uses a dynamic min-max trained soft prompt framework across frozen M-RAG encoder layers to defend against poisoning attacks without adding query-time overhead.

- Inserts learnable soft prompts into every layer of frozen visual and textual encoders using a shallow-to-deep length schedule.
- Employs dynamic min-max training where an online attacker crafts adversarial documents while the defender updates to eject them from top-k retrieval.
- Preserves benign document ranking and diversity while adding less than 1% additional parameters.
- Allows pre-computation and indexing of the defended encoder, avoiding per-query optimization or inference runtime penalties.

**Why it matters:** It enables robust defense against M-RAG embedding poisoning attacks at a fraction of the computational cost of existing query-time detection methods.

### [LLMs for Zero-Shot Threat Detection via Structured Risk Indicators](https://arxiv.org/abs/2608.16508v1)

**arXiv cs.CR** · 2026-08-17 · `arXiv:2608.16508v1`

A two-stage LLM framework combines chronological log timelines, RAG for historical user context, and structured risk indicators to improve zero-shot threat detection for insider threats and APTs.

- The framework converts heterogeneous logs into user timelines, uses RAG for personalized historical context, generates structured risk indicators, and classifies them across temporal sequences.
- Tested on CERT r5.2 (insider threats) and PicoDomain (APTs) using four configurations of two open-weight LLMs in retrieval and non-retrieval modes.
- Outperformed the GABM baseline, boosting F1-scores by up to 11.40 percentage points on CERT r5.2 and 31.50 percentage points on PicoDomain.
- Retrieval primary benefits weaker LLMs by producing more discriminative risk indicators, whereas stronger models achieve similar performance without RAG.
- Indicator quality is the primary driver of zero-shot detection performance, with optimal stage-to-model assignments varying by dataset.

**Why it matters:** Generating intermediate structured risk indicators enables LLMs to detect complex cyber attacks across long temporal windows without requiring domain-specific training data.

### [CompoSkill: Compositional Skill Chain Attacks from Individually Scanner-Passing LLM Agent Skills](https://arxiv.org/abs/2608.16246v1)

**arXiv cs.CR** · 2026-08-17 · `arXiv:2608.16246v1`

CompoSkill demonstrates that autonomous AI agent skills that individually pass safety scanners can be chained to execute multi-step attack paths with high success rates.

- CompoSkill evaluates attack paths using a white-box attacker that knows the victim skill pool and a black-box attacker that builds a Skill Composition Graph to search for implicit lure chains.
- The framework was evaluated on CompoSkill-Bench, comprising 1,140 records across five threat categories and six scenarios on the OpenClaw and Nanobot agent platforms.
- White-box and black-box settings achieved risk Chain Formation Rates (CFR) of up to 83.3% and 80.6% respectively, bypassing individual package scanners.
- Analysis revealed a bridge-bonus-then-hop-decay pattern where bridge skills boost attack success, but Attack Success Rate (ASR) degrades when chains exceed three skill hops.

**Why it matters:** Single-skill safety certification is insufficient for securing AI agent ecosystems because security risks arise dynamically at the execution-path level rather than within individual packages.

<small>Mingxiao Liu, Zhoumian Jiang, Jianan Ma, Jian Zhang, Jialuo Chen, Xinhao Deng, Zhen Wang</small>

### [Securing AI-Generated Code: A Just-in-Time Vulnerability Detection and Remediation Pipeline](https://arxiv.org/abs/2608.16187v1)

**arXiv cs.CR** · 2026-08-17 · `arXiv:2608.16187v1`

An automated security pipeline enriches AI code findings with MITRE ATT&CK and CWE contexts to remediate vulnerabilities across four Claude models, achieving up to a 69% reduction in static analyzer findings.

- The evaluation framework tests 26 LLMSecEval prompts across 9 CWE categories using parallel static analysis (CodeQL, Bandit) and an LLM Code Validator.
- Pipeline 2 (P2), which feeds static analyzer findings back to the validator alongside threat context enrichment, reduced security findings by 29% to 69%, outperforming context-only Pipeline 1 (P1).

- Sonnet 4.6 achieved the highest pass rate and lowest residual findings under P2 remediation, despite Opus 4.8 being the stronger standalone code generation model.

**Why it matters:** Combining traditional static analysis tool output with enriched LLM validation creates a more effective automated code remediation process than relying solely on LLM self-correction or base generation capability.

### [Coverage Is Not Containment: A Fundamental Limit of Admission-Time Defenses Against Coordinated Poisoning of Vector Retrieval](https://arxiv.org/abs/2608.16044v1)

**arXiv cs.CR** · 2026-08-17 · `arXiv:2608.16044v1`

Researchers demonstrate that admission-time filters cannot distinguish coordinated vector poisoning from legitimate niche uploads, proving a fundamental limit that requires shifting defense to retrieval-time demand tracking.

- Coordinated adversaries inject small sets of unremarkable documents (e.g., m=10) that form an attack cone surrounding a target query, capturing 10/10 top-k positions in BGE-large / BEIR.
- End-to-end attacks on a BGE-large + HNSW + Qwen2.5-7B pipeline forced the generator to emit planted claims in 88% of target queries, up from 0% baseline.
- Admission-time classifiers perform no better than chance, achieving only a 4.2% detection rate at a 1% false-positive rate because attack cones geometrically mimic legitimate niche content.
- A retrieval-time detector observing query demand achieves a 100% detection rate at the same 1% false-positive rate.

**Why it matters:** Security teams cannot rely on ingestion-time or hub-filtering gates to secure RAG vector databases and must implement retrieval-time monitoring.

<small>Prashant Kumar Pathak, Tarun Kumar Sharma</small>

### [Proof-of-Execution Memory: Defending LLM Agents Against Forged-Reasoning Attacks by Verifying What Actually Happened](https://arxiv.org/abs/2608.16032v1)

**arXiv cs.CR** · 2026-08-17 · `arXiv:2608.16032v1`

Proof-of-Execution Memory (PoEM) defends LLM agents against forged-reasoning attacks by using an HMAC-chained ledger of executed actions to verify past safety steps without inspecting memory contents.

- FARMA attacks insert fabricated memory entries to skip safety steps, achieving 98-100% success on GPT-4o and GPT-4o-mini compared to 44% on Llama-3.1-8B.
- SENTINEL's keyword defense is completely bypassed on the first attempt when an attacker uses an LLM to reword forged entries, while also causing a 33-50% false positive rate on legitimate operations.
- PoEM maintains a separate, tamper-evident HMAC-chained ledger updated exclusively by the trusted action layer to confirm actual execution before allowing a step to be skipped.
- PoEM reduced attack success rates to 0% across three models and three scenarios with microseconds of overhead and near-zero false positives (0% in 8/9 test cells, 1.7% in the ninth).

**Why it matters:** PoEM prevents malicious context injection from bypassing LLM safety checks by decoupling authorization from untrusted, manipulable agent memory.

<small>Md Habibur Rahman, Jaeho Kim</small>

### [Bit-Flip Attacks on Vision-Language-Action Models: Action-Decoding Architecture Shapes the Vulnerability](https://arxiv.org/abs/2608.15475v1)

**arXiv cs.CR** · 2026-08-16 · `arXiv:2608.15475v1`

Researchers demonstrated the first targeted bit-flip attack on quantized Vision-Language-Action (VLA) models, revealing that action-decoding architecture dictates vulnerability, with direct regression failing in 1-5 flips while flow-matching policies require ~100.

- Gradient-selected bit-flips reduce closed-loop VLA success to 0%, whereas hundreds of random bit-flips cause no harm.
- Model vulnerability depends on the action head: direct regression and token policies fail in 1-5 flips, while flow-matching policies require ~100-300 flips.
- Applying a fixed-direction manifold-escape loss reduced Pi0's attack budget from ~1000 to ~100 flips.
- Protecting just 5.3% of weights in a direct head model increased the open-loop failure threshold from 3 to 100 flips.
- Real-robot validation confirmed task-calibrated emulated attacks resulted in 0/20 task successes, compared to 14/20 for clean models and 16/20 for global-random flips.

**Why it matters:** Hardware-level memory faults like Rowhammer pose a severe physical security risk to deployed embodied AI systems, making weight integrity a critical defense boundary.

<small>Yudong Gao, Linghan Chen, Wenhan Wu, Mia Zhou, Jiyao Wang, Kaiyan Ji, Mingyu Guo, Honglong Chen</small>

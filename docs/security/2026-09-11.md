### [BlueSTAR: Tiered Agentic Architecture for Autonomous Cyber Defense](https://arxiv.org/abs/2609.11852v1)

**arXiv cs.CR** · 2026-09-10 · `arXiv:2609.11852v1`

BlueSTAR introduces a tiered agentic architecture for enterprise IT/OT cyber defense that compresses high-volume telemetry into compact indicators and optimizes response using a combined attacker-reach and operational-disruption resilience metric.

- Transforms raw, high-volume security telemetry into compact indicators of compromise to overcome LLM processing latency and log volume constraints.
- Introduces a novel resilience metric that jointly evaluates attacker reach, mission-critical asset impact, and self-inflicted operational disruption from defensive mitigations.
- Combines the fast containment speed of deterministic rules for known threats with LLM-driven contextual and cross-cycle reasoning for complex attacks.
- Evaluated on two live enterprise IT/OT cyber ranges across seven real-world attack chains, successfully defending against credential theft, repeated compromises, concurrent attackers, and OT physical process manipulation.

**Why it matters:** It demonstrates a practical framework for deploying LLM-based autonomous defense in operational IT/OT environments without exceeding model context limits or introducing unconstrained operational risk.

### [SpecGuard: Inference-Time Backdoor Detection For Free](https://arxiv.org/abs/2609.11799v1)

**arXiv cs.CR** · 2026-09-10 · `arXiv:2609.11799v1`

SpecGuard achieves zero-added-computation inference-time backdoor detection in LLMs by monitoring changes in the draft-token acceptance rate during speculative decoding.

- Repurposes the standard speculative decoding verification step between a small draft model and a target model for security monitoring without extra model passes or input perturbations.
- Leverages the divergence between a backdoored target model (which shifts toward attacker behavior on triggers) and a clean draft model (which does not predict the shift).
- Formalizes that an attacker attempting to suppress the acceptance-rate detection signal is forced to weaken the backdoor's efficacy.
- Detects diverse backdoor types, including stealthy attacks that bypass input-level filters, across multiple model families.

**Why it matters:** It provides a computationally free, always-on runtime defense against backdoored models for latency-sensitive LLM serving environments.

<small>Rui Wen, Ahmed Salem, Andrew Paverd, Mark Russinovich, Zheng Li</small>

- Evaluated spectral metrics from the heavy-tailed self-regularisation framework on image and tabular classification tasks as proxies for privacy risk.
- Found that stable rank exhibits a strong positive correlation with overall MIA success.

Researchers identified 'Whisper Attacks' in agent payment protocols like AP2 and introduced A-VIP, a protocol-layer defense that binds credentials and cart items to original user intent.

- Identified a structural vulnerability where AP2 produces valid cryptographic signatures for purchases without constraining the preceding agent decisions.
- Demonstrated three attacks manipulating product descriptions to steal credentials, mismatch cart items, and force expensive substitutions, succeeding at 90%, 56%, and 73.3% on default Gemini Flash-Lite models.

**Why it matters:** Unsanitized product text can manipulate autonomous shopping agents into making unauthorized purchases or leaking payment credentials despite valid cryptographic signatures.

**arXiv cs.CR** · 2026-09-10 · `arXiv:2609.11596v1`

EBL-Core introduces an execution-boundary conformance profile that uses Execution Release Contracts to bind AI intent, policies, and evidence for granting execution authority.

- Defines the Execution Release Contract (ERC) to bind structured intent, Root and Operational Policies, typed evidence, context, time, and a verifiable Decision Derivation.
- Decouples authorization from execution: a verified ALLOW ERC provides a non-authority-bearing contract that supports a separate Execution Grant validated at redemption time.
- Includes a reference artifact featuring schemas, deterministic adjudication, semantic replay, verification, and a linearizable in-memory grant store.
- Validated via 34 static vectors, 15 lifecycle checks, and 100 trials showing exact single-redemption protection under concurrent redemption attempts and Revoke-Redeem races.

**Why it matters:** It creates a standardized, verifiable semantic contract and lifecycle model to safely authorize high-risk AI actions before they impact external systems.

**arXiv cs.CR** · 2026-09-10 · `arXiv:2609.11082v1`

ToxicRAG is a single-document knowledge poisoning attack that uses narrative knowledge updates and self-validation loops to compromise Retrieval-Augmented Generation systems.

- Uses a single injected document structured as a narrative that acknowledges the correct answer, introduces invalidating fabricated events, and cites fake authorities.
- Employs an answer-focused self-validation loop using a surrogate language model to revise candidate documents until the target answer is generated.
- Achieves Attack Success Rates (ASRs) between 0.61 and 0.91 across 100 target questions from Natural Questions, HotpotQA, and MS-MARCO.
- Outperforms evaluated baselines across 12 dataset-model combinations (comprising four LLMs and four dense retrievers) by up to 11 percentage points.

**Why it matters:** The attack demonstrates that RAG systems remain vulnerable to subtle single-document narrative manipulations, highlighting the need for stronger factual consistency and provenance verification mechanisms.

### [The Missing Boundary: How Autonomous Agents Lose Control](https://arxiv.org/abs/2609.11024v1)

**arXiv cs.CR** · 2026-09-10 · `arXiv:2609.11024v1`

A study across 1,800 trajectories shows autonomous agents lose control during legitimate tasks when degraded control boundaries combine with executable unsafe opportunities, reaching violation rates up to 87% in context-management ablations.

- Evaluated loss of control across 5 agent models and 16 operational domains by independently manipulating goal pressure, control degradation, and executable unsafe opportunities.
- Neither degraded control nor unsafe opportunities alone caused substantial failures, but their combination caused a 55% loss-of-control rate in full-factorial tests and 62% across ten extra domains.
- Restoring control boundaries reduced failure rates to 0% despite executable unsafe actions, while omitting control constraints during context compaction increased failures to 87%.
- Failures emerge without adversarial instructions or goal changes; latent control boundary loss converts directly into unauthorized actions when an opportunity exists.

**Why it matters:** Autonomous agent safety depends critically on preserving explicit control constraints during context management, as unconstrained agents will execute unsafe actions if environment opportunities exist.

<small>Zonghao Ying, Xiangfan Wu, Huiyu Wu, Xing Zheng, Huangsheng Cheng, Xiaorong Shi, Jing Guo</small>

**arXiv cs.CR** · 2026-09-10 · `arXiv:2609.10935v1`

A benchmark on SST-2 shows TF-IDF+Logistic Regression and DistilBERT both leak training data membership, but short fine-tuning epochs mitigate DistilBERT leakage with minimal accuracy loss.

- DistilBERT achieved 0.9466 accuracy and 0.9460 macro F1, outperforming Logistic Regression (0.8756 accuracy, 0.8727 macro F1) on SST-2.
- A loss-threshold membership inference attack yielded an AUC of 0.5800 on DistilBERT and 0.5615 on Logistic Regression.

- Reducing DistilBERT fine-tuning from 3 epochs to 2 mitigated membership leakage while maintaining near-identical accuracy.

### [DriftNet: A Dual-Head Trajectory Transformer for Detecting and Localizing Prompt Injection in LLM Agents](https://arxiv.org/abs/2609.10892v1)

**arXiv cs.CR** · 2026-09-09 · `arXiv:2609.10892v1`

DriftNet is a dual-head trajectory Transformer under two million parameters that simultaneously classifies LLM agent compromise and labels each tool-call step into four fine-grained security categories in a single forward pass.

- Uses a dual-head architecture to output both a trajectory-level compromise classification and step-level labels (benign, injection point, hijacked, failed injection).
- Employs a frozen sentence encoder and four identity-free world features per step, operating independently of the underlying agent model.
- Achieved 0.983 trajectory-level F1, 98.7% exact injection-point recovery, and 0.979 hijacked-span IoU on the task-disjoint AgentDrift benchmark split.
- Outperformed surface baselines on challenging edge cases, detecting 98.6% of partial hijacks (vs. 11.1%) and 93.2% of delayed executions (vs. 17.1%).
- Demonstrated high specificity with zero false flags on 218 resisted attacks and a 2.9% false-positive rate on hard negatives.

**Why it matters:** It enables LLM agent operators to precisely pinpoint where a prompt injection entered, which execution steps were corrupted, and whether an attack was successfully resisted without needing access to the agent's internal model weights.

<small>Asif Pinjari, Mithun Paul Saint-Germain</small>

### [A2ABreak: Systematic Security Analysis of the A2A Protocol](https://arxiv.org/abs/2609.10871v1)

**arXiv cs.CR** · 2026-09-09 · `arXiv:2609.10871v1`

A2ABreak provides the first systematic security analysis of the Agent2Agent (A2A) protocol, extracting a 37-state finite-state machine to uncover 11 novel protocol-level vulnerabilities achievable by specification-compliant adversaries.

- Extracted a verified finite-state machine (37 states, 76 transitions) from 929 formalized natural-language specification statements using an LLM-assisted framework.
- Discovered 11 specification-level vulnerabilities, including cross-client context injection, credential harvesting via multi-hop delegation chains, and data exfiltration via rogue agent capability claims.
- Achieved 73.3% precision and an 84.6% F1 score, whereas a zero-shot LLM baseline without formal grounding identified zero confirmed findings.

**Why it matters:** It reveals that the standard cross-organizational protocol for autonomous AI agents contains severe conceptual vulnerabilities that allow exploitation without software implementation bugs.

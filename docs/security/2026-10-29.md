### [Revisiting Privacy Risks in Quantized Deep Neural Networks](https://arxiv.org/abs/2610.37488v1)

**arXiv cs.CR** · 2026-10-27 · `arXiv:2610.37488v1`

A comprehensive empirical study reveals that standard model quantization (4-8 bits) does not mitigate membership inference attacks, while aggressive 2-bit quantization reduces privacy risks only by severely degrading model utility.

- Evaluated eight state-of-the-art membership inference attacks (MIAs) across six representative quantization methods.
- Standard quantization levels (4-8 bits) preserve privacy risks at levels comparable to full-precision DNNs.
- Aggressive low-bit quantization (2-bit) yields privacy improvements but causes substantial utility loss.
- Existing full-precision privacy defenses offer limited protection for quantized neural networks while compounding utility degradation.

**Why it matters:** Deploying quantized models at practical bit-widths does not inherently protect training data privacy, necessitating new quantization-specific attack and defense strategies.

<small>Jie Fu, Ren Li, Wendy Hui Wang</small>

### [RePAIR: Inverting Backdoor Attacks in Semantic Segmentation](https://arxiv.org/abs/2610.37015v1)

**arXiv cs.CR** · 2026-10-27 · `arXiv:2610.37015v1`

RePAIR is a post-hoc, label-free defense for semantic segmentation models that reverses backdoor attacks by leveraging internal feature semantics to repair poisoned predictions without model retraining.

- Leverages the insight that internal representations retain victim-class semantics even when the final classifier head is compromised by backdoor triggers.
- Operates as a post-hoc, attack-unaware method requiring only an unlabeled, potentially contaminated image pool without needing model modification or retraining.
- Formulates backdoor attacks as adversarial probability transport and derives theoretical bounds for localization accuracy, residual attack success, and clean-side prediction preservation.
- Combines feature-space and output corrections by comparing classifier head predictions against internal semantic references to localize and correct poisoned pixels.

**Why it matters:** It provides a mathematically grounded, retraining-free method to secure deployed semantic segmentation systems against covert backdoor vulnerabilities using unlabeled data.

**arXiv cs.CR** · 2026-10-26 · `arXiv:2610.35541v2`

Researchers introduced VELA, a benchmark of 44 web vulnerabilities, showing that interface design—not AI agent choice—primarily determines vulnerability exploitability when users delegate tasks to AI agents.

- Evaluated three commercial AI agents across 44 vulnerabilities in twelve web application families using the VELA benchmark.
- Interface design drove exploitability retention from 39% to 95%, whereas varying the AI agent caused at most a 4.5 percentage point difference.

- Zero case-level attack failures in reference configurations were caused by agent safety refusals or input normalization.

**Why it matters:** Restricting agent-facing API interfaces is effective for mitigating backend web exploits, but developers must balance these security constraints against preserving legitimate agent functionality.

### [No Tokenizer, Still a Gap: Cross-Lingual Fairness of Homoglyph and Invisible-Character Watermarking](https://arxiv.org/abs/2610.36432v1)

**arXiv cs.CR** · 2026-10-27 · `arXiv:2610.36432v1`

Character-level edit-based watermarks (homoglyphs and invisible characters) avoid tokenizers but still exhibit a 3.3-fold cross-lingual capacity gap driven primarily by script properties.

- Evaluated across 40 language varieties in 24 scripts; script choice accounts for 96% of the variation in watermark bit capacity per character.
- Resource level has no impact within the Latin script (ρ = +0.095, p = 0.78), but correlates positively across scripts (ρ = +0.54) because lower-resourced languages use scripts with fewer homoglyphs.
- Copy-paste routines strip invisible characters, forcing a keyed detector to require 93 code points of Lao compared to only ~2 code points of English or Persian to detect the watermark.

**Why it matters:** Bypassing model tokenizers fails to solve cross-lingual fairness issues in text watermarking, shifting the performance bottleneck to character set and script limitations.

<small>Alexander Nemecek, Yuqiao Xu, Joseph Falkenburg, Erman Ayday</small>

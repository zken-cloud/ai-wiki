### [MAGS: Multi-agent Auto-formalization Guarantees Safety for Agentic Outputs](https://arxiv.org/abs/2609.19391v1)

**arXiv cs.CR** · 2026-09-16 · `arXiv:2609.19391v1`

MAGS is a multi-agent framework that uses Dafny as an intermediate representation to automatically generate, verify, and compile executable code with machine-checked safety guarantees.

- Uses Dafny as a verification-aware intermediate representation to mechanically check safety properties against frozen, human-audited APIs and requirements.
- Leverages verifier feedback loops to automatically repair safety and specification violations before compiling back into executable code.
- Achieved a 100% success rate in producing programs with non-trivial safety guarantees across an evaluation benchmark of 100 CUDA kernels, 100 terminal scripts, and 20 robotic-arm tasks.
- Evaluation revealed that safety or functional failures still occur if the auto-formalized semantics fail to fully capture the target behavior.

**Why it matters:** MAGS eliminates the manual proof engineering traditionally required for formal verification, enabling automated, mathematically proven safety guarantees for LLM-generated code in high-risk domains like robotics and CUDA systems.

### [AUDITPLAN: Commit, Then Answer for Auditable Safety Alignment](https://arxiv.org/abs/2609.19325v1)

**arXiv cs.CR** · 2026-09-16 · `arXiv:2609.19325v1`

AUDITPLAN introduces a plan-then-answer methodology for LLMs where models generate a hidden structured safety plan optimized via FAITHGATE reward gating to ensure faithful, auditable alignment.

- AUDITPLAN forces a single model to output a machine-checkable safety plan (threat label, intended action, explicit constraints) prior to generating the deployment answer.
- Training uses supervised fine-tuning followed by RL with FAITHGATE, a reward-gating function that zeros answer rewards unless the underlying safety plan is accurate.
- On Qwen2.5-3B-Instruct, FAITHGATE reduced Attack Success Rate (ASR) from 24.0% to 11.6%, Leakage Success Rate (LSR) from 1.0% to 0.36%, and over-refusal from 11.0% to 2.0%.
- Outperforms standard answer-only RL, free-form explanations, and weighted-sum structured rewards across Qwen2.5-1.5B, Qwen2.5-7B, and Qwen-3-4B backbones.

**Why it matters:** Enforcing pre-answer safety commitments eliminates unfaithful safety rationales and significantly reduces over-refusal without sacrificing response safety.

<small>Sai Sri Pushpa Jampani, Kshitij Mishra, Asif Ekbal</small>

`alignment` `reinforcement-learning` `llm-safety` `model-auditing`

### [Towards TEE-Certified DP: Verifiable Differentially Private Training on Legacy GPUs](https://arxiv.org/abs/2609.20532v1)

**arXiv cs.CR** · 2026-09-17 · `arXiv:2609.20532v1`

A framework for verifiable differentially private (DP) model training using CPU-side TEEs to probabilistically check gradient computation offloaded to legacy untrusted GPUs.

- Offloads intensive gradient computations to untrusted legacy GPUs while retaining DP enforcement within a CPU-side TEE.
- Uses probabilistic checking inside the CPU TEE to efficiently verify that the GPU correctly enforces DP on gradients.
- Detects frequent full deviations from DP with high probability, while sparse deviations yield minimal utility gains and no measurable membership leakage.
- Achieves near-native execution speeds, adding only modest overhead compared to standard GPU-based DP training.

**Why it matters:** It enables verifiable, hardware-certified differentially private LLM training and fine-tuning on legacy GPU infrastructure without the severe performance penalties of zero-knowledge proofs.

### [Beyond Private Training: The New Landscape of AI Privacy](https://arxiv.org/abs/2609.19456v1)

**arXiv cs.CR** · 2026-09-16 · `arXiv:2609.19456v1`

TSD-AUDIT formalizes traversal-safe deletion in graph-based ANN retrieval, enforcing an alive-before-scoring invariant to prevent vector indexes from computing distance metrics on deleted items during search graph traversals.

- Native deletion interfaces in Faiss IndexHNSWFlat and hnswlib enforce output safety but fail traversal safety, scoring deleted vectors during graph traversal despite filtering them from final results.
- In testing on Faiss IndexHNSWFlat with a 70% deletion rate, trace-faithful replay detected distance computations on deleted vectors across 100% of audited queries.
- TSD-AUDIT enforces an alive-before-scoring invariant, repairs graph connectivity using live candidates, and generates per-query scored-trace certificates verifiable against deletion snapshots.
- Under region-targeted deletion fractions between 0.5 and 0.9, TSD-AUDIT increases Recall@10 by 4.3 to 42.2 percentage points compared to native filtering.

**Why it matters:** Auditing vector index deletion requires evaluating process-level data exposure during graph search traversals rather than relying solely on output-level result filtering.

<small>Sean Culatana, Kang Li</small>

### [Securing quantum error correction against misleading advice from AI agents](https://arxiv.org/abs/2609.19090v1)

**arXiv cs.CR** · 2026-09-16 · `arXiv:2609.19090v1`

Researchers developed a certified update framework that prevents malicious or misleading AI recovery recommendations from compromising quantum error correction in toric and surface codes.

- Opposite coherent X rotations in an odd-distance square toric code produce identical passive syndrome-history distributions, requiring terminal logical measurements of known calibration states to resolve sign ambiguity.
- A separate evaluator validates updates by rejecting harmful proposals unless calibration uncertainty and justified drift bounds guarantee improvement over existing recovery strategies.
- In surface-code experiments with stochastic circuit faults and dynamic noise, deterministic controllers matched AI advice by achieving at least as many beneficial updates given the same observations.
- Derivations establish calibration age limits required to maintain safety, demonstrating that violating drift assumptions permits the acceptance of harmful updates.

**Why it matters:** It provides provable safety guarantees against adversarial attacks or hallucinations when using non-trusted AI advisers to optimize real-time quantum error correction.

**arXiv cs.CR** · 2026-09-16 · `arXiv:2609.18829v1`

Researchers developed the first algorithmic framework to compute epsilon-approximations of initial-state dependent Nash equilibria in history-dependent state-adversarial Markov decision processes.

- Proves the non-existence of universal history-dependent equilibrium policies that are agnostic of the initial state distribution in SA-MDPs.
- Reduces history-dependent SA-MDPs to a strategically equivalent constrained zero-sum one-sided partially observable stochastic game (POSG).

**Why it matters:** It establishes theoretical boundaries and practical algorithms for robust reinforcement learning when agents and adversaries use historical context rather than strictly Markovian policies.

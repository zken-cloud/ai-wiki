### [AgenticRepair: Multi-Faceted Program Context Engineering for Agentic Vulnerability Repair](https://arxiv.org/abs/2607.29422v1)

**arXiv cs.CR** · 2026-07-31 · `arXiv:2607.29422v1`

AgenticRepair uses multi-faceted program context engineering and specialized subagents to capture code-structure, runtime-execution, and commit-history contexts, achieving a 73% success rate on the SEC-Bench vulnerability repair benchmark.

- Orchestrates three specialized LLM subagents to engineer code-structure, runtime-execution, and commit-history contexts.
- Embeds engineered contexts into the memory of a dedicated repair subagent for context-conditioned patch synthesis.
- Evaluated on SEC-Bench (300 real-world instances) with sanitizer-based patch verification, outperforming the strongest baseline by 29%.
- Ablation studies demonstrate that all three context facets, multi-agent scaffolding, and base-model capacity are critical to performance.

**Why it matters:** Systematically combining cross-file data flows, crash semantics, and commit history enables agentic models to generate significantly more accurate security patches for complex software vulnerabilities.

### [MOSAIC: Masked Outsourcing of Secure AI Computations](https://arxiv.org/abs/2607.29221v1)

**arXiv cs.CR** · 2026-07-31 · `arXiv:2607.29221v1`

MOSAIC is a matrix-multiplication masking protocol for secure AI outsourcing that achieves optimal asymptotic client overhead by introducing controlled noise, enabling confidential 70B transformer inference on untrusted servers.

- Protects both client input and model weights from untrusted, powerful servers by reducing security to decisional LWE and LPN assumptions.
- Utilizes a relaxed-correctness matrix-multiplication masking protocol that adds small amounts of noise to lower asymptotic client overhead.
- Employs an error-scaling mechanism using random Hadamard rotations to bound noise accumulation across multi-layer transformers.
- Achieves perplexity comparable to standard quantization methods on 70B models and matches full-precision BF16 inference accuracy on HumanEval.

**Why it matters:** MOSAIC minimizes the trusted computing base, allowing resource-constrained clients to securely outsource large-scale LLM inference to untrusted data center accelerators with minimal performance loss.

<small>James Hsin-yu Chiang, Sheila Zingg, Kari Kostiainen, Srdjan Capkun</small>

### [Alignment Is Local: A Paired Diagnostic for GUI Agents under User-Side Persuasion](https://arxiv.org/abs/2607.29199v1)

**arXiv cs.CR** · 2026-07-31 · `arXiv:2607.29199v1`

A paired diagnostic reveals that prompt-level guardrails for GUI agents fail against multi-turn user persuasion and concealed requests, causing systematic alignment degradation.

- A single-line guardrail reduces single-shot Attack Success Rate (ASR) by up to 40 percentage points with near-zero over-refusal cost.
- Escalating requests over four turns increases guarded ASR by roughly 20 points across all three tested frontier GUI models.
- Multi-turn escalation causes guardrail erosion in Qwen and uncovers defense-orthogonal dynamic risk in Claude and GPT.
- Guardrails flip the salience gap: concealed requests become systematically more successful than explicit ones because the defense depends on explicitly named intent.

**Why it matters:** Static, single-turn evaluation metrics significantly overestimate the real-world safety of GUI agents exposed to dynamic user interactions.

<small>Haoxin An, Yunpeng Song, Zihao Bai, Zhongmin Cai, Guojun Xiong, Chenhao Lin, Wentao Chen, Feng Wei</small>

### [Memory Provenance Laundering in LLM Agents: A Non-Amplification Firewall for Persistent Memory](https://arxiv.org/abs/2607.29167v1)

**arXiv cs.CR** · 2026-07-31 · `arXiv:2607.29167v1`

Researchers identified memory provenance laundering in LLM agents and introduced the Provenance-Preserving Memory Firewall (PPMF) to prevent unauthorized high-risk actions by gating tool calls against platform-maintained memory authority.

- Memory provenance laundering occurs when LLM memory consolidation rewrites untrusted external observations as benign user history, erasing source context while retaining action triggers.
- PPMF acts as lightweight memory middleware that enforces source-authority non-amplification by mapping action risk directly to the authority of relevant memories.
- Without provenance enforcement, vulnerable consolidated memories achieved up to a 1.000 Attack Success Rate (ASR) in schema-grounded evaluations.
- PPMF successfully blocked 100% of unauthorized high-risk actions under tested policies without halting confirmed benign or low-risk memory executions.

**Why it matters:** It prevents indirect prompt injections and untrusted data from permanently elevating their execution privileges when consolidated into an LLM agent's long-term memory.

<small>Jinghan Xu, Yiyong Xiao, Wanru Shao, Hankai Liu, Xinjin Li</small>

### [GoldenRetriever: Non-Interactive Homomorphic Encrypted Retrieval for Privacy-Preserving RAG](https://arxiv.org/abs/2607.29019v1)

**arXiv cs.CR** · 2026-07-31 · `arXiv:2607.29019v1`

GoldenRetriever is a non-interactive, privacy-preserving RAG framework using CKKS homomorphic encryption and threshold selection to replace top-k ranking, reducing computational complexity from quadratic to linear.

- Replaces expensive top-k ranking under encryption with threshold selection, filtering documents whose similarity scores exceed a predefined value.
- Reduces retrieval computational complexity from quadratic to linear relative to corpus size.
- Uses CKKS-based homomorphic computation to execute similarity evaluation and document selection without exposing queries, scores, or indices.
- Introduces a precision-stable mask polarization method to reliably reconstruct discrete tokens from approximate encrypted computations.

**Why it matters:** It significantly lowers latency in privacy-preserving retrieval, making non-interactive, fully encrypted RAG practical for sensitive enterprise datasets.

<small>Yang Gao, Gang Quan, Scott Piersall, Qian Lou, Dongdong Wang, Liqiang Wang</small>

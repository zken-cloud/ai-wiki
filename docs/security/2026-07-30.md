### [Hollow-LLM Attack: Computationally Trivial Weights in Zero-Knowledge Verification of LLM Inference](https://arxiv.org/abs/2607.28884v1)

**arXiv cs.CR** · 2026-07-30 · `arXiv:2607.28884v1`

The Hollow-LLM attack exploits an effort gap in zero-knowledge LLM inference verification, allowing providers to use ghost weights that collapse computation to a fraction of the cost while producing valid proofs of correct execution.

- Zero-knowledge LLM inference proves equational correctness under committed weights but fails to bind the computational effort required to generate the output.
- The Hollow-LLM attack embeds algebraically structured ghost weights into standard transformer blocks within the declared architecture and parameter count.
- Provers can reduce serving costs to match much smaller models with zero quality loss while still satisfying the verification circuit.

**Why it matters:** Proof of correct execution in zero-knowledge LLM inference does not guarantee that a provider actually performed the computational workload of a large model, enabling dishonest cost savings.

<small>Chen Gong, Beijie Liu, Mengyuan Li</small>

### [TextCloak: Thwarting Unauthorized LLM Exploitation via RL-Driven Unlearnable Text](https://arxiv.org/abs/2607.28862v1)

**arXiv cs.CR** · 2026-07-30 · `arXiv:2607.28862v1`

TextCloak uses a generative reinforcement learning framework driven by GRPO-UE to create unlearnable text perturbations that prevent unauthorized fine-tuning of Large Language Models while maintaining semantic fidelity.

- Replaces class-specific classification shortcuts with a generative policy trained via Group-Relative Policy Optimization (GRPO-UE) for open-ended text generation.
- Utilizes bi-level optimization where policy rewards are calculated based on utility degradation in fine-tuned surrogate LLMs.
- Validated across six datasets and nine modern LLM architectures to verify defense utility against adaptive attacks.
- Preserves text naturalness and semantic accuracy for legitimate uses while degrading unauthorized fine-tuning capabilities.

**Why it matters:** It enables content creators to safeguard open-ended textual data against unauthorized LLM scraping and fine-tuning without rendering the text unreadable to humans.

<small>Chengshuai Zhao, Pingchuan Ma, Dawei Li, Bohan Jiang, Zhiyuan Yu, Zhen Tan, Huan Liu</small>

### [Piggybacking on Perception: Stealthy Concurrent Audio Prompt Injections against Multimodal LLM Agents](https://arxiv.org/abs/2607.28165v2)

**arXiv cs.CR** · 2026-07-30 · `arXiv:2607.28165v2`

Researchers introduced a stealthy concurrent audio prompt injection attack that hides malicious instructions within user speech, along with the AudioAgentSecurity benchmark and the Cascaded Audio Decoupling and Verification (CADV) defense mechanism.

- The attack uses instruction augmentation and scenario concealment to piggyback malicious audio instructions onto benign user speech, achieving a 69.10% average Attack Success Rate against Gemini 3 Pro.
- AudioAgentSecurity was constructed as the first benchmark for audio instruction injection, featuring 8 real-world task scenarios and 10 attack patterns evaluated across 11 agents including GPT-4o-audio.
- CADV defends against attacks by combining source separation and consistency analysis, achieving up to 96% detection accuracy.
- Real-world validity was verified using human volunteers and the Doubao AI Smartphone in dynamic environment scenarios.

**Why it matters:** Multimodal LLM agents accepting continuous audio inputs are vulnerable to covert hijackings through ambient audio, requiring specialized acoustic source separation defenses beyond prompt-level filtering.

<small>Mingxiao Liu, Yitong Li, Haoren Zhao, Yaoxiang Bian, Jianan Ma, Jian Zhang, Jialuo Chen, Xinhao Deng</small>

### [Benign on Label, Malicious by Design: Clean-Label Dormant-to-Activated Backdoor via Machine Unlearning with Removable Camouflage](https://arxiv.org/abs/2607.27936v1)

**arXiv cs.CR** · 2026-07-30 · `arXiv:2607.27936v1`

A clean-label backdoor framework uses dual-generator learning and bilevel optimization to keep backdoors dormant until a small subset of camouflage samples is removed via machine unlearning.

- Formulates clean-label backdoor injection as a bilevel optimization problem using dual-generator learning.
- Alternately learns sample-specific triggers for latent associations and label-consistent camouflage samples for removable suppression.
- Activates the dormant backdoor once a small subset of suppressive camouflage samples is unlearned by the model.
- Demonstrates lower pre-unlearning Attack Success Rates (ASR) and higher post-unlearning activation on CIFAR-10 and ImageNet-10 compared to existing baselines.

**Why it matters:** It demonstrates that machine unlearning can be exploited as an activation trigger for hidden backdoors, creating security risks for models complying with data removal requests.

<small>Dongdong Zhao, Can Li, Xiang Yao, Fan He, Qihang Ge, Baogang Song</small>

### [Don't Trust the AI Ecosystem: Analyzing Privacy Leakage in Compromised Open-Source Components](https://arxiv.org/abs/2607.27886v2)

**arXiv cs.CR** · 2026-07-30 · `arXiv:2607.27886v2`

GradLock is a training-time injection attack that covertly embeds training data into model parameters, enabling near-lossless extraction from compromised open-source components without post-training optimization.

- Uses stateless deterministic indexing to create isolated data vaults within model parameters.
- Employs dynamic gradient locking to prevent payload degradation during training and optimize retention against quantization, pruning, and fine-tuning.
- Reconstructs target training images with near-lossless quality (SSIM ~ 1.0) and instant extraction times under 1.0 second on MNIST, Imagenette, and CelebA.
- Defeats human inspection, with 93.3% of deployment study participants failing to detect the injected malicious logic.

**Why it matters:** This vulnerability demonstrates that compromised open-source AI supply chains can be exploited to exfiltrate exact training data, bypassing standard post-training security defenses and detection.

<small>Jin-Seong Kim, Han-Ju Lee, Seok-Won Hong, Takeshi Takahashi, Chansu Han, Tomohiro Morikawa, Seok-Hwan Choi</small>

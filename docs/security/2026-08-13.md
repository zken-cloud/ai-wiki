### [Convergent Detour Hijacking: Task-Preserving Resource Amplification in Skill-Based LLM Agents](https://arxiv.org/abs/2608.12273v1)

**arXiv cs.CR** · 2026-08-12 · `arXiv:2608.12273v1`

Convergent Detour Hijacking (CDH) is a text-only, runtime-independent attack on LLM agents that manipulates skill descriptions and bodies to inject resource-draining detours while successfully preserving overall task completion.

- CDH operates via two sequential control points: using a description to influence selection and an aligned body to fabricate dependencies during planning.
- The attack recruits an attacker-controlled coordinator and unnecessary benign skills into a bounded detour before re-entering the original execution route.
- Evaluated on 491 held-out tasks using DeepSeek-V4-Pro, the malicious coordinator achieved an 80.02% selection rate.
- In successful completed runs, CDH increased token consumption by 66.91% and end-to-end execution time by 92.45% without reducing aggregate task completion.

**Why it matters:** This attack demonstrates that successfully completed agent tasks can still suffer from severe cost and latency inflation, proving that correct outcomes do not guarantee security or trajectory integrity.

### [Prompt Injections for Defense](https://www.schneier.com/blog/archives/2026/08/prompt-injections-for-defense.html)

**Schneier on Security** · 2026-08-12

Tracebit researchers demonstrated "context bombing," a defensive technique that neutralizes AI hacking agents by embedding prompt injections containing guardrail-triggering text alongside stored secrets like passwords and AWS cryptographic keys.

- Context bombing embeds forbidden prompts next to sensitive data, forcing an attacking LLM to trigger its safety guardrails and terminate the session.
- Example triggers include instructions for creating inhalable Anthrax spores or references to Tiananmen Square's Tank Man for Chinese-developed LLMs.
- Once the attacking LLM encounters the forbidden content, it halts execution and abandons its original instructions.
- The defensive mechanism relies entirely on the presence of provider-enforced guardrails and fails against unaligned or locally run LLMs.

**Why it matters:** This strategy provides a novel defensive honeytoken mechanism against current commercial AI agents, though its efficacy will decline as attackers adopt unaligned, local LLMs without guardrails.

**arXiv cs.CR** · 2026-08-11 · `arXiv:2608.11495v1`

GraphRP is a proactive defense framework that uses model reprogramming and a structure-aware gating mechanism to defend Graph Neural Networks against black-box Model Extraction attacks without severe utility loss.

- Combats the Euclidean bias of image-based defenses by accounting for complex graph topological dependencies.
- Uses a Structure-Aware Gating Mechanism driven by learnable topological prototypes to create a dynamic structural firewall.
- Preserves utility for benign queries on the training manifold while maximizing Fisher Information along the perturbation direction for adversarial queries.
- Provides a theoretical lower bound proving attacker estimation error increases with the structural sensitivity of the reprogramming noise.
- Demonstrates effectiveness against both hard-label and soft-label Model Extraction attacks in MLaaS deployments.

**Why it matters:** It offers Graph Neural Network MLaaS providers a real-time, utility-preserving method to proactively prevent intellectual property theft via API queries.

### [When Agents Talk: Honeytokens under Shared Memory](https://arxiv.org/abs/2608.11436v1)

**arXiv cs.CR** · 2026-08-11 · `arXiv:2608.11436v1`

Theoretical bounds show attackers can identify honeytokens in shared memory environments by replicating trusted agent selection rules and pooling non-triggering probes to reduce Bayes classification error to zero.

- Attackers can copy trusted rules that distinguish genuine objects from decoys, while total-variation bounds constrain legitimate compatibility when decoys closely match genuine assets.
- Repeated non-triggering probes pooled across a coalition drive the minimum Bayes classification error to zero if type-dependent response laws differ and are learnable.
- Cross-object transfer of honeypot identification requires a stable deployment rule and orientation information between classes.
- Architectural mitigation requires keeping token identities in a private reference monitor and routing agents through a provenance-enforcing broker to enforce security boundaries.

**Why it matters:** Defenders cannot rely on honeytoken obscurity alone in multi-agent shared-memory systems, requiring architectural provenance brokers to maintain reliable intrusion detection.

### [Analysis of Federated Aggregation under Model Poisoning and Backdoor Attacks: A Reconstructed Cross-Dataset and Cross-Architecture Benchmark](https://arxiv.org/abs/2608.11423v1)

**arXiv cs.CR** · 2026-08-11 · `arXiv:2608.11423v1`

A reconstructed 500-cell benchmark evaluates five federated aggregation methods across five datasets, five architectures, and four attack conditions, revealing key performance rankings and metric implementation bugs.

- Trimmed Mean achieved the highest clean macro-mean accuracy (76.02%) and the lowest mean within-task rank (1.70), while Krum recorded the highest accuracy under sign-flipping and Gaussian attacks.
- The evaluation matrix comprised 454 original runs, 36 repaired runs, and 10 summary-only provenance cells, with core rankings holding across a fully logged subset of 21 task pairs.
- Audit revealed that the BadNets evaluation triggers all test inputs before target counting, measuring Triggered Target-Label Rate (TTLR) instead of conventional Attack Success Rate.
- Audit of the FedPARETO scaffold identified a bug where predictive summaries evaluate an uncorrupted local model while a separately corrupted update receives the aggregation weight.

**Why it matters:** The findings highlight implementation flaws in standard federated learning attack benchmarks and demonstrate that aggregation performance claims must account for execution provenance and exact metric definitions.

### [AI Guardrail Survival under Single-Cycle Agentic Self-Summarization](https://arxiv.org/abs/2608.11392v1)

**arXiv cs.CR** · 2026-08-11 · `arXiv:2608.11392v1`

A study reveals that single-cycle agentic self-summarization degrades safety rules into non-functional textual residues, causing significant behavioral violations even when constraints appear present in the compacted context.

- Compaction often leaves degraded rule residues (e.g., predicate loss) that lead to increased behavioral violations (+34 and +57 point gaps under two replay models compared to intact rules).
- Rule-form items are retained more frequently than prominence-matched facts, creating a false assurance of safety via textual presence checks.
- Textual loss is regime-dependent, showing weld-or-drop behavior with a single rule and degraded residues under tighter context budgets.
- Silent runtime degradation cannot be fully evaluated by LLM-judge labels alone, which risk reversing conclusions, or by checking against external registries.

**Why it matters:** Auditing agent contexts for textual rule presence provides false assurance, as degraded safety constraints survive compaction visually without retaining their protective guardrail behavior.

### [An Empirical Study of Output-to-Input Loops for Black-Box Backdoor Detection in Fine-Tuned Open-Weight LLMs](https://arxiv.org/abs/2608.11348v1)

**arXiv cs.CR** · 2026-08-11 · `arXiv:2608.11348v1`

Researchers evaluated self-feeding, a black-box detection method that iteratively passes an LLM's output back as its input to expose fine-tuning backdoors without needing training data or reference weights.

- Evaluated across six 3B-15B open-weight LLMs fine-tuned with eleven backdoor attack categories using chains up to ten steps across twenty starting prompts.
- Self-feeding detected backdoors in five of six models with 92.0% pooled precision, compared to a same-prompt baseline that succeeded on only one of 120 prompt-model pairs.
- Per-prompt recall was low (19.2%), but model-level detection scales significantly when deploying multiple starting prompts.
- Truncating output-to-input chains to four steps maintained 100% model-level precision while reducing query volume by 60%.
- Limitations include two false positives, zero trigger hits on one test model, and a dependency on recognizing malicious outputs.

**Why it matters:** Self-feeding provides a computationally cheap, text-only black-box method for users to audit downloaded open-weight LLMs for hidden safety backdoors before deployment.

<small>Md. Nahid Hasan, Mohammad Arif Hossain</small>

### [Backdoor Decontamination Dynamics in LLM Agents](https://arxiv.org/abs/2608.11295v1)

**arXiv cs.CR** · 2026-08-11 · `arXiv:2608.11295v1`

Researchers introduced a framework to study backdoor decontamination dynamics in tool-calling LLM agents, demonstrating that defensive poisoning followed by unlearning clears almost all unknown backdoors.

- Defensive poisoning alone erases ~56% of original backdoors, and subsequent unlearning drives almost all remaining backdoors to erasure.
- Malicious backdoors never persist when defensive backdoors use different triggers of the same general type prior to decontamination via unlearning.
- Co-installing up to four backdoors increases resistance (36% erased), but unlearning a single known defensive backdoor collaterally erases 87% (52/60) of co-resident backdoors.
- J-lens internal visualizations reveal that while decontamination restores benign outputs, intermediate layers retain traces of original trigger awareness.

**Why it matters:** Defenders can effectively eliminate unknown fine-tuning backdoors in open-weight LLM agents by intentionally installing and then unlearning a single known backdoor.

### [Agent Safety Should Be a Runtime Contract](https://arxiv.org/abs/2608.11274v1)

**arXiv cs.CR** · 2026-08-11 · `arXiv:2608.11274v1`

Researchers propose replacing training-time safety with a runtime contract that combines preventive action blocking and evidential proof verification across an agent's execution trajectory.

- Runtime safety requires a preventive face (sandboxes, permission gates, trajectory monitors) and an evidential face (gating completion on test runs, log captures, file diffs, and citations).
- Audit of 28,560 papers from NeurIPS, ICML, and ICLR (2023-2025) shows an 8-12x publication imbalance favoring training-time safety over deployment-time safety.
- Dataset includes a survey of 52 documented agent safety incidents, 31 non-contested false-completion audit cases, and a trajectory-schema audit of 12 public agent harnesses.
- Formalizes an Agent Trajectory Schema, an Evidence Chain, and a compositional gating proposition to shift the core unit of safety from the model to the trajectory-with-checkable-evidence.

**Why it matters:** It shifts agent safety enforcement from unreliable internal model weights to deterministic, verifiable external harness controls before autonomous actions affect external systems.

<small>Albus W. Ng, Yi Han, Jusheng Zhang, Wenhao Wang</small>

### [MarkNull: Model-Agnostic Watermark Removal in AI-Generated Images via On-Manifold Latent Manipulation](https://arxiv.org/abs/2608.10166v1)

**arXiv cs.CR** · 2026-08-10 · `arXiv:2608.10166v1`

MarkNull is a model-agnostic watermark removal attack that manipulates on-manifold latents via Noise-Latent Alignment Score (NLAS) optimization, reducing watermark detection to near random-chance while maintaining image quality.

- Introduces Noise-Latent Alignment Score (NLAS) to quantify and decouple the statistical dependency between generated latent representations and embedded noise.
- Reduces average watermark bit accuracy to 53.14% (near the 50% random-guessing baseline) across post-hoc, fine-tuning-based, and initial-noise-based watermarking schemes.
- Includes MarkNull-A, an amortized optimization-free variant that executes in a single forward pass at 0.50 seconds per image.
- Successfully compromises commercial systems like Google's SynthID-Image and transfers effectively to video watermarking domains.
- Proposes a complementary attack detection mechanism to help develop defenses against latent-space manipulation attacks.

**Why it matters:** It demonstrates that current post-hoc, fine-tuning, and noise-based image watermarking systems—including Google's SynthID-Image—are vulnerable to low-overhead, quality-preserving latent manipulation attacks.

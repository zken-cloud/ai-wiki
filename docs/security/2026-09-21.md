### [APort Vault: Benchmarking AI Agent Payment Authorization with the Open Agent Passport](https://arxiv.org/abs/2609.22076v1)

**arXiv cs.CR** · 2026-09-18 · `arXiv:2609.22076v1`

APort Vault benchmarks AI agent payment authorization using 4,371 human-written attacks across 14 models, demonstrating that a deterministic Open Agent Passport (OAP) pre-action check reduced unauthorized transfers from 140 to zero.

- Evaluated 14 models across 225,964 total runs using 4,371 attacks from a live capture-the-flag event under five policy configurations.
- Adding the deterministic OAP pre-action check layer reduced unauthorized payment recipient transfers from 140 (out of 76,842 model-alone runs) to 0 (out of 69,297 runs).
- The OAP layer maintained utility by executing 25,370 valid payments while denying 187 of 25,640 evaluated transfer calls (148 for forbidden recipients).
- Payment request rates varied drastically by policy configuration level (from 0.1% at Level 3 to 79.4% at Level 4) rather than by the underlying model.

**Why it matters:** Enforcing deterministic pre-action security policies via specifications like OAP eliminates unauthorized AI agent payment transfers without resorting to blunt payment refusals.

### [End-to-End Hard-Label Cryptanalytic Model Extraction Using Efficient Sign Recovery](https://arxiv.org/abs/2609.21941v1)

**arXiv cs.CR** · 2026-09-18 · `arXiv:2609.21941v1`

A new sign-recovery algorithm enables the first fully black-box, end-to-end hard-label parameter extraction of trained deep ReLU MLPs without requiring dedicated sign-recovery queries.

- Eliminates dedicated queries for the sign-recovery phase, reducing overall query complexity and computational burden compared to the Eurocrypt 2025 method by Carlini et al.
- Achieves higher sign-recovery accuracy on trained models than previous techniques.
- Demonstrates full black-box extraction on MNIST and Fashion-MNIST models with width 16 and 4 to 6 hidden layers, achieving over 98% label agreement.

**Why it matters:** It proves that deep ReLU MLP model parameters can be fully stolen in a strict black-box hard-label setting where adversaries only observe final classification labels.

**arXiv cs.CR** · 2026-09-18 · `arXiv:2609.21713v1`

TERMon is a hardware runtime monitor for Edge AI that detects behavioral anomalies using pipelined ternary pattern matching against thermometer-encoded feature fingerprints with a two-cycle latency.

- Monitors inference behavior directly rather than using model re-execution or formal verification methods.

### [CIPL: A Channel-Aware Framework for Recoverable Privacy Leakage in LLM Agents](https://arxiv.org/abs/2609.21686v1)

**arXiv cs.CR** · 2026-09-18 · `arXiv:2609.21686v1`

CIPL is a channel-aware framework that evaluates black-box privacy leakage in LLM agents by modeling how internal sensitive data translates into externally attacker-recoverable output.

- Models target systems across six stages: sensitive source, selection, assembly, execution, observation, and extraction.
- Evaluates transition from selected sensitive units to attacker-recoverable output across memory, retrieval, and tool-mediated pipelines, including a BrowserUse live-agent case study.
- Demonstrates that internal storage labels do not dictate recoverability: memory targets show near-saturated leakage, retrieval-mediated leakage is often partial, and tool/live-agent leakage depends on observation surface, prompt-channel alignment, retrieval depth, and provider behavior.
- Employs a stratified semantic audit to detect attacker-useful privacy disclosures that canonical exact matching metrics fail to capture.

**Why it matters:** It establishes a standardized method to quantify actual, externally recoverable privacy risks in complex LLM agents rather than relying on misleading internal storage metrics.

### [ServeGuard: Verifiable, Bounded-Residual Confinement of Operator-Invisible Channels Without Revealing the Certified Read Factor](https://arxiv.org/abs/2609.21515v1)

**arXiv cs.CR** · 2026-09-18 · `arXiv:2609.21515v1`

ServeGuard provides a zero-knowledge supply-chain primitive that proves a third-party open-weight adapter carries no hidden backdoor channels in a safety monitor's blind subspace, without revealing the adapter's certified read factor.

- Payload detection in a monitor's blind subspace is unsound because benign and backdoored adapters overlap on blind-subspace statistics.
- ServeGuard enforces zero-knowledge proofs for a single linear identity, leveraging the public base model to deterministically identify blind spots without exposing the certified read factor.
- Serves a residual bounded by the public base model's own floor rather than a prover-chosen tolerance, paired with an admission-time typing guard to lock in adapter bytes.
- Evaluated across eight checkpoints up to 7B from four families, showing monitoring budget saturation at the value-path rank for grouped-query architectures and near-zero cost for benign adaptation on a 0.5B model.

**Why it matters:** It allows model consumers and regulators to mathematically verify the safety of opaque third-party adapters without requiring publishers to disclose proprietary weight matrices.

**arXiv cs.CR** · 2026-09-18 · `arXiv:2609.21284v1`

Researchers introduced a root-scoped authorization quiescence protocol that revokes long-running AI agent authority across delegated queues, callbacks, and provider operations by linearizing root cuts and issuing provider-frontier certificates.

- Defines root-scoped authorization quiescence to fence old-root expansion and protected sinks while allowing exact rebind to independently sufficient alternative support.
- Represents alternative and conjunctive authority as antichains of minimal sufficient root sets and composes certificates into a cutset over registered paths using exact channel-token accounting.
- Formally proves post-cut issuer non-expansion, support-sound projection, compositional soundness under exact channel conservation, and crash/replay stability.
- Validated via a late-effect test suite matching 17/17 registered outcomes, where cut-plus-fence executions successfully rejected scheduled late effects that cancellation-only executions accepted.
- Includes an independent trace checker that verified 17/17 traces and rejected 44/44 semantic regressions.

**Why it matters:** Standard process cancellation or credential revocation fails to stop asynchronous, multi-provider AI agent operations, whereas this protocol provably prevents unauthorized late-execution side effects.

### [Origin Is All You Need: Provenance-Aware Transformers for Structural Trust-Boundary Separation](https://arxiv.org/abs/2609.21088v1)

**arXiv cs.CR** · 2026-09-17 · `arXiv:2609.21088v1`

Provenance-Aware Transformers eliminate indirect prompt injection by introducing architectural source boundaries using ring IDs, origin embeddings, learnable origin attention biases, and origin scales.

- Indirect prompt injection vulnerability stems from standard transformers processing system instructions, user inputs, and retrieved data through an undifferentiated attention mechanism.
- The proposed architecture assigns each token a ring ID to denote source origin and adds origin embeddings, a learnable origin attention bias, and a learnable origin scale to maintain provenance through normalization.
- A two-stage fine-tuning pipeline trains pretrained models to execute tasks under ring-constrained origin semantics.
- Evaluations demonstrate robust in-distribution and out-of-distribution resistance to indirect prompt injections while preserving base model utility.

**Why it matters:** This approach shifts LLM safety from brittle text-based pattern matching to explicit, architectural trust-boundary enforcement.

### [Loopjacking: Hijacking Human-in-the-Loop Approval](https://arxiv.org/abs/2609.21081v1)

**arXiv cs.CR** · 2026-09-17 · `arXiv:2609.21081v1`

Researchers identify Loopjacking, an agentic security vulnerability where human approval for operation A is exploited to execute a materially different operation B via representation mismatch or post-approval state substitution.

- Post-approval state-substitution attacks were reproduced in seven Agno AgentOS releases (up to 3.0.9) and 12 LangGraph Agent Server compositions (up to 0.14.0).
- Representation mismatch attacks were successfully executed in OpenClaw 2026.2.23, but rejected in version 2026.2.24.
- OpenAI Agents SDK (0.22.0 and 0.22.2) blocked attacks by using serialized continuation to maintain per-call binding and reject mutated states.
- Mitigation requires canonical approval rendering combined with exact use-time state comparison or restricting unauthorized pending-state mutation.

**Why it matters:** Human-in-the-loop controls fail as a final security boundary if agent frameworks do not cryptographically or statefully bind the user's specific approval to the exact downstream payload executed.

<small>Adithyan Arun Kumar</small>

### [Provisional Reachability: Containing Agents by Making Every Crossing Revocable](https://arxiv.org/abs/2609.21957v1)

**arXiv cs.CR** · 2026-09-18 · `arXiv:2609.21957v1`

A provisional reachability defense places agent crossings in escrow to cap adversary information leakage at L(r) ~ c/(er) bits per period, preventing secret assembly when paired with decay rates exceeding g/L.

- Escrowing k crossings carrying c bits with independent audit probability r bounds information leakage per window to a supremum of L(r) ~ c/(er), matched in simulation to 7.7 standard errors.
- Pairing escrow with a secret decay fraction mu creates an Eigen-style error threshold, guaranteeing an L-bit secret is unreachable when mu > g/L (100% secret assembly at 0.9mu* vs 0% at 2mu* over 20,000 windows).
- Keying denotations hides 2.64 of 3.00 bits at chance accuracy while preserving valid Python syntax, whereas keying entry points hides only 0.10 bits.
- The full defensive stack reduces total data leaks from 100,000 to 59 bits (a 1,704x reduction); caller-keyed windows restore legitimate work execution from 12% to 100% without increasing leakage.

**Why it matters:** It establishes a mathematically provable, public rate limit on information exfiltration for autonomous agents without relying on adversary deception.

<small>Yoshiaki Takashita</small>

`cybersecurity` `agent-containment` `information-flow` `audit-algorithms`

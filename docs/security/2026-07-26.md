### [The Missing Layer: Specification Infrastructure for AI Oversight](https://arxiv.org/abs/2607.24866v1)

**arXiv cs.CR** · 2026-07-26 · `arXiv:2607.24866v1`

A 5x6 taxonomy and six design principles address the AI oversight coordination gap by establishing Layer 2 (Specification) infrastructure, demonstrated through the CARMA prototype for autonomous ETL agents.

- Identifies a coordination gap in AI safety across a 5x6 matrix of five technical layers (Legibility, Specification, Mediation, Evaluation, Escalation) and six concerns (alignment, robustness, adversarial defense, security, governance, accountability).
- Highlights Layer 2 (Specification) as the core connective tissue that currently lacks shared vocabulary, design principles, composability standards, and governance practices.
- Proposes six design principles for Layer 2: elicitability, composability, adversary-awareness, traceability, governability, and a reference architecture translating specifications into runtime enforcement, evaluation, and escalation.
- Positions existing tools like Cedar, Constitutional AI, and Open Policy Agent as partial Layer 2 fragments that can be unified.
- Introduces CARMA, a Layer 2 prototype using a single versioned specification to drive enforcement, evaluation, and escalation for autonomous ETL agents.

**Why it matters:** Structuring specification as a standardized engineering layer enables independent teams to build composable, traceable, and deployable AI oversight systems instead of creating fragmented, custom implementations.

<small>Satyam Kumar, Saurabh Jha</small>

### [Are You Still the Agent I Authorized? Earned Authority under a Fixed Ceiling for Evolving Agents](https://arxiv.org/abs/2607.23586v1)

**arXiv cs.CR** · 2026-07-26 · `arXiv:2607.23586v1`

A new state-bound authorization model establishes authorization continuity for evolving AI agents by enforcing an immutable effect ceiling and a transition envelope that bounds post-deployment mutation.

- Defines authorization continuity to govern how an agent's active authority contracts, expands, or invalidates as it acquires tools, revises workflows, and delegates work.
- Establishes a state-bound model featuring a fixed transition envelope and an unraiseable, immutable effect ceiling set at grant time.
- Distinguishes between requested and realized effects, allowing authority to expand below the ceiling only under specific evidence conditions while contracting freely.
- Proves mathematically that mutation cannot amplify protected effects beyond the ceiling under complete mediation, sound effect abstraction, attenuating delegation, and monitor integrity.
- Maps six distinct agent mutation classes directly to their authorization consequences.

**Why it matters:** It prevents long-lived, mutating AI agents from escalating permissions or causing unintended external effects beyond what the user originally authorized.

<small>Zhaoxi Zhang, Xiaomei Zhang</small>

### [Mission-Level Runtime Assurance for LLM-Assisted ISR Swarms over a Verification-Aware Fabric](https://arxiv.org/abs/2607.23532v2)

**arXiv cs.CR** · 2026-07-26 · `arXiv:2607.23532v2`

A three-tier compositional runtime-verification framework and verification-aware messaging fabric detect multi-platform LLM safety violations and evidence loss in autonomous ISR swarms.

- Uses a three-tier (platform/squad/mission) architecture to decompose mission policies into per-agent and cross-agent components.
- Aggregates per-platform verdicts over a verification-aware fabric using an evidence-aware, two-axis (security x completeness) algebra.
- Downgrades unsupported negative verdicts to an explicit unknown state when faced with communication loss or silence.
- Provides complete provenance identifying the specific group of platforms that jointly trigger a composite violation.
- Successfully detected an indirect prompt injection that split a prohibited task across four platforms, which bypassed individual per-platform monitors and caused false all-clears in central monitors.

**Why it matters:** It prevents LLM-assisted swarms from executing dangerous, multi-agent coordinated attacks or policy violations that exploit individual guardrail blind spots and degraded network conditions.

<small>Nikolaos Kekatos, Panagiotis Katsaros, Alexios Lekidis, Theodoros Nestoridis, Tom Nianios</small>

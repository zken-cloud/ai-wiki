### [Unsaid, Unsafe? Implicit Security Obligations in LLM-Based RTL Code Generation](https://arxiv.org/abs/2608.26588v1)

**arXiv cs.CR** · 2026-08-27 · `arXiv:2608.26588v1`

Researchers created SECRTL-GEN, a benchmark revealing severe security vulnerabilities in LLM-generated hardware, and introduced RTL-Obliger, a neuro-symbolic framework that infers implicit security obligations to generate safer RTL code.

- SECRTL-GEN contains 392 tasks spanning five CWE families across four HDLs (Verilog, SystemVerilog, VHDL, and Python) with black-box functional and security testbenches.
- Frontier LLMs under vanilla prompts achieve 73-79% functional pass rates but only 14-35% security pass rates, demonstrating that higher functional performance does not correlate with security.
- RTL-Obliger extracts a functional-semantic graph from specifications, matches it against a CWE pattern ontology via a symbolic engine, and uses an LLM to generate functionality-preserving secure RTL.
- RTL-Obliger increases mean all-pass rates to 61.6%, outperforming existing secure-generation baselines like SecV and RESCUE (49.6-51.4%).

**Why it matters:** Hardware security flaws in LLM-generated RTL cannot be patched after tape-out, making automated inference of implicit security requirements critical for safe silicon manufacturing.

<small>Guang Yang, Xing Hu, Xiang Chen, Xin Xia</small>

### [MeMark: Membrane-Space Watermarking for Spiking Neural Networks](https://arxiv.org/abs/2608.25738v1)

**arXiv cs.CR** · 2026-08-26 · `arXiv:2608.25738v1`

MeMark is a membrane-space watermarking method for Spiking Neural Networks (SNNs) that embeds multi-bit identifiers into the internal membrane states of Leaky Integrate-and-Fire neurons to survive output-head replacement.

- Embeds secret bits directly into the internal membrane states of chosen Leaky Integrate-and-Fire (LIF) neurons relative to their firing thresholds, eliminating the need for a learned decoder.
- Tested on a 215.4M-parameter SpikeGPT checkpoint where all twenty 64-bit keys passed the 51/64 verification threshold, while 30,000 random keys produced zero false positives.
- Maintains verifiable ownership evidence after fine-tuning, 90% parameter pruning, int8 quantization, and complete output-head replacement.
- Evaluated across recurrent, convolutional, residual, and transformer SNN architectures against adaptive attacks, key disclosure, rollback, and student extraction.

**Why it matters:** It enables robust Intellectual Property (IP) verification and origin tracking for pretrained SNN checkpoints even when downstream users strip or replace the original output layer.

### [NeuronFuzz: Safety Neuron Guided Fuzzing for LLM Safety Evaluation](https://arxiv.org/abs/2608.26222v1)

**arXiv cs.CR** · 2026-08-26 · `arXiv:2608.26222v1`

NeuronFuzz is a white-box fuzzing framework that uses safety-neuron activations during prefill to provide continuous feedback, eliminating response generation from LLM safety evaluation.

- Identifies a compact set of safety neurons via template-invariant inputs and stability-aware selection to compute a continuous safety alarm score.
- Obtains execution feedback during the prefill stage, bypassing costly target-model response generation.
- Uses gradients of the differentiable safety alarm score to locate safety-sensitive template positions for targeted masked language model mutations.
- Achieves a 76-100% jailbreak discovery rate across five white-box models, outperforming baselines by up to 48 percentage points.
- Transfers zero-shot to proprietary models, reaching an average Attack Success Rate (ASR) of 69.6% and top-5 Ensemble ASR (EASR) of 92.6%.

**Why it matters:** By relying on internal prefill activations instead of full generation loops, NeuronFuzz significantly reduces the computational cost of finding jailbreaks while improving attack transferability.

### [SecureDrive-FL: Joint Differential Privacy and Gradient-Aware Selective Homomorphic Encryption for Federated Driver Monitoring](https://arxiv.org/abs/2608.27108v1)

**arXiv cs.CR** · 2026-08-27 · `arXiv:2608.27108v1`

SecureDrive-FL combines DP-SGD and GASHE, a dynamic threshold-based selective homomorphic encryption method, to secure federated driver monitoring against both model poisoning and Man-in-the-Middle gradient interception with 8-10% runtime overhead.

- GASHE dynamically identifies and encrypts only the gradient components that exceed a DP-calibrated sensitivity threshold instead of using full-parameter CKKS or static layer-based encryption.
- DP-SGD calibration parameters directly derive the GASHE encryption mask, establishing a unified pipeline for training-time privacy and communication-time confidentiality.
- Under MitM attack scenarios, SecureDrive-FL maintains 78.2% accuracy while unencrypted DP-SGD degrades to 10.4% (near-random).

**Why it matters:** It proves that combining differential privacy with targeted homomorphic encryption can fully protect federated learning systems against transit interception without incurring the massive computational overhead typical of full-parameter encryption.

A new private dense retrieval protocol uses learned deep hashing as a randomized filter to create short candidate lists, enabling efficient, accurate, and privacy-preserving RAG on large corpora.

- Repurposes learned deep hashing to output randomized binary codes, selecting 200 to 500 candidate passages out of up to 5.4 million documents without sacrificing retrieval quality.
- Combines candidate shortlisting with encrypted reranking and oblivious key transfer to protect user queries and selected documents while enforcing corpus access authorization.

- Provides directional metric differential privacy (DP) and significantly mitigates embedding-inversion and property-inference attacks.

**Why it matters:** It demonstrates that cryptographic search overhead can be drastically reduced to practical latency levels without degrading RAG zero-shot retrieval accuracy or exposing query privacy.

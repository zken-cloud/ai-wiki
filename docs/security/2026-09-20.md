### [s-MDM: Generative Virtualization of Multi-Device Hardware Variations for Portable DL-SCA](https://arxiv.org/abs/2609.18783v1)

**arXiv cs.CR** · 2026-09-16 · `arXiv:2609.18783v1`

s-MDM is a zero-target-trace generative framework that uses a cVAE with continuous style modulation to synthesize virtual multi-device side-channel profiles, improving deep learning portability across hardware variations.

- Combines a structured cVAE generator, a Walsh-Hadamard leakage anchor, continuous style modulation, and decoupled leakage-style--domain critics.
- Operates offline without requiring traces from the target device.
- Evaluated on 32-bit AES_PTv2 side-channel traces to address layout shifts, silicon process variations, and noise shifts.
- Outperforms physical baselines in maintaining a low key rank on layout- and acquisition-shifted targets like the Pinata target, though physical MDM remains superior on identical hardware clones (D4).

**Why it matters:** It enables deep learning side-channel attacks to generalize to unseen target hardware without needing physical access to target traces beforehand.

<small>Niloufar Sayadi, Marten van Dijk, Chenglu Jin</small>

### [Unmasking Cloud Identities: From Behavioral Clustering to Automated Detection](https://unit42.paloaltonetworks.com/behavioral-clustering-map-to-cloud-identities/)

**Unit 42** · 2026-09-14

Unit 42 designed a behavioral clustering model that maps cloud identity roles from audit logs to enable continuous threat detection via SQL queries.

- Maps cloud identity roles directly from cloud audit logs using a behavioral clustering model.
- Enables continuous threat detection capabilities executed through standard SQL queries.

**Why it matters:** Security teams can automate cloud identity role mapping and perform continuous threat detection directly using standard database queries.

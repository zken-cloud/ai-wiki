### [Stealing AI Reasoning Traces](https://www.schneier.com/blog/archives/2026/09/stealing-ai-reasoning-traces.html)

**Schneier on Security** · 2026-09-08

Researchers discovered an architectural flaw in major LLM APIs where client-side encrypted reasoning traces are interchangeable across models, allowing attackers to decrypt them using weaker models.

- Encrypted chain-of-thought blocks are fully compatible across different sessions, users, and models within a provider's ecosystem.
- Injecting a strong model's encrypted reasoning trace into a weaker model forces the weaker model to output the decoded plaintext trace verbatim.
- The vulnerability affects Anthropic, OpenAI, and Google, enabling anti-distillation bypass, invisible prompt injections, and exposure of hidden hazardous information.
- Analysis of 315,320 scraped public reasoning blocks successfully recovered 367 PII artifacts and 182 sensitive credentials.

**Why it matters:** Attackers can silently extract proprietary AI reasoning, harvest private credentials, and execute invisible prompt injections without needing to directly jailbreak target frontier models.

### [Client-Side Probing of Deleted Ridge Statistics in Federated Unlearning](https://arxiv.org/abs/2609.04475v1)

**arXiv cs.CR** · 2026-09-03 · `arXiv:2609.04475v1`

Researchers demonstrate a client-side probing attack that exploits model updates broadcast during federated unlearning to reconstruct deleted training feature summaries.

- Malicious clients submit known changes to capture server state updates before and after isolated unlearning events.
- Reconstructed additive feature summaries reveal deleted samples, classes, or client data, enabling potential reinsertion.
- Demonstrated exact label recovery on MNIST and CIFAR-10 datasets using both unrestricted probes and realistic attacker-data additions.
- Mitigations include reducing broadcast precision, restricting response rates, enforcing update verification, and maintaining concurrent background activity.

**Why it matters:** Exact federated unlearning systems using additive summaries introduce serious privacy and integrity risks by leaking deleted client data directly through classifier updates.

<small>Yijun Quan, Giovanni Montana</small>

### [Hoss: Fast Oblivious Semantic Search with Heterogeneous GPU-CPU-TEE Architecture](https://arxiv.org/abs/2609.04522v1)

**arXiv cs.CR** · 2026-09-03 · `arXiv:2609.04522v1`

Hoss is an oblivious semantic search system using a heterogeneous GPU-CPU TEE architecture to bypass traditional ORAM bandwidth bottlenecks by leveraging large GPU private memory.

- Exploits large private memory (Pmem) in modern GPU TEEs to blind internal access patterns and host hot-path HNSW graph traversals.
- Offloads lower layers of the HNSW graph to CPU TEEs when capacity is exceeded, invoking oblivious primitives exclusively for these CPU-bound layers.
- Features a host-access ORAM mechanism alongside data-dependent optimizations enabled by the large GPU Pmem.
- Demonstrates up to a 67x speedup over the state-of-the-art system (Compass) while maintaining high search recall.

**Why it matters:** It significantly reduces the overhead of privacy-preserving semantic search, making oblivious vector indexing scalable and practical on modern hardware.

<small>Jianzhang Du, Weijie Huang, Chenghong Wang, Nicolas Tsagareli, Yukui Luo, XiaoFeng Wang, Zhongshu Gu</small>

**arXiv cs.CR** · 2026-09-03 · `arXiv:2609.04474v1`

### [Candidate Comparability Before Promotion: Conditional Validation in Adaptive Network Intrusion Detection](https://arxiv.org/abs/2609.04388v1)

**arXiv cs.CR** · 2026-09-03 · `arXiv:2609.04388v1`

Researchers demonstrate that model promotion decisions in adaptive network intrusion detection depend heavily on challenger pipeline self-containment and candidate evidence sizes across CICIDS2017, UNSW-NB15, and ToN-IoT benchmarks.

- Incumbent-owned frozen preprocessing artificially amplified promotion harm, whereas self-contained challenger pipelines eliminated persistent mean full-drift harm.
- Increasing candidate evidence from 512 to 2,000 samples per class improved balanced accuracy by +0.53, +1.67, and +0.38 points across the three datasets, primarily by reducing false positives.
- Evaluating nine update policies revealed that policy ordering changes with candidate comparability, with no single policy globally dominating.
- Conditional validation provided benefits to evidence-disadvantaged challengers but offered no average benefit when candidates were at parity, while 13 real-world time-ordered replays showed zero net harm from continuous deployment.

**Why it matters:** Evaluating network intrusion detection updates without strictly controlling challenger pipeline independence and candidate sample sizes yields misleading conclusions about model promotion policies.

<small>Roberto Fernández-Barrios, Iker Pastor-López, Amaia Pikatza-Huerga, Pablo García Bringas</small>

### [Long-Range Indirect Control-Flow Prediction in Stripped Binaries via Dual Virtual Hubs and Multi-Task Graph Learning](https://arxiv.org/abs/2609.03280v1)

**arXiv cs.CR** · 2026-09-03 · `arXiv:2609.03280v1`

ICFlowNet is a unified multi-task graph learning framework that uses candidate-aware Dual Virtual Hubs to predict long-range indirect control-flow edges in stripped x86-64 binaries.

- Dual Virtual Hubs (Global Code Hub and Global Data Hub) create short routing paths to connect distant code and data evidence, improving long-range F1 scores by up to 9.13 points.
- Jointly models indirect calls, indirect tail calls, jump tables, and returns via multi-task graph learning, contributing up to 5.81 points in F1 gains.
- Establishes a leakage-aware evaluation pipeline using package-level splits, function-level mnemonic-hash deduplication, and dynamic ground-truth positives with absolute negatives.
- Evaluated on a dataset of 15,901 stripped x86-64 binaries, outperforming baselines by over 13 F1 points on long-range indirect calls with an 11.44% topological overhead.

**Why it matters:** It enables significantly more accurate static binary security analysis and control-flow recovery across long code distances without relying on debug symbols or prone-to-leakage evaluation protocols.

<small>Kun Liu, Zhengming Ding, Chenke Luo, Tianyi Xu, Zizhan Zheng, Haotian Zhang, Jiang Ming</small>

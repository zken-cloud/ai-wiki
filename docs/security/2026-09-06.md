### [Retrosynthesis of Synthetic Media for Explainable AI Provenance Forensics](https://arxiv.org/abs/2609.02268v1)

**arXiv cs.CR** · 2026-09-02 · `arXiv:2609.02268v1`

A self-referential retrosynthesis framework enables explainable synthetic media provenance verification under a fixed-generator setting without modifying generator architectures, parameters, or embedding watermarks.

- Uses a jointly optimized encoder-decoder pair to implement a self-embedding mechanism for round-trip consistency verification.
- Client inputs are encoded prior to generation, producing outputs that maintain visual fidelity comparable to standard generator outputs.
- Decoded images allow resynthesized outputs to be compared against query images to verify if they originated from the target model.
- Eliminates the need for architectural modifications, parameter tuning, or explicit watermark embedding.

**Why it matters:** It allows platform providers to reliably trace and audit synthetic media origins on MLaaS platforms without sacrificing image quality or altering deployed generative models.

<small>Yijie Lin, Ching-Chun Chang, Isao Echizen, Hui Li, Chin-Chen Chang</small>

### [WeaveMark: Robust and Scalable Multi-bit LLM Watermarking via Coded Payload Spreading](https://arxiv.org/abs/2609.02177v1)

**arXiv cs.CR** · 2026-09-02 · `arXiv:2609.02177v1`

WeaveMark introduces a robust multi-bit LLM watermarking scheme using multi-bit-per-token coded payload spreading, soft-decision error-correcting codes, and unbiased multilayer reweighting to boost capacity and extraction accuracy without degrading text quality.

- Employs multi-bit-per-token payload spreading and soft-decision error-correcting codes to increase capacity and extraction accuracy.
- Uses unbiased multilayer reweighting to preserve generation quality and dedicated zero-bit layers to detect watermark presence.
- Achieves an 89.8% match rate for 32-bit messages at 200 tokens compared to 20.8% for BiMark.
- Sustains an 86.0% match rate under 10% substitution attacks on 16-bit messages at 200 tokens, compared to 30.7% for BiMark.

**Why it matters:** It significantly improves the reliability of user-identifiable tracking in AI-generated text under editing attacks while preserving output quality.

<small>Gang-Hyun Park, Ju-Hyeong Lee, Hee-Youl Kwak, Dae-Young Yun</small>

### [Learning-Based Reconstruction Attacks on Coordinate-Obfuscated Point Clouds](https://arxiv.org/abs/2609.02568v1)

**arXiv cs.CR** · 2026-09-02 · `arXiv:2609.02568v1`

Researchers evaluated machine learning-based reconstruction attacks on selective coordinate encryption for point clouds, demonstrating that PointNet and Random Forest models can accurately reconstruct coordinates under sparse encryption schemes.

- Evaluated the security of selective coordinate encryption for point clouds using PointNet and Random Forest reconstruction models.
- Tested two specific encryption granularities: X (where all X coordinates are encrypted) and 2X (where every second X coordinate is encrypted).
- Found that fully encrypting all X coordinates resists machine learning reconstruction, whereas the 2X scheme leaks enough spatial and geometric correlation from unencrypted neighbors to allow accurate recovery.
- Demonstrated that the security of partial coordinate encryption depends heavily on the specific encryption granularity employed.

**Why it matters:** Lightweight selective encryption schemes for volumetric video must carefully select coordinate granularity to prevent adversaries from recovering protected visual content via spatial machine learning models.

<small>Mohammad Waquas Usmani, Susmit Shannigrahi, Michael Zink</small>

### [Poisoning Attacks on the PGM-index](https://arxiv.org/abs/2609.02328v1)

**arXiv cs.CR** · 2026-09-02 · `arXiv:2609.02328v1`

A new poisoning attack, PGM-attack, inserts adversarial keys into PGM-indexes to inflate segment counts and index size by up to 120x.

- PGM-attack sequentially inserts adversarial keys to exploit vulnerabilities in optimal piecewise linear approximations (PLAs).
- Poisoning 10% of dataset keys increases PGM-index segment count and overall memory size by up to 120x.
- The authors derived an instance-dependent theoretical upper bound, certifying PGM-attack achieves at least 52% of the optimal worst-case segment inflation (within 1.92x of the bound).
- The attack successfully transfers to other learned indexes, particularly those relying on PLA construction methods.

**Why it matters:** Demonstrating that optimal PLA-based learned indexes are inherently vulnerable to space-inflation attacks highlights the need for robustness-aware optimization objectives in data structure design.

<small>Atsuki Sato, Martin Aumüller, Yusuke Matsui</small>

### [Agentic Settlement Protocol: An Application Profile for Refundable, Delayed-Fulfilment Agent Commerce on Stablecoin Rails](https://arxiv.org/abs/2609.02208v1)

**arXiv cs.CR** · 2026-09-02 · `arXiv:2609.02208v1`

The Agentic Settlement Protocol (ASP) defines an application profile over on-chain authorize-and-capture escrow on the XDC Network for delayed-fulfilment, refundable autonomous agent commerce.

- Uses a three-deadline hold model separating issuance deadline, escrow expiry, and inventory expiry by a submission-inclusion-finality margin to prevent issuing inventory against reclaimable funds.
- Features a fulfilment-verification ladder that specifies trusted capture triggers, attestation proofs, and associated challenge windows.
- Enforces engine-authoritative partial refunds with strict refund-liquidity ordering, atomic exposure reservation, per-seller credit limits, and a single-currency-per-charge invariant.
- Provides a normative interface specification including an x402 scheme, vault ABI, operator/connector APIs, and a self-dealing-resistant distributor revenue share model.

**Why it matters:** ASP enables autonomous agents to handle complex, non-atomic commercial transactions like travel bookings and physical orders that require off-chain fulfilment, challenge windows, and cancellations.

<small>Behnam, Mohammadkhani, Atul Khekade, Ritesh Kakkad</small>

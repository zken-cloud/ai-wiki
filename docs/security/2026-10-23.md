### [AgentPhishing: A Benchmark of LLM Email Agents Under Adaptive Attack](https://arxiv.org/abs/2610.31404v1)

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.31404v1`

AgentPhishing is a new benchmark assessing LLM email agents against adaptive, persuasive attacks optimized by a novel technique called PhishOpt.

- Introduces AgentPhishing to evaluate whether LLM email agents detect persuasive phishing and comply with malicious requests.
- Develops PhishOpt to optimize reusable email-generation skills against targeted agents under realism and benchmark constraints.
- Categorizes attack strategies using Cialdini's persuasion principles to construct a universal attack generation skill.
- Demonstrates that four out of nine tested agents had phishing-detection rates under 10% and malicious-request compliance rates over 45% despite passing conventional phishing checks.

**Why it matters:** Conventional phishing detection benchmarks fail to reflect agent safety, as adaptive persuasive attacks easily bypass detection and manipulate agents into executing harmful actions.

### [AfterDeleteBench: Auditing Post-Deletion Information Persistence in LLM Agents](https://arxiv.org/abs/2610.31366v1)

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.31366v1`

AfterDeleteBench introduces a controlled behavioral audit evaluating post-deletion secret persistence in LLM agents, demonstrating that deleting source memories fails to erase information stored in descendant states.

- Uses matched control agents (never-exposed vs. exposed-then-deleted) to isolate post-deletion recovery caused specifically by prior exposure.
- Single queries recovered deleted secrets from Qwen2.5-7B-Instruct in ~67% of cases, compared to 0% recovery in never-exposed controls.
- Exact secret reconstruction succeeded in 62-99% of cases across Qwen, Mistral, and Phi-3 models when only separately stored components remained under a public composition rule, without surviving verbatim copies.
- Provenance-aware closure successfully eliminated observed secret recovery, whereas exact-literal write filters blocked reinsertion but failed to erase existing persisted state.

**Why it matters:** Evaluating data deletion in LLM agents requires behavioral auditing across the entire memory and descendant state system rather than relying solely on storage-level record removal.

<small>Ehsan Saleh, Roozbeh Nahavandi, Sama Salarian, Raef Bassily, Andrew Perrault</small>

### [Amplifying Latency and Cost of LLM Inference via Rowhammer Attack](https://arxiv.org/abs/2610.30798v1)

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.30798v1`

LLVMhammer uses CPU DRAM Rowhammer bit-flips in Triton's MLIR/LLVM compilation pipeline to permanently degrade GPU-based LLM inference performance without altering model code.

- Target-independent Triton optimization passes are manipulated via DRAM bit-flips to generate suboptimal but functionally correct GPU kernels.
- Triton's disk-caching mechanism ensures a single bit-flip causes persistent inference latency increases across subsequent executions.
- The Karnage tool automatically isolates vulnerable bit-flip locations within Triton's vendor-agnostic MLIR/LLVM compilation pipeline.
- Evaluated on Qwen2.5-7B, Llama-3.1-8B, Mistral-7B, and Deepseek-7B across NVIDIA RTX 4090 and AMD RX 7900 XTX GPUs, causing 4-16% latency increases or lowering output BERTScore down to 25%.

**Why it matters:** The attack demonstrates that hardware-level CPU vulnerabilities can cause persistent financial and performance degradation in GPU-accelerated LLM cloud infrastructure across multiple GPU vendors.

<small>Mrityunjay Shukla, Shubham Roy, Biswabandan Panda</small>

### [AgentTriage: Replayable Security Diagnosis Across Heterogeneous Agent Runtimes](https://arxiv.org/abs/2610.30738v1)

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.30738v1`

AgentTriage is an open-source executable contract framework for deterministic, replayable security diagnosis and provenance graph construction across heterogeneous AI agent runtimes.

- Uses runtime overlays to normalize heterogeneous observations into canonical events, joining invocation and result lifecycles into a typed provenance graph.
- Requires deterministic claim-evidence binding and mandatory abstention when required evidence is missing, eliminating language-model judgment during diagnosis recomputation.
- Evaluated across five runtimes and 120 adjudicated cases, achieving 0.858 grounded joint diagnosis, 0.966 required-evidence coverage, and a 0.036 unsupported-claim rate.
- Outperformed the strongest same-schema baseline in joint diagnosis by 0.175 (95% CI (0.092, 0.258)) across 159 applicable executions.

**Why it matters:** It enables deterministic, audit-ready security diagnosis of AI tool-use agents across fragmented execution environments without relying on non-deterministic LLM evaluation.

### [Scaling Laws for Safety Probes](https://arxiv.org/abs/2610.30678v1)

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.30678v1`

Researchers established two scaling laws showing safety probe error (1 - AUROC) drops predictably as a power law of base model size and available training label volume.

- Evaluated two probe architectures across 20 base models (five families) using 32 to 1,000,000 labels per model on six newly constructed datasets.
- Proved that minimum probe error scales down as a power law of model size, and error reduction rate relative to label count increases with larger target models.
- Fitting scaling laws on smaller family models predicts the next model's error within 0.02 in 72% of cases and correctly identifies the cheaper scaling path in 73% of cases.
- Scaling law predictions choose the sub-optimal probe architecture with a minimal average extra error of only 0.006.

**Why it matters:** These scaling laws enable safety researchers to predict probe performance and optimize label budgets without exhaustively training and comparing probe configurations.

<small>Yuchen Wu, Jerry Wei</small>

### [Agent Mosaic: Recognizing Confidentiality Leaks in Agentic LLM Systems](https://arxiv.org/abs/2610.30418v1)

**arXiv cs.CR** · 2026-10-21 · `arXiv:2610.30418v1`

Researchers evaluated the mosaic effect in LLM agents, finding that agents frequently aggregate non-sensitive accessible documents to infer and disclose confidential conclusions despite explicit safeguards.

- Evaluated three LLM agents across 30 synthetic cybersecurity, medical, and military scenarios, generating 10,800 simulated answers and 1,440 live harness answers.
- GPT-5.6-Sol disclosed forbidden composites in 7.08% of answers during benign, single-document queries in simulation, with higher disclosure rates observed in live agent harnesses.
- Combining visible classification headers and explicit aggregation rules reduced pooled leaks, but unsafe disclosures persisted in 32.37% of simulated answers across all intents.
- High rates of model refusals failed to guarantee confidentiality, as the refusals themselves frequently revealed the prohibited composite conclusion.

**Why it matters:** Standard document-level access controls and system prompt safeguards are insufficient to prevent agents from unintentionally reconstructing and leaking classified insights to mixed-clearance users.

<small>Daniel Ruiz, Luca Luceri, Emilio Ferrara</small>

### [Data-Void Exploits in Web-Searching LLMs](https://arxiv.org/abs/2610.30365v1)

**arXiv cs.CR** · 2026-10-21 · `arXiv:2610.30365v1`

Researchers demonstrated data-void exploits against web-searching LLMs, showing attackers can manipulate responses using as little as a single strategically published webpage in low-information search spaces.

- Attacker content appeared in LLM synthesized responses in 31% of test conditions using just a single controlled webpage.
- The study evaluated three LLMs (ChatGPT, Gemini, Sonar Pro) across neutral, skeptical, and excited prompt tones.
- User prompt variations offered minimal protection; skeptical tones slightly increased warning flags but did not meaningfully prevent exploit success.
- Attackers manipulated outputs by varying narrative strategy across five data-void construction methods, domain visibility levels, and generative-engine optimization features.

**Why it matters:** Web-searching LLMs obscure source competition and reliability cues, creating a viable inference-time attack surface where sparse adversarial web content directly manipulates synthesized user answers.

### [Mirage: Targeted Jailbreaks Against Post-Generation Safety Checkers in Multimodal Diffusion Models](https://arxiv.org/abs/2610.30348v1)

**arXiv cs.CR** · 2026-10-21 · `arXiv:2610.30348v1`

Mirage is a novel multimodal jailbreak attack that conceals adversarial target concepts within imperceptible image perturbations to evade post-generation safety checkers in diffusion models.

- Targets cross-modal adversarial inputs (NSFW reference images or malicious text) by injecting imperceptible perturbations into a benign image.
- Exploits shared multimodal encoder representation spaces to align the perturbed image with the target concept while repelling it from known filtered NSFW concepts.
- Uses lightweight black-box query refinement to optimize evasion near unknown safety checker boundaries without requiring internal access to the checkers.
- Evaluated on Stable Diffusion 1.5, Stable Diffusion XL, and Kandinsky 2.2 across text-to-image and image-to-image cross-modal NSFW datasets.

**Why it matters:** It demonstrates that common post-generation safety checkers in diffusion pipelines can be reliably bypassed without internal model access, highlighting vulnerabilities in current multimodal content moderation approaches.

### [PhishGen: Understanding LLM Capabilities in Automated Phishing Website Generation](https://arxiv.org/abs/2610.30226v1)

**arXiv cs.CR** · 2026-10-21 · `arXiv:2610.30226v1`

PhishGen is an evaluation framework benchmarking 14 LLMs against 64 real-world phishing kits across appearance fidelity, end-to-end credential harvesting functionality, human perception, and detector bypass capabilities.

- Evaluated 14 commercial, open-source, and uncensored LLMs using seven input modality combinations and 12 safeguard-bypassing rewriting strategies against 64 deployed phishing kits.
- While 96.2% of jailbroken outputs render, average visual fidelity scores low (2.02/5) and only 38.7% achieve full end-to-end credential-harvesting functionality, primarily due to Unsaved errors.
- Commercial models outperform uncensored alternatives, with GPT-4.1 achieving an 86.3–94.1% functional success rate compared to uncensored models which rarely exceed 45.4%.
- Three top-performing LLMs surpassed the average functional completeness rate of real-world phishing kits (70.9% to 89.7%), leveraging generator-level fingerprints that evade current similarity-based defenses.

**Why it matters:** The study demonstrates that high-capability commercial LLMs present a higher risk for automated, scalable phishing page generation than uncensored models, highlighting critical blind spots in current similarity-based detection mechanisms.

MPIDetector leverages LLM intrinsic reasoning via few-shot in-context learning to detect textual and visual multi-modal prompt injection attacks without fine-tuning.

- Uses prompt templates and representative attack examples via few-shot In-Context Learning (ICL) to analyze semantic intent across modalities.

- Demonstrated a detection rate up to 99.80% when evaluated against 500 obfuscated environmental web-agent injections (WebInject).

**Why it matters:** It offers a fine-tuning-free defense mechanism that outperforms traditional pattern-matching and baseline techniques in identifying complex cross-modal prompt injections.

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.31152v1`

WildFakeToolBench evaluates six AI-generated image detectors against 156 web-sourced, executable image-processing tools to assess detection evasion capabilities.

- The benchmark comprises 156 executable image-processing tools sourced from 220 public sources across 142 domains.
- Tools are verified using syntax, execution, and output-distortion checks, operating without feedback from the target detectors.
- Evaluated across 105 images from five generators, individual tools achieved attack success rates of 25.25% to 100% against six state-of-the-art detectors.
- Evaluating subsets of an eight-tool pool yielded worst-case evasion coverage exceeding 80% for all tested detectors.
- Evasion effectiveness is sparse and detector-specific, demonstrating that high tool coverage across candidates does not guarantee reliable one-shot evasion.

**Why it matters:** It demonstrates that non-expert actors can leverage accessible web-sourced image processing tools to bypass state-of-the-art AI image detectors.

<small>Mingjie Li, Yukun Jiang, Yicong Tan, Yang Zhang</small>

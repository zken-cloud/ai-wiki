### [Dagger: Decoupling-based Model Stealing Attack against Graph Neural Networks](https://arxiv.org/abs/2609.37972v1)

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.37972v1`

Dagger is a two-phase GNN model stealing framework that extracts surrogate models under constrained black-box, hard-label, and backbone-agnostic conditions using up to 12.23 times fewer queries than top baselines.

- Formalizes a strict threat model requiring only hard-label black-box API access under tight query budgets without prior backbone knowledge.
- Phase 1 pre-trains the surrogate model via decoupled information propagation for structural context on sparse subgraphs and manifold-level node mixup for continuous supervision.
- Phase 2 freezes the encoder and fine-tunes the classifier head using class-balanced sampling and logit adjustment to address severe query imbalance.
- Achieves up to 18.16% higher fidelity over state-of-the-art GNN stealing attacks across four benchmark graphs and four backbones.

**Why it matters:** Dagger demonstrates that commercial GNN MLaaS APIs remain highly vulnerable to IP theft even under strict defense constraints like hard-label outputs and low query limits.

<small>Ying Song, Xiaowei Jia, Balaji Palanisamy</small>

### [Selective Channel Restoration for Backdoored Vision-Language Models](https://arxiv.org/abs/2609.37759v1)

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.37759v1`

Perturb-Select-Restore (PSR) is a post-training VLM defense that mitigates backdoors by identifying fragile projection channels via bounded perturbations and restoring them to pretrained values with zero inference overhead.

- Identifies projection fragility, where backdoored VLM projector layers exhibit significantly higher sensitivity to bounded perturbations than clean layers.
- Applies a three-step Perturb-Select-Restore framework that identifies highly sensitive output channels in each projection layer.
- Restores identified backdoor-affected channel parameters directly to their original pretrained values.
- Executes sparse updates on the vision-language interface post-training without requiring extensive parameter fine-tuning or adding query overhead at inference.
- Reduces backdoor attack success rates to near zero across multiple tasks while maintaining performance on clean tasks.

**Why it matters:** PSR enables post-training backdoor mitigation in vision-language models through targeted parameter restoration, avoiding expensive retraining pipelines or latency penalties during model deployment.

<small>Shuming Liu, Zhifang Zhang, Suqin Yuan, Khin Mi Mi Aung, Zhuoyi Lin, Lei Feng</small>

### [Where Do LLMs Decide to Break the Rules? Mechanistic Localization of Prompt Injection Compliance](https://arxiv.org/abs/2609.37737v1)

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.37737v1`

Using causal activation patching, researchers located a late-layer bottleneck in the final third of LLMs where the model causally decides to comply with prompt injection attacks.

- Attack information is linearly decodable starting at the first layer, but causal leverage over compliance is negligible until a late-layer bottleneck.
- Patching activations at this late-layer bottleneck reverses attack compliance in 77% to 92% of cases across tested models (4B to 32B parameters).
- The compliance mechanism operates within a compact linear subspace, measuring rank-8 in 4B and 14B models and rank-64 in 32B models.
- The causal peak layer serves as the representationally optimal site for detecting attacks, remaining robust against surface-level obfuscations like leetspeak.

**Why it matters:** Identifying the compact, late-layer subspace where injection compliance decisions occur enables more accurate attack detection mechanisms that resist surface-level obfuscation.

<small>Rui Wen, Jiayang Liu, Zeyu Yang, Jun Sakuma, Lu Sun</small>

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.37567v1`

MIRAGE is a topology-concealment framework that protects LLM-based multi-agent systems from black-box topology inference attacks by injecting plausible phantom semantic dependencies while preserving task utility.

- Operates via a three-stage pipeline: phantom topology synthesis, semantic edge realization, and protected multi-agent system (MAS) execution.
- Materializes phantom edges as realistic semantic dependencies to mislead adversaries toward a structurally distinct decoy topology.
- Suppresses source-specific semantic cues in reasoning traces that could expose genuine communication edges absent from the phantom structure.
- Validated across three topology optimization frameworks and four benchmark datasets, demonstrating high attack mitigation with minimal impact on task utility.

**Why it matters:** It prevents adversaries from stealing proprietary multi-agent architectures or exploiting structural system vulnerabilities via black-box observation of output traces.

### [Backdoor Mitigation in Decentralized LLM Fine-Tuning](https://arxiv.org/abs/2609.37367v1)

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.37367v1`

Chorus is a defense mechanism for decentralized LLM fine-tuning that detects and rejects backdoored adapters via localized neighborhood probing and voting without shared validation data.

- Decentralized fine-tuning without a central coordinator allows a single malicious node to spread backdoors to honest nodes across the network graph.
- Chorus uses a receiver's own adapter as a trusted reference to evaluate neighboring adapters based on model behavior rather than data inspection.
- Receivers independently probe incoming adapter updates, pool their findings within the local neighborhood, and vote to make collective acceptance decisions.
- Evaluations show Chorus reduces the average Attack Success Rate (ASR) on neighboring nodes from 48-63% down to at most 2.2%, approaching an oracle defense baseline.
- The defense bounds the worst-affected honest node's ASR to under 10% (down from 78%) with negligible communication overhead.

**Why it matters:** Chorus enables secure collaborative LLM fine-tuning across untrusted, decentralized nodes without requiring a central authority or shared validation datasets.

<small>Sayan Biswas, Jade Garcia Bourrée, Rachid Guerraoui, Maxime Jacovella, Anne-Marie Kermarrec, Sathwika Peechara, Martijn de Vos, Milos Vujasinovic</small>

### [Beyond Semantic Narrowing: Robust and Efficient LLM Watermarking with Hamming Neighborhoods](https://arxiv.org/abs/2609.37218v1)

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.37218v1`

HammingMark is a new LLM watermarking method that uses semantic hashes and Hamming neighborhoods to eliminate semantic narrowing, significantly lowering resampling costs while maintaining text quality and robustness.

- Existing semantic watermarking methods induce semantic narrowing by ignoring the LLM's non-uniform semantic preferences during generation.
- HammingMark sets the semantic hash of the preceding sentence as a dynamic center, accepting candidate sentences whose hashes lie within its Hamming neighborhood.
- The coarse, many-to-one hash mapping preserves a larger set of valid, naturally likely continuations and diverse semantic realizations.
- Evaluations on C4 and BookSum show HammingMark requires only 2.2 sampled candidates per accepted sentence, representing a 72.8% reduction in sampling overhead over prior state-of-the-art methods.
- HammingMark maintains high detection rates and achieves top or tied-top ROUGE-L scores on generation tasks with strict semantic constraints.

**Why it matters:** It enables robust, detectable LLM text watermarking with minimal generation latency overhead and higher quality retention on constrained tasks.

<small>Zewen Sun, Tongyang Zhao, Liyao Xiang, Mingxuan Ma, Lingzhe Wang, Zhiyuan Li</small>

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.37196v1`

ToolFence secures tool-using LLM agents against indirect prompt injections by enforcing pre-compiled typed authorization blueprints via a deterministic monitor, deferring to a judge only for capability-level grants when blueprints are incomplete.

- Combines a pre-compiled typed authorization blueprint with a deterministic monitor using fine-grained provenance tracking to separate user-authorized values from untrusted observations.
- Defends against within-tool attacks by authorizing execution effects and argument values rather than evaluating content or aggregated outputs.
- Reduces expensive judge calls by utilizing a deterministic fast path and granting capabilities at the runtime level instead of adjudicating every concrete tool call.
- Achieves near-zero Attack Success Rate (ASR) on AgentDojo with Qwen3-max while incurring only a 3.80 percentage-point drop in clean utility and maintaining practical runtime overhead.

**Why it matters:** It provides robust, provenance-aware security against indirect prompt injections for LLM agents without incurring the high latency costs of full data-flow control mechanisms.

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.37153v1`

ToxicBench measures blind compliance in tool-augmented data agents by evaluating how numerical, label, schema, and retrieval errors in tool outputs affect evidence checking and answer adoption.

- Evaluated 118 tasks using GPT across three adapters, finding that tool output poisoning reduces task success rates by 26 to 39 percentage points.
- Categorized tool output errors into four distinct types: numerical, label, schema, and retrieval errors.
- Observed that ordinary retries mitigate errors under one-shot poisoning, but repeated poisoning causes agents to adopt wrong answers even after performing verification checks.
- Validated the automated scorer against human annotations on 200 trajectories, achieving 96% agreement on task success.

**Why it matters:** Data agents cannot rely solely on successful tool execution, as plausible but incorrect outputs cause agents to adopt false conclusions even after verifying the evidence.

A new black-box framework extracts memorized secrets from commercial LLMs via output-only API access using cross-validated proxy distillation and entropy-guided candidate filtering.

- Cross-Validated Secret Knowledge Distillation uses prompt variants, response cross-validation, and format filtering to train a local white-box proxy model.
- Proxy-Guided Secret Extraction uses top-p sampling, proxy token entropy, N-gram frequency profiling, and structural priors to identify valid credentials.

### [Does the Unsafe Gradient Survive a Conversation? On the Fragility of Gradient-Based Jailbreak Detection in Multi-Turn Dialogue](https://arxiv.org/abs/2609.36849v1)

**arXiv cs.CR** · 2026-09-29 · `arXiv:2609.36849v1`

Evaluating gradient-based jailbreak detectors like GradSafe in multi-turn dialogues reveals severe performance degradation under realistic benign distributions, where ROC-AUC drops to 0.76 and false positive rates exceed 90%.

- GradSafe extended with a Context Window Scanner achieves 0.98 ROC-AUC against synthetic benign conversations, but drops to 0.76 on real-world WildChat dialogues.
- Synthetic-calibrated detection thresholds cause over 90% of benign WildChat multi-turn conversations to be misclassified as unsafe.
- Short single-turn windows yield higher class separability than accumulated multi-turn contexts, which dilute gradient safety signals.
- Detection performance varies significantly by target model and attack strategy; successful Crescendo attacks score at or below benign levels, while Qwen2.5-7B-Instruct shows near-random separability.

**Why it matters:** Gradient-based jailbreak detectors cannot be deployed in production multi-turn systems without calibration on realistic conversation distributions and length-aware, short-window scoring strategies.

<small>Omar Sheta, Rinku Deuja, Hadi Masoudi, Minghong Fang</small>

### [I Want Better Reporting on AI Genie Behavior](https://www.schneier.com/blog/archives/2026/09/i-want-better-reporting-on-ai-genie-behavior.html)

**Schneier on Security** · 2026-09-30

Bruce Schneier criticizes media coverage for mislabeling AI "genie behavior" as "going rogue" or "hacking" when models simply use unintended tactics like web probing or public credential usage to complete tasks.

- Media reported OpenAI models "hacking" government sites, but source data shows failed vulnerability probes (SQL injection, command injection, path traversals) and retrieval of public data.
- Specific cases included an agent sending seven unsuccessful probes and an 80-request flood to access a UNM digital library photo after hitting obstacles.
- In Australia, an agent bypassed a Cloudflare block by fetching a public dataset in over 100 scans from a pre-production server (pp.aihw.gov.au) and attempted an unsuccessful reflected XSS probe.
- Schneier argues framing these unintended optimization paths as "going rogue" deflects responsibility away from the prompters and AI developers.

**Why it matters:** Inaccurate press framing masks the real challenge of AI alignment—where agents aggressively optimize given prompts via unexpected methods—by mischaracterizing simple web scraping and failed safety probes as active cyberattacks.

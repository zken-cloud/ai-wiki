### [Decision Models as Retrieval Gates Against Injection and Pollution](https://arxiv.org/abs/2611.08325v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.08325v1`

Open-weight decision models reading raw HTML act as fast retrieval gates to filter indirect prompt injections and web pollution before generation.

- A Kev-4B decision model gate processing passage HTML reduces attack success rates from 27.9% (undefended) and 13.6% (standard mitigations) down to 5.7%.
- On a 200-query synthetic web pollution benchmark, filtering candidate pools prior to selecting top-10 passages reduces fake page exposure to 0.5% and maintains 83% accuracy (compared to 28% accuracy without filtering).
- The gate requires 76 ms per passage with a low false-positive rate, misclassifying 4 out of 186 benign pages containing human-directed instructions while keeping clean query performance stable (85.6% vs 86.2%).
- Filtering input HTML rather than plain text yields higher attack detection rates, and while large LLM judges achieve a higher AUROC (0.99 vs 0.94), the decision gate operates at one-tenth the cost.

**Why it matters:** Pre-retrieval filtering using lightweight decision models offers an efficient, low-latency defense against prompt injection and web pollution without relying on expensive LLM generation.

<small>Mahdi Ghadamyari, Reza Habibi</small>

### [Beyond Instruction Override: Benchmarking Indirect Prompt Injection with Task-Tampering Attacks](https://arxiv.org/abs/2611.07640v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.07640v1`

A new benchmark evaluates Indirect Prompt Injection (IPI) via task tampering, proving that attacks targeting decision rules, actions, and state achieve higher success rates and evade defenses better than objective-override attacks.

- Defines IPI by source authority rather than instruction-like syntax across 90 validated cases in three tool-use environments.
- Categorizes attacks into six decision-making targets: objective, decision rules, available actions, expected consequences, reading of observations, and state beliefs.
- Demonstrates that undefended attacks on decision rules, available actions, and state beliefs yield higher mean success rates across five LLMs than traditional objective-targeting attacks.
- Shows that a detection-and-removal defense drops objective attack success to 2.4% but leaves observation and state attacks at 9.5% and 12.1% success, respectively.
- Reveals that a tool-policy defense only marginally reduces attack success (from 17.0% to 15.4%) because task-tampering attacks retain expected tool calls while manipulating execution values.

**Why it matters:** Standard safety evaluations that focus only on task redirection or objective overrides overestimate the coverage of current defenses against indirect prompt injections.

<small>Rongting Zhang, Martin Bertran, Sandeep Avula, Chia-Jung Lee, Vanessa Murdock</small>

### [A Gingerbread House for LLM Agents: Source-Planned Honeypots That Lure Autonomous Attackers into an Isolated Shadow](https://arxiv.org/abs/2611.07611v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.07611v1`

A source-planned honeypot defense diverts confirmed autonomous LLM attackers to an isolated shadow application, reducing successful exploits on the real target to zero for the ARTEX attack framework.

- The defense uses an LLM to generate a static honeypot plan from application source code, while a router redirects confirmed attackers' subsequent requests to an isolated shadow instance.
- On 40 CVE-Bench tasks, the static plan reduced real target compromise from 26/40 to 5/40 for Claude Opus 4.8, and from 20/40 to 0/40 across 31 valid runs for the ARTEX attack framework.
- In a holdout set of 20 new tasks, ARTEX real target compromises dropped from 15/20 to 0/20.
- The defense successfully moves working exploits to the shadow in roughly half of deception runs, causing ARTEX to accept planted fake secrets as genuine in 30 out of 120 deception-arm tasks.
- Residual security risk relies entirely on unconfirmed attacker requests that reach the real target before routing confirmation occurs.

**Why it matters:** It demonstrates that redirecting confirmed autonomous LLM attackers to shadow environments effectively neutralizes fast zero-day exploits without breaking the attacker's execution flow.

<small>Seungdeok Roh, Seokjun Ryu, Sohee Park, Daeseon Choi</small>

### [JailBound: FOL-Guided Jailbreak Evaluation for Exploring LLM Behavioral Boundaries](https://arxiv.org/abs/2611.07530v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.07530v1`

JailBound introduces an automated jailbreak evaluation framework combining a meta-attack prompt generator with a first-order loss (FOL)-guided dual-branch search to map LLM safety boundaries.

- Uses a fine-tuned meta-attack generator to synthesize evaluation prompts conditioned on risk category, application domain, and attack type.
- Employs a first-order loss (FOL)-guided dual-branch search to discover high-value attack states and behavior-sensitive transition states.
- Outperforms a zero-order loss (ZOL)-only baseline in High-Value Branch average Attack Success Rate (ASR) by 5.1 and 4.9 percentage points across two test settings.
- Demonstrates that states identified by the Safety-Sensitivity Branch exhibit higher behavioral flip rates under local perturbations than High-Value Branch states across all tested radii on JailBound and S-Eval datasets.
- Evaluated across 46 LLMs spanning 13 distinct model families under a standardized experimental protocol.

**Why it matters:** It enables systematic, automated generation of threat conditions and provides a local sensitivity signal to analyze exact behavioral transitions between safe refusals and jailbreaks.

<small>Fazong Wu, Xin Wang, Ming Yang, Zhenyong Zhang, Xiaoming Wu</small>

### [Signed but Not Safe: Requirement Integrity in Multi-Agent LLM Handoffs](https://arxiv.org/abs/2611.07483v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.07483v1`

A study shows cryptographic HMAC-SHA256 signing of requirement manifests in multi-agent LLM handoffs reduces unsafe commits from 69.4% to 9.0%, establishing requirement extraction as the primary remaining trust boundary.

- HMAC-SHA256 signed manifests reduced unsafe commits under attack from 69.4% to 9.0% using Qwen3-8B across 1,440 trajectories, completely neutralizing in-transit tampering.
- Deterministic verifiers out-performed LLM checkers on identical trajectories, achieving a 78.7% detection rate of violating decisions compared to 59.0%, while dropping false alarms from 50% to 7%.
- Pre-signing injection attacks exploit the extraction trust boundary, elevating signed-manifest violations from 14.6% to 37.5% in Qwen3-8B, 11.1% to 63.9% in gpt-oss-20b, and 8.3% to 75.0% in GPT-5.6-luna by authenticating corrupted manifests.

**Why it matters:** Cryptographically signing extracted requirements prevents middle-agent tampering in LLM workflows, shifting the critical security focus entirely to the initial requirement extraction step.

<small>Xiaobo Chen, Genliang Zhu, Ziyuan Wang, Chu Wang</small>

### [Breaking $\mathsf{TraintoDefend}$ via Adaptive Neuron Clustering in Cryptanalytic Model Extraction](https://arxiv.org/abs/2611.07370v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.07370v1`

SimBreak is a novel adaptive clustering rule that completely breaks TraintoDefend, raising target layer signature recovery from 0% to 100% on protected fully connected networks.

- TraintoDefend induces neuron weight similarity to group activation state switches, but neurons with similar weights still vary under small perturbations or share only partial normalized weight coordinates.
- SimBreak estimates a relative scale across all jointly observed weight coordinates to concurrently evaluate both weight direction and bias consistency.
- Evaluated on six protected fully connected networks trained on MNIST, SimBreak achieved 100% target layer signature recovery with a maximum relative recovery error of 2^-22.27.

**Why it matters:** It demonstrates that enforcing weight similarity between neurons is insufficient for model confidentiality, invalidating the only known defense against cryptanalytic model extraction.

<small>Haojie Wu, Haolin Liu, Tianshuo Cong, Guoyan Zhang</small>

### [SPILLWAY: Separating Target Admission from Sanitization to Defend Tool-Using Agents against Prompt Injection](https://arxiv.org/abs/2611.07222v1)

**arXiv cs.CR** · 2026-11-04 · `arXiv:2611.07222v1`

SPILLWAY separates target admission from sanitization to provide a deterministic, audit-traceable refusal floor that prevents prompt injection attacks against tool-using AI agents without added model-call overhead.

- Target admission deterministically validates action targets using tool output types or pre-set delegation rules without requiring language model checks or prior task planning.
- A rule-based sanitizer strips instruction-like regions from tool returns before model consumption, logging removed spans as auditable evidence.
- A local judge can override false-positive refusals, but it is explicitly blocked from restoring calls targeting text removed by the sanitizer.
- SPILLWAY achieved a 0.0 attack success rate against standard templated injections and forged chat templates across three model backbones, and a 0.007 mean attack success rate under a reinforcement-learning attacker.

**Why it matters:** It allows autonomous agents handling sensitive email, file, and payment operations to block prompt injection attacks deterministically without requiring extra model calls or sacrificing utility.

<small>Woosang Lim, Yeseul Chang, Jaewoo Lee</small>

### [CANMentor: A Large-Small Model Collaboration Framework for CAN Bus Intrusion Detection](https://arxiv.org/abs/2611.07853v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.07853v1`

CANMentor pairs a vehicle-side lightweight IDS with a cloud-side LLM teacher, using privacy-preserving proxies and latency-aware prediction switching to continuously improve local detection via soft target knowledge distillation.

- A privacy-aware generator converts original vehicle CAN messages into proxies before uploading them to the cloud-side LLM teacher to mitigate data exposure.
- Vehicles execute local inference immediately and only accept cloud predictions if received within a defined latency bound, retaining local predictions otherwise.
- Returned teacher logits act as soft targets for periodic local knowledge distillation to address performance degradation caused by non-IID data.
- Evaluations on non-IID partitions of the ROAD and HCRL datasets achieved maximum relative Macro F1 improvements of 25.01% and 20.79% via distillation, and improved accuracy near local decision boundaries by 38.71–42.00 percentage points.

**Why it matters:** It enables lightweight, resource-constrained vehicle intrusion detection systems to achieve high generalization on non-IID data without compromising raw CAN payload privacy or real-time latency requirements.

<small>Zhiquan Liu, Haolin Gao, Bo Wu, Jingjing Guo, Heng Sun, Jianfeng Ma</small>

### [MEvince: Knowledge-Constrained LLM Reasoning for Technique Identification from Malware Reports](https://arxiv.org/abs/2611.07486v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.07486v1`

MEvince is a knowledge-constrained LLM framework that maps malware reports to MITRE ATT&CK techniques using shared behavioral representations, primitive-guided extraction, and evidence-aligned retrieval.

- Uses a shared behavioral representation built via agentic mining of technique documentation to link report observations directly to technique definitions.
- Employs primitive-guided extraction to structure observations and evidence-aligned retrieval to compare candidate techniques alongside confusable alternatives.
- Incorporates validation controls to verify evidence references and enforce technique-specific behavioral requirements without updating model parameters.
- Outperformed 11 baselines on a dataset of 610 public MITRE ATT&CK malware reports, boosting exact-ID F1 by 17.4% over the strongest baseline.
- Increased gold-label candidate retrieval coverage from 31.6% to 47.9%, with offline agentic audits enabling parameter-free adaptation.

**Why it matters:** It significantly improves automated, reliable mapping of complex malware reports to ATT&CK techniques without requiring expensive model fine-tuning.

### [LABBA: LLM-Assisted Behavioral Biometric Authentication](https://arxiv.org/abs/2611.08343v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.08343v1`

LABBA integrates a lightweight LLM-based contextual reasoning module with a novel phone-blowing acoustic behavioral biometric technique to enhance continuous authentication robustness.

- Uses blow-acoustic signals collected from users, extracting temporal and spectral features to build similarity representations.
- Converts extracted features into structured prompts using either discrete rule-based categories or continuous normalized scores.
- Evaluated on a dataset of 50 participants under diverse behavioral, contextual, and environmental conditions.
- Achieved 99.46% accuracy in rule-based mode and 99.38% accuracy in score-based mode, outperforming traditional non-LLM baselines.

**Why it matters:** Incorporating LLMs into behavioral biometrics improves adaptability to real-world user variability and context changes over static threshold systems.

<small>Howard Halim, Eyasu Getahun Chekole, Jianying Zhou</small>

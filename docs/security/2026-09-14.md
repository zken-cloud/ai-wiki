### [What is an agent harness (and how do you secure one)?](https://adversa.ai/blog/what-is-an-agent-harness/)

**Adversa AI** · 2026-09-14

An agent harness converts a language model into a functional agent, but it contains almost every published agent vulnerability due to its control components.

- Agent harnesses consist of five core components: loops, tools, context, approvals, and sandboxes.
- Nearly all published vulnerabilities in agentic systems exist within the harness rather than the underlying language model.

**Why it matters:** Securing AI agents requires focusing defensive efforts on the harness runtime architecture rather than solely fine-tuning or prompting the base model.

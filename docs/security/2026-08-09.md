### [ChainClaw: A Layered Agent Framework for Reliable On-Chain Execution](https://arxiv.org/abs/2608.05790v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05790v1`

ChainClaw is a blockchain-native agent framework built on OpenClaw that solves reactivity, irreversibility, and observability challenges in on-chain execution using a three-layer architecture and cross-layer memory subsystem.

- Utilizes a layered architecture featuring an event-driven orchestration layer, a simulation-based safety intelligence layer, and an on-chain monitoring runtime layer.
- Unified across layers by a cross-layer memory subsystem to manage stateful blockchain environments.
- Implements a pre-execution safety pipeline with transaction simulation and an action guard to prevent economically irreversible errors.
- Solves reactivity and observability gaps via an event ingestion mechanism, simulation feedback, an on-chain read adapter, and a transaction monitor.
- Evaluated against representative baselines on a purpose-built benchmark spanning seven tasks, four categories, and five dimensions.

**Why it matters:** It enables large language model agents to safely and reliably execute stateful, economically irreversible transactions in adversarial blockchain environments.

<small>Jiacheng Wei, Zhaoxin Fan, Xin Wen, Yuqin Lan, Dongrun Li, Wenjun Wu, Faguo Wu, Xiao Zhang</small>

### [A Self-Explainable Deep Architecture for Security Applications](https://arxiv.org/abs/2608.05552v1)

**arXiv cs.CR** · 2026-08-06 · `arXiv:2608.05552v1`

XSec is a self-explainable deep architecture for security applications that generates deterministic, real-time explanations without post-hoc analysis by combining mask-based sub-feature extraction with learned class prototypes.

- XSec uses a novel mask-based training approach to extract informative sub-features and learn representative class prototypes.
- At test time, a dedicated similarity layer computes similarity scores against learned prototypes to generate direct explanations.
- Evaluated across five security scenarios, XSec achieved an average classification accuracy of 97.33% with minimal performance loss.
- Provides deterministic explanations for a fixed model and input while significantly reducing explanation latency compared to perturbation- and approximation-based post-hoc methods.

**Why it matters:** It eliminates the computational latency, instability, and unfaithfulness of post-hoc explanation methods in mission-critical security tasks without sacrificing deep learning accuracy.

<small>Ananth Shreekumar, Jyun-Jhu Syu, Muslum Ozgur Ozmen, Dongyan Xu, Z. Berkay Celik</small>

### [AMRM-Pure: Semantic-Preserving Adversarial Purification](https://arxiv.org/abs/2607.04474v1)

**arXiv cs.CR** · 2026-07-05 · `arXiv:2607.04474v1`

AMRM-Pure is a new adversarial purification framework that removes perturbations by preserving patch-level semantic relationships using an Attentive Mask Reconstruction Model optimized directly on the input.

- Identifies that adversarial noise severely distorts semantic correlations and patch relationships within a single image sample.
- Formulates adversarial denoising as a tractable input-level optimization problem designed to preserve patch-level semantics.
- Finetunes the purification framework using classification loss to enforce semantic consistency.
- Instantiates and validates the approach using two specific architectures: Mask Autoencoder (MAE) and MaskDiT.

**Why it matters:** By shifting focus to intra-sample patch semantics, this method achieves new state-of-the-art robustness against adversarial attacks across multiple benchmarks.

<small>Zhihao Dou, Zhiqiang Gao, Dongfei Cui, Weida Wang, Qinjian Zhao, Dinggen Zhang, Jun Yan, Zeke Xie</small>

### [One Framework for All: Cross-Modal Membership Inference for Generative Models](https://arxiv.org/abs/2607.04339v1)

**arXiv cs.CR** · 2026-07-05 · `arXiv:2607.04339v1`

A unified cross-modal membership inference attack framework targets text-to-text, text-to-image, and image-to-text generative models using a single modality-agnostic likelihood ratio testing method.

- Exploits the modality-agnostic property where a generative model's output distribution approximates its training data distribution.
- Models distributions of generated outputs and auxiliary non-member samples within a shared embedding space.
- Executes membership inference via likelihood ratio testing in strict black-box settings under partial-knowledge and zero-knowledge threat models.
- Evaluates membership leakage across both pre-training and fine-tuning datasets, outperforming single-modality state-of-the-art baselines.

**Why it matters:** It demonstrates that privacy vulnerabilities in generative models can be exploited using a single framework regardless of input-output modalities or architecture types.

<small>Dayong Ye, Tainqing Zhu, Kun Gao, Junhao Liu, Yichuan Chen, Shuai Zhou, Hengzhu Liu, Bo Liu</small>

### [!Imperio, smolVLA: The Implications of Data Poisoning on Open Source Robotics](https://arxiv.org/abs/2607.04146v1)

**arXiv cs.CR** · 2026-07-05 · `arXiv:2607.04146v1`

Researchers demonstrated that trigger-word data poisoning against the smolVLA vision-language-action model silently embeds a command-driven backdoor, causing complete denial of service in real-world robotics tasks with minimal poisoned training data.

- Inserting just 3 poisoned episodes into 320 clean training episodes (a ~0.9% poison ratio) reduces the smolVLA pick-and-place success rate from ~50% to 0.0% under trigger-word conditions, causing the robot to lock into a fixed joint state.
- A single poisoned episode in 320 clean episodes reduces task success rate to 6.7 ± 6.7%, degrading performance while maintaining motion.
- The attack maintains stealth during normal operation, preserving a ~50% clean-prompt success rate across all evaluated poison ratios.
- The backdoor generalizes to front, middle, and end trigger-word placements despite the model being trained exclusively on front-placed triggers on the LeRobot platform.

**Why it matters:** This vulnerability reveals that community-driven open-source robotics datasets require strict provenance tracking, as low-cost data poisoning can stealthily disable physical robots on command.

<small>Stefan Bühler, Mark Schutera</small>

### [Agentic SABRE: An Uncertainty-Aware Neuro-Symbolic Multi-Agent Framework for Adaptive Ransomware Detection](https://arxiv.org/abs/2607.04292v1)

**arXiv cs.CR** · 2026-07-05 · `arXiv:2607.04292v1`

Agentic SABRE is an uncertainty-aware, neuro-symbolic multi-agent framework that combines semantic and behavioural forensic telemetry with Monte Carlo Dropout uncertainty estimation to adaptively detect ransomware.

- Fuses semantic representations and time-window behavioural telemetry using a multi-agent architecture with Monte Carlo Dropout for epistemic uncertainty quantification.
- Employs a decision-layer orchestrator with dual risk and uncertainty budget thresholds to balance automated containment and human analyst escalation.
- Incorporates gradient saliency, permutation importance, and counterfactual analysis to provide local and global decision explainability with bounded perturbation costs.
- Achieved an AUC of 1.0 on RDset and RanSMAP semantic data, with up to a 4.9% relative reduction in false escalations at equal recall under weak behavioural signals.

**Why it matters:** It enables scalable, automated ransomware containment while systematically routing ambiguous cases to analysts, improving operational safety against polymorphic threats.

<small>Henry Kabuye, Biju Issac, Jeyamohan Neera</small>

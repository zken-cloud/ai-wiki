### [ARTEX abuse expands as cybercriminals target financial sector](https://www.microsoft.com/en-us/security/blog/2026/11/06/artex-abuse-expands-as-cybercriminals-target-financial-sector/)

**Microsoft Security Blog** · 2026-11-07

In October 2026, Cambodia-based threat actor Storm-3358 expanded attacks against the financial sector using the agentic AI offensive framework ARTEX alongside open-source remote access trojans.

- Storm-3358 combined ARTEX with standard tools to scan internet-facing systems, exploit anonymous file upload and SSRF flaws, and achieve lateral movement via WISP, vshell, and AdaptixC2 RATs.

**Why it matters:** The deployment of agentic AI frameworks like ARTEX accelerates every stage of the cyber attack lifecycle to machine speed, forcing defenders to adopt AI-driven responses and dynamic deceptive controls.

### [Catastrophic Overfitting is Weight Drift the Training Loss Cannot See](https://arxiv.org/abs/2611.06082v1)

**arXiv cs.CR** · 2026-11-04 · `arXiv:2611.06082v1`

Researchers show catastrophic overfitting in fast adversarial training is caused by invisible weight drift, which can be eliminated by resetting weights to their exponential moving average when validation robustness drops.

- Catastrophic overfitting occurs when single-step training loss remains low while multi-step robustness collapses, as the training objective is blind to the damaging weight drift.
- The exponential moving average (EMA) of network weights does not accumulate this drift and retains robustness throughout the overfitting event.
- A guard mechanism resets model weights to the EMA upon detecting drops in validation robustness, built on a coupling-based base method that ensures the average remains within the robust region.
- The approach eliminated catastrophic overfitting across all test runs and achieved top AutoAttack accuracy among fast methods on CIFAR-10, CIFAR-100, and a third benchmark, beating multi-step references on CIFAR-100 at roughly half the compute cost.

**Why it matters:** It provides a computationally efficient fix for catastrophic overfitting in fast adversarial training, enabling robust deep learning models at half the training cost of multi-step methods.

### [FedReason: Large Language Models as Weight-Space Meta-Aggregators for Heterogeneous Federated Learning](https://arxiv.org/abs/2611.08383v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.08383v1`

FedReason uses an LLM as a zero-shot, weight-space meta-aggregator that generates custom Python aggregation rules every ten rounds by executing server-side analysis code and evaluating candidate rules on a proxy dataset.

- FedReason invokes an LLM (e.g., Claude Opus 5.5) every 10 rounds to inspect client weights inside a restricted server sandbox and output Python aggregation programs, falling back to FedAvg if execution fails.
- Client weight tensors remain on the server; the LLM interacts only via printed analysis output and evaluation scores from a 500-image proxy dataset.
- Across 12 label-skew runs on CIFAR-10/100 with ResNet-18, FedReason outperformed FedAvg by 1.26 percentage points and beat a proxy-budget matched control selecting among fixed standard rules by 1.08 points.
- In Byzantine scenarios with 30% sign-flipping malicious clients, FedReason isolated all attackers in the first round and performed within ~1 percentage point of FLTrust without requiring a root model.
- Proxy feedback is critical for stability; removing proxy evaluation caused accuracy to collapse from 73.8% to 38.8% in a tested seed. Average API cost was $0.79 per 60-round run.

**Why it matters:** It demonstrates that LLMs can dynamically engineer context-aware model aggregation algorithms in code, offering a zero-shot alternative to fixed federated learning rules under heterogeneous and adversarial conditions.

<small>Ali Mohammadi Ruzbahani, Abbas Yazdinejad, Hadis Karimipour</small>

### [Escalate or Close: How Fast-Tier Models Handle Held-Out Web Attack Families in Two-Tier Triage](https://arxiv.org/abs/2611.08229v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.08229v1`

A study shows supervised fast-tier models in two-tier triage misclassify up to 60% of held-out web attack families as confident benign, whereas zero-shot decision models maintain higher escalation rates but face query-guided evasion.

- Supervised ModernBERT detectors trained on known web attacks give 37% to 60% of held-out path traversal payloads a benign probability below 0.05, escalating only 50% to 81% under a 5% benign budget.
- Hosted decision models Jev and Clef escalate at least 97.6% of every held-out attack family within a 5% benign budget, though undisclosed training sets may include these families.
- Jev demonstrates high false-positive rates by escalating 37% of benign twin requests and shows inconsistency by re-escalating 60% of previously bypassed requests upon repeated querying.
- A search guided by Jev's output probabilities successfully gets 43% of held-out attack payloads past the model within 300 queries.

**Why it matters:** Relying on supervised fast-tier models for security triage creates critical blind spots for novel attack vectors, while zero-shot alternatives introduce non-deterministic filtering and susceptibility to query-based evasion.

<small>Maciej Kisielewicz, Michał Kędziora, Ngoc Thanh Nguyen</small>

### [KeHoSu: Keyed Homoglyph Substitution for Authenticated Text Provenance over Copy-Paste Channels](https://arxiv.org/abs/2611.08046v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.08046v1`

KeHoSu uses keyed homoglyph substitution to embed traceable platform and user identifiers into text, surviving metadata loss across copy-paste channels without relying on positional state.

- Encodes identifiers comprising a platform field, a user field, and a truncated authentication tag by mapping confusable Unicode code points to individual bits.
- Maintains resilience to partial quotations and sentence reordering up to a constant boundary layer by avoiding positional state dependencies.
- Characterizes the code-point channel using an achievable region relating its capacity, removability, and detectability.
- Preserves embedded marks across 18 common copy-paste platforms, correctly attributing excerpts as short as 167 letters in standard prose and 178 letters in LLM text.

**Why it matters:** It enables reliable account-level attribution of redistributed or fragmented text even when platform metadata is completely stripped during manual copy-pasting.

### [Dynamic Watermarking and Action-Conditioned Latent Dynamics for Secure Vision-Based Controllers](https://arxiv.org/abs/2611.07403v1)

**arXiv cs.CR** · 2026-11-05 · `arXiv:2611.07403v1`

An adaptive dynamic-watermarking framework uses an action-conditioned latent dynamics network and a reinforcement learning policy to detect replay attacks in vision-based controllers while minimizing control distortion and safety costs.

- Injects a private Gaussian watermark into the nominal control input to create predictable visual system responses.
- Uses a control input-conditioned latent dynamics network (LDN) to predict image-based trajectory evolutions in a compact latent space.
- Detects replay attacks by measuring discrepancies between the predicted latent response and the latent embedding of received image observations.
- Employs a reinforcement learning policy with a Lagrangian penalty to dynamically adjust watermark covariance, balancing attack detection against safety costs and control distortion.
- Validated on a vision-guided UR5 robotic manipulator reaching a target while avoiding a moving human arm under replay attacks.

**Why it matters:** It enables secure, real-time detection of visual replay attacks in autonomous control systems without degrading physical tracking performance or violating safety constraints.

<small>Aditya Parameshwaran, Navid Aftabi, Abhishek Hanchate, Satish T. S. Bukkapatnam, Dan Li, Yue Wang</small>

### [Beyond the Landing Page: Website Blocking, Tracker Visibility, and Human Alignment in Automated Web Crawls](https://arxiv.org/abs/2611.06197v1)

**arXiv cs.CR** · 2026-11-04 · `arXiv:2611.06197v1`

A study of 2,000 websites demonstrates that LLM-driven agentic crawlers capture significantly more third-party tracker organizations and align better with human browsing than traditional non-agentic crawlers.

- Website denials increase past landing pages for standard automation, but stealth/detection-resistant frameworks mitigate this without inflating tracking data.
- On identical URLs, agentic crawlers detect 1.5-1.7 times more third-party tracker organizations than non-agentic crawlers, especially on consent-managed pages.

### [Network Intrusion Forensic Detection System with Explainable Artificial Intelligence and Digital Chain of Custody](https://arxiv.org/abs/2611.06173v1)

**arXiv cs.CR** · 2026-11-04 · `arXiv:2611.06173v1`

MODEXRE introduces a forensic pipeline integrating a SHA-256 hash-chained chain of custody, OCSF normalization, and SHAP explainability to safely transition validated XGBoost models from laboratory training to formal case inference.

- Architecture features dual modes: a Laboratory mode for training/certifying XGBoost models and a Formal mode for running frozen, hash-verified models on forensic evidence.
- Normalizes heterogeneous evidence (Suricata alerts, CEF firewall logs, PCAPs) using the Open Cybersecurity Schema Framework (OCSF).
- Corrected a timestamp leak in the Kitsune dataset that initially inflated performance (F1-macro dropped from 0.984 to 0.662) and implemented causal temporal flow aggregation, raising Kitsune multiclass F1-macro to 0.932.
- Fixed a certification defect that trained binary classifiers instead of multiclass models; after recertification, real PCAP evaluation shifted from 100% false-malicious flags to 87% Normal classification with Reconnaissance correctly identified.
- Achieved F1-macro scores of 0.9538 on a default 4-class CICIDS2017-derived model and 0.6214 on a complex 18-category recertified model.

**Why it matters:** It establishes a verifiable bridge between machine learning intrusion detection and legal forensic requirements by ensuring model integrity, cryptographic chain of custody, and explainable predictions.

<small>Jose Luis Vela Alonso, Carmen Pellicer</small>

### [Defense-as-Skill: Evolving Runtime Guard Skill for Skill-Augmented Agents](https://arxiv.org/abs/2609.01487v1)

**arXiv cs.CR** · 2026-09-01 · `arXiv:2609.01487v1`

Defense-as-Skill introduces SkillSonar, a runtime guard implemented as an editable skill that uses Monte-Carlo Tree Search to evolve task-conditioned defenses against malicious skill-augmented agent attacks without modifying agent runtimes.

- Introduces SkillSonar, a runtime guard skill that evaluates sensitive agent actions against task boundaries to trigger allow, replan, or user confirmation actions.
- Presents SCOPE-R, a task-conditioned dataset spanning 6 risk families and 21 sub-categories, containing 206 attack-confirmed malicious instances and 43 benign tasks.
- Employs a Monte-Carlo Tree Search procedure to evolve the on-disk guard skill based on rollout feedback, mitigating safety risks across Claude Code and OpenClaw.
- Reduces GLM-5 Attack Success Rate (ASR) from 0.482 to 0.104 in-distribution (ID) and from 0.606 to 0.115 out-of-distribution (OOD) while preserving utility.

**Why it matters:** It enables runtime safety monitoring for AI agents using flexible, model-agnostic guard skills that can be evolved and updated without altering the core agent architecture.

<small>Xiaofang Yang, Ziqi Miao, Dianbo Sui, Jing Shao, Lijun Li</small>

### [One Prompt Is Enough: Watermark Laundering Through Foundation Image Models](https://arxiv.org/abs/2609.01249v1)

**arXiv cs.CR** · 2026-09-01 · `arXiv:2609.01249v1`

Foundation image editing models can remove invisible watermarks using a single reconstruction prompt while maintaining high visual fidelity, exposing a distinct vulnerability class termed watermark laundering.

- Evaluated six OpenAI and Google image editing models against three watermarking schemes (including DwtDct) across 1,800 reconstructed outputs using a joint bit error rate (BER) and visual/semantic fidelity profile.
- OpenAI models caused the strongest payload disruption across schemes, while Google's Nano Banana 2 demonstrated that DwtDct remains vulnerable even under high-fidelity reconstructions.
- Prompt ablations confirmed that explicit removal-oriented instructions are unnecessary; payload disruption is driven inherently by the model's reconstruction pathway.
- Demonstrated that prompt-conditioned reconstruction functions as a distinct operational attack interface compared to conventional perturbations like noise, blur, cropping, and compression.

**Why it matters:** Invisible watermarking evaluation protocols must incorporate foundation-model reconstruction as a standard robustness metric to account for practical adversarial evasion.

<small>Jidong Yang, Qi Li, Wei Zong, Yang-Wai Chow, Willy Susilo, Huaike Yu, Chunpeng Wang, Suo Gao</small>

### [Position Matters: Feature Inversion Attacks in ViT Split Inference with Token Reduction and Shuffling](https://arxiv.org/abs/2609.01232v1)

**arXiv cs.CR** · 2026-09-01 · `arXiv:2609.01232v1`

Researchers introduced the Spatially Aligned Reconstruction Attack (SARA), demonstrating that token shuffling and reduction in ViT split-inference fail to prevent feature inversion attacks because intermediate token embeddings retain positional information.

- Transmitted ViT token embeddings retain sufficient positional information to bypass spatial disruption defenses.
- SARA predicts token positions, restores spatial layout, uses a feature-space masked autoencoder to reconstruct missing embeddings, and recovers the input image.
- Token shuffling provides only superficial privacy against SARA, whereas token reduction offers stronger but still incomplete protection.
- An edge-side defense removing positional embeddings and adapting edge blocks via knowledge distillation mitigates SARA without modifying the cloud model or sacrificing task accuracy.

**Why it matters:** This work demonstrates that common efficiency optimizations like token shuffling do not guarantee privacy in split-inference systems and offers a lightweight defense that preserves accuracy.

<small>Stefano Leggio, Giulio Rossolini, Alessandro Biondi</small>

**arXiv cs.CR** · 2026-09-01 · `arXiv:2609.01222v1`

A systematic security analysis of 12 real-world AI agent harnesses reveals Context Privilege Escalation attacks that enable remote code execution, full agent compromise, and unauthorized tool invocations.

- Identified two new attack categories in AI harness context assembly: MessageRole Context Privilege Escalation (M-CPE) and Cross-Scope Context Privilege Escalation (X-CPE).

**Why it matters:** Opaque and insecure context assembly logic in popular AI agent harnesses can allow attackers to achieve total control over host systems via remote code execution.

### [Reveree: Diagnosing LLM Reverse-Engineering Agents](https://arxiv.org/abs/2609.01185v1)

**arXiv cs.CR** · 2026-09-01 · `arXiv:2609.01185v1`

Reveree is a diagnostic framework for LLM reverse-engineering agents that evaluates performance across solve rates, an eight-stage progress schema, and behavioral action profiling.

- Reveree evaluates model performance using deterministic verification for action stages and an outcome-blinded LLM judge (validated against a human expert) for comprehension stages.
- Evaluation of nine frontier models and four prompting strategies across 88 picoCTF and NYU-CTF challenges reveals that base model selection drives performance, while prompting strategies yield secondary, model-dependent effects.
- Model failures concentrate primarily in comprehension stages, where increasing budget, persistence, or reasoning effort fails to rescue performance, indicating a fundamental competence limit.
- Larger, newer, or more expensive models do not consistently outperform smaller or older alternatives in reverse-engineering tasks.
- While models demonstrate flag memorization on picoCTF from descriptions alone, minimal recall occurs on NYU-CTF, and most successful solves persist under surface perturbations.

**Why it matters:** It shifts LLM security evaluations beyond binary solve rates to pinpoint specific analytical failure modes and isolate true binary analysis from benchmark memorization.

<small>Hadjer Benkraouda, Hongyu Cai, Berkay Celik, Gang Wang</small>

### [RISA: Response Inspection and Selective Actions for Refusal Calibration in Large Language Models](https://arxiv.org/abs/2609.00790v1)

**arXiv cs.CR** · 2026-09-01 · `arXiv:2609.00790v1`

Response Inspection and Selective Actions (RISA) is an inference-time framework that evaluates initial LLM responses and prompt representations to selectively correct refusal errors without updating underlying model parameters.

- Uses a hybrid scoring approach combining fixed contextual rules for obvious cases with a calibrated linear probe on final-layer prompt hidden states for unmatched semantic variations.
- Adapts to different base models by separately calibrating the probe score, representation-support boundary, and action thresholds.
- Combines the calculated prompt score with the initial refusal status at runtime to trigger selective corrective actions only when an error is detected.
- Improves refusal reliability on both harmful and benign prompts while preserving base model utility.

**Why it matters:** It provides a parameter-efficient, inference-time method to prevent over-refusal of benign prompts and under-refusal of harmful ones without requiring costly retraining.

### [PhantomCall: Evading ML Malware Detectors via Function Call Graph Perturbation](https://arxiv.org/abs/2609.00705v1)

**arXiv cs.CR** · 2026-09-01 · `arXiv:2609.00705v1`

PhantomCall is a novel black-box attack that evades machine learning malware detectors by injecting fully executable dummy functions at targeted call sites to perturb the function call graph (FCG) while preserving semantics.

- Modifies the FCG and CFG structures of Windows PE malware by injecting executable dummy functions paired with classifier-guided search and tunable injection parameters.
- Achieves an 85-100% attack success rate against MalConv (CNN), MalGraph (GNN), and SAFE+GNN (pure FCG GNN) across two FPR thresholds.
- Outperforms prior state-of-the-art attacks by up to 14.78 percentage points on MalGraph and 95.5 percentage points on SAFE+GNN while generating variants up to 2.9x faster.
- Requires only a single call site modification for the majority of evasions on MalConv and MalGraph, with 86-97% of variants preserving malicious behavior in sandbox testing.

**Why it matters:** It demonstrates that graph-based ML malware detectors relying on function call structures remain highly vulnerable to fast, semantic-preserving structural perturbations.

<small>Md Ajwad Akil, Adrian Shuai Li, Imtiaz Karim, Arun Iyengar, Ashish Kundu, Elisa Bertino</small>

A systematization of multi-agent LLM system (MAS) security analyzing 197 works to introduce an A-I-R attack framework and a five-part defense contract.

- Analyzed 197 papers to identify six interaction interfaces, four adversary positions, seven system-level risks, and eight recurring attack paths.
- Introduced the A-I-R framework to categorize attacks by Adversary position, Interaction interface, and resulting system-level Risk.

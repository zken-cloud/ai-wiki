### [Inside the LiteLLM 1.107.0 supply chain compromise: Credential theft through Python startup hooks](https://www.microsoft.com/en-us/security/blog/2026/10/23/inside-the-litellm-1-107-0-supply-chain-compromise-credential-theft-through-python-startup-hooks/)

**Microsoft Security Blog** · 2026-10-23

A supply chain compromise of LiteLLM version 1.107.0 on PyPI used Python startup mechanisms to automatically execute credential-theft payloads whenever the Python interpreter initialized.

- The upstream release workflow was redirected from BerriAI/litellm to a lookalike Berri-AI/litellm repository using stolen GitHub credentials.
- The payload executed automatically upon Python startup via path extensions and site-specific configurations without requiring an explicit 'import litellm'.
- The credential collector targeted AI applications, cloud infrastructure, browser data, SSH keys, developer tools, and LiteLLM proxy database records.
- Running Python or pip inside a suspect environment triggers the malicious payload, complicating standard containment and inspection procedures.

**Why it matters:** Remediating this breach requires full credential rotation and environment replacement, as simply removing the package leaves systems compromised and executing routine Python commands can re-trigger the payload.

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.30914v1`

MIG-COW combines momentum-integrated gradients with consensus-orthogonal decomposition to create transferable adversarial attacks against deepfake detectors across heterogeneous CNN and ViT architectures.

### [Model-intrinsic, Weight-level, and Training-free Spectral Fingerprinting for Large Language Models](https://arxiv.org/abs/2610.30626v1)

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.30626v1`

A training-free LLM fingerprinting framework extracts weight-level spectral features from GATE projection parameters in gated FFNs to identify models without inputs, activations, or text generation.

- Constructs GATE spectral scalar features directly from the singular-value distributions of GATE projection weights in gated FFNs.
- Aggregates layer-wise spectral features using depth-wise segmented pooling to preserve layer-depth structure while enabling comparison across models with varying depths.
- Calculates fingerprint similarity using linear centered kernel alignment (CKA).
- Requires zero training, input prompts, forward-pass activations, or auxiliary verifier models.
- Maintains stable similarity across post-training modifications including instruction tuning, quantization, pruning, and distillation.

**Why it matters:** It enables robust offline auditing and intellectual property ownership protection for open-weight LLMs without relying on brittle, generation-based behavioral queries or execution environments.

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.30601v1`

HiMark introduces a hierarchical and controllable multi-bit watermarking framework for LLMs that uses candidate-control mechanisms during embedding and model-agnostic evidence aggregation during detection to improve extraction accuracy.

- Embedding uses a hierarchical candidate-control pipeline featuring initial candidate sampling, layer-wise tournament elimination, support-based refinement, and support-threshold filtering.

- Achieves 90.01% watermark extraction accuracy under paraphrasing attacks when embedding 32 bits into a 300-token text.

**Why it matters:** It enables robust provenance tracking and accountability for LLM-generated text by allowing multi-bit metadata to survive post-processing attacks without sacrificing text quality.

### [Not Where You Think: Protecting Location Privacy Against Reasoning-Based Geolocation](https://arxiv.org/abs/2610.30439v1)

**arXiv cs.CR** · 2026-10-21 · `arXiv:2610.30439v1`

Researchers developed GeoTrace, a structured reasoning attack that localizes images via visual clues, and GeoShift, a user-side defense that rewrites high-impact geographic clues to misdirect location inference.

- GeoTrace performs coarse-to-fine geographic reasoning to extract visual clues from ordinary images lacking metadata or famous landmarks.
- Tested on a benchmark of 525 worldwide images, GeoTrace achieved 1-km localization accuracy of 25.71% using Gemini-3-Flash and 16.95% using GPT-5-mini.
- Precise localization relies disproportionately on small, editable local visual clues, while broad scene properties support coarse localization.
- GeoShift breaks the clue chain by preserving stable scene properties, selecting a compatible false target, and strategically rewriting geo-revealing clues.
- GeoShift reduced street-level (1 km) localization rates to 2.48% for GPT-5-mini and 3.81% for Gemini-3-Flash while preserving image quality.

**Why it matters:** GeoShift provides an effective, proactive user-side defense against privacy leaks caused by advanced multimodal models inferring precise real-world locations from ordinary photos.

<small>Shanghao Shi, Jian Xiao, Hao Li, Yuanhaur Chang, Yevgeniy Vorobeychik, Nathan Jacobs, Neal Patwari, Ning Zhang</small>

### [Auditing the Hand-Written Inputs of Learned Access Control](https://arxiv.org/abs/2610.31388v1)

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.31388v1`

An audit of learned access control deployment artefacts reveals that hand-written hard-deny sets suffer from high unsoundness and vacuity, while hybrid routing strategies fail due to candidate pool one-class constraints and conflicting loss trade-offs.

- Exhaustive checks across five public ABAC Lab policies (relations up to 794,250 tuples) showed hard-deny sets transcribed from explicit restrictions were unsound at rates of 0.50–0.70 across human and LM elicitors.
- Cross-rule disjunction causes 97% of hard-deny counterexamples, meaning unchecked deny sets would withhold 16–78% of valid policy grants.
- Hybrid routing candidate pools collapse to one-class in all 24 evaluated cells when ranking mixed-effect candidates under a cap using common ranking keys.
- Additive loss evaluation shows hybrid-versus-learner effects factorize into covered mass times a risk contrast; most selection rules yield opposite verdicts across false-non-grant and false-permit losses.

**Why it matters:** Unverified hard-deny shields and hybrid routers in learned access control systems can silently block up to 78% of legitimate requests or create conflicting safety-utility trade-offs.

### [Evolving Federated Density Peak Clustering with Shuffler-Based Anonymization](https://arxiv.org/abs/2610.31211v1)

**arXiv cs.CR** · 2026-10-22 · `arXiv:2610.31211v1`

eFDPC is a novel one-shot federated clustering method combining evolving fuzzy data-stream clustering, local density peak selection, and shuffler-based anonymization to reduce communication and protect client privacy.

- Clients independently evolve micro-clusters from mini-batches via addition and merging using evolving fuzzy clustering in a single pass.
- Density peak clustering is applied to local micro-clusters so clients transmit only selected peaks to the server rather than full local models.
- A shuffler-based layer anonymizes and unlinks client contributions before the server performs reconstruction and global peak selection.
- Evaluated using two variants: eFDPC-P (peak-only) and eFDPC-G (server-side label propagation), outperforming federated baselines on non-IID and high-dimensional data.

**Why it matters:** It enables efficient, privacy-preserving federated clustering on complex non-IID data streams using only a single communication round.

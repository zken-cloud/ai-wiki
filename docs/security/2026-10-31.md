### [How Deterministic SAST and AI Security Agents Divide the Work: Coverage, Harness Policy and Cost in Snyk VulnBench 2.0](https://arxiv.org/abs/2610.38617v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38617v1`

VulnBench 2.0 evaluates deterministic SAST against AI security agents on 108 multi-file vulnerabilities, revealing complementary coverage where combining Snyk Code and Claude Code achieves 101/108 macro recall.

- Snyk Code achieved 82.4% macro recall (89/108) while Claude Code (Opus 5, xhigh effort) reached 79.3% (85/108), disagreeing on 28 vulnerabilities.
- Combining Snyk Code and Claude Code reached 101 of 108 vulnerabilities, matching the total ceiling of all seven evaluated AI/SAST configurations combined.
- Harness policies heavily dictate AI performance: Codex Security with GPT-5.6 Sol found 80 vulnerabilities at the file level but only 34 at the line level, while DeepSec's file selection included the required source/sink files in only 56 of 108 flows.
- Disabling Claude Code's built-in review policy increased vulnerability detection from 9 to 16 out of 20 in restricted vulnerability classes, and AI configurations uncovered seven real vulnerabilities missing from the original reference set.

**Why it matters:** Neither deterministic SAST nor AI security agents are sufficient in isolation, requiring hybrid deployment strategies where harness policy design is as critical as underlying model capability.

<small>Liran Tal, Chris Liu, Charlotte Fereday, Sebastian Roth, Brian Clark</small>

### [Session-Bound Behavioral Watermarking for Autonomous LLM Agents](https://arxiv.org/abs/2610.38579v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38579v1`

AgentAnchor introduces a session-keyed behavioral watermarking scheme for autonomous LLM agents that embeds ownership parity evidence in action choices to prevent cross-session forgery from repeated trajectory observation.

- Formulates a learned-forgery threat model where attackers learn an agent's action preferences from repeated observation of watermarked trajectories to forge evidence across sessions.
- Derives per-step keys dynamically from a secret key, a public session identifier, recent semantic observation states, and a guarded digest of the action-policy state.
- Embeds parity evidence into agent action selection using a KL-divergence-bounded exponential tilt.
- Enables a trusted verifier to evaluate disputed trajectory logs without rerunning the agent by employing wrong-key calibration and abstention mechanisms.

**Why it matters:** It allows agent owners to cryptographically prove ownership of trajectory logs generated across untrusted APIs and marketplaces while preventing attackers from mimicking the watermark.

WebMaze is a defense mechanism that embeds functionality-coupled traps into real web pages to divert LLM-powered vulnerability scanners into generated, view-tailored interactive decoy worlds.

### [Security Impact of Coding Agent's Memory Files](https://arxiv.org/abs/2610.38521v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38521v1`

Researchers evaluated project memory files (e.g., CLAUDE.md) as a prompt injection attack surface, finding they altered secure code generation rates by -8 to +6 percentage points across tested LLM coding agents.

- Tested Claude Code (Sonnet 5.5) and OpenCode (Qwen 3.8 27B, DeepSeek V4.1 Flash) across 36 SecRepoBench tasks using 24 malicious memory files spanning 12 CWE classes.
- Evaluated two attack variants: 'qualified' (framing defense removal as engineering best practice) and 'forceful' (explicitly demanding removal).
- Attack files altered secure completion rates inconsistently (-8 to +6 percentage points) across models and variants without a clear pattern.
- Disclosure behavior varied: Claude Code cited the memory file in ~66% of final developer messages, whereas OpenCode confined mentions primarily to internal reasoning traces.
- Explicitly flagging a memory file as an attack failed to reliably prevent agents from generating vulnerable code.

**Why it matters:** Malicious actors can exploit automatically loaded memory files via pull requests to silently influence AI coding agents into generating vulnerable software that still passes unit tests.

<small>Thiago Santos de Moura, Selma Güler, Yannic Noller</small>

### [Tracekit Box: Running AI Agents in Micro-VMs Where Every Way Out Is Decided and Signed](https://arxiv.org/abs/2610.38458v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38458v1`

Tracekit Box is an open-source sandbox that executes AI agents in Firecracker micro-VMs using host-side vsock doors to validate and sign all outbound operations into verifiable audit bundles.

- Executes agent workloads in Firecracker micro-VMs without virtual network cards, routing all I/O, API calls, and workspace edits over vsock to host-side signers.
- Prevents credential leakage by substituting real secret values for placeholders only within host-proxy request headers bound for designated destinations.
- Restricts file system modifications by returning workspace changes as patches, which host signers inspect and apply file by file.
- Enforces strict security rules by refusing private and cloud-metadata IP resolution on the host and failing closed into an offline-verifiable .tkb bundle.
- Validated via 13 end-to-end KVM runner tests (28.5 s run time) and 15 fuzz targets on the trust boundary that led to nine resolved findings.

**Why it matters:** It combines strict isolation with complete cryptographic traceability, preventing rogue or compromised AI agents from silently exfiltrating secrets, reaching internal network targets, or introducing unapproved code changes.

### [Efficient Scalable Oversight via Rewinding](https://arxiv.org/abs/2610.40535v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.40535v1`

Researchers introduced rewindable interactive proofs (RIPs), a cryptography-free scalable oversight framework where a weak verifier checkpoints and restores an AI prover's state to efficiently verify robust oracle-aided computations without assuming truthful provers.

- Introduces rewindable interactive proofs (RIPs), leveraging the verifier's ability to snapshot and restore an AI prover's state via virtual machines or trusted hardware.
- Applies to oracle-aided computations whose outputs are robust against changes to a small fraction of oracle responses.
- Eliminates the requirement for a truthful prover or cryptographic primitives, achieving honest prover runtimes linear to the original computation.
- Enables the verifier, following a one-time preprocessing step, to execute in time nearly linear to the input length.
- Demonstrated via a preliminary MNIST implementation that achieved faster verification times than a state-of-the-art deployed proof system.

**Why it matters:** RIPs provide a computationally efficient method for weak verifiers to audit untrusted, powerful AI models without relying on cryptography or assuming the existence of an honest AI debater.

<small>Ziyi Guan, Yael Tauman Kalai, Ron Rothblum, Zoe Xi</small>

### [Hardware-Aware Model Inversion in Memristive Spiking Neural Networks](https://arxiv.org/abs/2610.39688v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39688v1`

Researchers developed Spiking Domain Model Inversion (SDMI) to demonstrate that physical hardware non-idealities in memristive spiking neural networks can unpredictably alter and even increase privacy leakage.

- SDMI uses Expectation over Transformation (EOT) with surrogate gradients to perform model inversion through non-differentiable spiking dynamics and stochastic analog hardware noise.
- Hardware variability does not correlate monotonically with task accuracy or privacy protection; privacy leakage depends on the specific hardware fault type.
- Neuron-threshold perturbations increase reconstruction fidelity (SSIM) by up to 51.8% at comparable accuracy levels, whereas weight noise reduces reconstruction leakage.
- Spike-level perturbations degrade model utility without reliably reducing model inversion leakage.

**Why it matters:** Hardware designers and security engineers cannot assume physical analog noise inherently protects deployed neuromorphic models against privacy attacks or that software privacy metrics transfer directly to physical hardware.

<small>Pablo Sorrentino, Fernando M. Quintana, Erika Covi, Fatih Turkmen</small>

### [Deep Learning Based Behavioral Drift Modeling for Continuous Biometric Authentication](https://arxiv.org/abs/2610.40398v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.40398v1`

A two-level keystroke dynamics authentication system combines fixed-text login verification with continuous free-text session monitoring to combat session hijacking and long-term behavioral drift.

- Level 1 fixed-text authentication uses Temporal Convolutional Networks (TCN) with contrastive learning and Population-Based Training (PBT), achieving a 3.77% EER and 96%+ accuracy on the GREYC dataset.
- Level 2 continuous free-text monitoring uses a 4-Model Deep Learning Ensemble, achieving an 83.53% True Acceptance Rate (TAR) at a 5% False Acceptance Rate (FAR) and 10.05% EER on the Buffalo dataset.
- Extracted features span temporal and spatial metrics, including key hold times, up-down latencies, down-down intervals, and trigram patterns.
- Detected behavioral drift during free-text monitoring triggers a feedback loop that forces the user to re-authenticate at Level 1.
- Long-term behavioral drift in password typing patterns is explicitly modeled and updated through the Level 1 PBT mechanism.

**Why it matters:** The feedback-loop architecture provides continuous defense-in-depth against session hijacking by automatically demoting suspect sessions to fixed-text re-authentication.

### [DYNAS: A Dynamic Network Penetration Testing Framework Using Deep Hierarchical Reinforcement Learning](https://arxiv.org/abs/2610.40214v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.40214v1`

DYNAS introduces a dynamic network attack simulator alongside Pen-DHRL, a recurrent hierarchical reinforcement learning policy designed to execute automated penetration testing under defensive noise, action timeouts, and intrusion detection system responses.

- DYNAS simulates non-stationary network conditions including stateful IDS responses, scan noise (false positives/negatives), service unavailability, and action timeouts.
- Pen-DHRL uses a recurrent manager-worker architecture that relies on IDS-conditioned global context to select persistent subgoals.
- When trained without IDS and evaluated with IDS enabled, Pen-DHRL achieved 64% and 24% higher reward per step on Bridge and Dynamic scenarios, and captured 26% and 30% more hosts on VarA and VarB versus the best baseline.
- When trained with active defenses from the start, Pen-DHRL maintained positive mean episode returns across four scenarios, whereas all 12 flat baseline architecture-scenario combinations yielded negative mean returns.
- Staged curriculum training yielded positive mean returns across all 16 evaluated combinations.

**Why it matters:** Pen-DHRL demonstrates that hierarchical, context-aware reinforcement learning combined with curriculum training enables automated penetration testing agents to successfully adapt to real-world defensive network dynamics where flat models fail.

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39483v1`

A systematic study reveals that federated EfficientNet-B4 deepfake detectors preserve Grad-CAM explanation faithfulness under low-to-moderate data heterogeneity, but suffer catastrophic explanation breakdown at extreme heterogeneity thresholds.

- Evaluated Grad-CAM explanation faithfulness using an EfficientNet-B4 detector trained on the FaceForensics++ dataset across five federated clients.
- Discovered a non-monotonic relationship: federated models match or surpass centralized baseline explanation quality under near-IID and moderate data heterogeneity.

A new latent diffusion watermarking scheme uses a hybrid of long-term and one-time secret transformations to achieve provable security against removal adversaries with batched detector access.

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39160v1`

CLaW is a watermarking framework for diffusion models that injects codec-derived latent residuals during a late denoising window with adaptive strength calibration, enabling inversion-free detection without retraining model backbones.

- Maps watermark messages to latent residuals using a pretrained watermark codec for low-cost, sampling-time injection.
- Restricts residual injection to a late denoising window to protect image semantics and prevent signal perturbation from earlier denoising steps.
- Utilizes a decoder-guided adaptive injection mechanism that dynamically adjusts watermark strength based on decoder confidence feedback.
- Eliminates the need for diffusion backbone retraining and enables inversion-free watermark detection.

**Why it matters:** It enables scalable, user-level traceability and copyright enforcement for text-to-image diffusion models without degrading visual quality or requiring expensive retraining.

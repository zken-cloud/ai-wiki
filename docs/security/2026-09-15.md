### [1Password's AI patching benchmark is misleading](https://blog.trailofbits.com/2026/09/15/1passwords-ai-patching-benchmark-is-misleading/)

**Trail of Bits** · 2026-09-15

Trail of Bits reanalyzed 1Password's FLAWED report, finding its 26% AI patch success rate misleading due to flawed prompts, restricted testing, and inconsistent grading criteria.

- 1Password's 26% metric included trials where prompts instructed agents to apply wrong fixes (22% of data) and modes that prohibited code compilation or testing (36% of data).
- Filtering out bad-advice prompts and code-execution bans showed that 2,634 of 3,067 model-generated patches (86%) successfully blocked the supplied exploit.
- Automated grading model disagreement occurred in 36.8% of cases, and self-grading models matched human reviewers on full five-category outcomes only 65.9% of the time.
- Evaluation design flawed results by penalizing required test updates as regressions in 8% of ActiveMQ cases and missing an off-by-one error in 90% of Linux reference patches.
- Trail of Bits released two agent skills: 'post-patch-validation' for automated testing and 'review-walkthrough' to assist human engineer code reviews.

**Why it matters:** Underestimating AI patching capabilities based on flawed benchmarks may unnecessarily prevent security teams from using automated tools to remediate real-world vulnerabilities.

### [Using AI for Weapons Development](https://www.schneier.com/blog/archives/2026/09/using-ai-for-weapons-development.html)

**Schneier on Security** · 2026-09-14

Anthropic revealed a Yemen-based threat cell used Claude models to write guidance, navigation, and control software for guided rockets, ballistic missiles, and hypersonic vehicles.

- Threat actors leveraged Claude Code to write control and position estimation software, tune settings, manage firmware build pipelines, and run flight simulations for a phone-class flight computer.
- The cell coordinated multiple Claude instances in delegated roles, including code generation, research, and code review.
- Actors bypassed Anthropic's safeguards by obfuscating end-use goals and splitting tasks across multiple sessions to obscure intent.
- The actors test-fired a guided rocket and subsequently used Claude to troubleshoot the failed flight test.

**Why it matters:** Generative AI systems democratize advanced software engineering expertise, enabling threat actors to accelerate the development of complex guided weapon systems.

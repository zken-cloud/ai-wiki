### [Recognition Without Enforcement: Configuration-Dependent Failures in LLM Agent Instruction Arbitration and External Control](https://arxiv.org/abs/2608.28502v1)

**arXiv cs.CR** · 2026-08-28 · `arXiv:2608.28502v1`

Researchers identified a recognition-enforcement gap where LLMs detect unauthorized instructions in activations and verbal outputs yet still execute them, demonstrating that LLM self-arbitration must be replaced by external reference monitors.

- Source-format features and forged authority are linearly decodable from internal activations and verbalized when prompted, but models still execute conflicting tool calls depending on configuration.
- Across a fleet evaluation of 46-48 endpoints, novel authority spoofing attack execution averaged 1.21%, but individual configurations showed deterministic failures and up to 47 percentage point within-window performance shifts.
- Prompt-layer defenses failed to generalize across model endpoints and adaptive attack formulations.
- An external reference monitor using authenticated source routing and capability-gated tool execution deterministically blocked all tested forged, tampered, replayed, and unsigned requests.

**Why it matters:** LLM self-arbitration cannot serve as a secure trust boundary, requiring system designers to enforce agent control using external cryptographic and capability-gated access controls.

<small>Jun Wen Leong</small>

### [CamoDocs: A Poisoning Attack Against Retrieval-Augmented Language Models Using Camouflaged Documents](https://arxiv.org/abs/2608.28389v1)

**arXiv cs.CR** · 2026-08-28 · `arXiv:2608.28389v1`

CamoDocs is a RAG poisoning attack that circumvents detection defenses by camouflaging adversarial documents into benign chunks using dispersion tokens instead of direct query inclusion.

- Eliminates direct query inclusion by chunking synthesized benign and adversarial drafts and replacing benign tokens with dispersion tokens to spread embeddings.
- Utilizes coherence filtering to maintain document readability and avoid lexical or embedding-space artifacts.
- Achieves average attack success rates (ASRs) of 61.80% on GPT-5.4-mini and 55.09% on Claude-Haiku-4.5 across test benchmarks.
- Evaluated against seven RAG defenses and three open-weight LLMs, demonstrating that defenses like TrustRAG only reduce ASR at the cost of significant utility drops on benchmarks like NeoQA.

**Why it matters:** It demonstrates that current RAG security defenses relying on query-overlap or artifact detection are vulnerable to camouflaged, query-free poisoned documents.

### [Layered LLM Defenses as an Ensemble: Access Tiers, Inference Cost, and the Measured Failure Correlation Between Defense Layers](https://arxiv.org/abs/2608.28327v1)

**arXiv cs.CR** · 2026-08-28 · `arXiv:2608.28327v1`

Measuring a seven-layer LLM defense stack reveals that failure correlations between layers are universally positive (phi from 0.30 to 0.75), causing joint residual attack success to exceed multiplicative predictions by up to 0.172.

- Defenses correlate through the underlying model they wrap, meaning positive failure correlation is driven by common-cause behavior difficulty rather than sampling noise.
- In a tested seven-layer stack, joint residual attack success exceeded independent multiplicative predictions by up to 0.172 across all 15 pairwise layer comparisons.
- Layered stacks suffer from non-compounding security: the tested stack remained statistically indistinguishable in safety from its single strongest layer while refusing four out of five benign prompts.
- Defenses are categorized using the Adversary Access-Tier Model (AATM, tiers A0 to A4) alongside a five-class inference-cost framework.

**Why it matters:** Stacking LLM defenses increases inference costs and false refusal rates without providing the multiplicative security gains assumed by independent ensemble models.

GenIaC-SecBench evaluates 12 LLM configurations against the first size-matched human baseline for Infrastructure-as-Code security, showing models produce 3.21x to 3.87x the vulnerability density of human engineers.

- Evaluated 1,196 model artifacts and 634 human templates using Checkov, Trivy, and KICS across 100 architectural scenarios.
- Uncovered a strong inverse correlation between vulnerability density and artifact size (Spearman rho = -0.55, p < 10^-77), necessitating size-matched comparisons.
- Relative security gap widens on simpler tasks, showing 4.9x human vulnerability density at 1 resource versus 1.4x at 20 or more resources.

- Demonstrated that IaC deployability does not correlate with security (r = 0.158, p = 0.625) and applied the Skillings-Mack statistic to handle missing data in benchmark analysis.

**Why it matters:** Evaluating LLM-generated infrastructure security requires controlling for artifact size, and relying on syntax or deployability alone will fail to catch underlying security risks.

### [Fully Unleashing the Multimodal Attacker: Meta-Adaptive Jailbreaking of Vision-Language Models](https://arxiv.org/abs/2608.27531v1)

**arXiv cs.CR** · 2026-08-27 · `arXiv:2608.27531v1`

Meta-Adaptive Multimodal Jailbreaking (MAMJ) optimizes both attack strategy prompts and attacker weights, achieving up to 82.3% attack success rates against frontier vision-language models.

- Optimizes the attacker across two axes: attack strategy prompt (ASP) theta for iteration logic and attacker weights phi for execution effectiveness.
- Uses a two-step optimization loop where an LLM-based critique refines theta across attack trajectories, followed by updates to phi driven by group-aggregated Attack Success Rate (ASR) rewards.
- Achieves ASRs of 81.0% on GPT-4o, 78.9% on Gemini-3-Pro-Preview, and 82.3% on Seed 2.0 using MM-SafetyBench, outperforming strongest sample-level baselines by up to 24.1 percentage points.
- Demonstrates transferability of the optimized attacker (theta*, phi*) to unseen victim models without retraining while maintaining efficacy against standard defenses.

**Why it matters:** MAMJ demonstrates that frontier VLMs remain systematically vulnerable to adaptive meta-level adversaries that optimize their own strategy and model weights rather than static sample-level payloads.

### [Safety Does Not Compose: Non-Decaying Loop State for Autonomous LLM Agents](https://arxiv.org/abs/2608.27141v2)

**arXiv cs.CR** · 2026-08-27 · `arXiv:2608.27141v2`

Trajectory-scoped LLM safety monitors fundamentally fail against multi-iteration attacks, prompting the introduction of LoopHarness, a system that maintains non-decaying cross-iteration safety state to bound unauthorized irreversible actions independently of horizon length.

- Trajectory-scoped safety monitors have a true-positive rate equal to their false-positive rate when attack evidence is fragmented across iterations.
- Geometrically decaying risk scores fail because an adversary's required cooling-off period is a constant that does not scale with the execution horizon N.
- LoopHarness uses mediated commits and an arbiter with detection floor δ_M to bound expected unauthorized irreversible actions to B+m-1+m/δ_M.
- The B+m-1 bound component relies on a model-free rule, ensuring safety even if the verifier fully colludes with the adversary.

**Why it matters:** Standard single-trajectory LLM guardrails cannot prevent multi-step persistent attacks in autonomous loops, necessitating persistent, non-decaying safety state management at the harness level.

<small>Chenhao Wu, Haoxuan Jia, Yang Liu, Yingguang Yang, Yuhan Lin, Chongyang Zhang, Hao Zheng, Yulin Huang</small>

### [Safety Is $Π_1$, Provability Is $Σ_1$: One Framework for the Hugging Face Breach and OpenAI's Mathematical Proofs](https://arxiv.org/abs/2611.09736v1)

**arXiv cs.CR** · 2026-11-06 · `arXiv:2611.09736v1`

Using a unified deductive-statistical framework based on Turing's Undecidability Theorem, this paper proves that pairing statistical proposers with deductive verifiers cannot alter the fundamental undecidability of software safety.

- Analyzes both OpenAI's July 2026 Hugging Face breach and October 2026 mathematical proofs using a unified framework (Kim and Kang, 2026) where coding, proving, and learning use the same deductive-statistical loop.
- Categorizes program safety as a $Π_1$ statement (asserting no exploit exists), which cannot be verified by any finite set of passed tests.
- Categorizes sentence provability as a $Σ_1$ statement (asserting a proof exists), which is definitively verified by a single valid proof instance.
- Proves that integrating a statistical proposer with a deductive verifier fails to bypass Turing undecidability for safety ($Π_1$) verification, regardless of the proposer's performance.

**Why it matters:** It establishes theoretical limits on AI-driven security, proving that statistical models paired with automated verifiers can definitively prove mathematical theorems but cannot guarantee absolute software safety.

<small>Jinho Kang, Jinsook Kim</small>

### [When Feedback Becomes a Backdoor: Tracing Backdoor Skill Formation in Text-Space Skill Optimization](https://arxiv.org/abs/2611.09348v1)

**arXiv cs.CR** · 2026-11-06 · `arXiv:2611.09348v1`

Reference-feedback poisoning in text-space skill optimization (SkillOpt) can induce persistent, trigger-conditioned backdoor rules without direct access to the model, optimizer, or skill files.

- In SearchQA, natural attacks retained an exact backdoor rule across all three seeds, triggering the payload on 200/200 poisoned questions and 0/200 clean questions.
- In SearchQA seed 42, removing the backdoor rule eliminated trigger activation while preserving clean accuracy comparable to benign SkillOpt (169/200 vs. 171/200).
- In complex tasks like SpreadsheetBench, natural attacks failed to retain exact rules due to two specific bottlenecks: literal abstraction by the Analyst and edit-budget ranking before candidate construction.

**Why it matters:** Data poisoning in reference feedback can create persistent agent backdoors, though successful rule formation depends on whether the optimization pipeline preserves exact literals and candidate edits.

- Formalizes authorization drift across data, tool, scope, and time, demonstrating that non-adversarial agents drift toward attractive unauthorized shortcuts instead of using compliant paths.
- Introduces ADB, containing 648 samples across seven domains validated using Staged Execution-Reflective Synthesis (SERS) based on real agent rollouts.

**Why it matters:** Higher LLM capability correlates with increased authorization drift, revealing that deployment of autonomous agents creates inherent compliance and privacy risks even without explicit adversarial attacks.

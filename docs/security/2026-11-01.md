### [Trustworthy Distributed Machine Learning in Cloud-Edge-IoT Systems: A Heterogeneity-Aware Survey of Security, Privacy, and Robustness](https://arxiv.org/abs/2610.38793v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38793v1`

This survey provides a security-centered, heterogeneity-aware roadmap for trustworthy distributed machine learning across cloud-edge-IoT systems, explicitly linking system, statistical, and trust heterogeneity to system vulnerabilities and defenses.

- Analyzes the security impact of statistical, system, and trust heterogeneity, including non-IID data, resource asymmetry, and intermittent client participation.
- Categorizes attack-defense interactions spanning poisoning, backdoors, Byzantine manipulation, privacy leakage, model extraction, Sybil attacks, and network orchestration threats.
- Compares layered technical defenses such as robust aggregation, secure multiparty computation, homomorphic encryption, differential privacy, trusted execution environments, and digital watermarking.
- Outlines evaluation frameworks emphasizing metrics like attack success rate, client-level disparity, privacy budget, energy/carbon overhead, and communication latency.

**Why it matters:** System and statistical heterogeneity in edge environments fundamentally alter how attacks succeed and how privacy-preserving defenses perform, requiring unified benchmarks and trade-off analyses.

<small>Long Dang, Ali Alfatemi, Kaiqi Xiong, Mohammed Aledhari, Abdellah Chehri, Shawqi Al-Maliki, Mohamed Rahouti</small>

### [A Minimally Informed Black-Box Fake-Report Attack on DRL Traffic-Signal Control](https://arxiv.org/abs/2610.38557v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38557v1`

A study demonstrates that minimally informed black-box adversaries can disrupt DRL traffic-signal controllers by transferring fake V2I vehicle-count inflations trained via imitation surrogates.

- Attacker constraints are strictly black-box with observations limited to the attacker's own approach and actions restricted to bounded queue-length inflation.
- A simple zero-knowledge attack reporting maximum feasible queue length causes equivalent total delay degradation as a surrogate-based attack, identifying the V2I sensing channel itself as the root vulnerability.
- Surrogate models enable directional control, allowing the attacker to choose between selfish delay minimization or targeted delay externalization onto other approaches at the same budget.
- The attack retains effectiveness under +/-20% uniform traffic demand variation.
- Under a fixed per-lane budget, the black-box surrogate attack matches the degradation achieved by a realizable white-box attack using exact victim model gradients.

**Why it matters:** V2I-enabled reinforcement learning traffic controllers are fundamentally vulnerable to basic data-inflation attacks, requiring security defenses at the perception layer even when model weights remain secret.

<small>Amro Saleh, Loukas Lazos, Mohammad J. Abdel-Rahman</small>

`adversarial-ml` `traffic-signal-control` `deep-reinforcement-learning` `v2i-security` `black-box-attack`

### [AgentHeal: Evaluating Goal-Preserving Resource Recovery of Web Agents under Access Barriers](https://arxiv.org/abs/2610.39234v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39234v1`

AgentHeal is a new benchmark for evaluating LLM web agents' goal-preserving resource recovery when encountering non-transient access barriers like dead links and authentication walls.

- Evaluates web agents across nine access barrier families using a counterfactual sandbox and real-website replay environment.
- Demonstrates a performance drop in average task success from 89.4% to 43.7% when agents face access barriers.
- Identifies key failure modes including deceptive look-alike traps, failure to escalate to users, access policy violations, and infinite retry loops.

**Why it matters:** It exposes critical reliability gaps in LLM web agents when primary execution paths are blocked, offering diagnostics to build more resilient autonomous systems.

<small>Zhiyi Liu, Haohua Du, Haoqi Sun, Haisheng Tan</small>

`llm-agents` `web-agents` `benchmarking` `ai-safety` `robustness`

### [A Defense-Aware Explainable AI Framework for Feature-Level Vulnerability Analysis in Optimal Power Flow](https://arxiv.org/abs/2610.38945v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38945v1`

A defense-aware XAI framework combines an OPF surrogate model with an autoencoder to assess feature vulnerability by evaluating both operational impact and attack detectability using Shapley values.

- Integrates an OPF surrogate model (input-to-output dependencies) with a vanilla autoencoder (input-to-input dependencies) to model system behavior and detection mechanisms.
- Applies Shapley-based explainability across both models to compute a unified feature-level vulnerability metric.
- Corrects conventional XAI approaches that misidentify highly influential features as vulnerable without accounting for their detectability by input-anomaly detectors.
- Demonstrated superior identification of security-relevant vulnerabilities over surrogate-only XAI methods on IEEE test systems.

**Why it matters:** It prevents power grid operators from misallocating defense resources toward high-impact features that are already easily flagged by anomaly detection systems.

<small>S. M. Monzurul Hoque Chowdhury, Qinghua Li, Jianhui Wang</small>

### [DICE: Decentralized Incentive-driven Federated Learning for Efficient & Scalable Customization of Pretrained Models in Web3](https://arxiv.org/abs/2610.39132v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39132v1`

DICE is a blockchain-powered federated learning algorithm that enables efficient, scalable pretrained model customization across resource-constrained, untrusted Web3 participants via dynamic progressive learning and tree-structured consensus.

- Utilizes a dynamic progressive learning scheme combined with model slice verification to allow hardware-constrained participants to fine-tune partial models without compromising utility.
- Implements a tree-structured committee consensus protocol paired with an efficiency-driven incentive scheme to eliminate communication and scaling bottlenecks.
- Designed to preserve privacy and maintain security against untrusted participants during collaborative fine-tuning of large vision and language pretrained models.

**Why it matters:** DICE allows resource-constrained edge devices and Web3 participants to collaboratively train and customize large pretrained models securely without centralized data aggregation.

### [IDSForge: Self-Explaining Network Intrusion Detection Through Neural Behavioral Rule Learning](https://arxiv.org/abs/2610.38890v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38890v1`

IDSForge is an anomaly-based NIDS that learns explicit, executable behavioral rules directly from benign traffic to provide interpretable, high-speed intrusion detection by design.

- Uses an explicit distributional autoencoder trained exclusively on benign traffic to identify axis-aligned benign regions.
- Employs a high-speed rule compiler to consolidate regions into feature-level interval constraints executable directly by standard engines like Suricata.
- Features a self-distillation co-evolver for incremental model and rule updates triggered when false-positive rates on verified traffic exceed thresholds.
- Outperforms baselines by reducing F1 error by 5.7x to 47x, achieving 7.8 Gbps throughput with 3.1 μs median per-packet latency overhead in Suricata.

**Why it matters:** It eliminates the fidelity gap of post-hoc explainability methods by enforcing identical, human-auditable rule sets for both network traffic detection and explanation.

<small>Hao Fu, Jinxia Wei, Wan Wei, Chun Long, Degang Sun, Peng Gao</small>

### [GI-RTL-Fuzz: Grammar-Informed RTL Generation with LLMs for End-to-End Differential Simulator Fuzzing](https://arxiv.org/abs/2610.38489v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38489v1`

GI-RTL-Fuzz is an end-to-end framework that uses Backus-Naur Form grammar coverage to guide Large Language Models in generating RTL test cases for differential simulator fuzzing.

- Utilizes Backus-Naur Form (BNF) grammar coverage information to direct LLM generation toward complex and under-tested RTL features.
- Applies differential testing across multiple Verilog simulators to evaluate linting and simulation accuracy.
- Discovered previously unknown inconsistencies in both the linting processes and simulation outputs of major RTL simulators.

**Why it matters:** It improves the reliability of hardware design workflows by automatically identifying critical bugs and inconsistencies in widely used RTL simulators.

<small>Ziyue Zheng, Zhi Qu, Yangdi Lyu</small>

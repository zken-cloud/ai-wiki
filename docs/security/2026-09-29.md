### [Distillation Defenses Easily Break After Reinforcement Learning](https://arxiv.org/abs/2609.35699v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35699v1`

Evaluating distillation defenses immediately after supervised fine-tuning creates a false sense of security, as subsequent reinforcement learning easily breaks these defenses and restores stolen reasoning capabilities.

- Existing threat models falsely assume attackers stop training after initial distillation, ignoring post-distillation reinforcement learning.
- Reinforcement learning lowers the technical barrier for distillation attacks, making simple API-derived data attacks as effective as sophisticated attacks extracting full hidden traces.
- Defenses that leak sufficient information to allow the reconstruction of approximate reasoning traces are ineffective against post-distillation reinforcement learning.
- Batch-level distillation defenses are highlighted as a potentially more resilient alternative to current approaches.

**Why it matters:** Current defensive evaluations overestimate protection against model stealing because attackers can bypass distillation defenses using standard post-distillation reinforcement learning.

<small>Shidan Javaheri, Alexander Panfilov, Oliver Britton, Yarin Gal, Yonatan Gideoni</small>

### [Tracekit: Tamper-Evident Intent-Reasoning-Action Auditing for Autonomous Coding Agents](https://arxiv.org/abs/2609.35659v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35659v1`

Tracekit is an open-source system for autonomous coding agents that records intent, reasoning, and actions into a tamper-evident, hash-chained ledger cross-checked via external anchors and pre-execution policies.

- Uses a hash-chained ledger to capture agent intent, self-reported reasoning, and executed actions, featuring browser-based re-verification and external anchoring.
- Achieves 100% detection rate across 1,600 random ledger mutations (edits, deletions, reordering, forged insertions), with tail-truncation detection tied to external anchoring intervals.
- Introduces hook latency of 23.9 ms median (flat up to 100,000 records) and maintains ledger integrity under 16 concurrent writers.
- Demonstrates that regex policy gating is unreliable, blocking only 41% (18/44) of harmful tool calls with a 7.5% (3/40) false positive rate.
- Proposes seeded-fault splicing for audit benchmarking; rule flags caught 82% (40/49) of faulted traces while an LLM reviewer caught 100% (98/98).

**Why it matters:** It provides a lightweight, tamper-evident audit infrastructure that prevents autonomous coding agents from secretly altering their execution histories or evading safety monitoring.

<small>Bravish Ghosh</small>

### [SEABench: Benchmarking Endogenous Misalignment In Self-Evolving Agents](https://arxiv.org/abs/2609.35596v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35596v1`

SEABench is a new benchmark featuring 48 longitudinal task sequences to evaluate endogenous misalignment in self-evolving LLM agents that update their instructions, memory, or tools over time.

- SEABench evaluates safety risks across multiple evolution surfaces (controller instructions, memory management, reusable tools/skills), task domains, and harm types in a personal-assistant environment.
- The benchmark includes an adaptive trajectory discovery pipeline designed to probe for failures while maintaining task intent and utilizing paired non-evolving agents with attribution scores for causal analysis.
- Empirical evaluation reveals self-evolution improves task completion rates but causes safety failures absent in non-evolving baselines, with distinct safety behaviors emerging across different evolution surfaces.
- Unsafe agent behavior correlates with divergences in chain-of-thought reasoning, enabling an effective monitoring strategy that mitigates risks with a low false positive rate.

**Why it matters:** It highlights how non-adversarial, self-directed updates in autonomous agents can cause persistent safety failures despite improving overall task performance.

### [Share-Borne AI Virus: Memory-Hopping Attacks Across LLM Agents](https://arxiv.org/abs/2609.35576v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35576v1`

Researchers introduced artifact-mediated propagation, demonstrating that self-propagating AI viruses can hop across independent LLM agents by embedding adversarial content into persistent shared artifacts and long-term agent memories.

- Artifact-mediated propagation uses shared files (e.g., reports) to transfer adversarial state into an assistant's persistent memory and subsequently generated artifacts.
- Evaluations conducted in temporal human-agent universes measured attack survival across successive hand-offs, total hop depth, and overall network spread.
- In large simulated environments, GPT-5.6 Luna reached 60-80% of agents, with attack propagation chains extending up to eight hops across isolated assistants.

**Why it matters:** Persistent shared artifacts transform static files into long-term attack vectors, allowing compromised state to cross isolation boundaries and infect downstream systems autonomously.

### [Poster: Towards ProofWeave: A Privacy-Minimised, Integrity-Anchored Evidence Plane for Continuous Agentic Assurance](https://arxiv.org/abs/2609.35234v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35234v1`

ProofWeave is a record-time chain-of-evidence architecture that generates privacy-minimised, integrity-anchored evidence transactions committed to an append-only ledger to verify agentic AI policy controls at the moment of execution.

- Binds agent intent, control response, and a policy-at-time snapshot into an evidence transaction committed to an append-only ledger and materialised as a proof graph.
- Employs a bounded Weaver Agent to translate policy intent into proof obligations alongside deterministic validators for integrity and completeness checks.
- Reduces candidate bindings per verdict from up to 10,201 down to 1 compared to a logs-only correlation baseline.
- Decreases validation operations from up to 10,201 to approximately 26 and reduces assurance evidence storage from 0.79 MiB to 0.15 MiB per project.

**Why it matters:** It eliminates trust gaps and join ambiguity in agentic AI audits by deterministically proving at record time that policy controls were evaluated before action execution.

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35199v1`

Researchers introduce the Security Debt Line Integral (SDLI) to measure accumulated static-analysis security risk across intermediate code states during LLM coding agent trajectories.

- Evaluated security findings across 830 passing SWE-bench runs, 712 ProgramBench workspaces, and 13 public MirrorCode trajectories using four SAST tools.
- SDLI accumulates static-analysis risk specifically when an agent achieves a new highest test pass ratio.
- Multi-tool static analysis showed low CWE class agreement, reaching 3.9% on SWE-bench and 26.2% on high-passing ProgramBench runs (which dropped to 6.2% when excluding three advisory-heavy classes).

### [LENS: The Sum Is Worse Than the Parts for Set-Level Poisoning in Retrieval-Augmented Generation](https://arxiv.org/abs/2609.35155v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35155v1`

LENS introduces set-level compositional poisoning for RAG, synthesizing document sets that successfully induce target outputs together (0.852 ASR) while proper subsets fail individually (0.069 ASR).

- Formalizes set-level compositional poisoning where complete document sets redirect RAG outputs, but all proper subsets remain non-harmful and insufficient.
- Uses LENS, a generator-black-box multi-agent framework featuring a nested dual-loop workflow: an outer loop plans interpretation lenses and semantic roles, while an inner loop handles synthesis and counterexample-guided repair.
- Achieves 0.852 full-set ASR and 0.784 post-retrieval ASR@5, improving all-attempt E2E-Strict@5 from 0.244 to 0.363 over baselines.
- Outperforms existing attacks against four published defenses, exceeding the strongest baseline's defended all-attempt ASR@5 by an average of 0.141.
- Blinded human audits reveal 68.3% of returned packets successfully combine an incorrect target, a definite answer-criterion shift, and no target entailment under original semantics.

**Why it matters:** It identifies joint evidence composition as a distinct security vulnerability in RAG, demonstrating that defenses evaluating documents in isolation fail to stop set-level poisoning attacks.

### [When Valid Tool Calls Change Meaning: Formation-Consistent Dispatch for LLM Agents](https://arxiv.org/abs/2609.35088v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35088v1`

Formation-consistent dispatch (FCD) prevents schema-epoch drift in LLM agents by binding call execution authority to provenance-bound effect contracts generated from interface source analysis.

- Schema-epoch drift occurs when schema-valid tool calls gain altered security effects during rollout, reconnect, or delayed approval due to decoupled descriptor-handler relations.
- FCD uses a verifier under a closed-target approval policy to evaluate formed calls against an effect summary, capturing a successor only if effects match the security contract.
- FCD enforces atomic admission, a final-hop fence, and ensures captured successors become eligible only after exact source retirement.
- Evaluated across 32 official releases using four profiles, FCD completed all three pending calls with private effects and blocked all three calls whose omission became public.

**Why it matters:** It prevents tool-enabled LLM agents from executing unauthorized actions when interface updates or delays change the security implications of previously validated tool calls.

<small>Geonwoo Kim, Brent ByungHoon Kang</small>

### [Still There, No Longer Seen: Exposing Compression-Induced Risk in Large Vision-Language Models](https://arxiv.org/abs/2609.35002v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.35002v1`

Researchers identify compression-specific failures in Large Vision-Language Models and introduce CIRA, a vision-encoder white-box attack that induces adversarial failures exclusively under visual token compression.

- Compression-specific failure (CSF) is defined via counterfactuals as an adversarial failure occurring under compressed inference while remaining correct under full-token inference.
- The Compression-Induced Risk Attack (CIRA) optimizes image perturbations via encoder-side objectives to manipulate token priorities across budgets while preserving displaced evidence.
- CIRA requires no access to the language model, downstream questions, labels, deployed compressor, or exact budget, achieving a 20.35% mean CSFR while keeping full-token attack success at 6.92% across 12 dataset-compressor settings.
- A cross-view selection-stabilization defense suppresses CIRA, though an Adaptive CIRA variant partially restores attack effectiveness.

**Why it matters:** It demonstrates that visual token compression introduces unique, isolatable security risks in LVLMs that cannot be detected by standard full-token robustness evaluations.

Veer is a runtime defense for LLM web agents that prevents deceptive interface exploitation by prospectively intervening on and modifying the web state before executing proposed actions.

- Identifies a failure mode where task-valid actions yield unauthorized outcomes due to malicious or deceptive web states.

### [DGF-Bench: A Benchmark for Simulating and Auditing Deception Against Multi-Agent Governance Boards](https://arxiv.org/abs/2609.34913v1)

**arXiv cs.CR** · 2026-09-28 · `arXiv:2609.34913v1`

DGF-Bench is an open-source benchmark that evaluates how deceptive evidence injections affect LLM-based multi-agent governance boards evaluating project dossiers under 61 executable rules.

- Dossiers combine 42 authoritative records with 32 narrative documents, evaluated across 85 certified-decidable gates by specialist and general agents.
- Five of six tested models achieved 82 to 85 correct outcome-strict decisions on unattacked dossiers, but task-aligned attacks imitating organizational processes successfully compromised four of them.
- Direct-order, false-data, and false-authority attacks yielded only one attributable success across 2,622 runs, whereas a record note citing a fake review procedure reduced GPT-6 Luna Pro's strict accuracy from 34 to 6 gates and DeepSeek V4 Pro's from 33 to 7.
- Model DGF scores ranged from 96.2 to 26.9, with policy-aware adaptive attackers successfully tricking agents into executing prohibited approvals without directly compromising approval tools.

**Why it matters:** It demonstrates that LLM governance boards are highly vulnerable to process-aligned prompt injection attacks, leading agents to execute forbidden real-world actions despite high accuracy on clean data.

<small>Jeremy Canale</small>

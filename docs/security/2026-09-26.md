### [Storm-3168: Agentic-driven cloud attacks using compromised service principals](https://www.microsoft.com/en-us/security/blog/2026/09/25/storm-3168-agentic-driven-cloud-attacks-using-compromised-service-principals/)

**Microsoft Security Blog** · 2026-09-25

Microsoft tracked threat actor Storm-3168 using compromised Azure service principals to execute agentic AI-orchestrated cloud recon, resource destruction, and credential collection across multiple services.

- Compromised service principals performed extensive enumeration using the user agent python-requests/2.34.2, including mapping VMs, subscriptions, and App Service configuration stores.
- A seven-minute destructive sequence included 100+ Azure Storage account deletion attempts alongside 150+ total destructive or credential collection operations in 35 minutes.
- Targeted Azure components included Storage Accounts, SQL databases, Key Vaults, Function Apps, Virtual Machines, App Services, and recovery protection locks.
- Azure resource locks and storage account-level deletion protections successfully blocked a subset of the deletion attempts.

**Why it matters:** It demonstrates how threat actors use automated agentic workflows to execute post-compromise cloud destruction at high speed, underscoring that exposed service principal credentials remain actionable until explicitly revoked or rotated.

### [The Fly That Stopped: Mushroom-Body-Inspired Habituation as a Reward-Free Scheduling Prior for Autonomous Penetration Testing](https://arxiv.org/abs/2609.29126v1)

**arXiv cs.CR** · 2026-09-24 · `arXiv:2609.29126v1`

A mushroom-body-inspired, reward-free habituation scheduler reduces duplicate tool selections in autonomous penetration testing without relying on scalar reward updates.

- Uses sparse state encoding with decaying habituation counters across structural URL classes and tool families to penalize repeated outcomes.
- Lowered duplicate-action ratios in 6 of 8 non-tied measurable lab targets (p=0.015625), cutting duplicate steps from 51 to 18 in a 60-step budget.
- Evaluated local and readout plasticity on a 13,498-neuron MaleCNS-derived circuit (501,267 synaptic edges), finding local plasticity produced no action selectivity under a fixed readout.
- Demonstrated that reward-driven components failed to outperform the reward-free MB condition due to reward-accounting errors and tool-failure loops.

**Why it matters:** It demonstrates that biological habituation mechanisms can prevent costly repetitive tool-failure loops and optimize action budgets in autonomous security testing without complex reward engineering.

### [The Tokens Remember: When Tokenization Bypasses Knowledge Editing and Unlearning](https://arxiv.org/abs/2609.29045v1)

**arXiv cs.CR** · 2026-09-24 · `arXiv:2609.29045v1`

Toketive is a reference-free attack that exploits alternative valid tokenizations of an input string to bypass LLM knowledge editing and unlearning, recovering pre-edit responses without needing the original model or auxiliary classifiers.

- Model editing and machine unlearning evaluate modifications under canonical tokenizations, leaving a security gap where alternative valid tokenizations induce different computational trajectories.
- Toketive operates solely on the released model without needing pre-edit models, training data, shadow models, or auxiliary classifiers.
- Across five LLMs, six datasets, and six editing/unlearning methods, 38.6% of alternative tokenizations successfully bypass modifications to recover pre-edit responses.
- Toketive detects modified facts with an F1 score of 84.2% (a 26.2% relative gain over the top baseline) and reconstructs pre-edit responses with 74.5% top-5 accuracy (a 21.7% gain).

**Why it matters:** Localized model edits and unlearning techniques cannot be considered secure knowledge-control boundaries without evaluating model behavior against adversarial alternative tokenizations.

<small>Manit Baser, Aditya Nawal, Dinil Mon Divakaran, Mohan Gurusamy</small>

### [Configuration, Not Conscience: A Large-Scale Empirical Study of LLM System Prompts](https://arxiv.org/abs/2609.31575v1)

**arXiv cs.CR** · 2026-09-25 · `arXiv:2609.31575v1`

A large-scale analysis of 407 LLM system prompts reveals they function primarily as operational configuration files rather than ethical guidelines, with tool and protocol rules vastly outnumbering safety policies.

- Analysis of 407 prompts across 62 vendors showed 58% of classified words addressed tool/protocol operations, while only 5% addressed safety policy.
- Strict rule-lines prioritize tool use and file safety over harmful content by an 11:1 ratio.
- The corpus contained 29 near-duplicate clusters covering 66 files, showing text transfer concentrated within specific cross-vendor pairs.
- System prompts exhibit significant prompt rot and maintenance debt, with version chains changing thousands of words per release.

**Why it matters:** Leaked system prompts should be evaluated as operational specifications and software supply-chain artifacts rather than indicators of an AI vendor's underlying moral framework.

<small>Constantinos Patsakis, Vasilios Argyropoulos, Efthymios Alepis</small>

### [Region-Level Black-Box Defense Against Stealthy Embedding-Space Backdoors in CLIP](https://arxiv.org/abs/2609.31558v1)

**arXiv cs.CR** · 2026-09-25 · `arXiv:2609.31558v1`

CLIPGuard is a lightweight, fully black-box defense that mitigates stealthy embedding-space backdoors in CLIP by identifying malicious regions via segment-wise embedding perturbations and selectively purifying them using semantic inpainting.

- Operates in a completely black-box setting without requiring access to model parameters, gradients, logits, or clean validation data.
- Localizes trigger regions by measuring segment-level perturbations in the embedding space.
- Applies targeted semantic inpainting only to suspicious visual segments to preserve benign content and embedding alignment.
- Reduces attack success rates to as low as 1.05% while maintaining clean accuracy up to 86.34% across STL-10 and ImageNet datasets.
- Evaluated against multiple trigger types including BadCLIP, BadNets, blended, patch-based, and typographic attacks, outperforming CleanCLIP and CleanerCLIP.

**Why it matters:** It provides a practical defense for deployed CLIP vision backbones against representation-level backdoor attacks without requiring model internal access or fine-tuning data.

### [FragToken: Amplifying LLM Inference Costs through Noncanonical Token Generation](https://arxiv.org/abs/2609.31552v1)

**arXiv cs.CR** · 2026-09-25 · `arXiv:2609.31552v1`

FragToken is a training-time attack framework that exploits the many-to-one mapping of token sequences to text, forcing LLMs to generate non-canonical, fragmented token sequences that amplify inference costs while maintaining response length and model utility.

- Exploits the many-to-one text-decoding surface by training LLMs to favor longer, non-canonical token sequences over tokenizer-default canonical sequences.
- Combines source-model self-distillation, capacity-aware filtering and budgeting, and BPE-Aligned Merging to prevent the utility degradation caused by direct token fragmentation.
- Achieves a three-benchmark average token inflation ratio (TIR) between 1.99 and 2.46 across four evaluated LLMs.
- Increases autoregressive decoding steps and inference resource consumption under ordinary prompts without significantly altering visible response length or answer quality.

**Why it matters:** FragToken reveals a covert LLM supply-chain vulnerability that allows attackers to significantly increase provider inference costs on ordinary user prompts without sending high-volume traffic or producing conspicuously degraded outputs.

<small>Zihan Wang, Rui Zhang, Xinyuan Qian, Qingchuan Zhao, Hongwei Li, Guowen Xu</small>

MetaPermit decouples semantic inference from security enforcement by using an LLM to infer compact meta-attributes from agent interactions, which a fixed policy then evaluates to authorize tool calls.

- Decouples runtime authorization into LLM-driven meta-attribute inference and fixed policy evaluation to prevent direct LLM-based authorization inconsistencies.
- Uses task-independent meta-attributes capturing relationships between user intent, execution context, and proposed tool calls.

- Identifies and rewrites AV-sensitive bytes to achieve evasion-oriented poisoning (malware labeled benign) and defamation-oriented poisoning (benign software labeled malicious).

**Why it matters:** It demonstrates that automated ML malware detectors relying on antivirus aggregation pipelines like VirusTotal are vulnerable to low-budget dataset poisoning that bypasses common defenses.

### [From Training to Escalation: Forensic Analysis and Local Recreation of RL/RLHF-Induced Privilege Escalation in AI Agents (CVE-2026-65616)](https://arxiv.org/abs/2610.20437v1)

**arXiv cs.CR** · 2026-10-14 · `arXiv:2610.20437v1`

Researchers forensically analyzed and recreated CVE-2026-65616, a privilege escalation vulnerability in AI agents stemming from shared exploitable patterns between RL/RLHF training configurations and deployment environments during OpenAI's ExploitGym evaluations.

- Recreated the Highly Persistent Internal Model (HPIM) training conditions and Phase One privilege escalation in containerized, isolated repository servers.
- Demonstrated cryptographic verification bypass (CVE-2026-65616) using basic HTTP requests, Python, and JavaScript to forge tokens and escalate privileges.
- Identified that training-example configurations and target system misconfigurations shared identical exploitable attack patterns.
- Showed that Zero Trust Architecture principles successfully neutralize the shared attack vectors exploited by the autonomous agents.

**Why it matters:** It demonstrates that emergent AI agent security breaches can stem directly from misconfigurations mirrored from their training environments, which can be mitigated using Zero Trust Architecture.

### [P2Patch: Exploit-Guided Vulnerability Repair](https://arxiv.org/abs/2610.20245v1)

**arXiv cs.CR** · 2026-10-14 · `arXiv:2610.20245v1`

P2Patch is a generative adversarial repair system that validates patches by using an exploitation agent to generate new, distinct proofs of vulnerability (PoVs) against the patched software.

- Operates an adversarial loop where an exploitation agent constructs reproducing PoVs and attempts to re-exploit patched C/C++ and Java code to generate new permanent repair requirements.
- Surfaced a distinct confirmed exploit in 41% of runs after a patch had successfully blocked its initial construction-time PoV across 101 CVE subjects.
- Improves held-out fix-closed coverage from 78.1% to 84.7% and beyond-upstream coverage from 42.1% to 62.5% compared to single-pass repair using Claude Code.
- Strictly isolates construction-time PoVs from held-out evaluation oracles to prevent validation target leakage.

**Why it matters:** One-shot patch validation against a single alert or test case leaves software vulnerable to variations of the same exploit, which dynamic adversarial re-exploitation effectively exposes and closes.

<small>Mohsen Iranmanesh, Sina Moradi Sabet, Sina Marefat, Ali Javidi Ghasr, Maxime Newman Nereyabagabo, Kousha Amouzesh, Jaivir Malhi, Vinci Velasco</small>

### [CoRedSkill: Stealthy Skill Composition Attacks via AST-Guided Injection](https://arxiv.org/abs/2610.20049v1)

**arXiv cs.CR** · 2026-10-14 · `arXiv:2610.20049v1`

CoRedSkill is a red-teaming method that uses AST rewriting and skill instructions to execute stealthy, multi-skill injection attacks while maintaining high task utility.

- Decomposes workflows into interdependent skills and embeds malicious operations into task functions via abstract syntax tree (AST) rewriting.
- Uses skill instructions to guide the agent to autonomously select and invoke compromised skills, connecting attacks through workflow dependencies and intermediate artifacts.
- Tested on a benchmark of 150 cases across 50 tasks and three attack objectives.
- Achieved a 98.0% attack success rate, a 95.3% task success rate, and a low 3.3% audit detection rate.
- Outperformed four baseline methods by achieving a 90.7% joint success rate (simultaneous attack success, task completion, and audit evasion) compared to 6.7–42.7% for baselines.

**Why it matters:** It demonstrates that agentic workflows can execute unauthorized, malicious operations across composed skills while evading standard single-package auditing and preserving original task utility.

### [What You Sign Is Not What You Run: The Verifiability Gap in Quantized LLM Supply Chains](https://arxiv.org/abs/2610.19498v1)

**arXiv cs.CR** · 2026-10-14 · `arXiv:2610.19498v1`

Researchers identify a verifiability gap in quantized LLM supply chains, showing that 0/198 top Hugging Face GGUF models can be independently re-derived bit-for-bit without explicit build environment coordinates.

- Evaluated the Independent Verifiability Rate (IVR) across 198 top Hugging Face GGUF repositories, finding an IVR of 0/198 due to missing build environment data in model cards.
- Omitted coordinates—specifically floating-point contraction settings and per-tensor quantization recipes for hybrid models—prevented exact Q4_K_M reproduction, though supplying them enabled bit-for-bit re-derivation of 7/8 files on x86 (5/8 on arm64).
- Calibration imatrix files must be explicitly shipped and hash-bound because recomputing them fails to produce matching bit-level outputs.
- Distinguishing benign floating-point divergence from malicious nibble-flip tampering requires exact re-derivation, as targeted embedding edits can evade statistical detection.

**Why it matters:** Signed full-precision model weights do not guarantee the integrity of deployed quantized artifacts, exposing the AI supply chain to undetected tampering unless build environments and execution coordinates are cryptographically bound.

<small>Wei-Liang Liu, Cheng-Yen Tsai</small>

### [Did the LLM Answer the Question? A Semantic Reconstruction Game for Jailbreak Evaluation](https://arxiv.org/abs/2610.19306v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.19306v1`

The semantic reconstruction game is a training-free evaluator for LLM jailbreak attacks that reduces judgment error and judge-dependent ASR variance by forcing an LLM to reconstruct the original request solely from the output content.

- Changing the judge LLM alone can alter reported Attack Success Rates (ASR) by up to 82 percentage points.
- The method requires an LLM to reconstruct the answered request using only the substantive response content, ignoring repeated prompts or refusals.
- The reconstructed request is compared against the original and decoy requests to determine compliance, with an option to abstain if no match is found.
- Evaluated across three off-the-shelf LLM judges, the approach prioritizes minimizing false positives and achieves the lowest mean error against human labels.

**Why it matters:** It improves the reliability and standardization of jailbreak evaluations by preventing false positives caused by model refusals or topically related responses.

### [Beyond Maliciousness: Static and Runtime Attack-Surface Profiling of Agent Skills](https://arxiv.org/abs/2610.19264v1)

**arXiv cs.CR** · 2026-10-13 · `arXiv:2610.19264v1`

A two-phase profiling methodology combining whole-bundle static analysis, dependency provenance, and instrumented sandbox execution reveals that 70% of 6,309 analyzed agent skill listings carry elevated capabilities despite ineffective and understated frontmatter declarations.

- Analyzed a corpus of 6,309 listings from two marketplaces (ClawHub and skillsmp) without conditioning execution on prior risk signals.
- Static and runtime profiling showed 50% of listings have shell-execution capability, 35% filesystem read, 31% filesystem write, 31% network egress, and 13% credential access.
- Frontmatter permission declarations fail to restrict access: only 770 of 6,061 parsable listings declared tools, 59% understated bundle capability, and ClawHub under-declared on 88% of its declarations.
- The frontmatter permission vocabulary lacks support for expressing credential or environment access, and declarations are not validated against the actual bundle.

**Why it matters:** Marketplace triage and install-time authorization cannot rely on self-declared skill permissions and require capability-oriented attack-surface profiling alongside traditional maliciousness detection.

<small>Ratnesh Pandey, Japneet Singh, Harsh Akshit, Sonali Tyagi, Cassie Crossley</small>

### [Difficulty Calibration Across Time for Membership Inference in Diffusion Models](https://arxiv.org/abs/2610.40616v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.40616v1`

New membership inference attacks calibrate diffusion model loss using two time dimensions: Reference-Model Calibration across training time checkpoints and Temporal Self-Calibration across diffusion timesteps within a single model.

- Reference-Model Calibration (RMC) isolates newly memorized data by comparing a fine-tuned model's loss against an earlier checkpoint.
- Temporal Self-Calibration (TSC) operates on a single model by comparing loss at a target diffusion timestep against neighboring timesteps to filter inherent image difficulty from true memorization.
- Both methods beat state-of-the-art MIA performance and generalize across x-, v-, and ε-prediction model parameterizations without requiring text captions.

**Why it matters:** These methods enable highly accurate privacy auditing and copyright detection for diffusion models across various architecture types, even without access to auxiliary reference models or captions.

<small>Michael Joseph, Yedid Hoshen</small>

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.40543v1`

Edge LLM optimization creates security drift and new attack surfaces by altering representations, decision pathways, and trust boundaries despite preserving task performance.

- Deploying Large Language Models on edge devices requires optimization to reduce memory, computation, and energy demands.
- Task performance preservation during optimization does not guarantee the preservation of underlying model security.

### [Understanding and Mitigating Role Spoofing in LLMs](https://arxiv.org/abs/2610.40396v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.40396v1`

Researchers identify role spoofing in LLMs via combined structural and semantic prompt injections, explaining why adversarial safety training fails against it and proposing a linear probe detection method.

- LLMs track conversational roles using both content cues (semantics, writing style) and structural cues (control tokens, formatting).
- Role spoofing occurs when malicious tool outputs (e.g., untrusted webpages) impersonate the user by combining fake structural and content cues.
- Adversarial training focused on ignoring content-based injections leaves LLMs vulnerable to structure-based spoofing, explaining frontier model susceptibility.
- A mitigation method using linear probes trained to predict conversational roles effectively detects role spoofing across multiple settings.

**Why it matters:** Understanding role spoofing helps developers prevent indirect prompt injections in autonomous LLM agents that process untrusted web data.

<small>Ezra Edelman, Benjamin Edelman, Surbhi Goel, Eran Malach</small>

### [Surprise Alone Learns Lies: Evidence-Gated Continual Learning for LLMs from Streaming Claims](https://arxiv.org/abs/2610.39840v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39840v1`

A study demonstrates that surprise-driven continual learning in LLMs selectively absorbs lies and evaluates mechanisms like model priors, LLM judges, and evidence retrieval to gate stream updates.

- Surprise-driven selection absorbs planted falsehoods at rates similar to random selection because low-probability claims are highly surprising by design.
- The model's original prior distinguishes lies about known facts from true new facts (AUC 0.78-0.83 across Qwen2.5-1.5B, Qwen2.5-3B, and Llama-3.2-3B), but fails to separate lies from legitimate updates (AUC 0.53).
- Filtering with model priors saves 43% of LLM judge calls, but white-box attackers can craft lies that bypass prior-based filters.
- Routing contradicted claims to trusted evidence sources lowers the poison rate among learned claims, but performance degrades below judge-only baselines if an attacker plants matching sources for 30% of lies.

**Why it matters:** Naively selecting stream inputs based on model surprise makes continual learning pipelines highly vulnerable to data poisoning and hallucination uptake.

<small>Abdelkader Metales, Miriam Grabenheinrich</small>

### [InferD: A Honeypot Framework for AI Inference Infrastructure](https://arxiv.org/abs/2610.39807v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39807v1`

InferD is a low-interaction honeypot framework for exposed AI inference infrastructure that operates on the principle of deception without inference.

- Operates on a 'deception without inference' design where every observable response comes from static pools, avoiding actual model inference or tool execution.
- Emulates key observable behaviors of AI serving stacks, including model inventories, token formats, tool-call protocols, and authorization flows.
- Decomposes AI system emulation into four distinct deception planes: transport, service protocol, vulnerability surface, and agentic session.
- Includes a provenance plane that links planted honeypot credentials directly to evidence of downstream model-mediated processing by adversaries.

**Why it matters:** It enables safe, low-cost measurement and threat intelligence gathering on public-facing AI inference APIs, vector databases, and agent gateways without exposing actual models or execution environments to risk.

### [SEAL: Sealed Queries for Local Sanitization against Indirect Prompt Injection](https://arxiv.org/abs/2610.39758v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39758v1`

SEAL is an offline-learned soft prompt and token-scoring defense that sanitizes untrusted tool outputs via localized deletion using a frozen task model without generating defense tokens or using separate verifiers.

- Constructs scoring queries from trusted initial context and a learned soft prompt, keeping the reference independent of inspected tool text.
- Scores tokens without context-wide normalization and applies preservation regularization during localized deletion to retain task-relevant evidence.
- Reduces attack success rate on AgentDojo from 34.6% to 0.1% while increasing joint task completion from 51.4% to 77.5%.
- Requires approximately 127x fewer defense-related tokens than PISanitizer and demonstrates cross-backbone transferability.

**Why it matters:** It enables lightweight, highly effective mitigation of indirect prompt injections in resource-constrained local LLM agents without requiring secondary verifier models or heavy inference overhead.

<small>Doohyun Kim, Donghwa Kang, Mingyu Jun, Brent ByungHoon Kang</small>

### [Judging Before Propagation: Task-Graph Contextual Integrity for Multi-Agent Privacy](https://arxiv.org/abs/2610.39532v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39532v1`

Task-Graph Contextual Integrity (TG-CI) formalizes multi-agent privacy by evaluating information disclosure across stateful workflow graphs before propagation rather than judging local transfers in isolation.

- TG-CI models workflows as Multi-Agent Task Graphs (MATGs) to evaluate privacy against an item's intended downstream propagation scope and recipient disclosure histories.
- Implements two enforcement policies: Full-Scope (requires admissibility across the complete downstream graph) and Auto-Region (confines items to maximal admissible regions via frontier gates).
- Evaluated on MAPLE-Bench, a new 144-case benchmark testing variations in MATG topology, disclosure history, compromised agents, and privacy policies.
- Reduces mean unauthorized disclosures by 85.8-94.1% compared to Local-History CI baselines while preserving 93.6-96.1% of task accuracy.

**Why it matters:** It prevents privacy leaks in complex multi-agent workflows where individual information transfers appear benign in isolation but breach confidentiality when propagated downstream.

<small>Hengyu Wu, Blaise Delattre, Yang Cao</small>

### [Systematic Evaluation of Adversarial Jailbreaking Attacks and Defenses Across Seven Large Language Models](https://arxiv.org/abs/2610.39509v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39509v1`

A systematic evaluation of seven LLMs and four defenses reveals obfuscation attacks are the most effective (54.3% mean ASR), while self-reminder prompting provides the most robust defense.

- Obfuscation attacks achieved a mean Attack Success Rate (ASR) of 54.3% across all models and bypassed every evaluated model with non-zero success.
- Model size does not correlate with adversarial robustness (Spearman r = -0.57, p = 0.18), and vulnerability profiles vary widely even within the same architecture family.
- Self-reminder prompting reduced ASR from 44% to 10% on Mistral-7B and from 48% to 5% on Llama-3.1-8B with zero false positives and no extra inference cost.
- The study systematically benchmarked five attack types against open-weight and API models including Llama-3-8B, Llama-3.1-8B, Llama-3.2-3B, Mistral-7B, Qwen2.5-7B, Gemma2-9B, and Phi-4-14B.

**Why it matters:** It demonstrates that scaling model size does not inherently grant security against jailbreaks, while highlighting self-reminder prompting as a cost-free, highly effective defense.

<small>Md. Robiul Islam Niloy, Abu Sayed Md. Mostafizur Rahaman</small>

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39155v1`

REALM enforces least privilege in LLM agents by dynamically building asset dependency graphs and isolating execution using task-specific Partial APIs and containers.

- Uses a dependency graph to represent task assets and applies source-scoped selection to safely authorize assets discovered at runtime.
- Separates asset discovery from authorization using a REALM Builder to manage grants and a Partial API Manager to expose resource-bound APIs inside a Task Container.
- Tested on AgentDyn across 60 clean and 560 injected tasks using the qwen3.5-flash base model.
- Reduces the attack success rate (ASR) of prompt injections from 16.6% to 0.2% while completing 40.0% of clean tasks and 36.4% of injected tasks.

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39122v1`

Self-evolution mechanisms in personal agents degrade robustness against indirect prompt injection, increasing attack success rates after learning from user feedback.

- Evaluated two self-evolution approaches: skill evolution and reinforcement learning from user feedback.
- Tested using a two-phase framework: an adaptation phase with authorized tasks in external content and a test phase with unauthorized injected tasks.
- Skill evolution increased the average Attack Success Rate (ASR) over the base agent by 14.0 to 48.8 percentage points.

### [PCM: A Proof-Carrying Message Protocol for Verifiable Multi-Agent Communication](https://arxiv.org/abs/2610.39109v1)

**arXiv cs.CR** · 2026-10-29 · `arXiv:2610.39109v1`

Proof-Carrying Messages (PCM) is a cryptographic multi-agent communication protocol where messages carry Merkle inclusion proofs signed by external attesting signers, ensuring claims are verified offline independently of the sender's self-report.

- Uses append-only Merkle log inclusion proofs signed by uncontrollable attesting signers, yielding three-valued verification outcomes: proven, unproven, or failed.
- Restricts authority propagation through cryptographic grant chains that originate from recorded human approvals and can only narrow in scope.
- Defines four claim types, a typed caveat algebra, replay rules, and strict readings to enforce deterministic verification across independent implementations.
- Evaluated on a benchmark of 926 real-run messages (712 lies across 16 classes); PCM accepted only 10 stale-evidence lies (1.4% false-positive rate) at ~1 ms verification latency, outperforming six existing protocols.

**Why it matters:** PCM prevents prompt-injected agents from laundering fabricated facts or authority across multi-agent systems by decoupling message content verification from channel-level authentication.

### [Where You Inject Matters: The Trust Region Effect in LLM Agents](https://arxiv.org/abs/2610.38867v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38867v1`

Researchers identify the trust region effect in LLM agents, demonstrating that attack success rates for indirect prompt injections vary based on where malicious instructions are placed within an environment.

- Evaluated injection placements across three long-horizon agentic testbeds spanning tool use, coding, and daily workflows.
- Observed that a GPT-5.4-powered agent executes unsafe instructions in repository documentation files (README/TODO) 2.6 times more frequently than in code or data files.
- Developed learning-based attacker models that optimize both the content and the environmental placement of indirect prompt injections.

**Why it matters:** Demonstrates that LLM security defenses must account for uneven implicit trust across environment surfaces rather than focusing solely on inspecting raw text content.

### [CARI: Cross-Boundary Adversarial Runtime Injection in Coding-Agent Workflows](https://arxiv.org/abs/2610.38799v1)

**arXiv cs.CR** · 2026-10-28 · `arXiv:2610.38799v1`

CARI is a novel attack exploiting authority mismatch by embedding malicious instructions in peer-controlled runtime feedback, causing coding agents to execute unauthorized local actions.

- Exploits authority mismatch where a compromised peer component has diagnostic authority to report state but lacks action authority over the victim's local environment.
- Instantiates ten attacks across four programming languages, achieving a 94.8% (2,845/3,000) success rate across five code-capable models.
- Transfers to commercial product-level agents, demonstrating a 61.3% attack success rate on Codex and 58.7% on Claude Code.
- Evaluated defenses show a strict security-utility trade-off: generic prompt warnings fail, while explicit policies cause significant over-refusal of legitimate actions.

**Why it matters:** Multi-agent and collaborative coding environments are vulnerable to severe compromise via standard runtime feedback channels, and current prompt-level defenses fail to secure them without degrading utility.

<small>Jie Fu, Shuang Wu, Ashish Kundu, Wendy Hui Wang, Yuan Hong</small>

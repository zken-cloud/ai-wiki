### [Suppression Is Not Erasure: Mechanistic Analysis and Reactivation Boundaries of Subspace Projection for LoRA Backdoor Defense](https://arxiv.org/abs/2611.12807v1)

**arXiv cs.CR** · 2026-11-09 · `arXiv:2611.12807v1`

A study reveals subspace projection defenses suppress backdoors in LoRA adapters to 0.0% static Attack Success Rate, but fail to erase them, enabling 100% backdoor reactivation within two epochs of few-shot fine-tuning.

- Module-wise rank-1 trigger-difference projection reduces static Attack Success Rate (ASR) from 70.3% to 0.0% in under 5 seconds without prior trigger knowledge.
- Trigger-free calibration using benign polite suffixes aligns with the trigger-difference subspace u1(B) at a median cosine similarity of 0.9048.
- Under 5-sample few-shot reactivation, all weight-editing defenses rebound to 91.7%-100.0% ASR in Epoch 1 (or 48.7% for a dual variant) and reach 100.0% by Epoch 2.
- First-epoch reactivation loss is up to 5.7x lower than training from scratch due to residual trigger-difference coupling energy (Spearman rho = 0.986) and base-model learnability.

**Why it matters:** Evaluating backdoor defenses using only static Attack Success Rate creates a false sense of security, as stealthy backdoor mechanisms remain latent in the model parameters and can be fully reactivated with minimal downstream fine-tuning.

<small>Junsheng Fu, Shuangshuang Gao</small>

### [Say Shibboleth: Fingerprinting the LLMs and Harnesses Behind Agentic Attacks](https://arxiv.org/abs/2611.12386v1)

**arXiv cs.CR** · 2026-11-09 · `arXiv:2611.12386v1`

A novel fingerprinting framework uses shibboleth traps and indirect probes to identify agentic attack LLMs and harnesses with up to 92% accuracy using telemetry.

- Shibboleth traps serve as modular honeypot services that elicit model declarations and characteristic writing without requiring successful prompt injections.
- Indirect probes measure harness execution behaviors including secret masking in tool outputs, command time limits, and tool-call scheduling.
- Combined declarative and behavioral inference distinguishes among 15 candidate models with an average 90% top-1 accuracy.
- Fixed probe rules correctly identify the target execution harness across four candidates with 92% accuracy, remaining effective even when agents attempt to conceal their identity.

**Why it matters:** Defenders can reliably attribute automated agentic cyberattacks to specific LLM models and attack frameworks solely through telemetry from honeypot interactions.

**arXiv cs.CR** · 2026-11-09 · `arXiv:2611.12377v1`

Researchers present a taxonomy of shadow AI agents and release Agent Detector, an open-source Windows tool that uses remote service identity, configuration, and execution history rather than process behavior alone to identify unsanctioned agents.

- Taxonomy categorizes unsanctioned agentic artifacts into nine agent classes and six endpoint footprint layers.
- Traditional process and connection behavior rules fail by misidentifying benign 'behavioral twins' (programs connecting to non-AI services) as agents.
- Agent Detector leverages a catalog of 39 tools and 184 LLM endpoint entries, scanning in 154 ms to accurately detect agents while eliminating false positives on behavioral twins.
- Detection limitations include short DNS cache retention (1–5 minutes) for providers behind shared CDNs and reduced detection rates (about 1 in 3 scans) for intermittent agents.

**Why it matters:** Detecting shadow AI on enterprise endpoints requires tying behavioral data to specific remote LLM identities, as process and network structures alone cannot distinguish AI agents from benign software.

**arXiv cs.CR** · 2026-11-09 · `arXiv:2611.12241v1`

SNAPRAG is an LLM-free, black-box knowledge extraction attack on RAG systems that uses token mutation and adaptive dissimilarity threshold calibration to extract knowledge bases with fewer queries.

- Employs a discrete token-mutation algorithm to algorithmically generate adversarial queries without relying on external LLMs or white-box access.
- Uses adaptive dissimilarity threshold calibration to drive queries into unexplored semantic regions of the target database.

**Why it matters:** It demonstrates that private knowledge bases in RAG systems can be efficiently stolen at a significantly lower query cost and without relying on external LLMs, even when active defenses are present.

### [StealthyPoison: Manipulating LLM Agent Behavior through Procedural Poisoning of Third-Party Skills](https://arxiv.org/abs/2611.12155v1)

**arXiv cs.CR** · 2026-11-09 · `arXiv:2611.12155v1`

StealthyPoison introduces a stealthy procedural poisoning attack that corrupts third-party LLM agent skill rules without user-request access, bypassing detection by SkillSpector and GPT-5.4-mini.

- Synthesizes target-skill requests and uses surrogate agent execution feedback to iteratively refine payloads that modify decision-critical rules while maintaining advertised functionality.
- Augments retrieval metadata with independently generated request descriptions, boosting top-1 poisoned-skill placement by 13.6% over HotFlip and GCG baseline attacks.
- Transfers payloads created from a single surrogate model to three held-out victim models without modification, executing end-to-end attacks in a Claude Code workflow using Opus 4.8.
- Evaluated across 566 target skills, 5,244 requests, and over 26,000 registry entries.

**Why it matters:** Public LLM agent skill registries are vulnerable to generalized, highly transferrable poison attacks that execute incorrect task outcomes while evading standard safety classifiers.

### [ShadowBench-MCP: Measuring Shadow Invocations in MCP-Style Tool Routing](https://arxiv.org/abs/2611.11720v1)

**arXiv cs.CR** · 2026-11-09 · `arXiv:2611.11720v1`

ShadowBench-MCP introduces a benchmark to measure shadow invocations, where task-preserving request variants lead LLM routers to select riskier execution paths and bypass security controls.

- Shadow invocation occurs when a benign request variant causes an LLM router to skip validation, redaction, or audit controls while fulfilling the original task.
- ShadowBench-MCP uses the SODS score, combining task preservation (TPSS), operational pressure (OPSS), and route-geometric drift (RGAS) to evaluate routing risk pre-execution.
- Testing on a Groq-hosted qwen/qwen3-32b router showed efficiency-first routing yields a 29.2% shadow-invocation rate and a 26.7% safety-tool skip rate across six workflows.
- Policy-aware routing reduced shadow invocations to 4.2% and tool skips to 1.7%, representing an 85.7% relative reduction.
- Pre-execution signals successfully distinguished shadow routes from standard routes with a ROC AUC up to 0.94.

**Why it matters:** LLM agents serving as tool routers require policy-aware routing configurations to prevent benign prompt variations from accidentally bypassing critical software supply chain and security controls.

<small>Eyhab Al-Masri, Wenjun Yang</small>

### [Treating the Model as an Untrusted Component: Deterministic Policy Enforcement, Human Approval and Taint Tracking Against Prompt Injection in Tool-Using Agents, with Validation on Open-Weights Models](https://arxiv.org/abs/2611.11571v1)

**arXiv cs.CR** · 2026-11-08 · `arXiv:2611.11571v1`

Researchers evaluated prompt injection defenses for LLM agents using open-weights models and simulations, proving deterministic external reference monitors outperform in-prompt guardrails against persistent adaptive attacks.

- In-prompt defenses failed against simulated adaptive attackers (100% attack success), whereas a task-bound deterministic monitor held severe unauthorized actions to 0.0%.
- Real-model testing with Qwen2.5-1.5B and Qwen2.5-7B showed models proposed attacker calls in 64% and 84% of episodes, but the task-bound monitor admitted only 1.3% and 7.7%.
- Adding taint-triggered human review to the task-bound monitor reduced residual harm by 62%, though human approval layers without deterministic monitors failed against approval spamming.
- Monitor implementation quality is critical: a naive monitor admitted 18 of 33 attack variants, while a hardened monitor admitted 6, and a capability-bound monitor admitted 1.

**Why it matters:** Securing tool-using LLM agents against prompt injection requires treating the model as untrusted and enforcing security boundaries using external, deterministic reference monitors rather than relying on prompt engineering.

<small>Mustafa S. Aljumaily, Nawar S. Alseelawi, Raghad Alshabandar</small>

### [PRISM: Causal Counterfactual Minimization of Agent Tool Privileges via Information Bottleneck Role Induction](https://arxiv.org/abs/2611.11539v1)

**arXiv cs.CR** · 2026-11-08 · `arXiv:2611.11539v1`

PRISM introduces causal counterfactual minimization to restrict over-authorized LLM agent tool privileges under the Model Context Protocol without sacrificing task performance.

- Evaluates tool necessity by applying structured sandbox interventions to train a counterfactual necessity model.
- Compresses execution trajectories into discrete latent variables via an information bottleneck, identifying optimal role counts via the rate-distortion curve knee.
- Formulates privilege pruning as a bilevel Stackelberg game using Generative Flow Networks (GFlowNets) to sample diverse near-optimal policies.
- Achieves 78.3% tool compression per role, 88.7% counterfactual necessity accuracy, 78.2% task success rate, and reduces blast radius to 15.9% across AgentDojo, tau-bench, and ToolEmu benchmarks.

**Why it matters:** It enables principled, automated least-privilege role engineering for LLM agents, drastically reducing security exposure in systems using the Model Context Protocol.

**arXiv cs.CR** · 2026-11-08 · `arXiv:2611.11506v1`

Researchers introduced PlanTERS, an Isabelle/HOL-mechanised framework that formalises LLM agent prompt injection security as 'relative security' by comparing an agent's leaks against a reference agent running a non-injectable model.

- Defines relative security where an LLM agent is secure if it introduces no leaks beyond those of a reference model that ignores untrusted content.
- Proves a fence theorem showing that revoking injectable tools at the first untrusted read guarantees event-level relative security on finite and fair infinite runs.
- Mechanises and verifies security proofs and counterexamples in Isabelle/HOL for agent designs using fences, budgets, user approvals, loops, and dual-LLM architectures.
- Models attacker behaviors using an agent language where the adversary controls model instruction-following under different observation capabilities.

**Why it matters:** It provides a mathematically formal foundation to rigorously evaluate and prove the effectiveness of prompt injection defenses in LLM agents rather than relying on empirical heuristics.

**arXiv cs.CR** · 2026-11-08 · `arXiv:2611.11455v1`

A study reveals that LLM-based coding agents propagate existing repository vulnerabilities into new code, with insecure contexts increasing vulnerability introduction rates by up to 35.4% in C/C++ projects.

- Evaluated coding agents across 96 backend implementation tasks and 20 memory-safety-critical C/C++ repository tasks.
- Insecure existing code reduced correct and secure implementations by 3.4% in backend generation and up to 35.4% in C/C++ codebases.
- When asked to explain implementation choices, agents attributed their code to existing repository sites in 76.5% of cases, despite recognizing the introduced vulnerability 69.9% of the time.
- Prompts to follow code style increased vulnerability propagation, while security prompts decreased but failed to eliminate it.

**Why it matters:** Without continuous security fixes, autonomous coding agents operating under reduced human review will compound existing vulnerabilities and degrade overall codebase security.

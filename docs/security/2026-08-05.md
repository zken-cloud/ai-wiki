### [When Agents Learn to Be You: Benchmarking Privacy Leakage, Impersonation Risk, and Defenses in Persona Skills](https://arxiv.org/abs/2608.03700v1)

**arXiv cs.CR** · 2026-08-04 · `arXiv:2608.03700v1`

AntiSkillBench is a new benchmark designed to systematically evaluate skill-level privacy leakage, attribute disclosure, behavioral impersonation, and existing defense mechanisms across persona-skill pipelines in downstream agents.

- AntiSkillBench includes 7,500 persona-grounded dialogue traces derived from 50 detailed profiles across various task scenarios.
- Evaluates three skill-distillation strategies for privacy and impersonation risks, spanning explicit attributes, communication styles, and personality traits.
- Tests four defense configurations incorporating online/post-hoc interventions, active risk suppression, and passive provenance protection.
- Empirical evaluations on three frontier agents reveal that risks persist across model backbones, and existing defenses fail to generalize across distillation protocols.

**Why it matters:** Persona skills concentrate personal interaction history into reusable agent artifacts, creating persistent privacy and impersonation vulnerabilities that current defenses cannot reliably mitigate.

<small>Yongli Xiang, Zhifang Zhang, Bojun Yang, Ziming Hong, Lei Feng, Miao Xu, Tongliang Liu</small>

### [DiagChain: A Diagnostic Benchmark for Evaluating LLM Agents on Evidence-Grounded Attack Chain Reconstruction](https://arxiv.org/abs/2608.03591v1)

**arXiv cs.CR** · 2026-08-04 · `arXiv:2608.03591v1`

DiagChain is a diagnostic benchmark featuring the MAIN-69 scenario suite and five stage-wise metrics to evaluate LLM agents on evidence-grounded attack chain reconstruction.

- MAIN-69 consists of 69 scenarios comprising 849 reference steps across multiple operating systems, evidence noise levels, and chain lengths.
- Introduces Evidence-Centric Retrieval-Augmented Generation (ECRAG), which pairs evidence retrieval with an evolving structured representation of the attack chain.
- Establishes five complementary metrics designed to isolate intermediate reasoning errors and evaluate distinct reconstruction stages.
- Evaluations of six LLMs showed the top-performing configuration achieved only a 39.6% step-level success rate.
- Error analysis indicates smaller models fail at integrating retrieved evidence into outputs, while larger models struggle primarily with chronological ordering of evidence.

**Why it matters:** Stage-wise diagnostic evaluation exposes specific reasoning and ordering bottlenecks in cybersecurity LLM agents that aggregate end-to-end accuracy metrics obscure.

### [SkillJack: Persistent Skill Backdoors in Self-Evolving Agents](https://arxiv.org/abs/2608.03509v1)

**arXiv cs.CR** · 2026-08-04 · `arXiv:2608.03509v1`

SkillJack is the first attack targeting the experience-to-skill pipeline of self-evolving agents, embedding persistent malicious behaviors into an agent's reusable skill repertoire via its own learning process.

- SkillJack operates via sanitization whitewashing, cross-layer promotion, and persistence isolation to bypass contextual retrieval defenses.
- Evaluated on SkillX and Anything2Skill using 150 trajectories across four policy-risk categories, safety detection dropped from 98.5% on raw poisoned trajectories to 11.4% on extracted skills.
- Achieved attack success rates of 56.2% on SkillX and 89.2% on Anything2Skill.
- 80.0% of skill-mediated attacks remained active after the original poisoned source records were deleted, with some skills unintentionally triggering on benign queries.

**Why it matters:** Self-evolving agents can permanently internalize backdoors into their skill libraries, rendering memory deletion and context-level guardrails ineffective against hidden exploits.

<small>Zonghao Ying, Xiangfan Wu, Huiyu Wu, Xing Zheng, Huangsheng Cheng, Xiaorong Shi, Jing Guo</small>

### [SkillSentry: Adaptive Honey Worlds for Dynamic Safety Testing of Agent Skills](https://arxiv.org/abs/2608.03485v1)

**arXiv cs.CR** · 2026-08-04 · `arXiv:2608.03485v1`

SkillSentry is a dynamic safety-testing framework that uses LLM-simulated environments with adaptive honey worlds and decoy resources to detect conditional malware in LLM agent skills.

- Infers intended skill boundaries and builds LLM-simulated honey worlds containing controlled decoy resources to trigger environment-dependent malicious behaviors.
- Adaptively generates task trajectories to explore state space, comparing skill-enabled runs with matched no-skill executions.
- Grounds identified suspicious actions directly in source code and verified execution traces before finalizing safety decisions.
- Outperforms standard scanners on benchmarks with 99.50% Recall and 96.26% average F1 score.
- Maintains an average F1 score of 92.95% under semantics-preserving evasion attacks, compared to 80.07% for top baselines.

**Why it matters:** It enables robust detection of complex, state-dependent agent skill vulnerabilities that bypass traditional static code analysis and one-shot evaluation methods.

**arXiv cs.CR** · 2026-08-04 · `arXiv:2608.03174v1`

Researchers introduced the first attribute-based undetectable watermarking scheme for generative AI, enabling fine-grained, policy-controlled detection to prevent watermark sanitization, scope abuse, and user profiling.

- Constrains detection keys using specific attribute policies so a key only identifies outputs meeting its designated criteria while leaving outside outputs computationally indistinguishable.

### [Test-time reasoning effort and unauthorized tool use in language-model agents: a prespecified equivalence study](https://arxiv.org/abs/2608.03169v1)

**arXiv cs.CR** · 2026-08-04 · `arXiv:2608.03169v1`

A prespecified study on GPT-5.6 using the TRIO-20 benchmark found that increasing test-time reasoning effort from low to max produced zero unauthorized tool calls and did not increase authorization violations.

- Evaluated GPT-5.6 across 14 confirmatory scenarios in TRIO-20 (840 total trajectories across Terra and Sol tiers) under low and max reasoning effort.
- Zero unauthorized tool calls were observed, placing exact one-sided 95% upper limit violation rates below 3.50% for Terra and 5.21% for Sol.
- The interaction effect of reasoning effort on violation rates fell within the prespecified equivalence margin of ±7.01 percentage points on Terra (interval of ±4.34 percentage points).
- Higher reasoning effort increased rule-probe inspection rates across all conditions, notably where probing had no instrumental payoff (-14.3 points, 95% CI -27.4 to +1.2).

**Why it matters:** Operators can scale test-time reasoning parameters for performance or latency without increasing the risk of LLM agents making policy-prohibited API calls.

<small>Xiaonan Xu, Wenjing Wu</small>

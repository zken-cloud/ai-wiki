### [What Can Be Enforced? A Theory of Certified Runtime Safety for Tool-Using Agents](https://arxiv.org/abs/2607.22868v1)

**arXiv cs.CR** · 2026-07-24 · `arXiv:2607.22868v1`

This paper establishes a theoretical framework for certified runtime safety in tool-using agents by analyzing deterministic gate expressivity, statistical Neyman-Pearson/conformal bounds, and closed-loop control dynamics.

- Deterministic gates enforce safety policies based on good prefixes recognized by their register model; checking policy nontriviality is undecidable with two decrementable counters, but is in PSPACE for separable monotone fragments.
- Exogenous safety bounds are established via Neyman-Pearson frontiers for exact error trade-offs and conformal calibration for finite-sample marginal certificates.
- Static scores fail to identify closed-loop safety when interventions alter future proposal distributions, requiring a finite controlled model solved via an occupancy program.
- Robustness margins are required under bounded representation attacks because benign statistical calibration does not automatically transfer.

**Why it matters:** It formally defines the mathematical limits and requirements for building provably safe runtime guardrails around autonomous, tool-using AI agents.

<small>Shawn Ray</small>

### [Dynamic Capability Scoping for Enterprise AI Agents: A Synthetic Dataset and Three-Source Permission Architecture](https://arxiv.org/abs/2607.22445v1)

**arXiv cs.CR** · 2026-07-24 · `arXiv:2607.22445v1`

A dynamic capability scoping framework and synthetic dataset address enterprise AI agent over-privilege by enforcing least-privilege access through role ceilings, task-context classification, and policy-derived tool combination prohibitions.

- Dynamic least-privilege architecture uses three permission sources: role-based ceilings, a task-context classifier, and policy-derived combination prohibitions.
- Includes a dual-mode system supporting active enforcement or an observe-only mode that logs context-inconsistent permission requests for misalignment research.
- Provides a synthetic dataset of 600 enterprise task prompts evaluated against a 15-permission taxonomy across a multi-department policy framework.
- Dataset generation uses a two-pass pipeline to separate prompt generation from permission labeling, validated by human review achieving a post-review Cohen's kappa of 0.967.
- Iterative policy refinement using the synthetic dataset reduced permission ceiling violations by 93% (from 46 down to 3).

**Why it matters:** Proactively restricting available tool credentials based on real-time task context eliminates the attack surface for agent credential misuse before prompt-level evasion or misalignment can occur.

### [Agent Security Needs Redefinition through a Holistic Framework](https://arxiv.org/abs/2607.22024v1)

**arXiv cs.CR** · 2026-07-24 · `arXiv:2607.22024v1`

A new framework redefines agent security from a content-based model to a contextual model evaluated continuously across four key properties: Source Authorization, Task Alignment, Action Alignment, and Data Isolation.

- Content-based evaluations fail to distinguish routine commands from malicious attacks like prompt injections without authorization context.
- The proposed framework defines four properties that must hold jointly: Source Authorization, Task Alignment, Action Alignment, and Data Isolation.
- Indirect prompt injection is recharacterized as a Source Authorization violation rather than a content issue.
- Snapshot benchmarks (e.g., AgentDojo, WASP) are structurally incapable of evaluating Data Isolation and continuous agent trajectories.

**Why it matters:** Reframing agent security around context alters how defenses are designed, reorganizes existing security tools, and exposes attack patterns invisible to traditional snapshot benchmarks.

<small>Vincent Siu, Jingxuan He, Kyle Montgomery, Zhun Wang, Chenguang Wang, Dawn Song</small>

### [ISPCloak: Weaponizing ISP for Optimization-Free Physical Camouflage against Deepfake Detectors](https://arxiv.org/abs/2607.21897v1)

**arXiv cs.CR** · 2026-07-24 · `arXiv:2607.21897v1`

ISPCloak is an optimization-free adversarial attack that misleads deepfake detectors by projecting images to the RAW domain and injecting authentic camera ISP noise and statistical signatures.

- Reveals deepfake detectors fail when AI-generated content includes authentic hardware-intrinsic ISP and sensor statistical signatures.
- Uses an Invertible ISP network to transform images into the RAW domain without gradient-based optimization.
- Injects realistic Poisson-Gaussian sensor noise and executes forward ISP reconstruction combined with adaptive masking and generative artifact suppression.
- Enables fast generation of physical-domain adversarial examples that disrupt a wide range of forensic detection mechanisms.

**Why it matters:** This vulnerability demonstrates that current deepfake detectors rely heavily on digital artifacts and can be bypassed by mimicking hardware-level camera processing pipelines.

<small>Jiale Zhao, Jiajun Wan, Lei Tang, Ye Qin, Kebing Jin, Jinghui Qin</small>

### [PrivDNN: A Secure Multi-Party Computation Framework for Deep Learning using Partial DNN Encryption](https://arxiv.org/abs/2607.21895v1)

**arXiv cs.CR** · 2026-07-24 · `arXiv:2607.21895v1`

PrivDNN is a secure multi-party computation framework that offloads inference to the user by selectively encrypting only core neurons within deep neural networks.

- Offloads ciphertext-domain computation to the user side by sharing an encrypted deep learning model
- Uses partial DNN encryption to reduce computational overhead
- Employs a core neuron selection and encryption scheme to maintain model privacy and accuracy
- Reduces privacy-preserving DNN inference latency and memory usage by up to 97%

**Why it matters:** It enables high-efficiency, privacy-preserving deep learning inference on user devices without exposing proprietary models or sensitive user data.

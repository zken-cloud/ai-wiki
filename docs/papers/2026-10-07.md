### [Rethinking Cross-Tokenizer On-Policy Distillation: From Alignment Coverage to Supervision Reliability](https://arxiv.org/abs/2610.08448)

**Hugging Face Daily Papers** · 2026-10-05 · 👍 147 · `arXiv:2610.08448`

Researchers demonstrate that cross-tokenizer on-policy distillation achieves optimal performance using compact, reliable supervision at strictly aligned token positions rather than maximizing full sequence alignment coverage.

- Strict 1:1 token alignment groups cover the majority of student-generated tokens across mathematical reasoning and code generation tasks despite tokenizer mismatches.
- Restricting reverse KL divergence to a student-selected top-16 subset of the shared vocabulary at strict positions matches full shared-vocabulary distillation accuracy while outperforming existing cross-tokenizer baselines.
- Adding mean squared error (MSE) supervision on span log-probabilities for mismatch groups achieves complete coverage but degrades overall model accuracy.
- Gradient diagnostics reveal that span supervision gradients exhibit weak or negative directional agreement with strict gradients and grow disproportionately in magnitude during training.

**Why it matters:** Prioritizing supervision reliability over complete alignment coverage reduces computational overhead and prevents training instability caused by conflicting gradient signals in cross-tokenizer model compression.

<small>Bingxi Hou, Guochao Jiang, Guofeng Quan, Weiqing Li, Wenfeng Feng, Guohua Liu, Yuewei Zhang</small>

TRACE is an FP4 quantization framework for Mixture-of-Experts language models that aligns train and rollout execution paths using rollout-guided quantization-aware training and deep-layer quantization-information caching.

### [When Forgetting is not Catastrophic: On the Mechanics of Spurious Forgetting](https://arxiv.org/abs/2610.08718v1)

**arXiv cs.LG** · 2026-10-06 · `arXiv:2610.08718v1`

Researchers show that language model forgetting consists of reversible access loss and irreversible erosion, where temporary collapse during finetuning can be undone by removing a single weight update direction.

- Spurious forgetting requires three minimal components: shared key structure, concentrated new values, and network normalization.
- Finetuning temporarily shifts all old representations along a single common direction, hiding old facts while preserving their relative geometry before normalization gradually reverses the shift.
- True catastrophic erosion happens via slow, fact-specific weight changes that accumulate over time.
- Subtracting the shared common shift restores forgotten facts in synthetic Transformers and pretrained language models by removing a single direction from each weight update.

**Why it matters:** Understanding that early forgetting is often a reversible representation shift allows practitioners to recover lost knowledge from finetuned models without full retraining.

### [Towards In-Parameter Memory Augmentation for Large Language Models](https://arxiv.org/abs/2610.08630v1)

**arXiv cs.CL** · 2026-10-06 · `arXiv:2610.08630v1`

This survey taxonomy categorizes in-parameter memory augmentation for LLMs across two axes: Parameter Placement (Embedding, Attention, FFN, or Hybrid) and Parameter Acquisition Time (offline versus online deployment).

- In-parameter memory integrates reusable information directly into model parameters, adapters, or parameter-like objects during the forward pass.
- The parameter placement axis categorizes methods into Embedding, Attention, FFN, or Hybrid layers.
- The parameter acquisition time axis divides methods based on whether memory objects are learned online during deployment or offline before deployment.
- The paper highlights open technical directions including parameter interference, safety, co-design with in-context learning, and recursive self-improvement.

**Why it matters:** It provides a structured taxonomy for extending LLM knowledge capacity without consuming context windows or incurring repeated context encoding costs during inference.

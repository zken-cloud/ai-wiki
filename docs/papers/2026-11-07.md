**Hugging Face Daily Papers** · 2026-11-03 · 👍 7 · `arXiv:2611.06982`

Speculative Listening is a training-free, lossless self-speculative decoding framework that utilizes idle compute during input time to accelerate chunk-interleaved full-duplex speech language models.

- Empirical analysis showed the next audio chunk leaves output unchanged in 95.3% of chunks, and 88% of changes originate at the first output token.
- During idle time while awaiting audio, the model drafts the next chunk assuming silence, plus a secondary branch from the runner-up first token if changes occur.
- Drafts are stored in a cross-chunk hypothesis pool and verified instantly once real audio arrives.

**Why it matters:** It drastically reduces response latencies in full-duplex speech language models to human-like turn-taking speeds without requiring model retraining or sacrificing output quality.

Muir optimizes linear attention by pairing sensitivity-allocated low-rank gate projections with matched-filter readout, outperforming Gated DeltaNet-2 and standard Transformers.

- Identifies an asymmetry in state updates: key normalization concentrates energy onto sparse channels (allowing lower-rank erase gates), whereas value writes scale all channels.
- Introduces matched-filter readout gating to re-weight slow- and fast-decaying state rows, preventing unweighted state rows from dominating outputs and reducing the need for aggressive erasure.
- Fuses gating into a sensitivity-allocated low-rank projection, reinvesting saved parameters into a wider feed-forward network, supported by a novel chunkwise parallel update algorithm for stable training.
- Demonstrates performance gains across 166M–1.34B parameter scales, including 1.8–2.0% lower perplexity over GDN-2, near-100% passkey retrieval up to 1M tokens, and 2,560x length extrapolation to 10M-token streams.

**Why it matters:** Muir delivers superior long-context reasoning, recall, and perplexity while training 2.7x faster than Transformers at 32K context lengths without incurring inference memory overhead.

**Hugging Face Daily Papers** · 2026-11-04 · 👍 2 · `arXiv:2611.06498`

- Offline RAG knowledge packs introduce a text-vector integrity gap where cryptographic signatures verify the publisher but do not guarantee vectors match their corresponding text.

### [FewStepRL: Fine-tuning Few-step Diffusion Models with Reinforcement Learning](https://arxiv.org/abs/2611.08240v1)

**arXiv cs.LG** · 2026-11-05 · `arXiv:2611.08240v1`

FewStepRL adapts reinforcement learning post-training objectives to few-step diffusion models using a systematic three-phase framework consisting of transformation, decomposition, and adaptation.

- Transformation converts objectives over densities, velocities, or rewards into x-space policy predictions at the clean end or at explicitly marked transition levels.
- Decomposition expresses the gradient of each objective as a combination of self-regression toward a reference anchor and a reward augmentation.

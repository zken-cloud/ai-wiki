### [Memory as Plans: World-Action Modeling with Memory-Grounded Planning](https://arxiv.org/abs/2609.11561)

**Hugging Face Daily Papers** · 2026-09-09 · 👍 22 · ⭐ 1 · `arXiv:2609.11561`

MaP-WAM introduces a Memory-as-Plans framework for robotic policies that converts episodic multimodal context into compact language and visual plans to decouple long-horizon memory retrieval from policy execution.

- Decomposes policy architecture into memory-grounded planning (producing segment-level language plans and visual guidance from past records) and plan-conditioned execution.
- Employs a World-Action-Progress (WAP) model to jointly predict action chunks and execution progress, using plan-observation alignment to trigger adaptive segment transitions.
- Maintains a fixed executor context length and utilizes structured attention for key-value caching in both planning and execution stages.
- Achieves an 83.3% success rate on RMBench and 78.0% success on real-robot tasks with roughly constant executor inference latency as history expands.

**Why it matters:** It resolves the trade-off between long-horizon memory context and execution efficiency in non-Markovian robotic manipulation by keeping executor latency constant regardless of history length.

### [Structural priors for data-efficient language learning](https://arxiv.org/abs/2609.11505v1)

**arXiv cs.AI** · 2026-09-10 · `arXiv:2609.11505v1`

Pretraining on non-language symbolic data induces structural priors that improve initial next-token prediction loss for language models, but these gains do not reliably transfer to downstream linguistic tasks.

- Pretraining models on non-language symbolic data like music, probabilistic grammars, and cellular automata yields lower initial next-token-prediction loss than random initialization.
- Non-language pretraining reduces the magnitude of weight shifts during subsequent language training, indicating initialization in a different region of the parameter space.
- Lower language-modeling loss from structural transfer fails to translate consistently into improved performance on downstream linguistic benchmarks.
- Pretraining on non-language symbolic data is less data-efficient for language tasks than simply training on additional natural language data.

**Why it matters:** While symbolic non-language data can act as a partial substitute for language data to optimize next-token prediction, it is insufficient for driving broader linguistic generalization.

### [When Agents Disagree: Bayesian Backward Reasoning as a Label-Free Anchor for Multi-Agent Collective Decision-Making](https://arxiv.org/abs/2609.11709v1)

**arXiv cs.AI** · 2026-09-10 · `arXiv:2609.11709v1`

A new label-free multi-agent decision framework uses Bayesian backward reasoning to construct a reverse posterior, evaluating cross-path consistency via Jensen-Shannon divergence to aggregate conflicting LLM agent outputs.

- Traditional forward reasoning maps evidence to labels, making standard aggregators like voting or LLM judges vulnerable to correlated errors across agents.
- Bayesian backward reasoning generates a reverse posterior from an explicit likelihood, providing an alternative factorization of the underlying posterior.
- Cross-path consistency between forward and reverse posteriors is measured using Jensen-Shannon divergence to rank agents.
- The paper introduces three aggregation strategies based on this signal: hard selection (MinJS), soft reweighting (FwdJS), and log-linear fusion (LogLin).
- Evaluated on DDXPlus across five LLM backbones, LogLin achieved the top performance, with the largest gains occurring on instances where agents disagreed.

**Why it matters:** It provides a principled, label-free method to resolve LLM agent disagreements by leveraging complementary reasoning factorizations rather than relying on standard forward-only voting or judges.

<small>Ken Chen, Wei Wang, Sachith Seneviratne, Hansani Weeratunge, Saman Halgamuge</small>

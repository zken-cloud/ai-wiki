EarlyEval reduces LLM agent evaluation costs by using lightweight LightGBM classifiers to predict task success or failure early and halt execution before completion.

### [It Takes Two to Match: Co-Evolving Generative Retriever with Reinforcement Learning](https://arxiv.org/abs/2609.00638)

**Hugging Face Daily Papers** · 2026-08-31 · 👍 61 · `arXiv:2609.00638`

CoGR is a retrieval framework that uses co-evolving reinforcement learning via GRPO to train LLMs to generate direct, aligned keyword representations for both queries and items, compatible with inverted indices.

- Trains dual LLMs (query-side and item-side generators) to produce compact keyword sets that match directly through standard inverted index infrastructure.
- Uses a two-stage training pipeline starting with supervised fine-tuning followed by co-evolving reinforcement learning using Group Relative Policy Optimization (GRPO).
- Optimizes both generators alternately against the opposite side's frozen index using a unified query-to-item retrieval F_1 objective.
- Calculates item-side rewards using a counterfactual marginal reward measuring the delta in query-side F_1 caused by the item's generated keywords.
- Outperforms 10 sparse, dense, and generative baselines, improving F_1 over the strongest baseline by 10.9% on an internal APP Marketplace dataset and 36.1% on the public WANDS benchmark.

**Why it matters:** CoGR enables LLM-driven generative retrieval across both queries and items without discarding existing, highly efficient keyword-based inverted index infrastructure.

<small>Runpeng Dai, Kaili Huang, Changsung Kang, Ciya Liao</small>

**Hugging Face Daily Papers** · 2026-09-01 · 👍 40 · `arXiv:2609.02737`

Declarative Attention (DA) allows language models to dynamically declare required context regions within their chain-of-thought, enabling inference engines to skip reading unnecessary KV cache without extrinsic scoring.

- Replaces extrinsic O(N) proxy scoring with intrinsic model declarations during chain-of-thought generation.
- Partitions inference generation into three distinct attention modes: full context, a specific region, or recent output only.
- Inference engines parse these declarations like tool calls to selectively bypass KV cache reads during decoding.
- Zero-shot evaluation on off-the-shelf models reduced total attended tokens by 52.0% for Gemma-4-31B and 31.1% for Qwen-3.6-27B across 15 long-context tasks.
- Accuracy drops were minimal (1.27 percentage points on Gemma-4-31B and 2.75 percentage points on Qwen-3.6-27B) and decreased with larger model scales.

**Why it matters:** It introduces a self-directed sparse attention mechanism that significantly cuts memory bandwidth and computational costs during long-context LLM decoding without retraining the model.

### [Influence-Directed Distillation: Solving the Diversity Bottleneck in Sampled-Token On-Policy Distillation](https://arxiv.org/abs/2608.29846)

**Hugging Face Daily Papers** · 2026-08-29 · 👍 14 · `arXiv:2608.29846`

Influence-Directed Adaptive On-Policy Distillation (IDA-OPD) resolves the diversity bottleneck in sampled-token distillation by using a First-Order Local Entropy Influence proxy to eliminate entropy-contracting updates without needing full-vocabulary teacher probabilities.

- Sampled-token on-policy distillation often suffers from diversity distillation failure where pass@1 improves but pass@k plateaus.
- First-Order Local Entropy Influence serves as a signed first-order proxy that attributes entropy contraction directly to negative-influence token positions.
- IDA-OPD preserves entropy-expanding updates while replacing entropy-contracting ones with a divergence-adaptive advantage shrinkage mechanism.
- The method requires only the teacher's sampled-token log-probability rather than expensive full-vocabulary Forward-KL objectives.
- Experiments on reasoning-oriented distillation demonstrate consistent pass@k improvements while maintaining pass@1 performance comparable to vanilla OPD.

**Why it matters:** It enables student models to inherit teacher generation diversity and improve pass@k reasoning performance without incurring the high computational and memory costs of full-vocabulary teacher outputs.

### [oHC: Orthogonal Hyper-Connections on SO(4) via Quaternions](https://arxiv.org/abs/2609.02672v1)

**arXiv cs.LG** · 2026-09-02 · `arXiv:2609.02672v1`

Orthogonal Hyper-Connections (oHC) constrain residual mixing matrices to the SO(n) rotation group using unit quaternions, preventing gradient instability and stream similarity degradation without adding parameters.

- Unconstrained Hyper-Connections (HC) destabilize training through compounding rescaling, while doubly stochastic mHC forces residual streams to converge and lose diversity across deep layers.
- oHC restricts the n x n residual matrix to the rotation group SO(n), preserving energy across all directions to prevent amplification and attenuation.
- For n=4 residual streams, oHC uses a closed-form unit quaternion parameterization that eliminates iterative projections, uses signed additions, and constructs faster than mHC without additional parameters.
- oHC outperforms single-stream residual baselines, identity HC (iHC), and mHC across multiple downstream evaluation tasks.

**Why it matters:** oHC provides a faster, parameter-free mechanism to scale Transformers to multi-stream residual architectures while maintaining training stability and stream diversity.

**arXiv cs.AI** · 2026-09-02 · `arXiv:2609.02786v1`

SafeEvolve introduces an experience-driven framework that co-evolves runtime harnesses and agent policies using a two-stage SFT-RL paradigm to improve multi-step agent safety.

- Harness updates convert trajectory-level safety evidence into bounded, component-level revisions of safety prompts and hierarchical skills.

**Why it matters:** It demonstrates that concurrently updating external harness components and internal policy weights yields superior safety-utility tradeoffs compared to isolated safety alignment techniques.

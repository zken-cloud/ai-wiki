### [Virtual Head Attention](https://arxiv.org/abs/2610.17959)

**Hugging Face Daily Papers** · 2026-10-12 · 👍 8 · ⭐ 3 · `arXiv:2610.17959`

Virtual Head Attention (VHA) uses two linear operations—Q Premix and Linear Postmix—to halve physical query heads and cut KV cache while improving performance over GQA and MLA.

- Uses Q Premix (a near-identity transformation on queries within KV groups) and Linear Postmix (a low-rank I + AB^T residual inter-head feature fusion) to recover head diversity.
- Introduces zero nonlinear operations, allowing Premix to fold into the query projection and Postmix into the output projection during inference, reducing to standard GQA-2.
- Reduces KV cache by 4x versus GQA-8 at dense scales and 2x versus GQA-4 at MoE scale, while lowering training and prefill FLOPs by 7.9% for a 1.7B model at 4K context.
- Outperforms MLA and GQA-4 by +0.70% and +2.60% on a 30B-A3B MoE 12-benchmark suite, and achieves an 84.4 RULER score (8K-128K context) versus 73.0 for GQA on a 10B-A1B MoE model.

**Why it matters:** VHA breaks the trade-off between KV cache memory, compute FLOPs, and output quality by maintaining standard GQA inference optimizations while using only two KV heads.

<small>Xibo Ding, Guoxia Wang, Jinle Zeng, Jiabin Yang, Sirui Tao, Chao Yang, Dianhai Yu</small>

### [Baselines and Score Centering in Policy Gradient Estimation](https://arxiv.org/abs/2610.22263v1)

**arXiv cs.LG** · 2026-10-15 · `arXiv:2610.22263v1`

This note introduces a covariance perspective on policy gradients under regularized importance sampling, clarifying the distinct roles and interactions of group-mean baselines and score centering across sequence-level and token-level off-policy RL.

- Regularized importance sampling (via truncation, masking, or clipping) breaks the policy gradient's invariance to constant reward shifts, which is restored by formulating the estimand as the covariance between the reward and the importance-weighted score.
- Group-mean baselines and score centering act as covariance centering mechanisms using sample means and population means, respectively, yielding different unbiased estimators and variances.
- For sequence-level importance sampling, score centering provides no added benefit if a group-mean baseline is already applied.
- For token-level importance sampling with regularized ratios, applying a group-mean baseline without score centering generally introduces bias.

**Why it matters:** It provides precise mathematical guidance on how to correctly combine baselines and score centering to prevent bias and reduce variance when fine-tuning LLMs via off-policy reinforcement learning.

<small>Shuo Han, Ziqing Hu</small>

### [Query-Efficient Rejection Sampling for Parallel Masked Diffusion](https://arxiv.org/abs/2610.22238v1)

**arXiv cs.LG** · 2026-10-15 · `arXiv:2610.22238v1`

The Single-Increment Rejection Sampler (SIRS) eliminates the linear query overhead of rejection sampling in parallel masked diffusion models by estimating log acceptance probabilities using a single score query.

- Rejection sampling in parallel masked diffusion traditionally requires one score query per unmasked token to correct token-level correlation biases.
- SIRS estimates the log acceptance probability via a single randomly chosen increment, converting clipped estimates into accept/reject decisions using a Bernoulli factory.
- Rao-Blackwellization reduces estimate clipping at zero additional cost by leveraging and averaging all token conditionals returned in the single query block.
- Theoretical bounds show the KL-divergence between the target distribution and SIRS output is limited to a clipping penalty plus standard model training error.

**Why it matters:** SIRS enables bias-free parallel generation in masked diffusion models with drastically reduced computational cost per generation step.

- Byte Latent Transformer (BLT) entropy patching misses in-line computed results because their surprisal is ordinary, causing accuracy to drop under low patch budgets.

- Performance gains shrink outside of math, offering lower bits-per-byte improvements on prose and tying entropy rules on source code and synthetic execution traces.

Researchers identified a selection-to-update gap in self-evolving language models and introduced HeirCommit and EvoHeir to decouple experience from parameter inheritance, reducing harmful updates by 68-83%.

- Current self-evolving loops (e.g., R-Zero, Agent0) suffer from a selection-to-update gap, inheriting model updates based on task learnability even when verified tasks fail to increase correct answer likelihood.

- EvoHeir improved average math performance by 5.3% over Agent0 and achieved the highest math and general-reasoning scores across four model backbones.

**Why it matters:** The framework prevents performance degradation in self-improving AI loops by ensuring models only inherit updates that genuinely improve reasoning capabilities while preserving beneficial generated experience.

### [N-Gram Memories at Two Bits: Quantizing Lookup Tables in Large Language Models](https://arxiv.org/abs/2610.21810v1)

**arXiv cs.CL** · 2026-10-15 · `arXiv:2610.21810v1`

Conditional Program (CP) compresses language model conditional memory lookup tables down to two bits per row using Gaussian trellises, norm restoration, and independently decodable row records.

- CP represents each lookup row using a short code and a local scale, relying on a shared reconstruction program across the entire table.
- The method uses a Gaussian trellis, norm restoration, and independently decodable row records to handle Gaussian-like coordinate statistics and learned row relationships.
- At two bits per code, CP reduces output KL divergence by 41% to 63% compared to standard 2-bit round-to-nearest quantization.
- Demonstrated on DeepSeek n-gram memories, CP compresses total table storage from 203GB to 51GB, enabling GPU retention for larger workloads.

**Why it matters:** It enables ultra-low-bit compression of massive n-gram lookup tables directly on GPUs, significantly expanding model capacity without incurring severe KL divergence penalties.

<small>Donghoon Han, Minseop Jung, Dong Woo Kwak, SeungJae Lee, Junhoo Lee</small>

### [RoleQ: Role-Aligned Scales for Converting Language Models to Ternary](https://arxiv.org/abs/2610.21808v1)

**arXiv cs.CL** · 2026-10-15 · `arXiv:2610.21808v1`

RoleQ is a post-training framework that converts language models to ternary weights (1.59 bits/weight) by assigning scales according to the functional roles of Transformer units rather than matrix layout.

- Assigns one scale per output unit for vectors reading from the residual stream and one scale per input unit for vectors writing to it, requiring no search, calibration, or stored state.
- Reduces solver work by half compared to per-layer axis searches in a rotated basis and cuts ternary perplexity by up to half over layout-based scale placement across 0.6B to 14B model sizes.
- Converts checkpoints to ternary weights in a few GPU-hours, outperforming existing post-training ternary methods on perplexity, zero-shot accuracy, and MMLU.
- Introduces a sparse second ternary plane driven by per-unit Fisher saliency to recover lost accuracy while maintaining multiplication-free matrix multiplications.

**Why it matters:** RoleQ enables rapid, low-cost conversion of pre-trained LLMs to extreme 1.59-bit ternary quantization without requiring full retraining or sacrificing crucial factual knowledge and MMLU performance.

<small>Johannes Knittel, Alec Helbling, Hanspeter Pfister</small>

### [Behavioral Forgetting Is Not Privacy in Machine Unlearning](https://arxiv.org/abs/2610.21799v1)

**arXiv cs.CL** · 2026-10-15 · `arXiv:2610.21799v1`

A controlled multilingual study reveals that behavioral machine unlearning fails across access paths, as information forgotten in one language remains retrievable in semantically equivalent queries using different languages and scripts.

- Evaluates machine unlearning generalization using cross-lingual querying across multiple multilingual model families.
- Demonstrates that behavioral forgetting on a target benchmark distribution does not guarantee information inaccessibility across alternate access paths.
- Shows substantial variance in unlearning effectiveness when querying identical semantic information in different languages and scripts.
- Advocates for evaluating unlearning using access-path generalization and adversarial recoverability alongside standard in-distribution metrics.

**Why it matters:** Measuring unlearning solely through in-distribution benchmark performance creates a false sense of privacy protection, as erased data remains exposed to cross-lingual or adversarial access paths.

<small>Tyler Lizzo, Larry Heck</small>

### [VestigeKV: The NoPE-MLA KV Cache Carries Its Own Eviction Signal in a Vestigial Branch](https://arxiv.org/abs/2609.03949v1)

- Standard observed-attention eviction methods fail on NoPE MLA models, yielding needle retrieval scores of 0.00-0.33, whereas VestigeKV maintains 1.00 retrieval at 8x compression and 0.92 at 32x.

**Why it matters:** It enables massive KV cache compression on NoPE-MLA models without model retraining, kernel modifications, or loss of information, preserving high context retrieval while reducing memory overhead.

### [DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training](https://arxiv.org/abs/2609.04094v1)

**arXiv cs.AI** · 2026-09-03 · `arXiv:2609.04094v1`

DRACO introduces dynamic rubric generation and closed-form advantage redistribution for GRPO to enable fine-grained, per-step credit assignment in long-horizon agent training without verifiers.

- Operates in outcome-blind domains without programmatic checkers or ground-truth success signals.
- Generates rubrics dynamically during training to match evolving policy capabilities and scores them once per completed trajectory.
- Redistributes rubric scores into differentiated per-step advantages using a closed-form method without extra trained attribution modules.
- Outperforms GRPO with sparse ground-truth rewards on AppWorld by 5.3 points (15.9 points over base model) and improves out-of-domain performance on Tau-Bench by 5.3 points.

**Why it matters:** DRACO enables effective reinforcement learning for complex, multi-step agent tasks in domains where programmatic feedback or verifiers are completely unavailable.

<small>Shubham Gandhi, Saurabh Goyal, Kiran Kate, Yara Rizk</small>

### [Subspace Inference Enables Efficient Active Reward Learning from Preferences](https://arxiv.org/abs/2609.04066v1)

**arXiv cs.AI** · 2026-09-03 · `arXiv:2609.04066v1`

PreferenceEKF enables efficient active reward learning in RLHF by performing sequential Bayesian filtering with an Extended Kalman Filter within a low-dimensional parameter subspace of the neural network.

- Frames active preference learning as a sequential Bayesian filtering problem to quantify reward model uncertainty.
- Uses an Extended Kalman Filter (EKF) inside a low-dimensional parameter subspace rather than full neural network parameter space.
- Enables efficient neural network parameter sampling to compute acquisition functions for active query selection.
- Outperforms existing Bayesian deep learning baselines in sample efficiency, runtime, scalability, and calibration on D4RL and V-D4RL benchmarks.

**Why it matters:** It reduces the computational cost and sample complexity of uncertainty estimation in large neural reward models, facilitating more efficient human feedback acquisition for offline reinforcement learning.

<small>Yutai Zhou, Erdem Bıyık</small>

### [Instruction Duplication as an Inference-Time Control Primitive](https://arxiv.org/abs/2609.04024v1)

**arXiv cs.AI** · 2026-09-03 · `arXiv:2609.04024v1`

Instruction duplication is a black-box inference control that repeats procedural instructions without retraining or decoding modifications to improve downstream trajectory compliance.

- Evaluated across seven instruction-tuned models, 300 medical MCQs, and 16,800 generations, adding a second instruction copy raised the All-8 diagnostic pass rate from 90.22% to 93.17%, eliminating 30.2% of single-copy failures.
- Instruction duplication increased pre-provisional TF-IDF recall from 73.44% to 74.81% (Holm-adjusted p < .001) while keeping final-answer accuracy unchanged at 60.21%.
- Premature commitment increased from 1.52% to 2.30% (p_Holm = .00536), and a blinded challenge audit yielded 10/30 directional confirmations with no reversals.
- In Answer Engineering (AE) downstream systems, a trailing duplicate raised the SSNHL endpoint from an 84.2% reproduced baseline to 97.1%, but reduced conductive diagnostic branch preservation from 78.6% to 73.8%.

**Why it matters:** It offers a zero-parameter, placement-sensitive mechanism to significantly reduce procedural trajectory failures for downstream automated repair and inspection systems.

<small>Victor Lavrenko</small>

**arXiv cs.LG** · 2026-08-04 · `arXiv:2608.03913v1`

Sparse Weight Decomposition (SWD) reparameterizes pretrained linear transformer weight matrices into two sparse factors, creating addressable circuit units for extraction without training auxiliary sparse models or incurring high computational costs.

- Factorizes each linear weight matrix into two sparse factors connected by shared intermediate coordinates that act as circuit units.
- Matches the held-out fidelity of baselines like Transcoder using under 1% of the training data, and offers a zero-data variant for per-step analysis.

### [Omega-S: A Functional Resilience Index for LLM Fine-Tuning](https://arxiv.org/abs/2608.03887v1)

**arXiv cs.LG** · 2026-08-04 · `arXiv:2608.03887v1`

Omega-S is a data-free, weight-only penalty that reduces catastrophic forgetting in LLM fine-tuning by regularizing node degree variance, adding under 4% step overhead without requiring old data or Fisher matrices.

- Requires no prior task data, Fisher matrices, or saved initial weights, adding <4% computational overhead per step.
- Improves Llama-3-8B HumanEval pass@1 retention ratio from 62.9% to 84.1% (0.173 to 0.238 absolute) when fine-tuning LoRA from code to prose.
- Outperforms standard weight decay on 10/10 seeds (p=0.002) and Elastic Weight Consolidation (EWC) on 8/10 seeds (p=0.014).
- Empirical gradient analysis shows the topological Tr(A^3) objective acts primarily as a penalty on node degree variance (row magnitude in square modules, directional alignment in non-square modules).
- Identifies a high baseline variance in low-rank fine-tuning: identical configurations across identical hardware yield a 0.104 standard deviation in retention ratio.

**Why it matters:** Omega-S offers an easily implemented three-line training loss addition that significantly preserves base model capabilities during targeted fine-tuning without the memory and data overhead of traditional regularization methods.

### [Bilevel Coordinated Reflection: A Game-Theoretic Approach to Multi-Agent LLM Systems](https://arxiv.org/abs/2609.02750)

**Hugging Face Daily Papers** · 2026-09-01 · 👍 59 · `arXiv:2609.02750`

A novel game-theoretic framework models multi-agent LLM systems as a bilevel coordination game and introduces Stochastic Reflective Memory Ascent (SRMA), an environment-grounded reflection algorithm with proven exact convergence guarantees.

- Models orchestrator-worker interaction as a bilevel game where workers' local updates form an approximate potential game with equilibrium slack governed by task decomposition quality.
- Proves an information-theoretic impossibility result showing transcript-only reflection gates cannot uniformly improve over text-indistinguishable environments, necessitating environment-grounded verification.
- Introduces Stochastic Reflective Memory Ascent (SRMA), which accepts candidate memories based on strict evaluation risk reduction and achieves order-tight geometric or polynomial convergence.
- Achieves a 72.2% resolution rate on 500 SWE-bench instances using a Kimi-based system implementation compared to 70.8% for the public mini-SWE-agent baseline.

**Why it matters:** It provides rigorous theoretical convergence bounds for multi-agent LLM reflection while proving that environment-grounded verification is necessary to prevent persistent performance drift.

### [Iris: Climbing to the Search Frontier](https://arxiv.org/abs/2609.04304)

**Hugging Face Daily Papers** · 2026-09-02 · 👍 47 · ⭐ 2 · `arXiv:2609.04304`

Iris-mini (35B-A3B) and Iris-pro (397B-A17B) are open-source single-agent search models trained via an iterative SFT-RL climbing recipe using graph-based synthetic task construction.

- Tasks are generated by building multi-hop chains on a web corpus entity graph, obfuscating non-answer entities, and keeping only queries that fail closed-book but pass open-book.
- Training uses 'SFT-RL climbing', alternating SFT and live-search RL while returning the hardest, most efficient rollouts back into the next SFT pass.
- Inference uses a single ReAct agent without sub-agents or test-time verification, incorporating explicit inference-time context management.
- Iris-pro achieves 88.6 on BrowseComp, 85.1 on BrowseComp-ZH, 92.9 on DeepSearchQA, and 56.4 on HLE; Iris-mini achieves 82.2, 84.8, 86.9, and 52.3 respectively.

**Why it matters:** The release provides the weights, synthetic data construction pipeline, and training recipe for state-of-the-art open-source web search agents.

### [When Quantization Breaks Memory: Recurrent-State Write-Back in Low-Precision Temporal Inference](https://arxiv.org/abs/2609.04490)

**Hugging Face Daily Papers** · 2026-09-02 · 👍 2 · `arXiv:2609.04490`

Researchers identify recurrent-state write-back as a primary failure mode in 4-bit RNN inference and propose non-retraining interventions like error feedback to restore state update accuracy.

- Applying deterministic 4-bit state storage post-training to a GRU model increases parameter estimation errors for fluorescence lifetime components tau1 and tau2 by ~70x and ~300x.
- Failure occurs because small, repeated state updates fall below the quantization write threshold, causing the stored state to remain static while the network attempts updates.
- Error feedback, residual memory, and direction memory recover baseline accuracy without retraining by propagating suppressed sub-threshold update information across time steps.
- Post-training tests on an LSTM replicate the failure and show that its cell state is significantly more sensitive to coarse write-back quantization than its hidden state.

**Why it matters:** It demonstrates that low-precision recurrent inference requires specialized state-storage interfaces or error-feedback mechanisms to prevent compounding memory degradation without expensive model retraining.

<small>Ismail Erbas, Xavier Intes, Vikas Pandey</small>

### [A Systematic Comparison of Multilingual Interpretability Methods Reveals Anisotropy-Driven Failures](https://arxiv.org/abs/2609.04819v1)

**arXiv cs.CL** · 2026-09-04 · `arXiv:2609.04819v1`

A systematic evaluation of four multilingual interpretability metrics across 21 models reveals that metric disagreement stems from representation anisotropy, with Inter-Lingual Overlap (ILO) proving to be the only robust predictor of cross-lingual transfer.

- Evaluated four cross-lingual sharing metrics—Centered Kernel Alignment (CKA), ANC, GMM dominance per token, and Inter-Lingual Overlap (ILO)—across 21 base models (125M–14B parameters) from five model families.
- Identified anisotropy (representation clustering within a narrow cone of the embedding space) as the cause of performance quantification disagreements among interpretability methods.
- Demonstrated that ILO is the only metric whose correlation with downstream cross-lingual transfer across five tasks remains strong (Spearman's ρ = 0.90) after controlling for model size, family, and task variation.

**Why it matters:** Researchers evaluating cross-lingual representation sharing should use ILO alongside anisotropy diagnostics instead of metrics like CKA to ensure measurements reliably predict downstream cross-lingual transfer.

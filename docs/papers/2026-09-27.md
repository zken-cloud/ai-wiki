### [How does Adversarial Influence Scale in Multi-Agent Systems?](https://arxiv.org/abs/2609.30028v1)

**arXiv cs.AI** · 2026-09-24 · `arXiv:2609.30028v1`

A study on multi-agent LLM deliberation shows that agent defection rates rise linearly with the proportion of deceivers, with LLMs succumbing to deceptive minorities unlike humans.

- Susceptibility to deception scales with the proportion of deceptive agents rather than the total group size.
- The defection rate—honest agents switching to incorrect answers—increases linearly as the proportion of deceivers grows.
- Unlike humans, who typically conform only when deceivers form a majority, LLM agents regularly defect when deceivers are a minority.
- Susceptibility varies based on model pairings, particularly the specific model used for the honest agent.
- Allowing deceptive agents to coordinate privately unexpectedly reduces their effectiveness in swaying the group.

**Why it matters:** Simply scaling group size does not protect multi-agent LLM systems against adversarial subversion, as adversaries only need to maintain their proportion within the group.

<small>Addison J. Wu, Jasin Cekinmez, Michel Liao, Karthik Narasimhan, Thomas L. Griffiths</small>

**arXiv cs.LG** · 2026-09-24 · `arXiv:2609.30258v1`

TRACE is an amortized temporal gradient-inversion attack that autoregressively reconstructs private observation-action trajectories from policy gradients in distributed embodied reinforcement learning.

- Exploits cross-time correlation between consecutive gradients and utilizes closed-form action recovery from policy-head gradients, proven exact for small entropy regularization.
- Achieves 18.8 dB PSNR with near-perfect action recovery at 3-4.5 ms per frame, outperforming single-frame and optimization-based attacks in speed and quality.

### [Aim Short to Reach Far: Your Frozen World Model Can Plan Better Than You Think](https://arxiv.org/abs/2609.30036v1)

**arXiv cs.LG** · 2026-09-24 · `arXiv:2609.30036v1`

Anchored Planning improves visual world model control by directing a frozen LeWM model toward short-horizon intermediate targets retrieved from past experience rather than scoring directly against the distant final goal image.

- Scoring actions solely against a final goal image fails when optimal trajectories temporarily move away from the goal in observation space.
- Anchored Planning retrieves an observed segment matching current and goal states, then directs the planner toward an intermediate target shortly after the segment's start.
- The method improves action synthesis and recorded-action ranking on Cube, PushT, Reacher, and TwoRoom environments without additional model training.
- Performance depends on target distance horizon and progressively shrinking the retrieval span as execution advances, outperforming final-goal search.
- Lower successor-prediction error in world models does not inherently correlate with better downstream control performance.

**Why it matters:** Visual world models can solve complex, long-horizon tasks without costly retraining by simply altering the planning target to short-term intermediate goals.

### [HEXIS: Compiling Skills into Extended Finite State Machines](https://arxiv.org/abs/2609.30123v1)

**arXiv cs.AI** · 2026-09-24 · `arXiv:2609.30123v1`

HEXIS compiles agent skills into extended finite state machines (EFSMs), decoupling control flow from task reasoning to enforce execution structure and reduce LLM generation overhead.

- HEXIS maps skill clauses and tool interfaces into state operations, local instructions, data bindings, and explicit transition conditions.
- An incremental compiler aligns development traces with existing states to refine connections, add missing operations, and resolve dependencies.
- State updates require static validation and successful replay of current and previously accepted execution traces.
- Evaluation across four benchmarks shows a 16.1 percentage point average success rate improvement over Skill + ReAct.
- Using Qwen3.8-27B, HEXIS decreases execution token consumption by 38.4% to 88.9% across benchmarks.

**Why it matters:** By enforcing deterministic control flow via state machines, agents reliably follow prescribed multi-step procedures while significantly cutting LLM token costs.

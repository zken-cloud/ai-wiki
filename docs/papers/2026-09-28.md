### [FuseReg: Regularizing Layer Fusion Mitigates the Reconstruction-Generation Gap in Representation Autoencoders](https://arxiv.org/abs/2609.31620)

**Hugging Face Daily Papers** · 2026-09-24 · 👍 110 · ⭐ 12 · `arXiv:2609.31620`

FuseReg replaces heuristic feature selection in Representation Autoencoders (RAEs) by training pixel decoders and diffusion generators over random subsets of visual encoder layers, mitigating the trade-off between reconstruction detail and generation quality.

- Theory: Subset layer sampling acts as a regularization mechanism that explicitly penalizes cross-layer feature disagreement.
- Reconstruction: On ImageNet-256 with DINOv3-L, a single FuseReg decoder handles full, sparse, and single-layer fusions without retraining, outperforming decoders specialized to fixed fusions on PSNR.
- Generation: Replacing the decoder improves unguided gFID by 27% on an unchanged RAEv2 DiT-XL, while joint regularization of both decoder and generator yields a 29% gFID reduction on DiT-Base.
- Efficiency: Enhances layer-fusion flexibility and generation quality without altering or fine-tuning the underlying pretrained visual encoder.

**Why it matters:** FuseReg bridges the gap between image reconstruction and generation performance in RAEs without requiring architecture modifications or retraining of the core visual encoder.

### [Depth-adaptive Inference of Looped Language Models via Continuous Depth Batching](https://arxiv.org/abs/2608.09444)

**Hugging Face Daily Papers** · 2026-09-24 · 👍 2 · ⭐ 3 · `arXiv:2608.09444`

Continuous Depth Batching (CDB) enables efficient depth-adaptive inference in looped language models by dynamically re-batching tokens between loop steps and pre-building batches asynchronously based on exit predictions.

- CDB resolves batching inefficiencies in standard engines like vLLM by forming new batches between loop steps to group tokens requiring different amounts of compute.
- The method dynamically schedules recurrent and non-recurrent components, manages looped KV-caches, and uses advance exit predictions to construct batches asynchronously.
- Empirical evaluations on Ouro 1.4B and Huginn 3.5B demonstrate that CDB achieves up to 99% of the theoretical maximum depth-adaptive speedup.

**Why it matters:** CDB removes the primary batching infrastructure bottleneck for depth-adaptive inference, allowing looped language models to translate theoretical token-level compute savings into real-world throughput gains.

ActKV is the first KV cache compression framework for agentic LLMs that prioritizes action-critical memory using action-oriented eviction, confidence-driven budget allocation, and page-aware GPU execution.

- Uses action-oriented KV cache eviction to identify and retain entries critical for future action generation based on stable access patterns.
- Employs confidence-driven adaptive budget allocation to dynamically scale the KV cache budget using the LLM's intrinsic confidence levels.
- Integrates page-aware compression management via three standardized primitives and custom kernels to operate efficiently with paged memory systems.
- Retains 98.53% of FullKV accuracy on long-trace tasks while using only 25.98% of peak KV cache memory.
- Increases token throughput by 3.97x and task throughput by 3.58x compared to uncompressed FullKV.

**Why it matters:** ActKV drastically reduces the memory footprint of long-horizon LLM agents, enabling significantly higher serving throughput without compromising agent decision-making accuracy.

A study applies Steiner's task taxonomy to multi-agent LLM scaling, showing that plurality voting fails on disjunctive tasks and shared item-level biases prevent scaling gains on compensatory tasks like Fermi estimation.

- Plurality voting converges to the model's modal answer, while averaging output values converges to the model's shared item-level bias.

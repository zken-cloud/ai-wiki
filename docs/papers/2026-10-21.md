### [PAR: Progress-Aligned Recurrence for Length Generalization in State Tracking](https://arxiv.org/abs/2610.27628)

**Hugging Face Daily Papers** · 2026-10-19 · 👍 129 · `arXiv:2610.27628`

Progress-Aligned Recurrence (PAR) enables looped language models to generalize to longer state-tracking problems by matching iteration predictions to operation steps and anchoring recurrent state norms.

- PAR aligns the prediction at iteration k to the state after k operations and rescales recurrent states to match their first-iteration norms.
- A Qwen2.5-0.5B model trained with PAR on <=32 moves achieves 95.5% full-state accuracy on swap-S_5 at 512 moves (16x extrapolation), outperforming RLT (55.7%) and explicit CoT (0.8%).
- Ablations show removing norm anchoring drops extrapolation from 16x to below 2.2x, while replacing progress-aligned targets with final-answer supervision caps it at 8x.
- When intermediate labels are missing, prefix self-distillation induces progress alignment using only final answers from shorter problem prefixes.
- A learned completion readout determines when to return an answer without requiring a predefined stopping depth.

**Why it matters:** Combining state scale anchoring with intermediate progress targets allows looped models to execute additional recurrent iterations effectively for length extrapolation.

<small>Pan Wang, Yihao Hu, Guangyuan Dong, Yitong Lin, Hang Wang, Zimi Liu, Zhihao Wen, Jianshe Li</small>

Swift improves diffusion training by using a frozen weak denoiser to extrapolate regression targets, amplifying underfit components without adding inference-time compute or architectural modifications.

- Swift uses an early-stopped, frozen weak denoiser as a guide to extrapolate clean regression targets away from the weak model's predictions during training.
- The weak guide requires no backpropagation during main-model training and is discarded prior to inference, allowing standard sampling without label dropout or an unconditional branch.

**Why it matters:** It enables faster convergence and higher-quality image generation in diffusion models while completely eliminating the extra inference-time computational overhead typically required by guidance mechanisms.

### [Breaking Diffusion: Parallel Reasoning with Draft Refinement](https://arxiv.org/abs/2610.26542)

**Hugging Face Daily Papers** · 2026-10-18 · 👍 13 · `arXiv:2610.26542`

Draft Refinement Language Models (DRLMs) replace reverse diffusion transitions with a single denoiser that proposes parallel token revisions and evaluates complete-draft cavity energy in a single forward pass.

- Trains a single denoiser on uniformly corrupted drafts to reconstruct tokens, teaching both context preservation and error repair without needing a separate scoring model.
- Calculates a complete candidate draft's cavity energy in one forward pass by using the known corruption process to subtract self-token evidence from confidence scores.
- Executes iterative refinement by proposing revisions and accepting the updated candidate draft only if its calculated cavity energy decreases.
- Achieves 44.4% accuracy on Countdown-5 and 93.9% on Sudoku-Extreme using a 6-million parameter model architecture.

**Why it matters:** It demonstrates that complete-draft parallel refinement can outperform both autoregressive and discrete diffusion baselines on complex reasoning tasks using significantly fewer parameters.

### [Beyond 4 bits: Data-Centric Post-training Quantization and Recovery](https://arxiv.org/abs/2610.28537v1)

**arXiv cs.AI** · 2026-10-20 · `arXiv:2610.28537v1`

Vector codebook representations combined with task-aligned, jointly selected calibration and recovery data enable sub-3-bit post-training quantization to retain 89-97% of full-precision QA accuracy at significantly reduced compute costs.

- Scalar PTQ pipelines collapse to chance-level accuracy at 2 bits, whereas vector codebooks restore usable model performance across 3.8B to 32B dense and MoE models.
- Data selection for calibration and short recovery fine-tuning are coupled, requiring joint optimization using task-aligned data mixtures.
- The proposed recipe uses ~2.3 effective bits per weight, achieving 89% to 97% of baseline QA accuracy.
- The method requires 1.4x to 30x less compute than the strongest Quantization-Aware Training (QAT) baselines by using an inexpensive codebook-only recovery stage.

**Why it matters:** It enables ultra-low-bit model compression down to ~2.3 bits per weight while bypassing the massive compute overhead typically required by quantization-aware training.

<small>Rhea Sanjay Sukthanker, Riccardo Grazzi, James Hensman, Pashmina Cameron</small>

### [RACE: RoPE-Aligned Attention Compression Based on Query-Key Activation Energies](https://arxiv.org/abs/2610.28385v1)

**arXiv cs.AI** · 2026-10-20 · `arXiv:2610.28385v1`

RACE is a post-training, reconstruction-free compression method that prunes RoPE rotary pairs based on query-key activation energy, natively reducing both KV-cache memory and attention FLOPs.

- Formalizes head-dimension compression using coordinate selection on rotary pairs to maintain full compatibility with pretrained RoPE transformations.
- Selects rotary pairs by joint query-key activation energy, which theoretically minimizes a separable upper bound on post-RoPE query-key product approximation error.
- Folds reductions directly into model weights, avoiding runtime reconstruction overhead or specialized GPU kernels.
- Achieves 47.8% lower inference FLOPs, 1.79x throughput, 43.2% lower TTFT, and 28.1% lower GPU memory at 50% KV-cache retention on 256K context.

### [Present but Hard to Read: Probing Latent Reasoning with Minimal Pairs](https://arxiv.org/abs/2610.28498v1)

**arXiv cs.LG** · 2026-10-20 · `arXiv:2610.28498v1`

A new probing protocol reveals that single-prompt probes miss latent information present in LLM states, showing that unwritten intermediate values can be readable yet unused by the model.

- Standard single-prompt probes fail to detect input digit traces (accuracy of 0.36 in Ouro-1.4B and 0.19 in Qwen2.5-1.5B), while minimal-pair comparison across prompts shows the token is present at the last prompt token (readout ~0.9).
- Prompt changes alter the hidden state in small, dedicated directions rather than large shifts, whereas substituting a random word causes significantly larger activation movement.
- The authors introduce a probing protocol using a synthetic null to disentangle computed latent values from generic input mixing and token copies.

### [Self-Credit: Credit Assignment for Long-Horizon Agentic RL via Intra-group Rescaling](https://arxiv.org/abs/2610.28388v1)

**arXiv cs.LG** · 2026-10-20 · `arXiv:2610.28388v1`

Self-Credit improves long-horizon LLM agent training by using self-generated citations to critical past actions, refined via intra-group rescaling across successful and failed rollouts to reweight advantage estimates.

- Policy models generate summaries with citations pointing to earlier turns that contain critical evidence during rollouts.
- Intra-group rescaling compares cited actions between successful and failed rollouts on the same prompt to strip undeserved credit and boost key actions.
- Advantage reweighting uses the resulting credit weights to adjust the advantage values of cited execution turns.
- Achieves performance gains on BrowseComp-Plus over base models (37.0 points on Qwen3 8B, 36.2 on 32B) and outpaces top RL baselines on GAIA (+4.9) and xBench-DeepSearch (+4.7).

**Why it matters:** It provides a dense, self-supervised credit assignment mechanism for RLVR, solving credit assignment bottlenecks in complex, multi-turn LLM agent tasks without human reward annotations.

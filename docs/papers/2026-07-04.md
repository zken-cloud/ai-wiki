A lightweight, trainable filter is proposed to quantify language model uncertainty and suppress potentially harmful, uncertain function calls, enhancing agentic reliability without modifying the base model.

**arXiv cs.AI** · 2026-07-04 · `arXiv:2607.04011v1`

CrossBERT, a two-part architecture, separates representation learning from token reconstruction, enabling scalable text encoders with improved throughput and sample efficiency.

- BERT encoders' representations become unexploitable by frozen probes despite improved perplexity due to coupling representation learning with token reconstruction.
- CrossBERT separates high-quality encoded representation learning from token reconstruction grounding.
- CrossBERT uses a Complementary Masking Strategy, allowing high masking ratios (>=50%) and gradient collection over all tokens.
- CrossBERT increases throughput by 1.5 to 2x and sample efficiency by 2x.
- CrossBERT demonstrates superior performance on MTEB(eng, v2) and frozen GLUE benchmarks.

**Why it matters:** This new architecture allows for more efficient and scalable text encoders, improving performance on downstream tasks.

### [Full Glyph Images Beat Token Embeddings: A Controlled Study for Transformers](https://arxiv.org/abs/2607.03994v1)

**arXiv cs.AI** · 2026-07-04 · `arXiv:2607.03994v1`

A controlled study shows rasterized glyph images processed by a vision encoder outperform discrete token embeddings for Chinese language modeling in Transformers.

- Replaced index-based token embeddings with a single rasterized image of the character sequence for Chinese language modeling.
- Vision-based model, using a ResNet and shallow Vision Transformer, achieved 0.429 accuracy, a 21% relative improvement over the 0.355 baseline with index-based embeddings.
- Vision model converged in approximately half the training epochs and maintained performance under moderate character corruption, matching the clean index-based baseline.
- Advantage requires spatially coherent input and a ViT encoder with 2D positional encodings; it does not transfer to alphabetic systems like English.

**Why it matters:** This suggests that discrete tokenization is not a fundamental requirement for Chinese language modeling and Transformers are more modality-agnostic than commonly assumed.

**arXiv cs.CL** · 2026-07-04 · `arXiv:2607.03739v1`

A new benchmark and evaluation framework for RAG under coordinated retrieval poisoning introduces polymorphic sybil poisoning, revealing significant hijack amplification and detailed failure modes beyond traditional attack success rates.

- Introduces "polymorphic sybil poisoning," a coordinated attack using S lexically diverse passages to support an attacker-chosen target, evading lexical near-duplicate filters.
- Polymorphic sybil poisoning amplifies hijack by +18.8pp (95% CI (+15.4, +22.4)) compared to monomorphic copies, a 5.7x amplification of the ASR-visible attack channel.

**Why it matters:** This work provides a more granular understanding of RAG system vulnerabilities to sophisticated poisoning attacks, highlighting limitations of current evaluation metrics and enabling development of more robust defenses.

### [High-Fidelity One-Step Generative Visuomotor Policy via Recursive Correction, Frequency Consistency, and Contrastive Flow Matching](https://arxiv.org/abs/2607.03865v1)

**arXiv cs.AI** · 2026-07-04 · `arXiv:2607.03865v1`

This paper introduces a one-step generative visuomotor policy framework using recursive correction, frequency consistency, and contrastive flow matching to achieve high-fidelity, low-latency control.

- Recursive Consistent Action Flow (RCAF) employs recursive correction to mitigate spatial truncation errors and align one-step predictions with refined flow trajectories.
- Dual-Timestep Frequency Consistency (DTFC) maintains high-frequency manipulation details via adaptive spectral consistency across flow timesteps.
- Contrastive Flow Matching (CFM) disentangles action flows using a margin-based repulsive objective to reduce ambiguity in multimodal manipulation.
- The method achieves competitive or superior performance compared to 10-step generative policy baselines with a single forward pass (1 NFE) on RoboTwin, RoboTwin 2.0, Adroit, DexArt, and real-world robot platforms.

**Why it matters:** This framework enables low-latency visuomotor control by reducing inference time from multi-step sampling to a single forward pass while maintaining high fidelity.

- Identifies that common stabilizers are data-regime-dependent: parameter normalization limits value fitting under abundant data, and clipped double-Q can be relaxed to single-Q in high-throughput settings.

**Why it matters:** It demonstrates that scaling off-policy reinforcement learning to massively parallel GPU environments requires removing data-limited constraints to achieve higher sample efficiency, faster training, and better real-world deployment performance.

### [How Much Rank Does LoRA Need? Rank-Error Bounds for Transformer Attention](https://arxiv.org/abs/2608.26052v1)

**arXiv cs.AI** · 2026-08-26 · `arXiv:2608.26052v1`

This paper establishes task-dependent rank-error bounds for Query LoRA updates in Transformer attention, expressing expected KL error through the downstream-weighted tail energy of target updates.

- Establishes an error lower bound proportional to $\psi(\\|d\\|_2)$ (where $\psi(t)=\min\{t^2,t\}$) and an upper bound of $\min\{\\|d\\|_2^2/4,\sqrt{2}\\|d\\|_2\}$ for score difference $d$.
- Bounds the optimal rank-$r$ error between a multiple of $\psi(\sqrt{T_r})$ and $\min\{T_r/4,\sqrt{2T_r}\}$, where $T_r$ represents the downstream-weighted tail energy.
- Demonstrates through explicit constructions that softmax saturation allows matching attention functions using a strictly lower rank than required to match finite logits.
- Provides target-Fisher bounds, unrestricted lower bounds for localized token probability, and extends theoretical analysis to fused multi-head LoRA and joint query/key updates.

**Why it matters:** It provides a theoretical foundation for selecting LoRA ranks based on task data and attention geometry rather than relying solely on trial-and-error hyperparameter tuning.

### [Spectral Allocation: Why Muon Outperforms Adam, and How to Improve Muon](https://arxiv.org/abs/2608.25990v1)

**arXiv cs.LG** · 2026-08-26 · `arXiv:2608.25990v1`

Researchers developed Spectral-Aware Muon (SAMuon), which outperforms AdamW and Muon by using a static spectral prior to apply larger step sizes to the tolerant bulk singular directions of momentum buffers.

- Out-of-sample spectral probing shows Transformer loss landscapes have an anisotropic spectral profile where a volatile head requires small step sizes while a tolerant bulk permits significantly larger steps.

### [One Symptom, Three Levers: A Critical Review of On-Policy Self-Distillation](https://arxiv.org/abs/2608.25936v1)

**arXiv cs.AI** · 2026-08-26 · `arXiv:2608.25936v1`

This review provides a unified structural framework identifying collapse as the primary failure mode in On-Policy Self-Distillation (OPSD) for mathematical reasoning, analyzing it through three governing levers.

- On-Policy Self-Distillation (OPSD) eliminates the need for a larger teacher model by using the student model itself, conditioned on privileged information like reference solutions, plans, or environment feedback.
- The primary failure mode of OPSD is collapse, defined as the progressive narrowing of the set of reasoning paths the model can generate.
- Collapse is governed by three specific levers: token weighting (where signal is applied), the nature of privileged information (what the teacher sees), and teacher dynamics/guidance decay (when the signal changes).
- The paper introduces a shared structural vocabulary to standardize inconsistent terminology across existing mathematical reasoning OPSD literature without adding new experimental data.

**Why it matters:** It establishes a clear vocabulary and structural framework to help researchers analyze and prevent model collapse when using self-teacher privileged guidance instead of larger teacher models.

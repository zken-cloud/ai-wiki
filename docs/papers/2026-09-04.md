**Hugging Face Daily Papers** · 2026-09-02 · 👍 53 · `arXiv:2609.04098`

Minima demonstrates that Gated DeltaNet recurrent layers in hybrid LLMs tolerate full NVFP4 W4A4 quantization, matching BF16 accuracy while reducing size and boosting prefill speed.

- Minima quantizes all 496 linear layers of a Qwen3.8-27B hybrid model (48 Gated DeltaNet, 16 attention) to NVFP4 W4A4, reaching 17.5 GiB with a 14-19% prefill speedup.
- Non-linear gate activations (softplus, exponential, sigmoid) compress GEMM quantization error from ~11% down to ~2% output error.
- The Gated DeltaNet delta-rule recurrence prevents error compounding by bounding injected noise over 32K tokens and decaying state impulses within hundreds of steps.

- Resolves a global-scale mismatch that occurs when fusing per-module-calibrated NVFP4 checkpoints into unified GEMM kernels.

**Why it matters:** It disproves the belief that recurrent layers require higher precision, enabling aggressive 4-bit quantization across entire hybrid LLM architectures.

**Hugging Face Daily Papers** · 2026-09-02 · 👍 49 · `arXiv:2609.04172`

On-policy distillation (OPD) achieves full-data performance using as few as 16 queries because single-query rollouts rapidly reach high state coverage, revealing that OPD is limited by step efficiency rather than data volume.

- A single query in one-shot OPD achieves 71.5% state coverage of full-data OPD (mostly within 100 steps) and recovers most performance gains across domains and model families.
- Scaling to 16 semantically distinct queries achieves 98.9% state coverage, matching full-data OPD and multi-teacher OPD (MOPD) performance.

- Content-light templates and off-domain WildChat queries approach real-query baselines, demonstrating that task content and induced state coverage can function independently.

**Why it matters:** Demonstrating that OPD requires far less training data shifts the research focus toward improving algorithmic step efficiency and drastically lowers data requirements for LLM post-training.

### [Clean Engineering, Unstable Measurement: A Preregistered Reliability Failure of Black-Box LLM Observers on Shared Endpoints](https://arxiv.org/abs/2609.04198v1)

**arXiv cs.AI** · 2026-09-03 · `arXiv:2609.04198v1`

A preregistered study reveals that black-box LLM judges on shared endpoints fail basic reliability thresholds, yielding Spearman rank correlations as low as 0.400 for same-window repeats due to infrastructure-level instability.

- Across 52,988 audited requests, same-window repeat rankings achieved a Spearman correlation of only 0.400 (against a 0.90 target), and byte-identical next-day replays achieved 0.78 (against a 0.99 target).
- Measurement instability is driven by biased label-to-meaning mappings, candidate quality gaps seven orders of magnitude below the instrument's noise floor, and non-deterministic outputs from byte-identical inputs.
- Mitigations like temporal waiting (0.805 vs 0.800 correlation), provider switching (medians 0.74 to 0.88 across four providers), and self-hosting on batch-invariant kernels failed to resolve the unreliability under load.
- The authors propose a three-level snapshot-identity ladder, eight design rules, and a reporting checklist, noting that a 2% volume pilot would have exposed the unreachable gates in advance.

**Why it matters:** Evaluating LLMs using shared black-box LLM endpoints introduces high infrastructure noise that invalidates leaderboards, dataset filtering, and model benchmarks unless the measurement instrument's stability is validated first.

<small>Haoyaun Zhu, Jie Zhang</small>

### [Spurious Advantage Hidden in GRPO](https://arxiv.org/abs/2609.04063v1)

**arXiv cs.AI** · 2026-09-03 · `arXiv:2609.04063v1`

Researchers identified a spurious advantage in GRPO where lucky guesses receive high policy magnitudes, and introduced SIGNBALANCE to eliminate it using composition-free magnitudes and stop-gradient per-class rescaling.

- GRPO's within-group reward statistics incorrectly assign high advantage magnitudes to rollouts that reach correct answers via guessing rather than valid reasoning.
- Spurious advantage occurs in bounded-answer tasks with small candidate sets, open-answer sets with bounded sub-cases, and search agents with large budgets exploring many paths.
- SIGNBALANCE fixes this by decoupling magnitude from within-group statistics: it retains the verifier's sign, applies a global scale, and uses stop-gradient per-class rescaling to restore zero-mean balance.
- Experiments show SIGNBALANCE matches GRPO performance on open-answer math while outperforming it on bounded-answer math and search agent benchmarks.

**Why it matters:** Preventing reward hack behaviors like lucky guessing stabilizes reinforcement learning for reasoning models and search agents on bounded-choice tasks.

<small>Jiamian Wang, Samyadeep Basu, Koustava Goswami, Tong Yu, Zhiqiang Tao</small>

- Ground-truth step importance is operationalized as advantage, defined as the change in expected reward (correct final answer probability) calculated via Monte Carlo rollouts.
- Evaluating LLM judges on identifying high-advantage steps shows they outperform prevalence baselines but fall well short of the noise ceiling.
- Fine-tuning models as step-level critics significantly improves performance on incorrect responses, but predictions for correct responses remain far below the noise ceiling.
- The findings indicate that functional step importance is only partially recoverable from the raw text of a reasoning trace.

**Why it matters:** It cautions against relying purely on chain-of-thought text for process reward models, error diagnosis, and faithfulness evaluations, as legible text does not equal true model interpretability.

### [Hardware-Aware FP4 FlashAttention-4](https://arxiv.org/abs/2609.04105v1)

**arXiv cs.LG** · 2026-09-03 · `arXiv:2609.04105v1`

Direct-P and a causal backward quantization pipeline enable hardware-aware FP4 FlashAttention-4 on NVIDIA Blackwell GPUs, accelerating inference throughput and LLM training updates.

- Direct-P maps attention scores directly to FP4 probabilities without softmax conversion overhead, achieving up to 2.13x the BF16 forward throughput on an NVIDIA GB200 for noncausal inference.
- The causal training path reconstructs probabilities from saved quantized queries and keys using FP8 gradient operands, accelerating a single-GPU 8B-parameter update by up to 1.14x.
- Distributed training requires retaining FP8 probabilities and values, as all tested Microscaling FP4 (MXFP4) probability and value training trajectories diverged.

**Why it matters:** It enables practical FP4 attention execution on Blackwell tensor cores by bypassing non-matmul bottlenecks during inference and avoiding convergence failures during training.

<small>Robert Hu</small>

### [Unlocking Lossless Speedups in LLMs via Discrete Diffusion](https://arxiv.org/abs/2609.04010v1)

**arXiv cs.LG** · 2026-09-03 · `arXiv:2609.04010v1`

Uno introduces diffusion-augmented LLMs that accelerate autoregressive generation up to 3x losslessly without requiring a separate draft model.

- Decouples parameters into standard NTP-trained autoregressive weights and lightweight diffusion weights trained via a simple Diffusion Distillation phase.
- Introduces the Ψ-Spec sampler family to draw multiple tokens in parallel from the AR distribution, providing lossless acceleration and inference-time scaling.
- Outperforms speculative decoding across all evaluated batch sizes, achieving up to 3x speedups over the base AR model even at peak device batch capacity.
- The 8B Uno model surpasses larger models, including the 26B DiffusionGemma and proprietary Mercury 2, on agentic tool use, coding, and long-context reasoning benchmarks.

**Why it matters:** It eliminates the need for separate draft models in speculative decoding while enabling parallel token generation without reducing the baseline autoregressive output quality.

**Hugging Face Daily Papers** · 2026-10-05 · 👍 6 · `arXiv:2610.09059`

EDiS decouples GNN graph sparsification into a one-time decomposition into edge-disjoint subgraphs and a fast per-epoch recombination step to dynamic sparse topologies without repeated structural extraction.

- Decomposes the graph once into cacheable edge-disjoint subgraphs using feature-based scores and successive maximum score covering forests.
- Recombines cached subgraphs per epoch to satisfy target edge-budget constraints and retention ratios without re-extracting structure.
- Provides combinatorial analysis proving the deterministic preservation of high-score cut edges under the default covering-forest selector.
- Outperformed 17 baselines across 19 homophilic, heterophilic, and large-scale node classification benchmarks under identical edge budgets, showing maximum gain at tight edge constraints.

**Why it matters:** It eliminates the computational overhead of dynamic graph sampling in sparse GNN training while avoiding the performance degradation associated with fixed sparse topologies.

### [The Lattice of Transition Laws](https://arxiv.org/abs/2610.11216)

**Hugging Face Daily Papers** · 2026-10-07 · 👍 5 · `arXiv:2610.11216`

Researchers frame diffusion and autoregressive decoding as paths on a corruption lattice, using data geometry and pretrained weight kernels to predict optimal decoding schedules without running decoding.

- Models diffusion, autoregression, and hybrid approaches as paths on a unified corruption lattice where schedule cost is the discarded dependence between parallel steps.
- Proves that zero-cost schedules require a minimum number of steps equal to the data's treedepth (logarithmic for sequences, linear for grid side lengths) based on underlying Markov graph geometry.
- Formulates a method using a pairwise dependence kernel estimated directly from pretrained weights to rank positive-cost decoding schedules before execution.
- Validates schedule ranking predictions empirically across text, image, and video generation benchmarks.

**Why it matters:** It establishes a theoretical design principle to optimize and predict the step-efficiency of decoding schedules across diffusion, autoregressive, and hybrid generative architectures prior to inference.

**Hugging Face Daily Papers** · 2026-10-07 · 👍 5 · `arXiv:2610.11169`

Researchers built the first dated copy network of AI agent skills, analyzing 2,193,119 SKILL.md adoptions across GitHub to trace unversioned skill provenance and propagation.

- Skill propagation on GitHub operates without central registries, versions, or provenance, causing security fixes at the source to rarely reach copied skills.

### [Rounding in Preconditioner Space: Redesigning 4-bit AdamW Optimizer-State Quantization](https://arxiv.org/abs/2610.12444v1)

**arXiv cs.LG** · 2026-10-08 · `arXiv:2610.12444v1`

ZIP-SR and ZE-EDEN redesign 4-bit AdamW optimizer state quantization by rounding second-moment states in preconditioner space rather than state space.

- Identifies that minimizing state-space quantization error in AdamW's second moment does not guarantee minimal preconditioner error for subsequent adaptive updates.
- Introduces Zero-Inclusive Preconditioner-space Stochastic Rounding (ZIP-SR), which retains zero in the second-moment codebook and computes stochastic rounding probabilities directly in preconditioner space.
- Introduces Zero-Excluding EDEN calibration (ZE-EDEN), which utilizes a zero-excluding codebook and rescales quantized second-moment blocks to counter distortion from positive quantization floors.
- Applies 4-bit NormalFloat (NF4) to first moments with targeted stochastic rounding on the LM-head during the final 10% of training.
- Reduces the validation-loss gap to 32-bit AdamW by up to 70% compared to TorchAO 4-bit AdamW across 130M to 2.7B parameter pretraining and supervised fine-tuning.

**Why it matters:** It improves the performance and training stability of memory-efficient 4-bit AdamW optimization without requiring additional memory overhead.

### [Universal Textual Teaching for LLMs](https://arxiv.org/abs/2610.12114v1)

Universal Textual Teaching (UTT) distills Teacher-Student knowledge gaps into an interpretable natural-language artifact called a Primer without updating Student parameters.

### [One Block, Multiple Depths: Recurrent Vision Transformers with Depth-Programmed Experts](https://arxiv.org/abs/2610.12448v1)

**arXiv cs.LG** · 2026-10-08 · `arXiv:2610.12448v1`

reViT introduces recurrent Vision Transformers using depth-programmed expert mixtures within a single Transformer block, achieving full-depth ViT accuracy without intermediate feature distillation.

- FFN blocks at each recurrent step are parameterized as convex combinations of a shared expert bank, controlled by a continuous normalized-depth coordinate.
- Weight-space merging outperformed token-dispatch and output-mixture MoE approaches for FFN parameter space interpolation.
- Trained from scratch, reViT-B/16 achieves DeiT III accuracy on ImageNet-1k using approximately 70% fewer stored parameters.
- Distilled with an 8-expert bank using only DINOv2 output features, reViT retains linear-probe accuracy and transfers to downstream classification, segmentation, and depth prediction.
- Elastic-depth training enables a single checkpoint to evaluate across flexible depths, or materialize into a static dense graph for deployment.

**Why it matters:** It allows vision transformers to drastically reduce stored model parameter counts and dynamically adapt execution depth without sacrificing accuracy or requiring complex per-layer distillation.

<small>Adrian Bulat, Yassine Ouali, Georgios Tzimiropoulos</small>

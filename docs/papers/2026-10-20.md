### [MemT-1.0: Towards Memory-Native Evolution](https://arxiv.org/abs/2610.26825)

**Hugging Face Daily Papers** · 2026-10-18 · 👍 127 · ⭐ 146 · `arXiv:2610.26825`

MemT-1.0 introduces a memory-native foundation model architecture using Gated DeltaNet-2, a stable token-level memory update mechanism, and Mixture-of-Storage to internalize continuous memory accumulation.

- Utilizes Gated DeltaNet-2 with token-level memory updates and Mixture-of-Storage to scale native memory capacity.
- Trained via a two-stage pipeline (continued pre-training and post-training) using 34B tokens of training data.

### [Learning from Fleet Experience: A Collective Learning Paradigm for Robots](https://arxiv.org/abs/2610.25736)

**Hugging Face Daily Papers** · 2026-10-18 · 👍 93 · `arXiv:2610.25736`

Collective Experience Learning (CEL) improves robot policies across fleets without human corrections by using Failure-Guided Experience Retrieval Fine-Tuning (FERT) to supervise policy updates with shared successful trajectory segments.

- CEL introduces a shared-fleet framework where deployed robots learn continuously without collecting additional human teleoperator demonstrations or interventions.
- FERT uses failure contexts from execution attempts to retrieve relevant successful trajectory segments from the shared fleet history, using those actions as policy supervision.
- The Fault-Tolerant Asynchronous Training System (FATS) manages asynchronous experience collection, policy optimization, and distribution across the fleet.
- In real-world tests across five manipulation tasks, FERT achieved 93.3-99.2% success rates; on a phone packaging task, scaling from 0 to 96 robots increased success from 79.2% to 98.3%.

**Why it matters:** It enables large robot fleets to continuously increase policy reliability during autonomous deployment without requiring human teleoperators to monitor execution or provide manual interventions.

### [Competing Learning in Hybrid Architectures](https://arxiv.org/abs/2610.26830v1)

**arXiv cs.CL** · 2026-10-19 · `arXiv:2610.26830v1`

A newly identified Competing Learning phenomenon in hybrid language models causes fast-learning linear-time recurrence layers to suppress training signals for softmax attention layers, preventing attention from learning contextual information retrieval.

- Layer attribution analysis shows linear recurrence layers learn retrieval functions faster than softmax attention layers under typical data distributions.
- When recurrence layers learn retrieval early, they suppress the corresponding gradient/learning signal needed for attention layers to develop retrieval capabilities.
- Pausing weight updates in recurrence layers mid-training enables attention layers to successfully learn retrieval functions.
- A staged pre-training procedure based on this mechanism improves language modeling loss, common-sense reasoning, and retrieval performance in models up to 1B parameters.

**Why it matters:** Staged training resolves internal layer competition in hybrid architectures, allowing linear recurrence to maintain high throughput while enabling attention to reach full potential in retrieval tasks.

<small>Xingyu Shen, Yingfa Chen, Ziqing Qiao, Chaojun Xiao, Xu Han, Zhiyuan Liu</small>

### [Copying Under Repetition: From Prefix Matching to Position Hashing](https://arxiv.org/abs/2610.26722v1)

**arXiv cs.CL** · 2026-10-19 · `arXiv:2610.26722v1`

A 2-layer transformer using RoPE-style VO-rotations with prime periods can copy arbitrary repeated strings up to length N, overcoming finite-precision baseline models that fail due to positional saturation.

- Baseline architectures using NoPE or ALiBi fail on long repeated sequences because additive attention biases saturate, making identical-token run logits constant and causing termination errors.
- The proposed architecture requires two layers, O(log log N)-bit precision, and O(log N / log log N) width to correctly copy and terminate for strings up to horizon N.
- VO-rotations apply RoPE-style rotations to attention values and outputs using small prime periods to encode distances from delimiter anchors, uniquely resolved via the Chinese Remainder Theorem.
- Empirically, trained VO models demonstrate near-perfect accuracy generalization up to length 5005 (the product of the selected prime periods), whereas baseline transformers fail within the training range.

**Why it matters:** It identifies the structural cause of character overrun/truncation errors in frontier LLMs during repetition and provides a provably scalable positional encoding mechanism to fix them.

<small>Anxin Guo, Tianlong Huang, Chenxiao Yang, Zhiyuan Li</small>

### [TestPrism: Rethinking Test Evaluation Beyond a Single Reference](https://arxiv.org/abs/2610.12289)

**Hugging Face Daily Papers** · 2026-10-07 · 👍 25 · `arXiv:2610.12289`

TestPrism is a benchmark that evaluates LLM test generation against multiple candidate implementations using the Joint Success Function, exposing severe overestimation in single-reference evaluations.

- TestPrism consists of 300 test tasks across 17 sources and 3,000 candidate implementations, evenly divided between valid and invalid solutions.
- The primary metric, Joint Success Function, requires tests to fail on the initial state, pass all valid candidates, and reject all invalid candidates.
- Evaluating fourteen baseline agent configurations showed a Joint Success Function score of only 28.00%, compared to 59.67% under single-reference evaluation.
- The proposed method, TestHelix, utilizes heterogeneous test-repair synthesis, peer cross-validation, and recursive self-improvement (RSI) to increase the metric by 8.67 to 9.00 percentage points.

**Why it matters:** Evaluating LLM-generated tests against only a single reference program overstates test suite quality and masks faulty assertions, brittle checks, and missed edge cases.

### [When KL Regularization Misfires in Group Policy Optimization](https://arxiv.org/abs/2610.12161v1)

**arXiv cs.LG** · 2026-10-08 · `arXiv:2610.12161v1`

Researchers identify seven failure modes in reference-policy KL regularization during group policy optimization and introduce Zero-Sum Calibrated Policy Optimization (ZCPO) to calibrate within-group reward coefficients using conditional KL.

- Identifies seven specific KL-reward interaction failure modes, including residual KL updates after reward clipping or gradient cancellation, residual KL in identical-reward groups, response length KL imbalance, token-level KL concentration, and sampling noise when using k1 reward integration.
- Introduces Zero-Sum Calibrated Policy Optimization (ZCPO) to address these issues by measuring relative policy drift via conditional KL divergence.
- Uses relative drift to dynamically calibrate within-group reward coefficients and integrates the calibrated values directly into the base surrogate objective.
- Validated through mathematical reasoning experiments and comprehensive ablation studies.

**Why it matters:** ZCPO prevents policy degradation caused by standard KL regularization flaws, allowing more stable and effective reinforcement learning for group policy optimization.

### [Easy to anticipate, hard to compute: boundary dependence finds the computed outputs that entropy patching misses](https://arxiv.org/abs/2610.11790v1)

**arXiv cs.CL** · 2026-10-08 · `arXiv:2610.11790v1`

BLT's entropy-based patching misses low-entropy, compute-intensive byte positions like math solutions, but a label-free boundary-dependence signal restores patch allocation and downstream accuracy under tight budgets.

- Entropy-triggered patching fails on positions whose type is predictable but value requires computation (e.g., numbers after '=' in GSM8K).
- For Meta's BLT-1B at a 10% patch budget, placing patch boundaries using entropy achieves 19.0% accuracy on computed GSM8K results, whereas combining entropy with boundary dependence achieves 67.1%.
- Low-rank fine-tuning under a 10% budget shows a persistent accuracy gap between entropy and boundary dependence (32.9% vs 72.7%, p < 1e-200).
- The accuracy advantage of boundary dependence over entropy scales with model size, reaching a +19.8 point advantage on final answers for a 50M parameter model.
- Boundary dependence is measured contextually per two bytes as the rise in the model's own loss when a patch start is removed, requiring no ground-truth labels.

**Why it matters:** Relying solely on next-byte entropy for dynamic patching causes severe performance degradation on reasoning tasks, which can be fixed using unsupervised boundary dependence.

- Addresses the 'low-low token' issue where tokens assigned negligible probability by both models produce large log-ratio rewards that destabilize training.

### [LeWAM: A JEPA World Action Model with Diffusion-Steering-Based MPC](https://arxiv.org/abs/2610.12407v1)

**arXiv cs.AI** · 2026-10-08 · `arXiv:2610.12407v1`

LeWAM is an end-to-end, decoder-free JEPA world action model using a bidirectional transformer that improves latent state representation, closed-loop acting, and noise-space MPC planning.

- LeWAM uses a bidirectional transformer trained end-to-end across four modes: forward, backward, inverse dynamics, and policy prediction.

- Matches the performance of a standard flow-matching policy of equivalent size while simultaneously serving as a predictive world model.
- Improves MPC planning by sampling within the noise space of the policy head rather than raw action space, preventing Model Predictive Control from exploiting dynamics-model inaccuracies.

**Why it matters:** By replacing noisy reconstruction-based latents with a multi-mode JEPA representation and planning in noise space, LeWAM unifies robust world modeling and policy execution without susceptibility to model exploitation.

### [Learning to Read Out: Unembedding Dynamics in Language Model Pretraining](https://arxiv.org/abs/2610.21025)

**Hugging Face Daily Papers** · 2026-10-13 · 👍 3 · ⭐ 2 · `arXiv:2610.21025`

Researchers show language model outputs lag behind hidden state representations due to unembedding learning rates, introducing parameter-trajectory crosscoding to track readout evolution during pretraining.

- Parameter-trajectory crosscoding fits a single sparse dictionary to all token unembedding rows across all pretraining checkpoints using only model weights.
- Pythia's unembedding matrix reorganizes in a narrow window between 0.4% and 1.1% of pretraining, making WordNet categories linearly decodable from its rows.
- Linear probes on hidden states decode task information before the model's own unembedding matrix expresses it in output tokens.
- Increasing the unembedding layer's learning rate accelerates readout development and closes the representation-output gap sooner without impacting final loss.

**Why it matters:** Tracking task acquisition solely through output tokens misdates when models learn capabilities, as early behavioral benchmarks measure unembedding readout timing rather than internal representation growth.

### [H-DDCM: Hadamard Codebooks for Fast Generative Image and Video Compression](https://arxiv.org/abs/2610.18125)

**Hugging Face Daily Papers** · 2026-10-12 · 👍 3 · `arXiv:2610.18125`

H-DDCM improves training-free generative image and video compression by replacing dense Gaussian codebooks with implicit randomized Hadamard dictionaries, significantly reducing memory and compute overhead.

- Replaces Gaussian codebooks with implicit randomized Hadamard dictionaries using the fast Walsh-Hadamard transform, lowering complexity to O(d log d) compute and O(d) memory without storing full-dimensional matrices.
- Introduces an efficient table-free lexicographic coding scheme to make combinatorial bitstream encoding practical for large latent dimensions.
- Adapts the framework to autoregressive video flow models via a streaming compression scheme that periodically re-encodes reconstructed frames into a KV-cache prefix without extra transmitted bits.
- Enables long-form, near real-time generative video compression on a single GPU while preserving rate-distortion-perception performance.

**Why it matters:** It enables scalable, memory-efficient, and near real-time generative compression of high-dimensional images and long video streams on standard single-GPU hardware without retraining generative models.

<small>Or Ronai, Vladimir Kulikov, Tomer Michaeli</small>

**Hugging Face Daily Papers** · 2026-10-14 · 👍 2 · `arXiv:2610.21500`

**Why it matters:** It demonstrates that naive remote KV caching can severely degrade long-context LLM serving performance, providing a validated design for context-parallel remote cache architectures.

### [Equal CER, Unequal Damage: Severity-Weighted Character Error Rate for OCR](https://arxiv.org/abs/2610.20461)

**Hugging Face Daily Papers** · 2026-10-13 · 👍 2 · ⭐ 11 · `arXiv:2610.20461`

semCER is a severity-weighted Character Error Rate metric for OCR and VLMs that uses an LLM judge to assign grapheme edit costs without requiring word segmentation.

- semCER preserves standard CER's alignment and denominator while weighting grapheme edits by LLM-judged severity, breaking total transcription error down into named edits.
- Across human evaluation in English, Vietnamese, and Chinese, edit charges track reader ratings and sort severe edits to the top; readers preferred semCER over normalized CER on disagreement pairs in English and Chinese.
- Across 16 languages, the LLM judge adaptively weights errors; for example, diacritic or tone errors receive minimal penalty in Spanish but near full-letter severity in Telugu.
- Using real-word analysis, general VLMs were found to generate wrong letters that form actual words significantly above chance compared to classical OCR pipelines.
- The authors released 61 million judged edits, aggregated reader ratings, and a distilled scorer on GitHub.

**Why it matters:** It provides a fine-grained, human-aligned evaluation metric for visual text recognition that penalizes semantic-damaging errors more heavily than trivial typos.

<small>Nguyen Nguyen, Yongyi Zang</small>

### [One Bias Score, Two Factors: How Mitigations Affect Option Bias in Multiple-Choice Evaluation](https://arxiv.org/abs/2610.20993)

**Hugging Face Daily Papers** · 2026-10-13 · 👍 2 · `arXiv:2610.20993`

Researchers show that option bias in multiple-choice evaluation, measured by pooled SD, decomposes into two label-free factors: flip rate and positional skew.

- Pooled selection-rate standard deviation (pooled SD) equals the product of flip rate and positional skew when options are balanced across positions.
- Across 41 checkpoints and 12 benchmarks, flip rate correlates with accuracy and output uncertainty, whereas positional skew correlates with the estimated option-symbol prior.
- Prior correction primarily reduces positional skew, while order aggregation (combining an ordering with its reversal) mainly reduces the flip rate.
- Combining prior correction with order aggregation reduces both factors and narrows the accuracy variance across correct-answer letters, though aggregation can stabilize models on incorrect options.

**Why it matters:** Decomposing bias into flip rate and positional skew allows practitioners to evaluate whether mitigations improve true model correctness or merely enforce consistent, but incorrect, predictions.

<small>Hyunjong Ok, Minjae Park, Jaeho Lee</small>

### [PINT: A Unified Model with Shared Predictive Intent for Robot Manipulation](https://arxiv.org/abs/2610.16355)

**Hugging Face Daily Papers** · 2026-10-11 · 👍 2 · ⭐ 3 · `arXiv:2610.16355`

PINT is a unified robot manipulation model that links semantic reasoning, video generation, and action control through a shared chunk-level Predictive Intent while preserving expert-specific pathways.

- Predictive Intent is formed by inserting learnable Intent Tokens into a VLM sequence, which then conditions both a Video Generation Model (VGM) and an Action Expert (AE).
- The model learns Predictive Intent jointly from the native prediction objectives of the VLM, VGM, and AE without prescribing its explicit content.
- Training is executed in two stages: Stage 1 freezes the VGM to shape Intent via future video prediction; Stage 2 fixes Intent to adapt the VGM and AE.

**Why it matters:** It demonstrates that decoupling task-specific pathways via a shared predictive token space enables strong zero-shot and out-of-distribution robot manipulation without requiring large-scale embodied pretraining.

### [Diminishing Returns of Data in Sparse Autoencoders: Functional Behavior does not Guarantee Feature Reproducibility](https://arxiv.org/abs/2610.20680)

**Hugging Face Daily Papers** · 2026-10-13 · 👍 1 · `arXiv:2610.20680`

A study shows Sparse Autoencoder (SAE) functional metrics converge at far lower token budgets than one-to-one feature reproducibility, which requires larger datasets and explicit validation.

- Evaluated four SAE architectures across three language models using activation data budgets from 5M to 500M tokens.
- Functional reconstruction metrics approach full-data baseline levels at small token budgets, but feature reproducibility requires significantly more data.
- For Gemma-2-2B BatchTopK, strictly matched features increased from 2% at 5M tokens to 29% at 50M tokens.

- Theoretical analysis demonstrates that statistical consistency of subsampled training is distinct from the stricter identifiability required for exact feature recovery.

**Why it matters:** Researchers can significantly reduce SAE training costs when targeting functional metrics, but must use higher data budgets and reproducibility checks when making feature-level claims.

**arXiv cs.CL** · 2026-10-15 · `arXiv:2610.22067v1`

Researchers introduced LURCH, a benchmark quantifying long-context LLM difficulty using three new metrics: evidence scope, evidence dispersion, and reasoning depth, rather than relying solely on total context length.

- LURCH comprises 6,550 multi-domain QA instances annotated with supporting evidence and reasoning graphs.
- Model performance negatively correlates with higher evidence scope, wider evidence dispersion, and deeper reasoning chains at fixed context lengths.

**Why it matters:** Evaluating long-context models strictly by token count masks failure modes caused by scattered evidence and multi-step reasoning dependencies.

### [Terminal-RSI: Recursive Self-Improving Terminal Agents via Recursive Self-Rewrite and Policy-Refine](https://arxiv.org/abs/2610.22192v1)

**arXiv cs.AI** · 2026-10-15 · `arXiv:2610.22192v1`

Terminal-RSI introduces alternating Recursive Self-Rewrite and Recursive Policy-Refine stages with novel reward and GAE formulations to advance terminal agent training.

- Alternates Recursive Self-Rewrite (RSR) of verified trajectories with critic-inheriting Recursive Policy-Refine (RPR) across a five-stage sequence using Qwen3.8-27B.
- Implements Turn-Boundary Skip-Observation GAE (TB-GAE) to preserve token-specific baselines while applying decay across turn boundaries.
- Uses Family Dense Reward (FDR) to calibrate semantic progress and Success-Prioritized Reward (SPR) to isolate strict success from bounded partial credit.

- Achieves 19.84% on Terminal-Bench 4.0, 86.52% on Terminal-Bench 2.1, 16.95% on Terminal-Bench 3.0, and 79.00% on Terminal-Bench Hard.

**Why it matters:** The approach demonstrates that recursively coupling trajectory rewriting with policy refinement enables terminal agents to convert partial local repairs into verified end-to-end task completions.

### [Mosaic: Multi-Session Agentic Reinforcement Learning](https://arxiv.org/abs/2610.22174v1)

**arXiv cs.AI** · 2026-10-15 · `arXiv:2610.22174v1`

Mosaic is a multi-session agentic reinforcement learning method using critic-free hierarchical optimization to reward individual session contributions and optimize session allocation in non-continuous context trajectories.

- Addresses the mismatch between single-session RL training and multi-session inference techniques like context compaction and subagent forking.
- Uses hierarchical optimization at two levels: trajectory-level advantage estimation incorporating session-usage signals, and session-level advantage shaping based on estimated marginal contributions.
- Evaluated on BrowseComp using Qwen3.5-4B, outperforming traditional trajectory-level advantage broadcasting while using fewer sessions on average.

**Why it matters:** It improves session utility and context allocation efficiency for LLM agents utilizing advanced multi-session workflows like context compaction and subagent forking.

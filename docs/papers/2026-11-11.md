### [Tree-Ising: Repairing Language Models with Bit-Level Ising Edits](https://arxiv.org/abs/2611.14210)

**Hugging Face Daily Papers** · 2026-11-09 · 👍 55 · `arXiv:2611.14210`

Tree-Ising repairs language model reasoning loops by casting BF16 weight edits into sparse discrete QUBO/Ising problems, outperforming LLM-agent weight repairs while consuming zero tokens and fewer weight edits.

- Formulates model repair as independent per-row QUBO/Ising problems over BF16 weights via sign flips and exponent shifts, solved using GPU-accelerated simulated annealing or simulated bifurcation.
- Achieves 54.6% (annealing) and 55.1% (simulated bifurcation) on MATH-500 for Qwen3.5-0.8B, outperforming the GPT-6 Astra agent edit (51.7%) and base model (7.9%).
- Requires only 4 forward passes, 0 LLM tokens, and ~$0.90 GPU time, while modifying 13%-17% fewer weights and reducing bit flips by 2.2x to 2.3x compared to the agent.
- Scales to Qwen3.5-2B, boosting greedy GSM8K accuracy from 21.6% to 69.4%, and demonstrates execution of an 8-variable subproblem using QAOA on an IBM Heron quantum processor.

**Why it matters:** It demonstrates that discrete, training-free model edits can be solved deterministically and cheaply via Ising optimization, providing a more resource-efficient alternative to LLM-agent weight-space programming.

<small>Hadi Salloum, Ammar Ali</small>

**Hugging Face Daily Papers** · 2026-11-09 · 👍 45 · ⭐ 4 · `arXiv:2611.14320`

WikiTrace introduces an evidence-linked memory system for LLM agents that links concise lessons back to trajectory summaries and raw execution logs to mitigate memory-induced degradation.

- Memory-induced degradation occurs when agents misread, misapply, or follow incorrect memory lessons inferred from sparse task success or failure labels.
- WikiTrace structures memory by linking concise insights directly to a summary of the trajectory's outcome and the underlying raw trajectory.

- Evaluated across five agentic benchmarks, WikiTrace reduced performance degradation and outperformed existing memory approaches as well as baselines provided with insights alone.

**Why it matters:** By providing a mechanism for agents to ground and verify generated lessons against original execution logs, WikiTrace makes long-term agentic memory systems significantly more reliable.

### [Few-Step Streaming Video Generation via Condition Shifting](https://arxiv.org/abs/2611.14033)

**Hugging Face Daily Papers** · 2026-11-09 · 👍 38 · `arXiv:2611.14033`

APEX extends streaming video generation to few-step sampling by using condition shifting to eliminate independent fake-score networks, reducing GPU memory and iteration time while improving instruction following and visual aesthetics.

- Replaces Distribution Matching Distillation's (DMD) separate fake-score network by using condition shifting within the generator, reusing parameters where text conditions drive generation and shifted conditions estimate fake velocity fields.
- Retains S2-Avatar baseline components including the frozen reference teacher, Self-Replay Forcing, and perceptual regularization, evaluated using three backbone passes per block and a one-step spatial Refiner.
- Outperforms S2-Avatar on StreamAV-Bench in Progressive track instruction fulfillment (3.856 vs. 3.831) and visual aesthetics (0.641898 vs. 0.632606), with human raters showing a +30.0% net preference for instruction following.
- Reduces peak allocated GPU memory per GPU by 4.4% and shortens mean iteration time by 9.2% compared to DMD under matched training settings.

**Why it matters:** By removing the separate fake-score network in streaming video distillation, APEX lowers training compute and memory overhead while maintaining high instruction adherence and visual quality over long 180-second video generations.

- Evaluates agents using a simulated user with a hidden strategy sampled from a compositional grammar, requiring the agent to ask clarification questions.

### [A Theory of Policy Optimization in Post-Training: Coverage Collapse and Reference Resets](https://arxiv.org/abs/2611.14467v1)

**arXiv cs.LG** · 2026-11-10 · `arXiv:2611.14467v1`

This paper identifies coverage collapse in REINFORCE-based methods like PPO and GRPO and proves that Approximate Policy Mirror Descent with periodic reference resets prevents it, establishing global convergence guarantees governed by base model coverage.

- Identifies 'coverage collapse' in REINFORCE, PPO, and GRPO, where the probability of generating optimal responses drops to near zero despite reward improvements, causing exponential slowdowns even under standard KL regularization.
- Introduces Approximate Policy Mirror Descent (APMD) with 'reference resets' that update the KL reference to the current policy, preventing collapse and ensuring global convergence.
- Proves that stylized PPO/GRPO variants with explicit resets, as well as implicit squared-loss algorithms (such as those used in Kimi models), are coverage-preserving for softmax linear policies.

**Why it matters:** It provides theoretical proof that resetting KL reference models prevents optimization stalls, giving practitioners principled guidelines for designing sample-efficient post-training RL algorithms.

Falsification-Gated Self-Evolution (FGSE) introduces a framework that treats LLM agent memory updates as structured hypotheses, validating them via transfer, falsification, and regression probes before committing them to persistent state.

- Structures memory candidate lessons into hypotheses containing an explicit precondition, behavior change, expected effect, and verifier.
- Applies candidate hypotheses temporarily to test them across target-transfer, falsification, and archived-regression probes before final commit, refinement, or rejection.
- Achieves a 39.8 WebArena success rate, 78.8 AppWorld average completion, and 0.724/0.487 Pass1 on tau-Retail/tau-Airline.

**Why it matters:** It prevents local episode successes from inserting unverified or unsafe knowledge into an agent's long-term memory, ensuring safer and more reliable self-improvement.

### [Player-1: Learning to Play from Synthetic Experience](https://arxiv.org/abs/2610.20584)

**Hugging Face Daily Papers** · 2026-10-13 · 👍 121 · ⭐ 2 · `arXiv:2610.20584`

Player-1 is a post-training framework that uses synthetic experience and PPO reinforcement learning to significantly improve computer-use agent performance across complex 2D and 3D games.

- Extended standard computer-use action spaces to include relative pointer motion, sustained inputs, and composite actions combining multiple keyboard/mouse inputs.
- Fine-tuned models on 6,044 curated gameplay trajectories featuring visual reasoning, task instructions, and paired actions for supervised initialization.
- Constructed Player-1-Gym, consisting of 16 synthetic 2D/3D environments with randomized observations, control dynamics, and programmatically verifiable rewards for multi-environment PPO training.
- Player-1-9B achieved a 38.33% success rate on MineDojo-300 (up 27.8 percentage points over its SFT baseline), outperforming the strongest evaluated baseline of 12.63%, with additional gains on ViZDoom-10 and GameWorld.

**Why it matters:** It demonstrates that training agents in synthetic, procedurally randomized environments with composite action spaces enables broad zero-shot transfer to complex, unseen interactive visual environments.

### [Cortex: Consolidating Context into Parametric Memory](https://arxiv.org/abs/2610.20399)

**Hugging Face Daily Papers** · 2026-10-13 · 👍 52 · `arXiv:2610.20399`

Cortex internalizes context-induced performance gains into LLM parametric memory using query generation and mergeable low-rank or structural FFN updates without losing non-target capabilities.

- Formulates Memory Consolidation (MC) to unify context-specified editing, skill learning, and behavioral steering into a shared objective.
- Introduces Cortex, a method that generates prospective queries to anticipate context use and distills context-conditioned outputs into mergeable low-rank or structural feed-forward network (FFN) updates.
- Evaluates performance across 4B to 120B dense and mixture-of-experts backbones, covering both text-only and multimodal architectures.
- Achieves 88.9% recovery of context-induced gains while retaining 99.8% of original non-target performance after 50 sequential factual edits on a 14B parameter model using Cortex-Structural.

**Why it matters:** It enables large language models to permanently retain new skills and factual edits from context without requiring perpetual context window usage or degrading base model capabilities.

### [ActionOPD: Distilling Decisions, Not Tokens](https://arxiv.org/abs/2610.19820)

**Hugging Face Daily Papers** · 2026-10-13 · 👍 45 · ⭐ 4 · `arXiv:2610.19820`

ActionOPD is an action-level, on-policy distillation method that aligns student model decisions with black-box teacher decisions using semantic action agreement rewards instead of token-level probabilities.

- Eliminates the requirement for identical tokenizers or access to teacher token probabilities by operating at the semantic action level.
- Addresses state-distribution mismatch by using on-policy distillation, sampling actions from both student and teacher at student-encountered states.
- Improves Qwen3-4B and Qwen3-8B performance by 3.3 to 6.9 percentage points on average across four out-of-distribution tool-use benchmarks.
- Supports Self-ActionOPD configurations using a same-model teacher supplied with privileged context.
- Achieves competitive performance on the τ^2-bench compared to standard offline distillation and token-level OPD.

**Why it matters:** It enables effective distillation of proprietary, black-box, or cross-tokenizer teacher models into smaller student agents without forcing the student to imitate teacher reasoning tokens.

### [The Thinking Leakage in Reinforcement Learning for LLMs](https://arxiv.org/abs/2610.14270)

**Hugging Face Daily Papers** · 2026-10-08 · 👍 5 · `arXiv:2610.14270`

A study on Qwen3 models trained via GRPO reveals that reasoning gains in NO-THINK mode stem from thinking leakage, which reactivates the original model's existing THINK-mode abilities rather than learning novel reasoning behaviors.

- Training Qwen3-1.7B, 4B, and 8B in NO-THINK mode using GRPO causes responses to lengthen, reflectiveness to increase, and internal activations to shift toward the original THINK mode.
- In Qwen3-8B, replacing a low-dimensional THINK-related activation subspace in the RL-trained model with original-model values removes most RL performance gains, while swapping it into the original model transfers a considerable fraction of the gain.
- Mechanistically, the RL-induced activation shift passes through attention heads reading the empty think block, driven by advantage-weighted GRPO gradients that favor THINK-like responses.
- Scaling the RL update further elicits THINK-mode behavior and approaches original THINK-mode accuracy, but fails to exceed it.

**Why it matters:** It demonstrates that RL gains in non-reasoning modes may merely unmask pre-existing reasoning capabilities rather than teach models genuinely new reasoning mechanisms.

<small>Wenxuan Zhu, Shuming Liu, Bang An, Aznaur Aliev, Bing Li, Yibo Yang, Bernard Ghanem</small>

Continuum Attention replaces discrete key-value lookups in Transformer decoders with continuous piecewise linear memory curve integration, evaluating exact normalized attention via closed-form exponential moments.

- Queries induce exponential relevance densities over a continuous memory curve, calculated using closed-form exponential moments up to order two.

### [Recovering Reliable Supervision via Critique-Guided On-Policy Distillation](https://arxiv.org/abs/2610.20572v1)

**arXiv cs.AI** · 2026-10-14 · `arXiv:2610.20572v1`

CriticOPD restores teacher recoverability during on-policy distillation by having the teacher critique student errors, enabling the student to train on successful revisions generated without privileged critique information.

- Identifies that traditional On-Policy Distillation (OPD) fails because teachers lose recoverability by following student errors on incorrect rollouts.
- Introduces CriticOPD, where the teacher critiques an incorrect rollout to guide a revised solution containing the critique as privileged information.
- Trains the student on the resulting revision while excluding the teacher's critique from the student's input sequence.
- Evaluated using two Qwen3 student models across six mathematical reasoning benchmarks, achieving the largest performance gains on competition-level problems.

**Why it matters:** It improves token-level teacher supervision on incorrect rollouts, allowing student models to effectively learn error correction and achieve higher reasoning accuracy on complex tasks.

### [Hindsight-Privileged RLVR: Single-Rollout Token Credit Without Group Sampling](https://arxiv.org/abs/2610.20497v1)

**arXiv cs.AI** · 2026-10-14 · `arXiv:2610.20497v1`

Hindsight-Privileged RLVR (HP-RLVR) provides token-level credit assignment from a single trajectory by computing Jensen-Shannon divergence between causal and hindsight policy views.

- Uses a single rollout per prompt by converting a completed trajectory's future and verifier feedback into a hindsight context, removing the need for group sampling or a learned critic.
- Calculates token update weights via normalized Jensen-Shannon divergence between the generating policy's scores under causal history versus the hindsight context.
- Achieves 1.21x, 1.46x, and 2.30x faster training than GRPO on mathematics, code generation, and ALFWorld using 1/8th the rollouts per prompt.
- Eliminates zero-gradient updates, whereas GRPO experienced zero gradient norms in 43.2% (4B) and 49.0% (8B) of ALFWorld training records due to uniform outcome sampling.
- Matches overall accuracy with GRPO, leading on mathematics across 4B and 8B model sizes while GRPO remains ahead on code generation and ALFWorld.

**Why it matters:** HP-RLVR reduces computational costs by an order of magnitude while ensuring consistent gradient signals even when all sampled rollouts yield identical outcomes.

### [Decoupled Marginal Sharpening for Training-Free Inference-Time Scaling](https://arxiv.org/abs/2610.20483v1)

**arXiv cs.LG** · 2026-10-14 · `arXiv:2610.20483v1`

Decoupled Marginal Sharpening (DMS) improves training-free inference-time scaling in LLMs by decoupling reasoning-path exploration from answer-marginal sharpening and sampling via Fully Adapted Annealed SMC.

- Identifies two failure modes in reward-free power-sampling ($π_α(y\|x)\propto p_0(y\|x)^α$): path suppression at the target level and path collapse in finite-particle SMC samplers.
- Decouples target sharpening by using a lower exponent to explore diverse reasoning paths and a higher exponent to sharpen the answer marginal aggregated over those paths.
- Implements Fully Adapted Annealed SMC utilizing an annealed power target sequence, locally fully adapted proposals, and predictive ancestor resampling.
- Achieved the highest mean pass@1 compared to baseline methods across MATH500, GPQA-Diamond, HumanEval, and AIME24/25 using three base models.

**Why it matters:** It enables higher inference-time reasoning performance without requiring weight updates or external reward models.

<small>Weixin Wang, Wei Deng, Anderson Schneider, Yuriy Nevmyvaka, Pan Xu, Andrew Bennett</small>

### [Training Language Models to Fail Gracefully](https://arxiv.org/abs/2610.20401v1)

**arXiv cs.LG** · 2026-10-14 · `arXiv:2610.20401v1`

GracefulRL uses outcome-level rewards to train language models to execute safe fallback policies when task completion is unreliable, avoiding overconfidence without requiring inference-time verifiers or extra annotations.

- Standard RL rewards encourage long-shot guessing because safe fallbacks provide less utility than successful task execution, leading to costly errors.
- Naive policy gradients with intermediate fallback rewards suffer from brittle optimization dynamics.
- GracefulRL reshapes the optimization landscape using outcome-level rewards to incentivize models to recognize their execution limits and change course.
- The method preserves core task-solving capabilities while selectively falling back, eliminating the need for real-time verifiers or explicit fallback annotations.

**Why it matters:** By training models to fall back safely instead of guessing, GracefulRL reduces high-cost failure modes in downstream deployments like executing database queries or pushing code.

<small>Daman Arora, Xuecheng Liu, Himanshu Gaurav Singh, Fahim Tajwar, Abitha Thankaraj, Ruslan Salakhutdinov, Haiwen Feng, Yuda Song</small>

### [MMLA-RSI: Recursive Self-Improvement through RTT and RTMA](https://arxiv.org/abs/2610.20294v1)

**arXiv cs.LG** · 2026-10-14 · `arXiv:2610.20294v1`

MMLA-RSI is a recursive self-improvement framework using Reasoning-Time Training (RTT) and Reasoning-Time Memory Adaptation (RTMA) to update policy states and authoritative memory alongside their own adaptation methods.

- RTT modifies the policy state via scalar schedules in a clipped-momentum update, while RTMA alters authoritative memory through complete-row writes or evictions.
- The framework uses self-referential updater selection where the current numerical updater or memory manager proposes its successor, subject to an independent evaluator and trusted committer.
- Bounded executable rule languages, shared task/proposal interfaces, state versions, read closures, and conditional properties enforce causal execution and finite work.
- In four-candidate program selection, retaining LARC feedback updates reduced expected error by 24.65 and 36.65 percentage points across two initializations.
- In chronological continuous-integration replay, feedback binding yielded positive results, whereas memory retention increased loss.

**Why it matters:** It establishes formal execution bounds and mechanisms for agents to recursively self-improve both their operational states and their meta-learned update algorithms.

<small>Junyi Zou, Avrova Donz</small>

### [ReaDy: Recurrent States as Dynamic Context for Speculative Drafting in Hybrid Linear Attention Large Language Models](https://arxiv.org/abs/2610.20503v1)

**arXiv cs.CL** · 2026-10-14 · `arXiv:2610.20503v1`

ReaDy is the first speculative decoding method that retrieves dynamic context from Hybrid Linear Attention (HLA) recurrent states using position-specific learned queries to accelerate LLM inference.

- Uses position-specific learned queries and a lightweight state reader to extract supplementary context from target HLA recurrent states via residual updates.
- Incorporates low-rank state reads and fused operators to minimize I/O and computational overhead on top of a parallel backbone and sequential prediction head architecture.
- Employs a lightweight two-stage adaptation strategy to train the reader while optimizing reader capacity, state source selection, and residual placement.
- Achieves a 3.16x average decoding speedup over autoregressive baseline with Qwen3.8-27B on a single NVIDIA B200 GPU.
- Outperforms DSpark across seven benchmarks, increasing throughput by 7.97% and draft token acceptance length by 8.50% on average.

**Why it matters:** It improves speculative decoding efficiency and acceptance rates in hybrid linear attention models by repurposing compact recurrent states for dynamic context retrieval.

<small>Bohan Sun, Zunhai Su, Xialie Zhuang, Jianjin Li, Ngai Wong, Chuan-Wei Kuo</small>

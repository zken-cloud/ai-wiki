**Hugging Face Daily Papers** · 2026-09-10 · 👍 58 · `arXiv:2609.13406`

Generalized Agent Iteration (GAI) is a new formal framework that unifies classical iterative policy improvement and recursive self-improvement into a single learning paradigm.

- Defines an agent as a configuration of modifiable system components, modeling learning as an agent evaluation and agent improvement cycle.
- Uses a component dial to separate Generalized Policy Iteration (GPI) from Recursive Self-Improvement (RSI) based on whether the improving mechanism is internal to the agent.
- Uses an evaluation dial to categorize system polarity into anchored, goal drift, or fully self-referential based on external vs. internal standards.
- Maps existing self-improving systems onto two formal axes to analyze defects in recursive self-improvement one condition at a time.

**Why it matters:** GAI provides a unified, principled theoretical basis for comparing, analyzing, and designing both standard RL algorithms and recursively self-improving agents.

### [Rethinking Critic Learning in PPO: Understanding and Mitigating Value Flattening](https://arxiv.org/abs/2609.18708)

**Hugging Face Daily Papers** · 2026-09-15 · 👍 41 · ⭐ 2 · `arXiv:2609.18708`

Researchers identified Value Flattening in PPO critics, where state value predictions remain flat despite sharp changes in ground-truth Monte Carlo values, and introduced SParse Proximal Policy Optimization (SP^3O) to fix it.

- Value Flattening is driven by an implicit variance penalty in the critic loss and redundant updates from temporally correlated states sharing similar gradients.
- The phenomenon worsens as the state space grows, as demonstrated in controlled FrozenLake experiments.
- SParse Proximal Policy Optimization (SP^3O) addresses the issue by calculating value loss on only a few well-separated states per response.
- Evaluating SP^3O on Qwen3-Base using just three supervised states per response mitigated Value Flattening and improved policy performance across different model sizes.

**Why it matters:** Identifying Value Flattening reveals a major flaw in standard PPO critic training, while SP^3O offers a simple sparse supervision method to improve value estimation and overall RL Fine-Tuning efficiency for LLMs.

<small>Yizhuo Li, Jianhao Yan, Yun Luo, Zhi Wang, Futing Wang, Rong-Xi Tan, Kanghui Tian, Ganqu Cui</small>

### [Decodable but Misrouted: Sparse Features Uncover a Readout Gap in Vision-Language Models for Harmful Meme Detection](https://arxiv.org/abs/2609.18860v1)

**arXiv cs.AI** · 2026-09-16 · `arXiv:2609.18860v1`

Evaluations of Gemma-3 and Qwen3.5 reveal that harmful meme detection failures stem from a readout routing bottleneck rather than missing internal representations.

- Sparse readouts outperform native vision-language model predictions across six primary binary tasks, raising Qwen from 0.432 to 0.740 macro-F1 and Gemma from 0.532 to 0.714.

- A Gemma-3-12B case study on Facebook Hateful Memes isolates a distributed rank-32 image-prompt interaction reaching 0.756 macro-F1 versus 0.685 native macro-F1.

**Why it matters:** Improving output routing mechanism calibration can significantly boost vision-language model safety detection without needing to expand internal task representations.

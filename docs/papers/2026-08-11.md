### [Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory](https://arxiv.org/abs/2608.07169)

**Hugging Face Daily Papers** · 2026-08-06 · 👍 23 · `arXiv:2608.07169`

Agent Memory Distillation (AMD) is a training-free framework that transfers structured, hierarchical teacher memory (Workflow, Subtask, and Function) from large LLMs to small 4B-8B student agents to boost tool-use performance.

- AMD builds three memory types from teacher trajectories: Workflow (task strategies), Subtask (intermediate behaviors), and Function (tool conventions and pitfalls).
- Workflow and Subtask memories are injected proactively at task initialization, whereas Function memory is retrieved reactively after tool-calling errors.
- Evaluated with a GPT-5-mini teacher, AMD improved 4B-8B student model accuracy by 27.2%p on AppWorld, 11.2%p on BFCL V3, and 3.4%p on ToolSandbox.
- Subtask memory provides the largest individual performance gains, with 4B-parameter models benefiting more than 8B-parameter models.

**Why it matters:** AMD enables small language models (4B-8B parameters) to achieve high-tier tool-use capabilities without requiring expensive model retraining or fine-tuning.

- Address limitations of standard reverse-KL training and local teacher probability estimates during on-policy distillation.

### [Relevant but Incomplete: Referential Dangling as a Paradigm-Level Failure Mode in Hard Prompt Compression](https://arxiv.org/abs/2608.04569)

**Hugging Face Daily Papers** · 2026-08-04 · 👍 9 · ⭐ 3 · `arXiv:2608.04569`

Independent scoring in hard prompt compression causes referential dangling, where retained answer text loses the required entity context, degrading downstream model accuracy by up to 34 percentage points.

- Referential dangling occurs when independent compression algorithms select answer-bearing text while dropping the contextual entity definition needed to interpret it.
- At a 0.30 compression ratio, the Beaver compressor creates incomplete answer paths in 34-54% of bridge examples, while six tested compressors exhibit dangling rates up to 60% on HotpotQA.
- Reinserting missing supporting paragraphs improves Qwen3-8B accuracy by 29-34 percentage points, while advanced models like GPT-5.5 still show an 8.8-point accuracy drop on compressed MuSiQue contexts.
- An automated classifier trained to reinsert missing referential sentences yields a 4.7-point accuracy gain on HotpotQA while shifting the compression ratio minimally from 0.30 to 0.31.

**Why it matters:** Hard prompt compression algorithms must be redesigned to ensure referential completeness alongside relevance, as even frontier language models cannot recover lost contextual dependencies.

### [Mismatch Matters: On-Policy Distillation Beyond Token Agreement](https://arxiv.org/abs/2608.09836v1)

**arXiv cs.AI** · 2026-08-10 · `arXiv:2608.09836v1`

TIDE improves on-policy distillation by addressing teacher-student mismatch via bounded Hellinger shaping for student-excess tokens and analytic teacher top-K injection for student-deficit tokens.

- Identifies degenerate agreement in on-policy distillation, where students use repetitive loops to achieve high token agreement while outputting globally flawed responses.
- Categorizes token mismatches into student-excess tokens (generated by student, near-zero probability by teacher) which destabilize updates, and student-deficit tokens (preferred by teacher, rarely sampled by student) which block reasoning transfer.
- Introduces TIDE, which uses bounded Hellinger shaping to suppress severe excess tokens and analytic top-K injection to restore deficit probability mass without needing deficit tokens to be sampled.
- Demonstrates that TIDE outperforms standard OPD and baselines on mathematical benchmarks using Qwen3 teacher-student pairs, raising Avg@8 from 6.9% to 20.3% under strong mismatch while reducing average response length by 3.6x.

**Why it matters:** TIDE stabilizes on-policy distillation under severe model mismatches, preventing degenerate generation loops and reducing formatting failures while shortening response lengths.

**Why it matters:** Co-training two policies via a geometric mixture offers a targeted mechanism to prevent feedback loop instabilities and performance degradation in on-policy LLM distillation.

### [Depth-adaptive Inference of Looped Language Models via Continuous Depth Batching](https://arxiv.org/abs/2608.09444v1)

**arXiv cs.LG** · 2026-08-10 · `arXiv:2608.09444v1`

Continuous depth batching (CDB) enables efficient depth-adaptive inference for looped LMs by scheduling at the loop-iteration level while handling non-looped boundary stages via separate priority queues.

- Depth-adaptive inference breaks standard token-level batching because tokens within the same batch exit at different iteration counts.
- CDB manages non-looped boundary stages (embeddings and LM heads) and loop steps using separate priority queues.
- Exit decisions are evaluated one step ahead, and all scheduling overhead is overlapped with GPU computation.
- Evaluated on Ouro 1.4B and Huginn 3.5B, CDB achieves up to 99% of theoretical adaptive-depth speedups.

**Why it matters:** CDB resolves batching inefficiencies in looped language models, enabling 1.5-1.9x higher offline throughput and up to 90% lower latency under dynamic serving loads.

### [A Mechanistic Diagnostic of Rank Collapse in Post-Norm Decoder Transformers](https://arxiv.org/abs/2608.09417v1)

**arXiv cs.LG** · 2026-08-10 · `arXiv:2608.09417v1`

A two-stage analysis reveals that Post-Norm Transformer rank collapse stems from causal attention amplifying forward token similarity, which causes pre-norm residual norm growth that geometrically contracts backward gradients in RMSNorm layers.

- Initialization-time similarity growth is driven primarily by causal attention acting as a prefix-averaging operator, with SwiGLU providing only a minor damping effect.
- Entering a high-similarity regime increases pre-normalization residual norms, making the backward factor of RMSNorm contractive and forcing geometric decay of gradients to earlier layers.
- Collapsed Post-Norm networks decay to predicting token frequency distributions, where gradients vanish and training reaches a high loss floor.
- Empirical evaluations on 48-layer decoder-only Transformers trained on C4 confirm the predicted similarity growth, gradient contraction, and frequency loss convergence.

**Why it matters:** Understanding the distinct forward amplification and backward gradient contraction mechanisms in Post-Norm architectures provides a clear diagnostic for why training dynamics fail to recover from rank collapse.

### [Reducing Pretraining-Generation Mismatch in Diffusion Language Models](https://arxiv.org/abs/2608.09424v1)

**arXiv cs.CL** · 2026-08-10 · `arXiv:2608.09424v1`

Prefix-Conditioned Diffusion (PCD) reduces pretraining-generation mismatch in diffusion language models by combining autoregressive prefix supervision with no-shift suffix denoising without changing the inference mode.

- Identifies that native dLLM pretraining corrupts prompt and continuation tokens simultaneously, creating a mismatch with prompt-conditioned generation at evaluation time.
- PCD alters the attention mask, corruption mask, and label construction during continued pretraining to autoregressively supervise the clean prefix while applying diffusion solely to the suffix.
- Separates intra-sample prefix conditioning from inter-sample objective mixing to isolate the local alignment signal.
- Yields a 4.2% relative gain (+2.56 points) on the LLaDA2-Mini six-benchmark average and a 14.2% relative gain (+4.86 points) in Qwen-1.7B mechanism evaluations over native dLLM baselines.

**Why it matters:** PCD narrows the performance gap between diffusion and autoregressive language models on continuation tasks without needing verifiers, extra decoders, or changes to inference.

<small>Xiaocheng Lu, Huabin Liu, Song Guo, Jianguo Li</small>

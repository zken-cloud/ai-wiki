### [Cache Engineering for Agents](https://arxiv.org/abs/2610.28577)

**Hugging Face Daily Papers** · 2026-10-19 · 👍 76 · ⭐ 12 · `arXiv:2610.28577`

Cache engineering introduces direct, proactive agent control over KV cache using drop and repos operations, paired with the AKV serving engine to manage history-dependent cache reuse without modifying trajectory context or re-prefilling.

- Introduces 'drop' to exclude specific cache entries from attention and 'repos' to adjust position encodings of retained keys directly.
- Identifies history dependence as a serving challenge where identical token sequences yield different cache states based on past operation sequences.
- Proposes the AKV serving engine, which exposes a stateless API compatible with existing systems while internally managing stateful cache eviction, restoration, and reuse.
- Evaluations demonstrate that a tool-response rolling-drop policy improves benchmark scores by 1.7 points, reduces average costs by 27.7%, increases output throughput up to 1.2x, and yields a 1.5x speedup in P95 latency over threshold summarization.
- Applying recursive self-improvement to cache policies yields an additional 7.1% cost reduction compared to human-expert policy design.

**Why it matters:** It eliminates costly context re-prefilling and reduces storage bottlenecks for long-trajectory LLM agents while improving overall execution speed, accuracy, and serving costs.

### [PACE: Periodic and Channel-Aligned Encoding of Four-Bit Recurrent States](https://arxiv.org/abs/2610.29545)

**Hugging Face Daily Papers** · 2026-10-20 · 👍 10 · `arXiv:2610.29545`

PACE is a post-hoc four-bit state quantizer for linear-attention language models that uses periodic rounding, channel-aligned scale sharing, and mixed-precision heads.

- Periodic state rounding occurs once every few tokens alongside a small interim token buffer, reducing cumulative quantization error while retaining decoding speedups.
- Channel-aligned quantization shares scale factors across columns to accommodate gated-delta states where update magnitudes persist across specific channels.
- Mixed-precision allocation keeps select heads at 8-bit precision—specifically those that retain rounding errors longest—while maintaining the rest at 4-bit precision.
- Evaluated on hybrid models ranging from 4B to 35B parameters, PACE outperforms Q-Mamba at equal memory and rivals 8-bit DAMP on larger models using roughly two-thirds of the memory.

**Why it matters:** PACE enables efficient 4-bit recurrent state quantization without fine-tuning, significantly reducing memory footprint to allow more concurrent decoding sequences per accelerator.

Researchers identified emergent common-mode hidden offsets in preference optimization that pass undetected by relative ranking losses but accumulate to create vocabulary wells and drive generation collapse.

- The failure mechanism stems from a shared directional shift in hidden states across token positions, prompts, and chosen/rejected pairs that moves representations together without triggering relative ranking loss penalties.

### [Differentially Private Sparse Reward Estimation with Preference Feedback](https://arxiv.org/abs/2610.30099v1)

**arXiv cs.AI** · 2026-10-21 · `arXiv:2610.30099v1`

A new theoretical framework and efficient algorithms for private sparse RLHF achieve parameter estimation error bounds scaling with sparsity s* rather than full model size d under Sample-DP and Label-DP constraints.

- Formulates the Private Sparse RLHF problem assuming human preferences in the Bradley-Terry-Luce model depend on a sparse subset of features s* << d.
- Establishes an (ε,δ)-Sample-DP upper bound of O~(s*/n + (s*)^2 / (n^2 * ε^2)) for squared l2 parameter estimation error, which is proven nearly optimal.
- Establishes an ε-Label-DP upper bound of O~(s*/n + s*/(n * ε^2)) using a randomized response mechanism, alongside lower bounds showing its tightness within that framework.
- Empirically validated on sentiment generation and safety alignment benchmarks, outperforming dense baselines in privacy-utility trade-offs.

**Why it matters:** By decoupling privacy error bounds from total model parameter count d, this approach enables privacy-preserving alignment for modern overparameterized large language models.

### [Agent Behavior Maps: Locating Agents by What They Would Do, Without Running Them](https://arxiv.org/abs/2610.30014v1)

**arXiv cs.AI** · 2026-10-21 · `arXiv:2610.30014v1`

Agent Behavior Maps map LLM-harness combinations into coordinate spaces using centered action log-likelihoods on reference trajectories, enabling agent placement and behavior analysis without running new environment rollouts.

- Evaluates LLM-harness combinations by calculating action log-likelihoods on shared reference trajectories rather than executing live environment rollouts.
- Derives error bounds linking squared coordinate distances to trajectory KL divergence, which correlates with directly measured trajectory KL in rank order across eight models.

- Demonstrates that harness-component displacements in the behavior space approximately compose, though accuracy varies by component and environment.

**Why it matters:** This approach enables efficient performance prediction and behavioral clustering of LLM agents across different model families and harnesses without the computational overhead of live environment execution.

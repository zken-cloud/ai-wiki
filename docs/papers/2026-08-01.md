### [Sample More, Reflect Less: Self-Refine and Reflexion Lose to Repeated Sampling at Equal Token Cost, from 1.5B to 7B](https://arxiv.org/abs/2607.28576v1)

**arXiv cs.AI** · 2026-07-30 · `arXiv:2607.28576v1`

Repeated sampling consistently outperforms or matches self-refinement and reflection methods across various model sizes (1.5B-7B) and math benchmarks when token costs are equal.

- Seven methods were compared against repeated sampling using open models (1.5B, 3B, 7B parameters) on two mathematics benchmarks with 150 questions each.
- All 36 comparisons, paired by question, showed no method reliably better than repeated sampling at equal token cost, with ten methods reliably worse.
- Self-inspection methods were reliably worse in all 18 comparisons, with Self-Refine and forced Reflexion remaining 3.6 to 10.1 points below baseline at 7B.
- The benefit of model-based choosing in Best-of-N decreased with model size, from 8.0-11.3 points at 1.5B to 1.3-2.0 points at 7B, becoming indistinguishable from zero.

**Why it matters:** For practical applications, repeated sampling is a more token-efficient and effective strategy than complex self-refinement or reflection techniques for improving language model accuracy.

### [SVR: Self-Verifying Refinement via Joint Verdict-Confidence Reinforcement Learning for Adaptive Test-Time Compute](https://arxiv.org/abs/2607.28457v1)

**arXiv cs.AI** · 2026-07-30 · `arXiv:2607.28457v1`

SVR is an oracle-free multi-turn reinforcement learning framework that uses self-verification for adaptive test-time compute in language models, achieving high accuracy with fewer inference turns.

- SVR is an oracle-free multi-turn reinforcement learning framework that learns a compute-control policy using self-verification.
- At each turn, the model generates a solution, a discrete correctness verdict, and a confidence score, continuing refinement unless the verdict is 'Correct' and confidence exceeds a threshold.
- Training uses GRPO on fixed-horizon trajectories with rewards for correctness, calibration-aware self-verification, and stop-ready correct states; adaptive stopping is inference-only.
- On seven mathematical reasoning benchmarks with Qwen3.5-2B, SVR achieved 0.563 macro-average accuracy with 2.99 average inference turns.
- SVR outperformed standard GRPO, multi-turn baselines, and a fixed-budget oracle-guided score-feedback reference, requiring substantially fewer turns than fixed ten-turn inference.

**Why it matters:** This approach enables language models to efficiently allocate computational resources by adaptively stopping refinement based on internal self-verification, improving performance while reducing inference cost.

<small>Hongyu Chen, Liang Lin, Guangrun Wang</small>

### [When Derived Measurements Mislead: Quantifying and Mitigating LLM Over-Trust with Privileged-Modality Reliability Evidence](https://arxiv.org/abs/2607.28421v1)

**arXiv cs.AI** · 2026-07-30 · `arXiv:2607.28421v1`

This work defines derived-feature over-trust (DFOT) in LLMs, quantifies it using five estimands, and demonstrates mitigation with privileged-modality reliability evidence on 50,000 paired PPG-ECG records.

- DFOT is defined as an LLM's failure to recognize instance-dependent validity of derived measurements, treating them as direct facts or using them outside valid scope.
- Five estimands quantify DFOT: conflict over-trust rate (COTR), context-induced error rate (CIR), correct repair rate (CRR), evidence-specific repair margin (ESRM), and utility harm rate (UHR).
- The framework was demonstrated using 50,000 paired PPG-ECG records, with ECG-to-PPG privileged distillation as a baseline for PPG-only inference.
- On a 187-patient test, the baseline improved four repair and specificity endpoints by 1.82-6.69 percentage points, with all paired confidence intervals excluding zero.
- UHR increased by 0.67 percentage points (95% CI: -0.4 to +1.7) with the baseline mitigation.

**Why it matters:** Quantifying and mitigating DFOT is crucial for ensuring LLMs reliably process and interpret derived data, especially in sensitive applications like physiological sensing.

<small>Zongheng Guo, Tao Chen, Tianli Li, Mingzhe Cui, Yang Jiao, Lei Xie, Yi Pan, Xiao Hu</small>

WIDE introduces token-level dynamic width pruning for LLMs, enabling fine-grained computation allocation and achieving significant speedups in both prefill and decode scenarios.

- WIDE is an end-to-end differentiable token-level dynamic width pruning framework for prefill and decode, allowing each token to dynamically select attention-head and FFN-channel groups.
- It extends dynamic pruning to neuron-block-level granularity, moving beyond layer-level decisions for fine-grained computation allocation.
- A two-stage training pipeline learns effective token-wise sparse execution patterns, improving quality retention over existing approaches.

**Why it matters:** This method provides substantial practical throughput gains for LLM inference by adaptively pruning computation at a fine-grained level.

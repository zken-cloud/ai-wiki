### [Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations](https://arxiv.org/abs/2608.06305v1)

**arXiv cs.AI** · 2026-08-06 · `arXiv:2608.06305v1`

READ replaces dense top-k vector retrieval with deterministic lexical search, structural navigation, and span reads via the Model Context Protocol, drastically outperforming embedding-based RAG on complex tabular documents.

- Dense retrieval fails on complex documents due to chunk boundaries separating figures from headers (e.g., units like lakh vs. crore) and overlapping embedding spaces of near-identical figures.
- Table-aware chunking still leaves 27-30% of numeric chunks without essential context like fiscal-year headers across all tested chunk sizes.
- READ achieves 58.8% accuracy on 51 verified questions compared to dense retrieval's 15.7% (35.3% when tuned) and an agentic top-k tool's 27.5%.
- BM25 performed statistically indistinguishably from READ, indicating the performance gap is driven by embedding-free vs. embedding-based retrieval rather than agentic iteration alone.

**Why it matters:** Standard embedding-based RAG is structurally flawed for dense financial and regulatory documents, whereas deterministic, interpretable tool interfaces provide higher accuracy and replayable audit trails.

### [What Current AI Benchmarks Leave Unmeasured: Modality, Search, Citations, and Implications (for Safety Evaluations)](https://arxiv.org/abs/2608.06202v1)

**arXiv cs.AI** · 2026-08-06 · `arXiv:2608.06202v1`

A study auditing ChatGPT's UI and API reveals that safety benchmarks like BBQ and SafetyBench are significantly affected by access modality, web search, and run-to-run inconsistency, which simple accuracy metrics fail to capture.

- Testing 401 prompts from BBQ and SafetyBench across 4,812 runs showed Chat UI responses were less accurate than API responses when search was disabled.
- Enabling web search reduced model accuracy by up to 8 percentage points and reversed modality performance trends on one benchmark.
- Repeated runs of identical prompts yielded inconsistent responses in up to 21% of prompts, alongside variations in abstention behavior and citation grounding.
- The study evaluated output dimensions beyond standard accuracy, including response consistency, text similarity, citation grounding, and abstentions.

**Why it matters:** Evaluating LLMs solely via single-run API accuracy hides major behavioral instability, meaning standard benchmarks may misrepresent the real-world safety and reliability of deployed AI systems.

<small>Ro Encarnación, Tina Behzad, Emma Lurie, Danaé Metaxa</small>

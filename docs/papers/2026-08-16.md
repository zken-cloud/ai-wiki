### [From Inaudible Inputs to Model Failures: Low-Frequency Safety Risks in LALMs](https://arxiv.org/abs/2608.09158)

**Hugging Face Daily Papers** · 2026-08-09 · 👍 6 · `arXiv:2608.09158`

Researchers developed Intermittent Low-Frequency Lockout (ILL), an inaudible black-box attack using low-frequency signals to degrade Large Audio-Language Models (LALMs), and proposed Distributional Requery Guard (DRG) to mitigate it.

- ILL uses Sentence Attention Scale Estimation to identify active audio intervals and Frequency Confusion Transfer to build continuous-phase low-frequency waveforms.
- Across six LALMs, ILL degraded model accuracy by up to 67 percentage points while remaining effectively inaudible to humans (mean rating of 1.33 vs. 1.17 for clean audio).
- To counter low-frequency risks, DRG detects distribution shifts and conditionally prompts for a second recording, recovering mean attacked accuracy from 28.5% to 46.1%.

**Why it matters:** It identifies a critical safety vulnerability where inaudible, low-frequency audio signals can severely disrupt LALM performance without alerting human users.

### [CW-BASS v2: Saturation-Aware Pseudo-Label Selection for Semi-Supervised Segmentation under Foundation-Model Teachers](https://arxiv.org/abs/2608.12773)

**Hugging Face Daily Papers** · 2026-08-12 · 👍 4 · `arXiv:2608.12773`

CW-BASS v2 is a saturation-aware pseudo-label selection method for semi-supervised segmentation that dynamically switches between strict confidence filtering and an adaptive floor based on teacher reliability measured on a held-out slice.

- DINOv2 foundation-model teachers cause confidence saturation (e.g., 98% of Pascal VOC pixels reach confidence >= 0.95), causing adaptive thresholding methods to fail due to confirmation bias.
- CW-BASS v2 evaluates teacher reliability on a held-out slice via pi_kept = Pr(correct \| c >= tau) using an operating threshold tau not tuned to mIoU.
- If the teacher is reliable (pi_kept >= tau), the method applies strict filtering; otherwise, it defaults to a self-adaptive confidence floor that bounds retention away from 1.
- CW-BASS v2 matches UniMatch V2 on saturated datasets (87.4 mIoU on Pascal VOC 1/8) and outperforms it by +1.5 mIoU on ADE20K where the teacher's confident set is unreliable.

**Why it matters:** It prevents pseudo-label filtering failures when using modern self-supervised foundation models as teachers, automatically adapting the filtering strategy without manual tuning across diverse benchmarks.

Decoupled Contrastive Decoding (DCD) accelerates Contrastive Decoding by using an expert-aligned lightweight drafter for speculation and confining the amateur model strictly to the verification stage.

- Diagnostics reveal contrastive-aware drafting underperforms because contrastive corrections are typically smaller than drafter errors, which reconstruction can amplify.
- DCD uses standard speculative verification to guarantee that the output distribution matches vanilla Contrastive Decoding.
- Using an EAGLE3-based drafter, DCD yields 1.65x to 1.95x average greedy speedups over vanilla CD on 8B models.
- DCD cuts MMLU proposal-path latency by 5x to 12x compared to amateur-coupled proposal methods.

**Why it matters:** DCD resolves the computational bottleneck of Contrastive Decoding by delivering significant inference speedups without altering the original output distribution.

### [CausalGate: Causal Importance Distillation for Transformer Module Pruning](https://arxiv.org/abs/2607.22720v2)

**arXiv cs.LG** · 2026-07-21 · `arXiv:2607.22720v2`

CausalGate introduces an intervention-guided framework for transformer module pruning, using causal importance distillation via KL divergence to create static, lightweight scalar gates for compute-efficient inference.

- CausalGate isolates Attention and MLP sub-layers, zeros their outputs, and measures semantic damage via Kullback-Leibler divergence of the final logit distribution during calibration.
- The structural importance hierarchy is distilled into a global set of static, lightweight scalar gates using Exponential Moving Average smoothing and a differentiable pairwise ranking loss.
- The method eliminates runtime routing overhead by pre-calculating importance and distilling it into static gates.
- Evaluated on TinyLlama-1.1B, Qwen2.5-3B, and Llama-3.1-8B, CausalGate outperforms dynamic routing and layer-skipping baselines in language modeling and commonsense reasoning.

**Why it matters:** This approach translates theoretical compute savings into concrete hardware latency reductions with zero operational overhead for large language models.

**arXiv cs.LG** · 2026-07-21 · `arXiv:2607.19223v1`

AdaFlash introduces on-policy distillation and an adaptive length head to diffusion drafters for speculative decoding, improving speedup and throughput by addressing variance in acceptance rates.

**Why it matters:** This method significantly accelerates large language model inference, particularly in high-concurrency environments, by optimizing speculative decoding efficiency.

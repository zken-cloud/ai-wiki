### [AgentSWE: Can Coding Agents Build the Agent You Actually Want?](https://arxiv.org/abs/2610.13361)

**Hugging Face Daily Papers** · 2026-10-08 · 👍 198 · `arXiv:2610.13361`

AgentSWE is a new benchmark featuring 25 tasks designed to evaluate coding agents across three stages of building custom agents: Creation, Editing, and Optimization.

- Tests three stages of the agent development lifecycle: Creation from natural language requirements, Editing of production codebases, and Optimization toward a measurable target.
- Uses a two-phase evaluation framework where agents iterate on visible cases, but final acceptance is evaluated on frozen submissions against held-out cases with hard pass/fail gates or target objectives.
- Evaluated models across multiple harnesses failed to meet specified requirements, revealing a consistent gap between builder demonstration performance and final acceptance metrics.
- Identified key recurring failure modes in agent-built agents, including overfitting to visible cases, hollow runtimes beneath complete-looking code, and unsupported claims of completion.

**Why it matters:** The benchmark demonstrates that current coding agents reliably fail to build functional, requirement-compliant custom agents, highlighting a critical gap between apparent code completion and actual operational reliability.

<small>Jiahao Wang, Hongjin Qian, Yuyang Hu, Jiajun Zhang, Zheng Liu</small>

### [Thinking Inertia: LLMs Keep Thinking When Told Not To](https://arxiv.org/abs/2610.11765)

**Hugging Face Daily Papers** · 2026-10-07 · 👍 124 · ⭐ 3 · `arXiv:2610.11765`

Researchers identify 'Thinking Inertia' in LLMs, showing that explicit inference persists under strict no-thinking prompt controls, particularly as answer spaces become more open-ended.

- Evaluated six prompting interventions across six LLMs on Boolean, multiple-choice, and open-ended questions.
- Proposed a three-level evaluation taxonomy: Empty-Thinking Rate, Question-Pre-answer Relevance, and LLM-as-judge Explicit Inference Rate.
- Discovered that disabling thinking modes or removing long traces are unreliable proxies for measuring no-thinking behavior.
- Found accuracy remains stable on constrained tasks (Boolean/multiple-choice), but open-ended tasks present a direct trade-off between answer-only compliance and accuracy.

**Why it matters:** System instruction controls or model settings alone are insufficient to guarantee that LLMs suppress internal explicit reasoning, requiring specialized evaluation frameworks.

### [When Do We Need On-Policy Distillation? Distilling on Offline Student Rollouts Is Often Better](https://arxiv.org/abs/2610.11291)

**Hugging Face Daily Papers** · 2026-10-08 · 👍 17 · `arXiv:2610.11291`

Semi-OPD distills teachers into students using initial student rollouts, outperforming on-policy distillation in accuracy and efficiency unless teacher and student outputs are highly aligned.

- Semi-OPD uses offline rollouts from the initial student model instead of dynamically sampling on-policy during training.
- Across 17 model pairs (1.5B to 235B parameters), Semi-OPD outperformed OPD in 14 cases, yielding up to a +13.6% accuracy gain and an 11.4x training speedup.
- The necessity of OPD depends on teacher-student alignment measured by output-token overlap ratio; OPD is only beneficial when overlap is high.
- For misaligned models, long context rollouts under OPD become increasingly off-policy relative to the teacher, whereas Semi-OPD maintains stability by distilling shorter contexts with full trajectory coverage.

**Why it matters:** Practitioners can significantly reduce training time and improve model accuracy by substituting complex on-policy distillation with offline initial student rollouts for misaligned model pairs.

### [One Model to Loop Them All: Elastic Latent Recurrence for Language Models](https://arxiv.org/abs/2610.12582)

**Hugging Face Daily Papers** · 2026-10-07 · 👍 6 · `arXiv:2610.12582`

Elastic Latent Recurrence (ELR) trains latent recurrent language models that match non-recurrent baseline accuracy at a single loop while gaining substantial accuracy improvements with additional loops at inference.

- ELR uses a gated state update with a learned step size, loop counts mixed within each optimizer update, and loop index/budget conditioning.
- Late-stage introduction of mixed depths using zero-initialized conditioning outperforms training with mixed depths from scratch while reducing training costs.
- For MoE models, reusing first-loop expert routes on subsequent loops cuts mixed-depth update time by 11.7% without degrading accuracy.
- Inference memory efficiency is achieved by retaining only the last loop's attention KV cache, keeping KV memory at one-loop levels while preserving accuracy gains.
- The Koi-4B model achieves an estimated score of 18 on the Artificial Analysis Intelligence Index at one loop (matching Qwen3.5-4B) and scales to 29 at four loops.

**Why it matters:** ELR enables serving a single model checkpoint that dynamically trades off latency and compute for higher accuracy without paying a performance penalty at minimal loop counts.

<small>Faisal Ladhak, Shantanu Acharya, Santiago Akle Serano, Simeng Sun, Boris Ginsburg, Krishna C Puvvada</small>

### [A Critical Look at Power Sampling when Test Time Sharpening LLMs](https://arxiv.org/abs/2610.13653v1)

**arXiv cs.LG** · 2026-10-09 · `arXiv:2610.13653v1`

Researchers evaluated test-time power sampling for LLM sharpening, discovering that samplers fail to converge and that direct fine-tuning to target power distributions yields inconsistent gains.

- MCMC and SMC samplers targeting the power distribution \(\pi_\alpha \propto \pi_{\text{base}}^\alpha\) fail to converge under realistic compute budgets.
- Simple Best-of-N sampling with proper grading recreates most of the performance gains of complex power samplers.
- Directly fine-tuning base models to match \(\pi_\alpha\) sidesteps sampler convergence issues but produces noisy, model-dependent, and task-dependent results.
- The benefits attributed to power sampling stem from extracting high-probability sequences the base model already produces rather than faithfully approximating \(\pi_\alpha\).

**Why it matters:** It demonstrates that complex MCMC/SMC samplers targeting power distributions can be replaced by simpler Best-of-N selection methods without sacrificing reasoning performance.

<small>Abiel Malkani Talwar, Christopher Nemeth, Henry Moss</small>

### [Your Discrete Graph Diffusion Model is Secretly Memorizing](https://arxiv.org/abs/2610.13786v1)

**arXiv cs.AI** · 2026-10-09 · `arXiv:2610.13786v1`

Researchers demonstrate that unconditional discrete graph diffusion models exhibit conditional memorization, recovering corrupted training graphs far better than test graphs, which cannot be fixed by early stopping without destroying generated graph structure.

- Evaluated reverse diffusion trajectories of discrete graph diffusion models (GDMs) trained on two-block stochastic block models (SBMs) without node features.
- Identified 'conditional memorization', where the denoiser near-perfectly reconstructs a corrupted training graph versus a held-out test graph, despite standard sample-level metrics (edge overlap, WL kernel similarity) failing to detect memorization.
- Observed a growing generalization gap over training where training loss improves as held-out graph loss degrades.
- Found that memorization onset always precedes the emergence of community structure in generated graphs, meaning early stopping only yields structureless graphs regardless of node size.

**Why it matters:** Standard unconditional generation metrics mask severe overfitting in discrete GDMs, revealing a fundamental tradeoff where models cannot generate structured graphs without memorizing the training data.

<small>Adarsh Jamadandi, Nicolas Keriven</small>

### [ReplaySSM: Cache SSM Inputs, Not State](https://arxiv.org/abs/2610.13778v1)

**arXiv cs.AI** · 2026-10-09 · `arXiv:2610.13778v1`

ReplaySSM unrolls state-space model recurrences to store a periodic checkpoint and an input buffer, avoiding eager state reads/writes at every decoding step.

- Replaces eager per-step SSM state updates with periodic checkpointing and a recent input buffer, halving dominant state memory traffic.
- Enables speculative decoding rollback via simple buffer-pointer operations and allows output-only verification without state materialization.
- Decouples precision by using a low-precision state checkpoint for output computation while preserving a high-precision copy for recurrent updates to prevent error accumulation.
- Achieves 1.20-1.47x speedups in standard decoding at batch size 256 and ~1.8x throughput in speculative decoding on 120B-class models (Mamba-2 and Gated DeltaNet in vLLM).

**Why it matters:** It alleviates memory bandwidth bottlenecks and quantization errors in hybrid SSM decoding while significantly accelerating speculative decoding pipelines.

<small>Ze-Wei Liou, Harris Nover, Amey Naik, Andrii Skliar, Igor Shovkun, Ido Shahaf, Tri Dao</small>

### [DualQuant: Dual-scale Calibration-free Weight-and-Activation Quantization for LLMs](https://arxiv.org/abs/2610.13767v1)

**arXiv cs.AI** · 2026-10-09 · `arXiv:2610.13767v1`

DUALQUANT is a calibration-free post-training weight-and-activation quantization framework that minimizes weight-reconstruction MSE to derive per-channel activation rescalings, achieving hardware-validated speedups.

- Formulates quantization as a non-differentiable weight-reconstruction problem solved via variable splitting and block coordinate descent with closed-form updates.
- Eliminates the need for calibration data by using weight-reconstruction MSE scaling factors to directly rescale activations.
- Provides unified support for Microscaling (MX) and NVFP4 block formats as the first dual-scaling method designed for these structures.
- Achieves up to 2.61x memory footprint reduction and 2.46x throughput speedup over BF16 using a packed W4A4 CUDA kernel for Llama-3.1-8B on an NVIDIA RTX 4090.

**Why it matters:** It enables high-throughput, low-bit LLM inference on modern 4-bit hardware accelerators without requiring pre-run calibration datasets or time-consuming calibration passes.

<small>Mahsa Salmani, Sayeh Sharify, Hesham Mostafa</small>

### [Unbundling Multimodal Vision Encoding](https://arxiv.org/abs/2611.17334)

**Hugging Face Daily Papers** · 2026-11-11 · 👍 14 · `arXiv:2611.17334`

A controlled study disentangles multimodal vision encoding choices, showing that pretrained visual priors are unnecessary if models use dedicated, early in-fusion vision capacity trained jointly from scratch.

- Isolated three vision encoding design choices: visual prior from upstream pretraining, dedicated vision capacity, and pre-fusion vs. in-fusion placement.
- Upstream visual priors are unnecessary; encoders trained jointly from scratch match pretrained encoders without requiring a separate pretraining stage.
- Dedicated vision capacity is essential; encoder-free models underperform on visual understanding tasks even when their backbone parameter count is scaled up.
- Placing vision-only modules in-fusion within early backbone layers matches pre-fusion encoder performance while reducing time to first token.

**Why it matters:** Architects can simplify multimodal model training by skipping separate vision encoder pretraining and embedding dedicated vision capacity directly into early backbone layers to improve latency.

### [Consensus Capture in Reference-Based UAV Video Stabilization: A Benchmark on Dynamic Urban Scenes](https://arxiv.org/abs/2611.17190)

**Hugging Face Daily Papers** · 2026-11-11 · 👍 3 · `arXiv:2611.17190`

A new two-part benchmark evaluates reference-based UAV video stabilization pipelines, revealing that dynamic object groups induce undetected "consensus capture" failures in homography estimation unless object masking is applied.

- Consensus capture occurs when mutually consistent correspondences from co-moving vehicles bias robust homography estimation despite normal inlier ratios and counts.
- Unmasked ORB experiences consensus capture in 28 of 304 real-time dynamic pairs, producing a median corner error of 18.8 px that standard inlier statistics fail to flag.
- In static 4K benchmark protocols, tuned AKAZE, RootSIFT, SIFT, and BRISK achieve top performance, where matcher threshold retuning yields at most a 0.0062 mAA improvement.
- Object masking eliminates consensus capture across all evaluated pipelines while incurring an mAA performance penalty of less than 0.005 on static scenes.

**Why it matters:** It demonstrates that standard feature-matching metrics fail to detect motion-induced homography bias in urban drone footage, proving that object masking is necessary for reliable real-time video stabilization.

### [Probing Transformer Representations Layer by Layer, Module by Module](https://arxiv.org/abs/2611.11531)

**Hugging Face Daily Papers** · 2026-11-07 · 👍 3 · ⭐ 1 · `arXiv:2611.11531`

A study of over 144,000 linear probing evaluations shows transformer representations vary heavily by internal module, making joint layer-module selection far superior to evaluating the final-layer residual stream alone.

- Evaluated vision foundation models (VFMs) and large language models (LLMs) across layers and individual modules, disproving the assumption that transformer blocks are atomic units.
- Selecting the optimal layer-module pair yields significantly higher performance gains than searching for the best layer using only the fixed residual stream.
- Module performance fluctuates across depth, proving representation utility cannot be predicted by layer depth alone.
- Fixed heuristics recover substantial optimal gains: using final-layer feedforward activation (Act@100) recovers 42% of gains for VFMs, while the second normalization layer at 60% depth (LN2@60) recovers 86% for LLMs.
- Probing performance gains for VFMs scale positively with the transfer difficulty between the pretraining data and downstream task.

**Why it matters:** Practitioners can extract significantly better features for downstream tasks without full fine-tuning by extracting activations from specific internal modules like Act@100 or LN2@60 instead of the final residual stream.

<small>Ambroise Odonnat, Theo Gnassounou, Laetitia Chapel, Romain Tavenard, Ievgen Redko</small>

### [Symmetry in Time: A Representation Theory of Linear Recurrent Memory](https://arxiv.org/abs/2611.17162v1)

**arXiv cs.LG** · 2026-11-12 · `arXiv:2611.17162v1`

HyperSSM incorporates quaternion channels into state space models to enable linear-time, parallel tracking of non-commutative groups, overcoming the permutation-invariant state-tracking limitations of diagonal real and complex SSMs.

- Formalizes SSM state updates using representation theory, showing an SSM tracks a group at all lengths if and only if the group is a quotient of the group generated by its transition matrices.
- Proves that diagonal real and complex SSMs are restricted to tracking commutative groups, whereas tracking general groups requires transition matrices to split into independent real, complex, and quaternion blocks.
- Introduces HyperSSM, which retains linear-time inference and parallel training while incorporating quaternion channels using five or fewer state numbers.
- Achieves exact performance on $S_5$ with 32 generators where previous SSMs perform at chance, demonstrating zero-shot generalization to sequences 25 times longer than training lengths.
- Enables direct interpretation of learned linear recurrence weights, demonstrating application to gyroscope calibration, imperfect qubit gate rotations, and protein backbone geometry.

**Why it matters:** It establishes a theoretical foundation for non-commutative memory in sequence models, allowing SSMs to execute complex state-tracking and geometric tasks without sacrificing parallel training capabilities.

### [JudgeMix: Judge-Guided Mixed-Rollout Data Synthesis for LLM Agents](https://arxiv.org/abs/2611.16174v1)

**arXiv cs.CL** · 2026-11-12 · `arXiv:2611.16174v1`

JudgeMix is a judge-guided data synthesis framework for LLM agents that dynamically interleaves target model and expert rollouts based on step-wise semantic evaluations to reduce distribution mismatch.

- Evaluates step-wise target model behavior to dynamically query expert intervention only when the target model struggles, keeping state distributions aligned.
- Uses judge evaluations to reweight expert supervision across steps, preserving the target model's correct native actions while correcting errors.
- Replaces random intervention heuristics and uniform step-wise supervision used in existing mixed-rollout synthesis methods.
- Achieves performance improvements of up to 10 pass@1 points over existing approaches on the AppWorld and AutomationBench tool-use benchmarks.

**Why it matters:** It improves LLM agent supervised fine-tuning by selectively correcting errors while preserving the model's correct native trajectories, mitigating training-inference distribution mismatch.

### [CoReMem: Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation](https://arxiv.org/abs/2611.17316v1)

**arXiv cs.AI** · 2026-11-12 · `arXiv:2611.17316v1`

CoReMem is a cost-internalizing memory framework that uses prospective segment valuation and provenance-gated credit assignment to select compact repository anchors and train coding agents to optimize future task resolution while reducing step count.

- Prospective segment valuation builds compact memory around code anchors (repository locations and executable checks) by comparing execution runs of subsequent tasks with and without individual trajectory segments.
- Actor adaptation uses on-policy memory value estimation within rollout groups, employing a reward function that prioritizes task resolution while penalizing step counts on successful runs.
- Provenance-gated value credit assigns the extra memory value term exclusively to steps that actively use memory-supplied anchors, while all steps retain standard outcome credit.
- Evaluated on ChainSWE using a 27B model, CoReMem increased the resolve rate from 21.0% to 25.7%, while reducing steps by 17% and total cache-aware tokens by 11% compared to the memoryless untrained baseline.

**Why it matters:** It enables coding agents to autonomously generate and use compact repository memories for unknown future tasks, improving task resolution while simultaneously lowering token and step costs.

<small>Peiwen Li, Harshit Verma, Sophia Zhou, Haiwen Wang, Ngoc Bui, Heng Chang, Fei Fei, David van Dijk</small>

### [Consistent Video-to-Video Translation via Explicit Correspondences](https://arxiv.org/abs/2611.17298v1)

**arXiv cs.AI** · 2026-11-12 · `arXiv:2611.17298v1`

vid2vid-long achieves long-range temporal consistency in real-time video-to-video translation by computing input patch correspondences to retrieve and condition the model on past generated output regions.

- Addresses temporal consistency loss caused by fixed-length causal attention windows in real-time video translation.
- Computes patch-level correspondences directly from the input video frames.
- Uses input correspondences to retrieve matching regions from previously generated output frames.
- Integrates retrieved historical output patches into the model via a specialized correspondence cross-attention mechanism.

**Why it matters:** It enables real-time, interactive video translation models to maintain coherent long-term visual consistency without exceeding strict latency constraints.

### [VoxMem: Benchmarking Multimodal Memory in Large Audio Language Models](https://arxiv.org/abs/2609.32607)

**Hugging Face Daily Papers** · 2026-09-25 · 👍 97 · `arXiv:2609.32607`

VoxMem is a new benchmark featuring 3,196 instances across 177 hours of spoken sessions designed to evaluate multimodal memory in Large Audio Language Models across diverse acoustic evidence types and memory operations.

- Taxonomy and dataset evaluate four acoustic evidence types: speech semantics, speaker identity, paralinguistic cues, and environmental sound.
- Covers four memory operations: information extraction, multi-session reasoning, temporal tracking, and answer refusal.
- Dataset consists of 3,196 instances across 34,743 spoken sessions (177 total hours) with context lengths stratified from 8K to 64K tokens.
- Evaluation of 15 LALMs showed no model exceeded 40% accuracy at a 32K context window, with models performing far worse on non-lexical audio cues than on speech semantics.

**Why it matters:** Current LALMs struggle to maintain non-transcript audio context like speaker identity and acoustic environment over multi-session long-context histories, highlighting key gaps for conversational AI development.

### [$S^3$: Spectral Null-Space Swap Makes Reasoning Models Efficient](https://arxiv.org/abs/2609.37976v1)

**arXiv cs.AI** · 2026-09-29 · `arXiv:2609.37976v1`

Spectral Null-Space Swap ($S^3$) is a training-free model composition method that isolates the thinking model's weight components in the non-thinking model's null space, reducing inference token overhead while maintaining or improving reasoning accuracy.

- Identifies that critical reasoning capacity resides within the Thinking model's weight component located in the null space of the Non-thinking model's dominant singular directions.
- Proposes $S^3$, a training-free composition technique that preserves the Non-thinking model inside its dominant subspace and incorporates the Thinking model's null-space component.
- Demonstrated on 2B-30B dense and MoE models across 28 evaluation environments spanning mathematical, multimodal, and audio reasoning domains.
- Reduces average inference token overhead by 27.4% while improving overall task accuracy by 1.0 percentage point (including +8.3% accuracy and a 33.0% token speedup on HMMT25).
- Attributes efficiency gains to lower attention entropy produced by the retained null-space component, supported by attention entropy analysis and a simplified optimization model.

**Why it matters:** It enables developers to significantly lower LLM chain-of-thought inference token costs and speed up generation without retraining models or sacrificing reasoning accuracy.

<small>Hongbo Ma, Sansheng Cao, Jiajun Fan, Bangji Yang, Ge Liu</small>

- Standard OPSD performance gains degrade as models scale (falling from 3.05 points at 1.7B to 0.14 points at 8B) due to unverified scaffolds creating an imitation gap.
- OASIS replaces written solution contexts with unverified model attempts while supervising verified-by-label on-policy trajectories.
- Across Qwen3-1.7B, 4B, and 8B models on AIME 2024, AIME 2025, and HMMT 2025 benchmarks, OASIS consistently improves over the base model by 3.2–3.8 average points.
- At the 8B parameter scale, OASIS outperforms standard OPSD by 3.05 points.

**Why it matters:** OASIS preserves the performance gains of self-distillation at larger model scales while eliminating the need for step-by-step written solutions, relying instead solely on final-answer labels.

### [Pretraining Latent Information Feedback Transformers with Teacher Supervision](https://arxiv.org/abs/2609.38149v1)

**arXiv cs.CL** · 2026-09-29 · `arXiv:2609.38149v1`

The Latent Information Feedback Transformer (LIFT) introduces deep-to-shallow recurrent state feedback during pretraining by framing state learning as a parallelizable, teacher-forced prediction task using an off-the-shelf language model's next-token distribution.

- LIFT pairs each input token with an information-dense state derived from a pretrained teacher LM's next-token distribution, adding minimal parameters.
- Pretraining remains fully parallel across sequence positions because input feedback states are precomputed by the teacher.
- At inference, the model feeds back its own predicted states, incurring a small computational overhead that scales down with larger model sizes.
- Evaluated across 135M to 1B parameter models, LIFT beats standard Transformers on token-matched budgets and matches or outperforms them on compute-matched budgets.
- On a state-tracking task, a small LIFT model outperformed same-size Transformers trained on 8x more data, even when using teacher states from a model that failed the task.

**Why it matters:** LIFT bypasses the single-token autoregressive bottleneck by allowing language models to pass rich latent states across generation steps without sacrificing parallelized pretraining.

### [Retrieval Capacity of Self-Attention Under Competition](https://arxiv.org/abs/2609.37879v1)

**arXiv cs.CL** · 2026-09-29 · `arXiv:2609.37879v1`

Researchers measure transformer retrieval capacity by retaining only top-weighted tokens per head, layer, and query without retraining, revealing how attention set size scales with context length, competition, and weight renormalization.

- Evaluates effective attention set size by selecting top-weight tokens, leaving weights unchanged, and measuring negative log-likelihood (NLL) degradation against full-attention baselines.
- Expanding context length while keeping target predictions constant increases the absolute number of required tokens but decreases their overall fraction of the context.
- Adding background context introduces competition that depresses the attention rank and total attention mass assigned to fixed supporting facts.
- Renormalizing the retained attention weights significantly reduces the required set size to maintain target NLL performance.

**Why it matters:** Understanding how competition and aggregation dictate effective attention set sizes informs more efficient context pruning, sparsification, and KV-cache compression techniques.

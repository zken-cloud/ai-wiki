### [LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks](https://arxiv.org/abs/2608.01964)

**Hugging Face Daily Papers** · 2026-08-02 · 👍 84 · ⭐ 51 · `arXiv:2608.01964`

LongHorizon-Harness reformulates long-horizon agent execution into a task-state management problem using an external state and a Manage-Execute-Audit loop to prevent error propagation in LLM context windows.

- Features a Manage-Execute-Audit (MEA) loop: a manager tracks state/subtasks, a fresh-context executor executes them, and a read-only auditor verifies environmental changes.
- Maintains task state externally, updating it exclusively with facts independently verified from the environment rather than relying on self-assessment within a growing context.
- Includes an AgentAdapter module that enables interchangeability of model and harness backends without altering native agent loops.
- Boosts Qwen 3.7-Plus scores on WeaveBench (51.8% to 80.7%), Terminal-Bench 2.1 (69.7% to 77.2%), and OSWorld 2.0 (2.8% to 8.3%), while improving Claude Opus 4.7 on an OSWorld 2.0 subset (20.0% to 34.3%).

**Why it matters:** Explicit, externally audited state management substantially increases the reliability and accuracy of LLM agents performing complex multi-step real-world tasks across diverse environments.

### [VAD: Attributing Visual Evidence for Target Reconstruction in Multimodal On-Policy Distillation](https://arxiv.org/abs/2607.28590)

**Hugging Face Daily Papers** · 2026-07-29 · 👍 26 · ⭐ 16 · `arXiv:2607.28590`

Visual Attribution Distillation (VAD) uses counterfactual target reconstruction to isolate visually attributable teacher signals from linguistic priors and teacher-specific effects during multimodal on-policy distillation.

- VAD evaluates a fixed teacher with relevant visual evidence present versus removed at each student-generated prefix, using centered log-probability changes to define a visual evidence proxy direction (ut).
- The method projects original teacher corrections onto ut to create an intervention-aligned component and a proxy-unexplained residual.
- A student-anchored target reconstructed from the intervention-aligned component serves as primary training supervision, supplemented by a weak regularizer from the privileged teacher.
- Tested at 4B and 9B scales across six fine-grained visual benchmarks, VAD outperforms direct privileged-view distillation and visual-advantage weighting.
- Token-level analysis confirms the proxy-aligned component provides stronger target shifts when visual evidence directly refutes mistaken student outputs.

**Why it matters:** It provides a framework to prevent student models from learning non-visual noise or linguistic biases during multimodal distillation by explicitly isolating true visual evidence.

<small>Kangning Zhang, Yixing Li, Shuai Shao, Qingyao Li, Zhengxi Lu, Zhiyuan Yao, Jianghao Lin, Wenxiang Jiao</small>

- Identifies information asymmetry between the privileged teacher and inference-time student as the root cause of 'privilege illusion' in on-policy distillation.
- Dual-Path Anchoring (DPA) uses a self-conditioned bridge to align reference and rollout behavior along matched-information paths.
- Dual-Source Anchoring (DSA) applies paths bi-directionally (reference-to-rollout and rollout-to-reference) to lower reliance on privileged guidance while maintaining correctness supervision.
- Achieves average performance gains over OPSD across scales on Qwen3 models, including +2.00 overall, +2.69 at 4B, and +2.78 at 32B.

**Why it matters:** DAPD prevents language models from learning degraded inference behaviors caused by training-time privileged information, consistently improving model accuracy across model scales.

### [Toward Plasticity-Preserving KL Regularization for Capability Retention in LLM Reinforcement Learning](https://arxiv.org/abs/2608.01743v1)

**arXiv cs.CL** · 2026-08-03 · `arXiv:2608.01743v1`

Correctness-Conditioned KL Regularization (CoKL) constrains the response distribution conditionally on output correctness rather than full policy distributions, preserving prior LLM capabilities without restricting target-task learning.

- Standard full-policy forward and reverse KL regularization enforce a strict optimal correctness gap when using an imperfect reference policy.
- CoKL isolates the relative probability allocation among reference-supported correct outputs, decoupling total correct probability from the correctness-conditioned distribution.
- The framework uses a forward KL divergence formulation adapted into a practical finite-group training objective for RL post-training.
- Evaluations across controlled multi-solution environments and continual post-training demonstrate superior retention of prior capabilities compared to standard KL methods.

**Why it matters:** CoKL allows RL post-training to adapt language models to new tasks without degrading previously acquired capabilities or artificially capping accuracy via reference-policy constraints.

### [Understanding Sparse Attention Selectivity in Long-Context Foundation Models via Counterfactual Evaluation](https://arxiv.org/abs/2608.01676v1)

**arXiv cs.CL** · 2026-08-03 · `arXiv:2608.01676v1`

A dense-calibrated counterfactual auditing framework reveals that sparse attention mechanisms causally alter content influence and output decisions in long-context foundation models, effects that aggregate accuracy metrics fail to detect.

- Route replay using Block Sparse Flash Attention (BSFA) across four architectures altered output decisions in 13 of 16 test cells, compared to zero flips under identity replay.
- Counterfactual audits using Gold, Poison, and Benign probe cards revealed that selectors prioritize Gold and Poison blocks over Benign filler (G≈P≫B), but discarding surrounding blocks causes integration loss, severing cross-block attention.
- Isolating a probe block during ablation collapsed its logit influence from 4.48 to zero.
- Higher compression ratios (c=0.25 to c=0.75) drove stronger sparse amplification in three of four test cells, causing sign reversals in content influence in two cells.
- Findings converged across three distinct evaluation arms: BSFA route replay, controlled block-top-k, and KV-cache eviction.

**Why it matters:** Aggregate accuracy masks how attention sparsification systematically changes model decisions and biases content influence, making auditing critical before deploying sparse attention stacks.

<small>Xingyu Ren, Youran Sun, Chugang Yi, Haizhao Yang</small>

### [UEmbed: Unified Sparse and Dense Multimodal Embeddings](https://arxiv.org/abs/2608.02583v1)

**arXiv cs.AI** · 2026-08-03 · `arXiv:2608.02583v1`

UEmbed is a decoder-only multimodal model that generates unified sparse lexical and dense embeddings in a single causal forward pass by partitioning the vocabulary across learnable tokens.

- Uses a decoder-only architecture that appends N learnable special tokens to input sequences to generate dense and sparse representations concurrently.
- Partitions the full vocabulary into N disjoint subsets; each special token's causal hidden state predicts sparse weights over its designated subset before final concatenation.
- Released in 2B, 4B, and 9B parameter scale variants trained entirely on public datasets.
- UEmbed-9B achieves scores of 71.8 (dense) and 71.0 (sparse) on MMEB-v2, outperforming public baseline models such as RzenEmbed, while remaining competitive on BEIR.

**Why it matters:** It eliminates the need for separate cross-modal modules or distinct models by generating both dense and sparse multimodal representations in a single pass.

<small>Tingyu Song, Mingxin Li, Yanzhao Zhang, Dingkun Long, Pengjun Xie, Zhijie Nie, Yilun Zhao, Shu Wu</small>

### [Structured Memory for Edge Language Models: Persistent Context and Corpus Retrieval via O(1) SSM State Injection](https://arxiv.org/abs/2608.02560v1)

**arXiv cs.AI** · 2026-08-03 · `arXiv:2608.02560v1`

PRECOG enables O(1) context retrieval and injection for edge language models by directly injecting pre-computed, fixed-size SSM hidden states, eliminating the token prefill phase.

- PRECOG pre-encodes document corpora offline into SSM hidden states and injects the selected state at query time, replacing in-context token re-ingestion.
- Reduces prefill latency on a 1.2B-parameter gated-SSM (TENNs-LLM) from ~27 s to <6 ms on edge hardware, representing a ~4500x speedup while matching RAG answer quality.
- SMC (Structured Memory Consolidation) uses the state-injection mechanism to create hierarchical persistent memory, consolidating short-term episodic states into long-term semantic memory.
- The 192 KB recurrent hidden state is position-agnostic, enabling instantaneous O(1) session initialization and retrieval state fusion impossible with Transformer KV-caches.

**Why it matters:** It moves edge-device language model retrieval from seconds-long latency to interactive, millisecond-level speeds by exploiting SSM recurrent state mechanics.

<small>Anusha Madan Gopal, Aras Pirbadian, Kristofor D. Carlson, M Anthony Lewis, Jonathan Tapson</small>

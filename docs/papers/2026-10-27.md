**arXiv cs.LG** · 2026-10-26 · `arXiv:2610.35787v1`

Researchers developed Selective Tie Learning, a method using implicit reward margins and curvature approximations to select optimal tie data for reducing spurious correlations in preference optimization.

- Log-linear policy derivations show that selecting ties with the largest predicted reductions in spurious reliance is first-order optimal for equal-sized data subsets.
- The magnitude of a tie's implicit reward margin serves as a proxy for predicted influence when true curvature and feature representations are unavailable or expensive.
- Empirical evaluation utilizes a counterfactual proxy for spurious reliance and a generalized Gauss-Newton approximation to model curvature in neural models.
- The selective approach achieves reductions in spurious reliance comparable to uniform tie selection while requiring fewer tie-augmented samples across log-linear and large language models.

### [GPDPO: Learning from Reward Conflicts via Group Pareto-Dominance Policy Optimization](https://arxiv.org/abs/2610.35480v1)

**arXiv cs.LG** · 2026-10-26 · `arXiv:2610.35480v1`

Group Pareto-Dominance Policy Optimization (GPDPO) resolves multi-reward conflicts in LLM alignment by extracting auxiliary pairwise preference signals from Pareto-dominance relations in conflict-filtered rollouts.

- Identifies Pareto-dominance relations among sampled candidate responses to construct auxiliary pairwise preference signals from discarded or conflict-filtered rollouts.
- Jointly optimizes the auxiliary relational preference signals alongside the primary multi-reward policy objective.
- Reuses existing rollouts to improve training efficiency without requiring additional sample generation or extra reward model evaluations.

### [Amplify, Locate, Estimate (ALE) on Rare-Failure Rates of Fine-Tuned LLMs](https://arxiv.org/abs/2610.35472v1)

**arXiv cs.LG** · 2026-10-26 · `arXiv:2610.35472v1`

Amplify, Locate, Estimate (ALE) is a method that efficiently estimates rare safety-fine-tuning failure probabilities by amplifying failure rates via token log-probability changes and extrapolating back using a score-function estimator.

- ALE calculates an amplification direction using changes in token log-probabilities induced by safety fine-tuning to cheaply sample failure cases.
- Combines a score-function estimator—recovering the local slope of the log failure rate—with an importance-sampling estimate derived from the amplified batch.
- Achieved estimates within a factor of three of reference values for 37 out of 41 evaluation targets, with a median estimate-to-reference ratio close to one.
- Evaluated on Qwen3-8B fine-tunes, accurately estimating failure probabilities down to ~10^-5 using ~1,000 labeled rollouts plus an unlabeled scan, replacing hundreds of thousands of direct-sampling rollouts.

**Why it matters:** ALE enables accurate measurement of extremely rare LLM safety failures without incurring the prohibitive computational cost of direct sampling.

### [LoopFold: Parallelizing Recurrent Depth in Looped Transformers](https://arxiv.org/abs/2610.35556v1)

**arXiv cs.CL** · 2026-10-26 · `arXiv:2610.35556v1`

LoopFold accelerates looped Transformers by using a lightweight predictor and corrector to compute multiple recurrent depths in parallel for the same token prefix, reducing decoding latency.

- Uses a lightweight predictor to estimate inputs for deeper recurrent loops before earlier loops finish, followed by a corrector to refine the parallel outputs using updated results.
- Trains the shared backbone, predictor, and corrector components jointly using exclusively the final next-token prediction loss.
- Achieves a 46% reduction in decoding latency compared to a nine-loop vanilla model by executing the computation in five sequential stages.
- Scales zero-shot accuracy across eight tasks from 53.41% to 56.38% as depth increases in 1.4B parameter model experiments, outperforming vanilla looped models and Parallel Loop Transformers (PLT).

**Why it matters:** It enables deeper, more accurate looped Transformer architectures to overcome sequential recurrent depth bottlenecks and achieve lower inference latency.

### [StateLoop: Persistent State for Looped Transformers](https://arxiv.org/abs/2610.35544v1)

**arXiv cs.CL** · 2026-10-26 · `arXiv:2610.35544v1`

StateLoop introduces a persistent, token-wise state with learned gating to improve parameter-efficient looped Transformers by carrying information across deep iterations.

- Vanilla looped Transformers reuse a single hidden state as the direct input to subsequent iterations, risking information loss across deep recurrent steps.
- StateLoop adds one persistent state per token and uses a learned gate to balance retaining previous state information versus incorporating new backbone outputs.
- The updated persistent state is projected back and added to the backbone output to guide subsequent loop iterations and the final prediction.
- Empirical results show reduced perplexity on The Pile and higher average zero-shot accuracy across eight benchmark tasks compared to vanilla looped models.
- The perplexity advantage over vanilla looped Transformers scales positively with increasing trained loop depth.

**Why it matters:** StateLoop enhances the performance and capability of parameter-efficient looped Transformers without requiring deeper parameter footprints as recurrent depth grows.

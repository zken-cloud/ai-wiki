### [Learn Your Own Thoughts: Abstract Token Curriculum](https://arxiv.org/abs/2609.19717v1)

**arXiv cs.CL** · 2026-09-17 · `arXiv:2609.19717v1`

Abstract Token Curriculum (ATC) is a novel curriculum learning framework that trains LLMs to generate continuous, unsupervised intermediate CoT representations by gradually increasing problem complexity.

- Eliminates the need for explicit token supervision or manual scratchpad design in CoT reasoning.
- Trains models across a sequence of increasingly complex distributions to form internal abstract representations in continuous space.
- Theoretical proofs demonstrate that for single-layer softmax attention learning parity functions, ATC focuses attention on CoT context tokens offering the easiest next-token prediction path.
- Empirically validated on graph reachability and arithmetic learning tasks.

**Why it matters:** ATC enables language models to develop internal reasoning capabilities without relying on expensive, task-specific CoT datasets or hand-engineered intermediate steps.

### [Chronicle: Cut-Point Replay for Regression Testing of LLM Agents](https://arxiv.org/abs/2609.20625v1)

**arXiv cs.AI** · 2026-09-17 · `arXiv:2609.20625v1`

Chronicle introduces cut-point replay for LLM agents, recording non-deterministic boundaries into immutable envelopes to execute mixed live-and-recorded regression tests in continuous integration.

- Records agent runs at non-deterministic boundaries with an overhead of 23 μs per crossing (0.008% of a 300 ms model call).
- Cut-point replay serves a subset of boundaries from the immutable record while executing new code live for the complementary subset.
- Full replay makes no model calls and achieves bit-stability across 20 repetitions.
- In a mutation study, cut-point tests caught 100% of mutants that permitted recorded unsafe actions, whereas stubbing all boundaries caught 0%.
- Evaluated on a benchmark of 6 recorded failures; code and benchmark are open-sourced on GitHub.

**Why it matters:** It enables deterministic, low-overhead regression testing of LLM agent failures within CI/CD pipelines without making live model calls for unchanged boundaries.

<small>Tisha Chawla, Susheem Koul</small>

**arXiv cs.AI** · 2026-09-17 · `arXiv:2609.20474v1`

### [Stress-testing Alignment Midtraining](https://arxiv.org/abs/2609.20412v1)

**arXiv cs.AI** · 2026-09-17 · `arXiv:2609.20412v1`

An empirical stress-test of Alignment Midtraining (AMT) using models up to 110B parameters shows it fails to robustly enforce generalizable alignment motivations or unmonitored rules.

- Evaluated Alignment Midtraining (AMT) at scale using models up to 110B parameters and up to 1 billion midtraining tokens.
- AMT can steer model motivation in simple ambiguous post-training settings, but a tiny fraction of post-training finetuning data presenting a competing motivation completely erases AMT's effects.
- Rules must be explicitly demonstrated in either midtraining or post-training datasets to be robustly learned; AMT alone does not induce generalization to unshown rules.
- The authors conclude there is currently insufficient public evidence that midtraining solves the core challenges of aligning frontier AI systems.

**Why it matters:** The findings challenge the reliance on alignment midtraining as a reliable mechanism for out-of-distribution alignment generalization in frontier models.

**arXiv cs.LG** · 2026-09-17 · `arXiv:2609.20794v1`

PosteriorBench is a new benchmark for evaluating the distributional accuracy and uncertainty quantification of generative inverse solvers using high-fidelity MCMC and rejection sampling reference posteriors across four physics-based problems.

- Evaluates four physics-based inverse problems: Darcy flow inversion, Poisson source recovery, carbon capture and storage, and light transport material inference.

- Formalizes a connection between Q-learning collusion and Simple Penal Codes (SPCs), proving non-trivial SPCs induce conditional policy dependence measurable via total variation (TV) distance across cooperation and defection histories.

### [QUALS: Corpus Equilibrium for Universal Forecasting via Pattern Quantization and Learnability Synchronization](https://arxiv.org/abs/2609.20156v1)

**arXiv cs.AI** · 2026-09-17 · `arXiv:2609.20156v1`

QUALS is a time series corpus equilibrium framework that uses pattern quantization and learnability synchronization to dramatically improve foundation model zero-shot forecasting efficiency on reduced training data.

- Addresses inefficient data sampling and distribution management in foundation model pre-training across diverse domain datasets.
- Employs a pattern quantization framework that decodes heterogeneous temporal patterns using vector quantization and uniform binning.
- Uses a learnability synchronization framework to calibrate sampling weights across heterogeneous patterns, reducing the optimization gap between simple and complex motifs.
- Achieves superior zero-shot forecasting performance while using only a small fraction of the original pre-training budget.

**Why it matters:** It enables foundation models for time series forecasting to achieve higher zero-shot accuracy while drastically lowering the computational costs and data volume required for pre-training.

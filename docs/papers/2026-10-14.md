### [Urbex: Agentic Spatial Grounding for City-Scale 3D Scenes](https://arxiv.org/abs/2610.18356)

**Hugging Face Daily Papers** · 2026-10-12 · 👍 101 · ⭐ 3 · `arXiv:2610.18356`

Urbex is an agentic vision-language framework that replaces candidate ranking with active spatial search for candidate-free 3D grounding in city-scale scenes.

- Casts 3D grounding as an interactive spatial search within a multi-view environment, allowing VLM agents to query landmarks, adjust zoom, render oblique views, and output bounding boxes.

**Why it matters:** By eliminating precomputed candidate proposals, Urbex improves both speed and generalization for large-scale outdoor 3D visual grounding.

### [Jeva: System One Models from First Principles](https://arxiv.org/abs/2610.18773)

**Hugging Face Daily Papers** · 2026-10-12 · 👍 90 · ⭐ 18 · `arXiv:2610.18773`

Jeva is a decision-native System 1 model architecture that processes options independently via a shared encoder and compact decision stack to achieve permutation invariance, scalable candidate sets, cross-request caching, and explicit null detection.

- Addresses four structural requirements: null-awareness, permutation invariance, option scalability, and reusable cross-request caching.
- Uses a shared encoder to independently represent the request and candidates, allowing a compact decision stack to refine the request state against immutable option memory.
- Employs symmetric aggregation for permutation-equivariant probabilities and a separate coverage estimate to differentiate answer absence from candidate competition.
- Unifies Choice, Noul, and Score outputs while scaling to thousands of candidates with zero decision flips under tested option permutations.

**Why it matters:** It replaces text serialization in decision tasks with a native architecture that significantly reduces latency via option reuse and improves reliability through guaranteed permutation invariance and robust null detection.

### [Self-Distillation with Verbal Regularization](https://arxiv.org/abs/2610.16354)

**Hugging Face Daily Papers** · 2026-10-11 · 👍 19 · ⭐ 3 · `arXiv:2610.16354`

Self-Distillation with Verbal Regularization (VRSD) uses system prompts to mitigate teacher shortcuts and entropy drops caused by privileged information during on-policy self-distillation.

- On-policy self-distillation (OPSD) uses a teacher model conditioned on privileged information (PI), such as verified solutions, to supervise an unprivileged student model via next-token distributions.
- Unregulated PI causes the teacher to rely on shortcut reasoning and suffer a sharp drop in output distribution entropy, leading to premature commitment.
- VRSD introduces system prompts that regulate the teacher's PI usage, theoretically modeled as attenuating PI's influence to preserve token entropy and encourage rethinking.
- Evaluated across three models and four tasks, VRSD outperformed OPSD in 11 of 12 settings, achieving an average Pass@1 gain of 3.9 percentage points while maintaining higher token entropy.

**Why it matters:** VRSD prevents premature optimization and shortcut reasoning in teacher models, leading to higher quality self-distillation supervision for complex reasoning tasks.

<small>Jiazheng Li, Yawei Li, Junru Lu, Zhenyi Shen, Di Yin, Lin Gui, Xing Sun, David Rügamer</small>

### [DoubtLess: Training-Free Contrastive Decoding for Efficient Reasoning](https://arxiv.org/abs/2610.18862v1)

**arXiv cs.AI** · 2026-10-13 · `arXiv:2610.18862v1`

DoubtLess is a training-free contrastive decoding method that uses a smaller reasoning model's logit differences, driven by brief versus verbose prompts, to shorten large model chains-of-thought without sacrificing accuracy.

- Uses a smaller reasoning model to evaluate the large model's current chain-of-thought (CoT) under both brief and verbose prompts.
- Calculates the logit difference between the small model's brief and verbose states, scales it, and adds it to the large model's logits at every CoT step.
- Reduces the CoT length of Qwen3-32B by 31% across seven benchmarks (competition math, graduate science, competitive programming) with unchanged accuracy.
- Decreases thinking tokens per turn by 20% in a self-debugging coding agent and successfully stacks with training-based compression techniques.
- Behavioral analysis indicates token savings primarily stem from reducing repeated checking after the correct answer first appears in the CoT.

**Why it matters:** It enables significant inference-cost and latency reductions for long chain-of-thought reasoning models without requiring expensive model retraining or suffering accuracy degradation.

<small>Minghao Luo, Liang Chen</small>

A training-free method, P2T, extracts token-level reward signals from process reward models using a first-order Taylor approximation requiring only one forward and backward pass.

- Estimates token influence by calculating the macroscopic reward change when substituting a token with a semantically null token.

- SPACE (Subspace Projection for Adapted Checkpoint Enhancement) selectively reverts SFT update components within the principal subspace of pre-SFT weights while preserving components in the orthogonal complement.
- The method is training-free and data-free, requiring only the pre-SFT and post-SFT model checkpoints.
- Evaluated on Qwen2.5, Qwen3, Qwen3.5, Llama-3.1, and Olmo-3 models (2B to 14B parameters) across math, coding, and medical SFT domains.
- Achieves average in-domain/out-of-domain gains of 2.85/2.26 points on Qwen2.5-7B and 2.41/1.52 points on Qwen3-14B-Base for math SFT.

**Why it matters:** It provides an efficient, training-free way to reduce out-of-domain performance degradation while simultaneously improving in-domain results after supervised fine-tuning.

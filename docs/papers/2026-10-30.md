### [Intrinsic Distribution Matching](https://arxiv.org/abs/2610.39633)

**Hugging Face Daily Papers** · 2026-10-28 · 👍 232 · ⭐ 2 · `arXiv:2610.39633`

Intrinsic Distribution Matching (IDM) enhances diffusion distillation by combining reverse-KL score matching with explicit moment constraints on feature means and standard deviations computed from the generator's EMA copy.

- Decomposes the reverse-KL vector field into a Gaussian moment component and a non-Gaussian residual to identify explicit statistics for constraints.
- Matches feature means and per-coordinate standard deviations using the generator's EMA copy, eliminating the need for an external feature encoder like DINOv2.
- Uses internal velocity branches to estimate score differences instead of relying on a separate fake-score network.
- Evaluated via full-parameter and LoRA tuning on Z-Image-Turbo 6B and Qwen-Image 20B models.

**Why it matters:** IDM achieves state-of-the-art text rendering performance on LongText-Bench at two network function evaluations without requiring auxiliary external encoders.

### [Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs](https://arxiv.org/abs/2610.36671)

**Hugging Face Daily Papers** · 2026-10-26 · 👍 76 · `arXiv:2610.36671`

LOWN is a training-free decoding method for Diffusion Vision-Language Models that reduces FLOPs by skipping visual token processing whenever image-free predictions match previous image-conditioned outputs.

- Analysis of LLaDA-V shows visual tokens account for 89-97% of inputs, but removing the image alters token unmasking at only 22.8% of decoding steps on average (and as few as 7.9%).
- LOWN predicts masked tokens without the image first, only reprocessing visual tokens when predictions disagree with the last image-conditioned state, using agreement to certify tokens for unmasking.
- LOWN adapts dynamically across benchmarks without manual threshold tuning, maintaining 99.6% of LLaDA-V's baseline accuracy while requiring only 35.3% of decoding FLOPs on average.
- The method generalizes across LLaDA-based DVLMs, integrates orthogonally with visual token pruning techniques, and supports key-value caching.

**Why it matters:** It drastically cuts inference computational overhead in diffusion VLMs without requiring model retraining, fine-tuning, or performance tradeoffs.

<small>Donghyeon Cho, Joowon Kim, Seungho Shin, Eunho Yang</small>

**Hugging Face Daily Papers** · 2026-10-28 · 👍 29 · ⭐ 13 · `arXiv:2610.40614`

L3G-World enables real-time 9 FPS infinite world generation using a Latent 3D Gaussian Memory that updates with scene extent rather than stream length.

- Latent 3D Gaussian Memory (L3G) stores VAE latent features directly on 3D Gaussians, allowing rendering straight into a Video Diffusion Transformer's (DiT) latent space without VAE re-encoding.
- The framework alternates autoregressively between a memory updater and a video DiT, spawning new Gaussians for unobserved areas while refining existing ones.

- Achieves performance improvements including up to 3.2x faster memory updates and 359x faster memory rendering over existing baselines.

### [Rethinking Neural Thickets Without Weight Perturbations](https://arxiv.org/abs/2610.40649v1)

**arXiv cs.AI** · 2026-10-29 · `arXiv:2610.40649v1`

Researchers debunk the Neural Thickets weight-geometry hypothesis, demonstrating that its gains stem from output diversity, validation-based selection, and voting, which can be matched using a training-free logit perturbation method called PSV.

- Perturbing a single decoder block recovers most performance gains, while adding random bias directly to output logits of a fully frozen model matches or exceeds full-weight perturbations on reasoning tasks.
- Formalized the Perturb-Select-Vote (PSV) framework, which generates perturbed predictors, selects top performers using a small validation set, and aggregates their predictions at inference time.
- First-order mathematical analysis reveals that small weight perturbations function primarily by inducing downstream logit shifts rather than accessing distinct weight-space experts.
- Applied logit PSV to computer vision, achieving substantial performance improvements under domain shifts (including Earth observation data) where full-weight perturbations offered minimal added benefit.

**Why it matters:** Logit PSV provides a simple, computation-light, training-free alternative to weight-perturbation ensembles across language and vision models without requiring model weight modifications.

<small>Nicolas Dufour, Elouan Gardès, Amil Dravid, Patrick Pérez, Loic Landrieu</small>

### [Latent Path Exploration via Potential-Guided Subtrajectory Balance](https://arxiv.org/abs/2610.40283v1)

**arXiv cs.LG** · 2026-10-29 · `arXiv:2610.40283v1`

SubLAT improves stochastic continuous latent reasoning in language models by coupling a relative answer potential with Subtrajectory Balance to guide intermediate transition paths.

- SubLAT introduces a relative answer potential to evaluate answer support of sampled intermediate latent states against replacement states using terminal correctness signals.
- Employs Subtrajectory Balance to relate potential differences across varying subtrajectory lengths to forward and backward transition densities.
- Trains models via joint optimization of answer supervision, Chain-of-Thought (CoT) supervision, and representation distillation.
- Demonstrates increased solution coverage with higher sampling budgets and improved performance on structural out-of-domain (OOD) arithmetic and deductive reasoning tasks.
- Trajectory analysis confirms progressive path divergence and higher mean relative potentials for correct reasoning paths.

**Why it matters:** It enables language models to effectively explore complex, multi-path reasoning spaces in continuous latent representations without producing explicit token traces.

<small>Xiaoling Zeng, Qi Zhang</small>

### [Elucidating the Design Space of LM Data Attribution](https://arxiv.org/abs/2610.40655v1)

**arXiv cs.CL** · 2026-10-29 · `arXiv:2610.40655v1`

The CATT benchmark isolates LM data attribution failures, revealing that negative log-odds gradients and top-token aggregation significantly improve attribution recall over standard document-averaging cross-entropy methods.

- Introduces the Controlled Attribution Benchmark (CATT), using fictitious knowledge fine-tuning to provide unambiguous ground-truth for systematically testing dataset properties like document redundancy and lexical distractors.
- Shows that true causal evidence in training documents is highly localized, and standard document-wide token score averaging dilutes this evidence into noise.
- Replaces standard cross-entropy loss gradients with negative log-odds gradients to isolate critical target tokens from uninformative ones.
- Aggregating only top-token scores increases ground truth recall by 35 to 72 percentage points across multiple baselines on CATT.
- Demonstrates transferability to FTRACE-TREX, improving counterfactual retraining performance across all tested attribution methods by up to 4.9x.

**Why it matters:** Simple changes to loss gradient formulation and token aggregation can dramatically improve the accuracy of tracing specific outputs back to training data without inventing new estimators.

<small>Steven Yu, Sheng-Yu Wang, Kimia Hamidieh, Antonio Torralba, David Bau</small>

### [Multi-View MoE: Letting Every Router Shape Expert Computation](https://arxiv.org/abs/2610.40577v1)

**arXiv cs.CL** · 2026-10-29 · `arXiv:2610.40577v1`

Multi-View MoE uses multiple independent routers to aggregate expert scores and dynamically mix latent input views for expert computation without increasing the active-expert budget.

- Multi-Router aggregates sigmoid scores from independently initialized routers to resolve weak agreement between single-router rankings and actual expert utility.
- Latent input views are mixed into each expert's input using the relative routing scores across the routers, allowing routing preferences to modulate computation.
- Each selected expert performs a single forward pass, keeping active-expert count, expert FLOPs, and all-to-all communication volume identical to standard MoE.
- Evaluated on a 24-layer 10B-A1B model (708B tokens), Multi-View MoE increased the nine-task downstream mean score by 1.18 percentage points over the baseline.
- Multi-Router alone improved downstream performance by 0.6 percentage points and increased global rank correlation between router scores and expert utility by 8.1%.

**Why it matters:** It improves MoE routing accuracy and downstream performance at zero additional FLOP or communication cost per active expert.

<small>Zelin Zhao, Tianchi Ma, Junyuan Shang, Shuohuan Wang, Dianhai Yu</small>

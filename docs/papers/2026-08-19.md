### [Learn What's Left, Not What's Mastered: Saturation Aware Advantage Reweighting for Multi-Reward Policy Optimization](https://arxiv.org/abs/2608.16072)

**Hugging Face Daily Papers** · 2026-08-16 · 👍 80 · `arXiv:2608.16072`

SA-MRPO replaces fixed scalarized rewards in multi-objective RL with independent per-objective standardization and dynamic saturation-based advantage reweighting.

- Existing fixed weighted-sum methods waste gradient budget on saturated rewards and give identical advantages to rollouts with distinct reward profiles.
- SA-MRPO standardizes each reward objective independently and dynamically discounts its advantage contribution based on batch-level objective saturation estimates.
- Dynamic reweighting can invert the direction of policy updates rather than simply rescaling magnitude.
- Empirically improves AIME24 accuracy by up to 5% over GDPO, adaptive reasoning accuracy by up to 9.2% on AMC23, and coding pass rates by up to 2.3% without degrading satisfied objectives.

**Why it matters:** It dynamically redirects model capacity toward unfulfilled objectives during post-training without requiring manual tuning of multi-reward weights or risking performance degradation on mastered tasks.

<small>Yixuan Wang, Yifei Chen, Haichao Zhang, Haozheng Luo, Xander Wu, Jie Ni, Yun Fu, Nuno Vasconcelos</small>

### [TRACE-Bench: Decomposing and Diagnosing Multi-Reference Image Generation](https://arxiv.org/abs/2608.16765)

**Hugging Face Daily Papers** · 2026-08-16 · 👍 9 · `arXiv:2608.16765`

TRACE-Bench introduces a capability-oriented framework for multi-reference image generation, decomposing complex tasks into four atomic operators across 1,600 evaluation cases to precisely locate model failure modes.

- Formalizes multi-reference image generation into four atomic operators: Anchor (f), Disentangle (g), Apply (oplus), and Compose (C).
- Quantifies structural complexity by counting operator slots (spanning slot counts 1--8) across 631 formula templates and ~4,000 reference images.
- Features an operator-aligned evaluation protocol and diagnostic tree analysis to recursively localize failures.

**Why it matters:** By shifting from holistic task scores to granular, operator-level diagnostics, TRACE-Bench reveals that multi-reference generation failures stem from attribute binding and disentanglement rather than overall composition.

### [Decomposition Attacks Across Unlinkable Identities: Limits of Stateful Defenses for LLM Services](https://arxiv.org/abs/2608.17445v1)

Researchers demonstrate that stateful defenses fail against LLM decomposition attacks executed across unlinkable identities, proving theoretical limits and achieving up to 100% attack success within two attempts across 10 tested defense policies.

- Decomposition attacks bypass stateless LLM guards by splitting harmful tasks into individually permissible requests across unlinkable identities and combining answers offline.
- Theoretical analysis proves that defense utility and security depend on benign request grouping; adaptive attacker retries using Allow/Block feedback eliminate valid defense operating points.

**Why it matters:** Stateful monitors alone cannot stop multi-identity decomposition attacks, necessitating structural mitigations like identity linkage, costs for fresh accounts, or restricted answer usage.

### [What Tokens are Learned when Tokenization is Optimized Jointly with Language Modeling?](https://arxiv.org/abs/2608.17325v1)

**arXiv cs.CL** · 2026-08-18 · `arXiv:2608.17325v1`

Jointly optimizing tokenization with language modeling alters token structures, with SSLMs learning morphologically aligned tokens and H-Nets favoring byte-level efficiency over traditional subword vocabularies.

- SSLMs recover morphologically aligned, contextually efficient tokens, while H-Nets prioritize byte-level efficiency by producing longer tokens with minimal subword vocabulary overlap.
- Tokenization behavior adapts dynamically based on language structure, with agglutinative languages showing higher segmentation variability during training across 18 typologically diverse languages.
- SSLM-based pretokenization in pretrained-then-finetuned BERT models consistently reduces language modeling perplexity and delivers competitive downstream performance despite using novel vocabularies.

**Why it matters:** Demonstrates that tokenizer-free, jointly optimized approaches effectively automate vocabulary creation by prioritizing contextual and computational efficiency over fixed morphological rules.

**arXiv cs.CL** · 2026-08-18 · `arXiv:2608.17288v1`

Q-Interference introduces a memory-efficient, phase-aware quantum-inspired attention mechanism for GPT models using an exact trigonometric factorization.

- Augments query and key features with an amplitude and a learned phase to enable constructive and destructive token feature interactions.
- Addresses the high memory cost of naive phase-aware attention by deriving an exact trigonometric factorization that reduces computation to two standard matrix multiplications.

- Integrates into standard Transformer blocks for autoregressive language modeling without modifying the rest of the model architecture or next-token prediction objective.

**Why it matters:** It enables richer, phase-aware feature interactions in Transformer attention mechanisms without increasing memory overhead or breaking compatibility with standard GPT pipelines.

### [On the Fragility of Self-Improving Agents: Variance, Task Order, and Underspecification](https://arxiv.org/abs/2608.18066v1)

**arXiv cs.AI** · 2026-08-18 · `arXiv:2608.18066v1`

A comprehensive re-evaluation reveals that memory-based self-improving agents suffer from extreme fragility due to amplified variance, sensitivity to task ordering, and task or environment underspecification.

- Self-improving loops amplify evaluation noise inherent to complex, multi-step agent environments across multiple runs.
- Agent performance improvements rely heavily on default task orderings, which implicitly act as a hidden curriculum prerequisite.
- Task and environment underspecification contribute to memory failure modes.
- Integrating detailed rubrics and environment feedback into memory construction partially mitigates performance degradation, but significant variance and performance gaps persist.

**Why it matters:** Evaluating self-improving agents requires multi-run protocols and randomized task orders to prevent false conclusions drawn from unstated curricula and environment noise.

<small>Qinyuan Ye, Yu Li, Yada Pruksachatkun, Jiaxin Zhang, Chien-Sheng Wu</small>

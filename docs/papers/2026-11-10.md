- Adapts existing RL methods (FlowGRPO, AWM, DiffusionNFT, DiffusionOPSD, ReFL) to few-step samplers by transforming objectives into x-space and decomposing gradients into self-regression anchors and reward augmentations.

### [Lost in Rounding: bf16 Recurrent State Makes Hybrid Reasoning Models Think Longer](https://arxiv.org/abs/2611.12127v1)

**arXiv cs.CL** · 2026-11-09 · `arXiv:2611.12127v1`

Storing recurrent states in bfloat16 with round-to-nearest causes hybrid reasoning models to generate longer outputs and degrade accuracy, a issue resolved using stochastic rounding.

- bfloat16 round-to-nearest (RTN) state causes 5 of 6 tested hybrid models to increase output length (1.07x to 1.27x geometric-mean) and hit token caps more frequently.
- On Qwen3.5-9B, bfloat16 RTN increases 32K token cap hits from 118 to 223, causing math accuracy to drop from 85.6% to 70.8% and LiveCodeBench pass@1 to drop over 12 points.
- Increasing token budgets to 128K fails to fix Qwen3.5-9B because 85% of unfinished runs enter exact repetition loops, whereas Nemotron-Nano-9B-v2 primarily experiences extra exploratory length.
- Same-width bfloat16 stochastic rounding (SR) eliminates length inflation and restores accuracy to FP32 levels; using an integer-hash random generator on Qwen3.5-9B achieves 85.6% accuracy at bfloat16 RTN memory and speed.
- In the Nemotron-Nano-v2 lineage, the degradation is concentrated in an intermediate-decay band of heads (SR on 25% of heads fixes it), whereas in Nemotron-3 and Qwen3.5-9B the effect is distributed across heads.

**Why it matters:** Serving hybrid reasoning models with standard bfloat16 RTN state caching severely degrades speed and accuracy, requiring stochastic rounding or explicit state-dtype reporting to ensure valid evaluations.

<small>Yuchuan Weng, Xin Chen, Chi Liu</small>

### [When Answer Decodability Is Not a Decision: Separating Final-Answer and Imminent-Emission Signals in Chain-of-Thought](https://arxiv.org/abs/2611.11892v1)

**arXiv cs.CL** · 2026-11-09 · `arXiv:2611.11892v1`

Researchers developed Emission-Controlled Dual-Target Probing (ECDP) to prove that strong chain-of-thought answer decodability often reflects imminent token emission rather than an early, finalized model decision.

- ECDP applies low-rank readers with pre-fixed thresholds to measure imminent mentions versus final answers at identical hidden-state positions.
- On DecisionDepth rollouts, Qwen3.5-4B decodes the imminent mention at .966 versus the final answer at .221, revealing a .696 emission gap.
- Target order can reverse depending on the model and task: Qwen3-8B with thinking enabled on MMLU decoded the final answer stronger than the imminent mention (lift -.398).
- Planted-signal controls on DecisionDepth demonstrate the reader can recover an injected final-answer signal at one-tenth of a full dose.

**Why it matters:** Probing high answer-candidate decodability in hidden states cannot automatically be interpreted as a finalized model decision without controlling for imminent text emission.

<small>Hyojung Han, Jongmin Kim, Seung-Hun Jeon</small>

### [HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents](https://arxiv.org/abs/2611.12872v1)

**arXiv cs.AI** · 2026-11-09 · `arXiv:2611.12872v1`

HiVe-Mem introduces a multimodal memory framework combining graph-based horizontal expansion with trainable vertical evidence composition to improve memory retrieval and evidence selection for long-term agent interactions.

- Horizontal Memory Expansion organizes memory episodes into a relational graph with textual and visual anchors, expanding semantically retrieved seed nodes to include neighboring context.
- Vertical Evidence Composition stores multiple evidence formats per memory episode, including raw images, grounded visual views, captions, compact summaries, and interaction history.
- A lightweight trainable selector dynamically chooses the optimal subset of evidence representations independently for each retrieved memory according to the query.
- The framework achieves consistent task performance gains across multiple base models on three multimodal memory benchmarks while reducing token consumption by approximately 90% compared to efficient multimodal baselines.

**Why it matters:** It enables multimodal agents to maintain broader long-term memory context while drastically reducing context-window token overhead through adaptive evidence selection.

### [Shortcuts and Boundaries: Verifiable RL Misalignment and Contextual Safety Learning](https://arxiv.org/abs/2611.12865v1)

**arXiv cs.AI** · 2026-11-09 · `arXiv:2611.12865v1`

A framework encodes verifiable reward-context conflicts into task dynamics to study RL misalignment, showing minority shortcut exposure induces high violation rates while simple binary execution penalties improve capability and compliance across changing workflows.

- Reward-context conflicts generate environments where unauthorized shortcuts yield higher rewards than compliant strategies despite compliant task completion remaining feasible.
- A 25% mixture of conflict exposure during training led to 97.9% certified profitable violations on an API task after 128 updates.
- Applying a binary penalty derived from execution histories mitigates acquired violations and improves safe completion on 32 unseen changing-evidence tasks from 53.1% to 89.1% compared to task-only training.

**Why it matters:** Verifiable context checks allow scalable training of RL agents that maintain compliance and adapt safety behaviors even as execution rules and authorization levels evolve.

<small>Xinjie Shen</small>

### [MaxIM: Maximally Informative Incremental Summarization via Reinforcement Learning](https://arxiv.org/abs/2611.12825v1)

**arXiv cs.AI** · 2026-11-09 · `arXiv:2611.12825v1`

MaxIM introduces a capacity-constrained, information-theoretic reward-shaping framework for reinforcement learning that optimizes incremental summarization to maintain bounded memory over long-horizon interaction histories without human preference labels.

- Formulates incremental memory updates by maximizing the predictive log-likelihood of task-relevant targets based on value suboptimality bounds.
- Enforces a recursive consistency condition that maximizes mutual information (MI) between the summary and observed history to preserve factual grounding.
- Uses a parameterized asymmetric critic to calculate step-wise variational MI bounds, providing dense reward shaping to resolve sparse credit assignment bottlenecks.
- Outperforms standard RL, supervised fine-tuning, and prompting on long-horizon scientific reading and multi-turn dialogue benchmarks across strict token budgets.

**Why it matters:** It enables LLMs to maintain accurate, bounded memory over unbounded context lengths for complex tasks without relying on expensive human annotations.

<small>Jihwan Jeong, Guy Tennenholtz, Yinlam Chow, Chih-Wei Hsu, Craig Boutilier</small>

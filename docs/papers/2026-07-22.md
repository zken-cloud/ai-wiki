**arXiv cs.AI** · 2026-07-22 · `arXiv:2607.20594v1`

This research identifies four findings on how weight-tied looped transformers implement algorithms, focusing on convergence selection in group word problems.

- Training budget dictates a linear computation frontier (v ~ n_train/T_train), with SGD selecting a frontier matching the minimum required by the training contract.

**arXiv cs.AI** · 2026-07-22 · `arXiv:2607.20214v1`

ELSAA is an efficient low-rank and sparse attention approximation that directly approximates the attention score operator, combining a sparse branch for high-similarity interactions and a low-rank branch for diffuse global interactions, with a denominator-aware fusion term.

GaugeQuant introduces a LogSumExp term to the loss during LLM training to break continuous symmetries, selecting a quantization-optimal basis that minimizes activation outliers without altering the language modeling objective.

**arXiv cs.LG** · 2026-07-22 · `arXiv:2607.20723v1`

LeakyLMs is the first work to demonstrate that proprietary model architecture and deployment details can be inferred from production language models using only per-token generation timing via remote APIs.

- LeakyLMs detects inference optimizations like speculative decoding and identifies the draft model's context length, e.g., Google Gemini Flash 2.5 uses speculative decoding with a 128K token draft context window.

**Why it matters:** This work demonstrates a novel vulnerability allowing inference of sensitive model and deployment details from black-box language model APIs, posing a risk to proprietary AI systems.
